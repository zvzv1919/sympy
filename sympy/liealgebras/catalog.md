# sympy/liealgebras -- Catalog

> Part of [SymPy](../catalog.md). Lie algebras and root systems for classical groups (A, B, C, D, E, F, G).

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package init; imports `CartanType` to make it the primary public entry point. |
| `cartan_type.py` | Defines `CartanType_generator` (the factory callable `CartanType`) that dispatches to series-specific classes based on letter and rank. Enforces rank constraints for exceptional types (E: 6–8, F: 4, G: 2) and classical types (non-negative) **inside the dispatcher itself** — if a rank is valid but outside the allowed range for its series (e.g., E5), the dispatcher silently returns `None` instead of raising an error. Also defines `Standard_Cartan`, the concrete base class for all Cartan types. |
| `cartan_matrix.py` | Provides the `CartanMatrix` convenience function that returns the Cartan matrix for a given Lie algebra type string. |
| `dynkin_diagram.py` | Provides the `DynkinDiagram` convenience function that returns the ASCII Dynkin diagram for a given Lie algebra type string. |
| `root_system.py` | Implements the `RootSystem` class representing the root system of a simple Lie algebra, with methods for simple roots, all roots, root addition, Cartan matrix, and Dynkin diagram delegation. `add_simple_roots(root1, root2)` performs index-bounds validation and raises `ValueError` if either root index exceeds the algebra's rank (i.e., exceeds the number of simple roots). Note: the `type_*.py` files define individual root vectors for each series but do NOT validate root-index bounds — that validation lives here in `RootSystem`. |
| `type_a.py` | `TypeA(Standard_Cartan)` -- series A (sl/su) Lie algebras: simple/positive roots, Cartan matrix, Dynkin diagram, and basis count for A_n. |
| `type_b.py` | `TypeB(Standard_Cartan)` -- series B (so, odd-dimensional) Lie algebras: root system data, Cartan matrix, and Dynkin diagram for B_n. The Dynkin diagram is a straight chain (no fork/branch) with a double bond at the last node. The Cartan matrix is built as a simple tridiagonal matrix with a special last-row entry (-2) for the short-root double bond. Contrast with `type_d.py` which handles the even-dimensional orthogonal family with a forked diagram. |
| `type_c.py` | `TypeC(Standard_Cartan)` -- series C (sp) Lie algebras: root system data, Cartan matrix, and Dynkin diagram for C_n. |
| `type_d.py` | `TypeD(Standard_Cartan)` -- series D (so, even-dimensional) Lie algebras: simple/positive root vectors, Cartan matrix, and branched/forked Dynkin diagram for D_n. The D-series is the orthogonal family whose Dynkin diagram has a fork at the end — the last two nodes both connect to the (n-3)th node instead of forming a straight chain. The `cartan_matrix()` method specially handles this branching topology by setting off-diagonal entries for both the (n-2)th and (n-1)th rows/columns to connect to node (n-3). Contrast with `type_b.py` which handles the odd-dimensional orthogonal family with a straight-chain diagram. Does NOT contain reflection matrices or Weyl group logic. |
| `type_e.py` | `TypeE(Standard_Cartan)` -- exceptional series E (E6, E7, E8): root system data (simple root vectors, positive root enumeration), Cartan matrix, and Dynkin diagram. Does NOT contain reflection matrices, Weyl group matrix representations, or sign-convention logic for generators — see `weyl_group.py` for those. `__new__` contains a secondary rank guard (`ValueError` if n < 6 or n > 8), but this is only reached if the dispatcher in `cartan_type.py` passes the rank through — for out-of-range ranks like E5, the dispatcher in `cartan_type.py` silently returns `None` before `TypeE` is ever instantiated (see `cartan_type.py`). The `positive_roots` method enumerates roots in two stages: ±e_i ± e_j integer roots via `basic_root`, then half-integer (±1/2) coordinate vectors with an even-parity sign constraint using nested binary loops that mutate a root list in-place. |
| `type_f.py` | `TypeF(Standard_Cartan)` -- exceptional Lie algebra F4 (4-dimensional): root system data including 4-dimensional half-integer roots, Cartan matrix, and Dynkin diagram. See `type_e.py` for 8-dimensional half-integer root enumeration in E6/E7/E8. |
| `type_g.py` | `TypeG(Standard_Cartan)` -- exceptional Lie algebra G2: root system data, Cartan matrix, and Dynkin diagram. |
| `weyl_group.py` | `WeylGroup` class for computing Weyl group properties: generating reflections, group order, element order, and Coxeter diagrams. Contains `matrix_form` which builds explicit 8×8 / n×n matrix representations of generating reflections with per-series branching (A, B, C, D, E, F, G) — each series has its own special-case matrix construction with distinct sign conventions per generator index. E-type: generator 1 uses a special 8×8 rational matrix with ±1/4 and ±3/4 entries; generator 2 swaps the first two coordinates with **negation** (−1 off-diagonal); generators 3+ swap adjacent coordinates with **positive** entries (+1 off-diagonal) — this sign difference is a key distinguishing feature. D-type last generator uses negations instead of transpositions. Also provides `coxeter_diagram` for ASCII undirected Coxeter graphs. Note: `type_e.py` defines root *vectors* for E6/E7/E8 but does NOT contain reflection matrices or sign-convention logic — that lives here. |
