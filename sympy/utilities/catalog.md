# sympy/utilities -- Catalog

> Part of [SymPy](../catalog.md). General utilities: iterables, decorators, code generation helpers, lambdify, memoization, testing.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package init that re-exports key public utilities such as `flatten`, `lambdify`, `source`, `threaded`, `test`, and `timed`. |
| `autowrap.py` | High-level module that compiles symbolic expressions into callable Python binaries via f2py, Cython, or numpy-ufunc backends. Contains `_validate_backend_language` and `_infer_language` for backend/language selection. The main `autowrap` function catches `CodeGenArgumentListError` from `make_routine` and recovers by appending missing `OutputArgument`s to the argument list and retrying—this is the only place incomplete-argument-list recovery occurs. `CythonCodeWrapper` generates `.pyx` Cython wrappers via `dump_pyx`; its `_partition_args` method categorizes routine arguments into four groups: `OutputArgument` → returns + locals, `InOutArgument` → returns + user args, `InputArgument` → user args only, plus inferred dimension parameters extracted from array shapes. `UfuncifyCodeWrapper` is the ufunc backend wrapper: its `wrap_code` method overrides the parent to support compiling multiple expressions into a single binary; `dump_c` generates C extension source for NumPy ufuncs. Also provides `binary_function` and `ufuncify`. |
| `benchmarking.py` | A py.test plugin for benchmark test collection and reporting: custom `Directory`/`Module` collectors scan for `bench_*` files and functions, a `Timer` subclass of `timeit.Timer` runs them, and `BenchSession` (a `TerminalSession` subclass) formats results in a table. Not a standalone timing utility. |
| `codegen.py` | Lower-level code generation: produces complete compilable source files in C, C++, Fortran, Julia, Rust, and Octave/Matlab from SymPy expressions. Defines `Routine`, `CodeGen`, `CCodeGen`, `FCodeGen`, `JuliaCodeGen`, `OctaveCodeGen`, `codegen`, and `make_routine`. `Routine.__init__` validates argument completeness and raises `CodeGenArgumentListError` when required arguments are missing, but performs no recovery or argument categorization—recovery is handled solely in `autowrap.py`. |
| `decorator.py` | Utility decorators including `threaded`/`xthreaded` (apply functions elementwise), `conserve_mpmath_dps`, `doctest_depends_on`, `public`, and `memoize_property`. |
| `enumerative.py` | Multiset partition enumeration and counting following Knuth's TAOCP algorithm 7.1.2.5M. `MultisetPartitionTraverser` enumerates partitions and provides `count_partitions`, which uses dynamic-programming memoization with a persistent cross-call cache for efficient tallying. |
| `exceptions.py` | Defines `SymPyDeprecationWarning`, a structured deprecation warning class that includes version, issue tracker link, and migration guidance. |
| `iterables.py` | Extensive collection of iterable utilities: `flatten`, `group`, `subsets`, `variations`, `topological_sort`, `sift`, `ordered`, integer `partitions`, `multiset_partitions` (high-level dispatcher that handles special cases like all-identical elements by reducing to integer partitions, delegates general multiset cases to enumerative.py), and many more combinatorial helpers for sequences and sets. |
| `lambdify.py` | Converts SymPy expressions into fast numerical lambda functions targeting math, mpmath, NumPy, TensorFlow, and other numeric backends. |
| `magic.py` | Contains the `pollute` function that injects name-object mappings into a caller's global namespace via frame introspection. |
| `memoization.py` | Memoization decorators for recurrence-defined sequences (`recurrence_memo`) and associated sequences (`assoc_recurrence_memo`). |
| `misc.py` | Miscellaneous helpers including `filldedent` (text formatting), `rawlines` (pasteable string repr), `translate`, `replace`, `find_executable`, and the `Undecidable` exception. |
| `pkgdata.py` | Provides `get_resource` for acquiring data files from a package, supporting both filesystem and custom `__loader__` access. |
| `pytest.py` | Compatibility layer for py.test functionality (`raises`, `skip`, `XFAIL`, `slow`) that works both with and without py.test installed. The `raises` function dispatches on its second argument: `None` returns a `RaisesContext` context manager, a callable is invoked directly, a string raises `TypeError` with a migration message (the old string-eval API has been phased out), and any other type raises `TypeError`. The `XFAIL` decorator wraps test functions: if the function raises an exception whose message is 'Timeout', it converts it to a `Skipped` exception instead of marking it as expected failure (`XFail`); other exceptions become `XFail`, and no exception becomes `XPass`. |
| `randtest.py` | Helpers for randomized testing: `random_complex_number`, `verify_numerically` (compare expressions at random points), `test_derivative_numerically`, and deterministic generator factories `_randrange`/`_randint` that accept a seed (None for random, int for seeded, or a list of predetermined values—list-seeded generators silently skip values outside the caller's requested interval via recursion). |
| `runtests.py` | SymPy's built-in test runner framework, compatible with py.test but requiring no external dependencies. Supports doctest, test-execution time limits, and split-based parallelism. Includes `convert_to_native_paths` which converts forward-slash-delimited paths to OS-native separators and fixes a Windows edge case where `os.path.join` drops the backslash after a drive-letter colon. `SymPyDocTests.get_test_files` collects source files for inline documentation testing by walking directories, filtering by glob pattern, and checking importability—it determines whether a file is an importable package member by looking for `__init__.py` in the file's immediate parent directory only (a known limitation). `SymPyDocTests._process_dependencies` checks external requirements before running a doctest. Also includes `SymPyDocTestRunner` (subclass of stdlib's `DocTestRunner`), `SymPyDocTestFinder` for recursive doctest discovery, `SymPyOutputChecker` for approximate floating-point comparison, and `_enhance_asserts`, an AST-based assertion rewriter that transforms comparison-based `assert` statements into richer diagnostics (temporary variables + formatted message) but returns non-comparison asserts (e.g., bare booleans or function calls) unchanged. |
| `source.py` | Interactive source inspection utilities: `source` (print an object's source code), `get_class`, and `get_mod_func` (resolve dotted class paths). |
| `timeutils.py` | Standalone adaptive execution timing (no py.test needed). `timed` auto-scales the number of iterations until the measurement is reliable, picks the best display unit (s/ms/μs/ns) via `log10` of the per-call time, and guards against math domain error when time is exactly zero by defaulting to nanoseconds (order 3). Also provides `timethis`, a decorator for recursive-call timing instrumentation using a global time stack. |
| `mathml/__init__.py` | MathML utilities for transforming MathML content markup into MathML presentation markup using XSL transforms (requires lxml). |
