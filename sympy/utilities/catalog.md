# sympy/utilities -- Catalog

> Part of [SymPy](../catalog.md). General utilities: iterables, decorators, code generation helpers, lambdify, memoization, testing.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package init that re-exports key public utilities such as `flatten`, `lambdify`, `source`, `threaded`, `test`, and `timed`. |
| `autowrap.py` | Compiles generated code (C/Fortran) and wraps the resulting binaries for use in Python via backends like f2py, Cython, and numpy. Key entry points: `autowrap` (compile & wrap a single expression), `binary_function` (return a SymPy Function backed by compiled code), and `ufuncify` (create actual `numpy.ufunc` instances with ndimensional broadcasting). The numpy backend enforces numpy's compile-time argument limit (NPY_MAXARGS = 32) on the combined count of inputs and outputs. See also `lambdify.py` which converts expressions to pure-Python lambda functions without compilation. |
| `benchmarking.py` | Provides a py.test-based benchmarking framework with custom Timer, Function, and TerminalSession classes for timing SymPy functions. |
| `codegen.py` | Generates complete compilable routines in C, C++, Fortran, Julia, Rust, and Octave/Matlab from SymPy expressions. |
| `decorator.py` | Utility decorators including `threaded`/`xthreaded` (apply functions elementwise), `conserve_mpmath_dps`, `doctest_depends_on`, `public`, and `memoize_property`. |
| `enumerative.py` | Algorithms for enumerative combinatorics, primarily multiset partition enumeration following Knuth's TAOCP algorithm 7.1.2.5M. Contains `MultisetPartitionTraverser` — a stateful class that walks the partition tree using an internal stack (`pstack`) with methods like `spread_part_multiplicity` (distributes remaining multiplicities into new partition segments, skipping zero-availability components), `decrement_part`, `enum_all`, `enum_small`, and `enum_large`. Also provides the standalone generator `multiset_partitions_taocp`. Note: for higher-level multiset partition helpers (e.g., `multiset_partitions`), see `iterables.py`. |
| `exceptions.py` | Defines `SymPyDeprecationWarning`, a structured deprecation warning class that includes version, issue tracker link, and migration guidance. |
| `iterables.py` | Extensive collection of iterable utilities: `flatten`, `group`, `subsets`, `variations`, `partitions`, `multiset_partitions` (high-level dispatch interface that inspects the input and routes to specialized algorithms — integer input → set partitions via `_set_partitions`; all-identical elements → reduces to integer partitioning via `partitions`; mixed elements → delegates to `MultisetPartitionTraverser` from `enumerative.py`), `topological_sort`, `sift`, `ordered`, and many more combinatorial helpers. The special-case dispatch and optimization logic for multiset partitions lives here, not in `enumerative.py`. For the low-level multiset partition traversal algorithm and internal stack-based enumeration, see `enumerative.py`. |
| `lambdify.py` | Converts SymPy expressions into fast numerical lambda functions (pure Python, no compilation) targeting math, mpmath, NumPy, TensorFlow, and other numeric backends. For compiled binary ufuncs with numpy broadcasting, see `autowrap.py`. |
| `magic.py` | Contains the `pollute` function that injects name-object mappings into a caller's global namespace via frame introspection. |
| `memoization.py` | Memoization decorators for recurrence-defined sequences (`recurrence_memo`) and associated sequences (`assoc_recurrence_memo`). |
| `misc.py` | Miscellaneous helpers including `filldedent` (text formatting), `rawlines` (pasteable string repr), `translate`, `replace`, `find_executable`, and the `Undecidable` exception. |
| `pkgdata.py` | Provides `get_resource` for acquiring data files from a package, supporting both filesystem and custom `__loader__` access. |
| `pytest.py` | Compatibility layer for py.test functionality (`raises`, `skip`, `XFAIL`, `slow`) that works both with and without py.test installed. When py.test is absent, provides its own fallback implementations: `raises` (callable/context-manager for exception assertions via `RaisesContext`), `XFAIL` decorator (marks expected failures — converts caught exceptions to `XFail`, but specially converts "Timeout" exceptions to `Skipped`), `XFail`/`XPass`/`Skipped` exception classes, and `skip`/`SKIP`/`slow` decorators. Note: the test *runner* that executes tests and manages process-level timeouts lives in `runtests.py`. |
| `randtest.py` | Helpers for randomized testing: `random_complex_number`, `verify_numerically` (compare expressions at random points), and `test_derivative_numerically`. |
| `runtests.py` | SymPy's built-in test runner framework, compatible with py.test but requiring no external dependencies. Supports doctest, split-based parallelism, and process-level timeout handling. Handles test discovery, execution, and reporting — but test *decorators* (`XFAIL`, `slow`, `raises`, etc.) and their exception-handling logic live in `pytest.py`. |
| `source.py` | Interactive source inspection utilities: `source` (print an object's source code), `get_class` (dynamically resolves a fully-qualified dotted string path like `'package.module.ClassName'` into a live object by splitting the path via `get_mod_func`, calling `__import__` on the module portion, then using `getattr` to retrieve the named attribute — raises `AttributeError` if the resolved attribute is not callable), and `get_mod_func` (splits a dotted path at the last dot into module path and class/function name). |
| `timeutils.py` | Simple adaptive timing tools (`timed`) for measuring function execution time, plus recursive timing instrumentation via `timethis`. |
| `mathml/__init__.py` | MathML utilities for transforming MathML content markup into MathML presentation markup using XSL transforms (requires lxml). |
