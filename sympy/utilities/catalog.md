# sympy/utilities -- Catalog

> Part of [SymPy](../catalog.md). General utilities: iterables, decorators, code generation helpers, lambdify, memoization, testing.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package init that re-exports key public utilities such as `flatten`, `lambdify`, `source`, `threaded`, `test`, and `timed`. |
| `autowrap.py` | High-level module that compiles symbolic expressions into callable Python binaries via f2py, Cython, or numpy-ufunc backends. Maintains backend→language validation and inference. The main `autowrap` function handles error recovery when the user-supplied argument list is incomplete. `UfuncifyCodeWrapper` is the ufunc backend wrapper: its `wrap_code` method overrides the parent `CodeWrapper.wrap_code` to support compiling multiple expressions into a single binary—since the function name cannot equal the first routine's name for multi-expression cases, it generates a unique exported function name via `'wrapped_' + str(id(routines) + id(helpers))`; manages temp directories, compilation, import, and cleanup. `dump_c` generates C extension source for NumPy ufuncs with multi-routine support. Also provides `binary_function` and `ufuncify`. |
| `benchmarking.py` | Provides a py.test-based benchmarking framework with custom Timer, Function, and TerminalSession classes for timing SymPy functions. |
| `codegen.py` | Lower-level code generation: produces complete compilable source files in C, C++, Fortran, Julia, Rust, and Octave/Matlab from SymPy expressions. Defines `Routine`, `CodeGen`, `CCodeGen`, `FCodeGen`, `JuliaCodeGen`, `OctaveCodeGen`, `codegen`, and `make_routine`. Raises `CodeGenArgumentListError` when required arguments are missing, but does not itself recover—callers (e.g. autowrap) handle recovery. |
| `decorator.py` | Utility decorators including `threaded`/`xthreaded` (apply functions elementwise), `conserve_mpmath_dps`, `doctest_depends_on`, `public`, and `memoize_property`. |
| `enumerative.py` | Multiset partition enumeration and counting following Knuth's TAOCP algorithm 7.1.2.5M. `MultisetPartitionTraverser` enumerates partitions and provides `count_partitions`, which uses dynamic-programming memoization with a persistent cross-call cache for efficient tallying. |
| `exceptions.py` | Defines `SymPyDeprecationWarning`, a structured deprecation warning class that includes version, issue tracker link, and migration guidance. |
| `iterables.py` | Extensive collection of iterable utilities: `flatten`, `group`, `subsets`, `variations`, `topological_sort`, `sift`, `ordered`, integer `partitions`, `multiset_partitions` (high-level dispatcher that handles special cases like all-identical elements by reducing to integer partitions, delegates general multiset cases to enumerative.py), and many more combinatorial helpers for sequences and sets. |
| `lambdify.py` | Converts SymPy expressions into fast numerical lambda functions targeting math, mpmath, NumPy, TensorFlow, and other numeric backends. |
| `magic.py` | Contains the `pollute` function that injects name-object mappings into a caller's global namespace via frame introspection. |
| `memoization.py` | Memoization decorators for recurrence-defined sequences (`recurrence_memo`) and associated sequences (`assoc_recurrence_memo`). |
| `misc.py` | Miscellaneous helpers including `filldedent` (text formatting), `rawlines` (pasteable string repr), `translate`, `replace`, `find_executable`, and the `Undecidable` exception. |
| `pkgdata.py` | Provides `get_resource` for acquiring data files from a package, supporting both filesystem and custom `__loader__` access. |
| `pytest.py` | Compatibility layer for py.test functionality (`raises`, `skip`, `XFAIL`, `slow`) that works both with and without py.test installed. The `XFAIL` decorator wraps test functions: if the function raises an exception whose message is 'Timeout', it converts it to a `Skipped` exception instead of marking it as expected failure (`XFail`); other exceptions become `XFail`, and no exception becomes `XPass`. Also defines `RaisesContext` for context-manager-based exception checking. |
| `randtest.py` | Helpers for randomized testing: `random_complex_number`, `verify_numerically` (compare expressions at random points), and `test_derivative_numerically`. |
| `runtests.py` | SymPy's built-in test runner framework, compatible with py.test but requiring no external dependencies. Supports doctest, test-execution time limits, and split-based parallelism. `SymPyDocTests.get_test_files` collects source files for inline documentation testing by walking directories, filtering by glob pattern, and checking importability—it determines whether a file is an importable package member by looking for `__init__.py` in the file's immediate parent directory only (a known limitation: it does not verify ancestor directories). `SymPyDocTests._process_dependencies` checks external requirements (executables, modules) before running a doctest example. Also includes `SymPyDocTestRunner`, a subclass of stdlib's `DocTestRunner` whose `run` method executes doctest cases (rebinds parent's name-mangled attributes to fix inheritance lookup), `SymPyDocTestFinder` for recursive doctest discovery with module-origin verification, `SymPyOutputChecker` for approximate floating-point comparison in doctest output, and an AST-based assertion rewriter. |
| `source.py` | Interactive source inspection utilities: `source` (print an object's source code), `get_class`, and `get_mod_func` (resolve dotted class paths). |
| `timeutils.py` | Simple adaptive timing tools (`timed`) for measuring function execution time, plus recursive timing instrumentation via `timethis`. |
| `mathml/__init__.py` | MathML utilities for transforming MathML content markup into MathML presentation markup using XSL transforms (requires lxml). |
