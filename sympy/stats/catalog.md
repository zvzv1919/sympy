# sympy/stats — Catalog

> Part of [SymPy](../catalog.md). Symbolic probability and statistics: random variables, distributions, and expectation.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package entry point and authoritative export manifest for the stats module. Assembles the complete public API by explicitly importing from submodules, organized by distribution category: finite distributions (from `frv_types`), continuous distributions (from `crv_types`), discrete countably-infinite distributions (from `drv_types`), query functions (from `rv_interface`), and symbolic probability classes (from `symbolic_probability`). The definitive source for which distribution families and functions are available at the top-level `sympy.stats` namespace. |
| `rv.py` | Core random variable framework and **value-computing** engine. Defines abstract types for random domains, probability spaces (`PSpace`), and random symbols. Contains the `Density` class and the actual implementations of `expectation`, `probability`, `density`, `cdf`, `given`, `where`, and `sample` that perform real computation producing concrete numeric/symbolic results (called by `rv_interface.py`). The `Density` class handles edge cases for deterministic (non-random) expressions: when the input expression contains no stochastic symbols, it returns a Dirac delta distribution centered at the expression's value, rather than delegating to any probability space. The `expectation` function is where mean values are actually evaluated: it handles conditional expectations by delegating through `given`, applies a **linearity-of-Add optimization** (when `expr.is_Add`, it decomposes the sum and recursively computes the expectation of each addend, returning actual computed values), and for atomic expressions delegates to `PSpace.integrate` for final evaluation. The `cdf` function is the top-level entry point for cumulative distribution computation: when a conditional constraint is supplied, it reduces the conditional case to the unconditional case by recursively calling itself after applying `given()` to transform the expression, then for unconditional cases delegates to the probability space's `compute_cdf`. The `given` function builds conditional random expressions by solving equality conditions or constructing conditional probability spaces. Contains the sampling engine (`sample_iter`) with lambdify-first, symbolic-fallback strategy. Does NOT contain variance/covariance logic — the user-facing variance/covariance functions are in `rv_interface.py`. |
| `rv_interface.py` | User-facing interface for **concrete evaluated** statistical computations. Provides callable functions `P`, `E`, `variance`, `std`, `skewness`, `covariance`, `correlation`, `moment`, `cmoment`, `smoment` that compute final numeric/symbolic values — these are plain functions (not symbolic expression classes) that return actual results. Key: `covariance(X, Y)` directly computes E((X-E(X))*(Y-E(Y))) by calling `expectation` twice for the means then once for the product — this is where the joint-tendency formula is actually evaluated. `correlation(X, Y)` (Pearson's correlation coefficient) computes `covariance(X,Y) / (std(X) * std(Y))` — the normalization divides by both standard deviations, with no guard against zero-variance (constant) inputs, so it can produce a division-by-zero. `variance` delegates to `cmoment(X, 2)` (central moment with n=2); `std` returns `sqrt(variance(...))`; `cmoment` and `moment` call `expectation` in `rv.py`. These functions produce computed values, not unevaluated symbolic wrappers. |
| `crv.py` | Continuous random variable infrastructure. Implements `ContinuousDomain`, `SingleContinuousDistribution`, `ContinuousPSpace`, and single/product continuous probability spaces with integration-based computation of densities, CDFs, a generic inverse-CDF method for drawing individual samples from a distribution, and expectation. Also implements `ConditionalContinuousDomain` whose `integrate` method is low-level integration infrastructure for conditional (restricted) domains — it adjusts how integrals are evaluated over constrained regions (equality constraints add Dirac deltas to the integrand, inequality constraints narrow integration intervals), but does NOT perform the top-level reduction of conditional queries to unconditional ones (that reduction happens in `rv.py`). `ContinuousPSpace.probability` computes likelihoods of conditions: for single-variable cases it integrates over the solved domain, and for multivariate cases it falls back to converting the problem into a univariate one by computing the density of (lhs − rhs) and constructing a new single-variable space. The `sample()` method here is only a generic fallback; most named distributions in `crv_types.py` override it with specialized implementations. |
| `crv_types.py` | Continuous distribution constructors — both prebuilt and custom. Contains the `ContinuousRV` factory function for creating custom continuous random variables from an arbitrary user-supplied probability measure expression and a specified support interval. Also provides constructors, PDF definitions (including piecewise PDFs with normalization constants), and distribution-specific method overrides for over 35 named distributions including: Normal, Exponential, Gamma, Beta, Uniform, Cauchy, Chi-squared, LogNormal, Pareto, QuadraticU (U-shaped bounded distribution), Triangular, Laplace, Rayleigh, Weibull, StudentT, FisherZ, Frechet, Nakagami, WignerSemicircle (semicircular density on [-R,R] proportional to sqrt(R²-x²)), and others. Each distribution class defines its own `pdf` method with type-specific density formulas and a `set` property specifying its support domain (the interval or region where the density is nonzero). Some distributions override `compute_cdf` and/or `expectation` to post-process results from the generic parent class integration — e.g., Uniform's `compute_cdf` calls the parent's generic CDF then substitutes Min/Max expressions with simplified boundary values to clean up symbolic artifacts. Questions about CDF simplification or expectation post-processing for a specific named distribution should look here for overrides, not in `crv.py`. Several distributions (e.g., LogNormal, Normal, Exponential, Beta, Gamma, Uniform, Pareto) also override the base class `sample()` method with specialized random-number generation using Python's `random` module instead of the generic inverse-CDF sampling. |
| `drv.py` | Discrete random variable infrastructure. Defines `SingleDiscreteDistribution` and `SingleDiscretePSpace` with summation-based CDF computation, inverse-CDF sampling, and expectation. `SingleDiscreteDistribution.expectation` computes expected values via summation of expr*pdf over the discrete set. `SingleDiscretePSpace.integrate` is the symbolic integration entry point for discrete spaces: it attempts to delegate to the distribution's `expectation` method, and if that raises any exception, falls back to constructing a raw unevaluated `Sum(expr * self.pdf, ...)` — a broad exception catch that silently degrades to a symbolic sum. Also provides `compute_cdf`, `compute_density`, and domain classes for discrete variables. |
| `drv_types.py` | Prebuilt discrete distribution types and their factory entry point. Contains the `rv` factory function that orchestrates discrete random variable construction: sympifies parameters, instantiates the distribution object, validates via `check` after instantiation, and wraps in a `SingleDiscretePSpace`. Provides constructors and PDF definitions for the Poisson and Geometric distributions. |
| `frv.py` | Finite discrete random variable infrastructure. Implements `FiniteDomain`, `FinitePSpace`, `FiniteDensity` (a dict-based density lookup), and related domain/space classes for random variables with a finite set of outcomes. Handles enumeration over finite sample spaces, conditional domains, and product spaces — but not individual distribution definitions or their PDF logic. |
| `frv_types.py` | Prebuilt finite distribution types — each distribution class defines its own `pdf` method with type-specific probability computation (e.g., DiscreteUniform computes equal probability 1/n for each of n outcomes and returns zero for values outside the outcome set; Die handles symbolic vs numeric arguments with KroneckerDelta sums; Binomial/Hypergeometric build full density dicts via combinatorial formulas). Provides constructors and distribution classes for Die, Coin, Bernoulli, Binomial, DiscreteUniform, Hypergeometric, Rademacher, and custom `FiniteRV`. This is where per-outcome probability mass is computed for finite distributions — not in `frv.py`. |
| `symbolic_probability.py` | Symbolic (unevaluated) probability expression containers for display and algebraic rewriting — these do NOT compute actual values. Defines `Probability`, `Expectation`, `Variance`, and `Covariance` as SymPy `Expr` subclasses whose `doit()` methods only perform **structural algebraic decomposition**, returning still-symbolic wrapper objects (e.g., `Expectation(X+Y).doit()` returns `Expectation(X) + Expectation(Y)`, NOT a computed number). `Variance.doit()` decomposes sum/product expressions into symbolic Variance/Covariance terms; `Covariance.doit()` expands bilinearity into pairwise symbolic Covariance terms. `Expectation.doit()` factors out deterministic multipliers and rewrites sums as separate unevaluated `Expectation` wrapper objects — this is purely a cosmetic rewrite, not a computational optimization; no integrals are evaluated and no numeric results are produced. The `Expectation` class also provides `_eval_rewrite_as_Probability` which converts a symbolic expected value into a weighted integral or sum over `Probability(Eq(rv, symbol))`. These classes are for symbolic manipulation and display; actual numeric/value computation of expectation is in `rv.py::expectation`, and covariance/variance value computation is in `rv_interface.py`. |
| `error_prop.py` | Arithmetic error propagation. Implements `variance_prop` to symbolically propagate variance through mathematical expressions using first-order Taylor expansion, optionally including covariance terms. |
