# sympy/stats — Catalog

> Part of [SymPy](../catalog.md). Symbolic probability and statistics: random variables, distributions, and expectation.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package entry point for the stats module. Re-exports all public symbols (distributions, query functions, symbolic probability classes) from submodules. |
| `rv.py` | Core random variable framework and **public API functions that perform actual computation** of statistical quantities. Defines the **base domain class hierarchy** for representing sample spaces: `RandomDomain` (abstract base with `__contains__` stub), `SingleDomain` (single-variable domain whose `__contains__` checks that the sample point has exactly one element, then verifies symbol identity and value membership), `ConditionalDomain` (abstract domain that merely **stores** an attached logical condition without processing it — the actual interpretation of And/Or conditions during integration happens in the concrete subclass `ConditionalContinuousDomain` in `crv.py`), and `ProductDomain` (Cartesian product of domains). These base classes define the containment/membership semantics that subclasses in `crv.py` and `frv.py` inherit or override. Also defines probability spaces (`PSpace`, `SinglePSpace`, `ProductPSpace`), random symbols, and fundamental operators like `probability`, `expectation`, `density`, `where`, `cdf`, and `sample`. The `cdf` function computes cumulative distributions: when a conditioning constraint is supplied, it reduces the problem to the unconditional case by calling `given()` to rewrite the expression, then recursively computes the unconditional CDF — it does **not** compute conditional CDFs directly. The `where` and `density` functions follow the same conditional→unconditional reduction pattern via `given()`. Contains the `Density` class whose `doit()` method dispatches density computation: for deterministic expressions (no random symbols) it returns a DiracDelta point-mass distribution, for single random variables it returns the underlying distribution directly, and for general expressions it delegates to the probability space's `compute_density`. Also contains boolean dependence/independence testing (`dependent`, `independent`, `pspace_independent`) that detects whether two stochastic expressions are statistically related by comparing conditional vs marginal densities. Includes helper utilities `rv_subs`, `NamedArgsMixin`, and `_value_check`. Unlike `symbolic_probability.py` (which holds unevaluated symbolic wrappers), this module contains the functions that **actually evaluate** probabilities, densities, and CDFs. |
| `rv_interface.py` | User-facing interface that wraps the core `rv` functions into convenient aliases (`P`, `E`, `variance`, `std`, `skewness`, `covariance`, `correlation`, `moment`, `cmoment`, `smoment`). These are the functions that **actually compute** numeric statistical measures — they contain the concrete formulas and arithmetic, not just symbolic wrappers. `variance` delegates to `cmoment(X, 2)`; `std` (standard_deviation) returns `sqrt(variance(…))`; `covariance` computes `E((X-E(X))*(Y-E(Y)))` via three expectation calls; `correlation` (Pearson coefficient) divides covariance by the product of standard deviations — this division is **unguarded**, so if either random variable is constant (zero spread / zero standard deviation), it produces a division-by-zero. `moment`, `cmoment`, `smoment` compute raw, central, and standardised moments respectively. Unlike `symbolic_probability.py` (which holds inert `Expr` subclasses for display/algebraic manipulation), this module performs the real arithmetic. For boolean dependence/independence testing (whether knowing one variable changes another's distribution), see `rv.py`. |
| `crv.py` | Continuous random variable infrastructure. Implements `ContinuousDomain`, `ContinuousPSpace`, and single/product/conditional continuous probability spaces with integration-based **actual computation** of densities, CDFs, and probabilities. Defines the concrete continuous domain subclasses (`SingleContinuousDomain`, `ProductContinuousDomain`, `ConditionalContinuousDomain`) that override the abstract base classes in `rv.py`. `ConditionalContinuousDomain.integrate` is where boolean conditions attached to a restricted domain are actually **processed during integration**: it walks the condition tree, handles conjunctions (And) by tightening integration limits, and explicitly raises `NotImplementedError` for disjunctive (Or) conditions — this is the code that determines how logical conditions on a continuous domain are resolved into concrete integral bounds. For the abstract base `ConditionalDomain` (which only stores the condition without processing it), see `rv.py`. `ContinuousPSpace.probability` computes the likelihood of a condition: it first attempts a univariate path via `where`; if that raises `NotImplementedError` (e.g. multivariate or complex conditions), it falls back by computing a density of the expression difference (lhs − rhs), wrapping it in a `ContinuousDistributionHandmade` if needed, creating a fresh `SingleContinuousPSpace`, and recursively computing the probability in that simpler univariate space. `SingleContinuousDistribution` provides inverse-CDF sampling: it symbolically inverts the cumulative distribution function via `solveset`, caches the result, and draws random realizations by evaluating the inverse at a uniform random value; raises `NotImplementedError` when symbolic inversion fails or yields multiple solutions. Also provides `compute_cdf` (integration of PDF from left bound), `compute_density` (marginalization or DiracDelta approach), and `expectation`. Unlike `symbolic_probability.py` (which holds unevaluated symbolic `Probability` expressions), this module performs the actual integration-based evaluation. |
| `crv_types.py` | Prebuilt continuous distribution types. Provides constructors and PDF definitions for over 35 named distributions (Normal, Exponential, Gamma, Beta, Uniform, Cauchy, Chi-squared, etc.). |
| `drv.py` | Discrete random variable infrastructure for distributions over infinite/countable supports (e.g. integers). Defines `SingleDiscreteDistribution` and `SingleDiscretePSpace` with summation-based CDF computation, inverse-CDF sampling, and expectation. |
| `drv_types.py` | Prebuilt discrete distribution types. Provides constructors and PDF definitions for the Poisson and Geometric distributions. |
| `frv.py` | Finite discrete random variable infrastructure. Implements `FiniteDomain` (subclass of `RandomDomain` from `rv.py`), `SingleFiniteDomain`, `ProductFiniteDomain`, `ConditionalFiniteDomain`, `FinitePSpace`, `SingleFinitePSpace`, `ProductFinitePSpace`, and related classes for random variables with a finite set of outcomes. `FiniteDomain.__contains__` simply checks element membership in its finite set (unlike the base `SingleDomain.__contains__` in `rv.py` which validates sample-point length and symbol identity). **`ConditionalFiniteDomain`** represents a finite domain restricted by a logical predicate (e.g. "die roll is even"). Its `__new__` constructor performs **foreign-symbol validation**: it checks that the condition's free symbols are a subset of the domain's free symbols, and raises a `ValueError` if the predicate references unknown variables not belonging to the original sample space — this prevents creating a constrained domain whose condition could never be evaluated through enumeration. Its `_test` method evaluates the condition on a single element via `xreplace`, with special handling for `Equality` objects, and `__iter__` filters the parent domain's elements through `_test`. This is the finite/discrete counterpart to `ConditionalContinuousDomain` in `crv.py` (which restricts continuous domains by tightening integration bounds); the finite version works by enumeration rather than integration. Also defines `SingleFiniteDistribution` with dict-based PMF lookup. Uses explicit enumeration for density, CDF (`compute_cdf`, `sorted_cdf`), probability, and conditional spaces. **`FinitePSpace.sample()`** is the runtime method that draws a random realization from a finite probability space: it builds a sorted CDF via `sorted_cdf`, draws a uniform random number, then iterates through CDF entries with a linear search to find where the random value falls below a cumulative probability — if no entry matches (which should be impossible for a valid distribution), it hits an `assert False` guard as an unreachable fallback. This is the code that actually executes random sampling for all finite RVs (Die, Coin, Bernoulli, etc.) — `frv_types.py` only defines the distribution constructors and PMFs, not sampling logic. For the abstract base domain classes and their containment semantics, see `rv.py`. See `drv.py` for infinite-support discrete variables. |
| `frv_types.py` | Prebuilt finite distribution types. Provides constructors and PMF definitions for Die, Coin, Bernoulli, Binomial, DiscreteUniform, Hypergeometric, Rademacher, and custom `FiniteRV`. These classes only define the probability mass functions (outcome-to-probability mappings); runtime operations like sampling, CDF computation, and probability evaluation are handled by the probability space classes in `frv.py`. |
| `symbolic_probability.py` | Symbolic (unevaluated) probability expression **wrappers** — these are inert `Expr` subclasses (`Probability`, `Expectation`, `Variance`, `Covariance`) used for display and algebraic manipulation, **not** for actually computing numeric values like Pearson correlation coefficients or detecting division-by-zero edge cases. Their `_eval_rewrite_as_Integral`/`_eval_rewrite_as_Sum` methods merely delegate to the real computation functions in `rv.py`. `Variance.doit()` decomposes the variance of a sum of random variables into individual variance terms plus pairwise covariance terms (the bilinearity expansion), and factors out squared constants from products. This is the canonical place for symbolic variance/covariance decomposition of random-variable expressions. For actual probability/CDF/density computation logic (including fallback strategies and conditional→unconditional reduction), see `rv.py` and `crv.py`. See `error_prop.py` for approximate Taylor-based error propagation (a different mechanism). |
| `error_prop.py` | Approximate arithmetic error propagation via first-order Taylor expansion. Implements `variance_prop` to propagate variance through general mathematical expressions (Add, Mul, Pow, exp) using partial derivatives, optionally including covariance terms. Unlike `symbolic_probability.py` (which performs exact symbolic expansion of `Variance`/`Covariance` for sums of random variables), this module uses a linearisation approximation suitable for error-analysis workflows. |
