# sympy/stats — Catalog

> Part of [SymPy](../catalog.md). Symbolic probability and statistics: random variables, distributions, and expectation.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package entry point for the stats module. Re-exports all public symbols (distributions, query functions, symbolic probability classes) from submodules. |
| `rv.py` | Core random variable framework and computational engine. Defines abstract types for random domains, probability spaces (`PSpace`), and random symbols. Contains the `Density` class and the actual implementations of `expectation`, `probability`, `density`, `cdf`, `given`, `where`, and `sample` that perform real computation. The `Density.doit()` method handles edge cases before delegating to probability spaces: deterministic expressions (containing no random symbols) short-circuit to a DiracDelta point mass, and single random symbols return their distribution directly. The `cdf` function handles conditional CDF requests by first transforming the expression via `given()` then recursing, and delegates unconditional CDF computation to the probability space's `compute_cdf` method. The `given` function builds conditional random expressions: it handles equality conditions by solving for the random variable (using `solveset`, including extracting results from `Intersection` sets containing `S.Reals`), and constructs conditional probability spaces for more complex conditions. Also includes efficiency optimizations such as exploiting linearity of expectation (distributing over sums), Monte Carlo sampling dispatch, and delegating to `PSpace.integrate` for evaluation. Distribution-specific CDF formulas, PDF formulas, and CDF inversion live in the type-specific modules (`crv.py`, `drv.py`, `frv.py`), not here. |
| `rv_interface.py` | User-facing interface for concrete (evaluated) statistical computations. Provides callable functions `P`, `E`, `variance`, `std`, `skewness`, `covariance`, `correlation`, `moment`, `cmoment`, `smoment` that perform runtime numeric/symbolic evaluation by delegating to `rv.py`'s `expectation`/`probability` engine. These are plain functions that compute final values, not symbolic expression classes. |
| `crv.py` | Continuous random variable infrastructure. Implements `ContinuousDomain`, `SingleContinuousDistribution`, `ContinuousPSpace`, and single/product continuous probability spaces with integration-based computation of densities, CDFs, a fallback inverse-CDF sampling method, and expectation. Also implements `ConditionalContinuousDomain` whose `integrate` method handles conditional (restricted) domains: equality constraints are incorporated by multiplying a Dirac delta into the integrand (modifying the integrand, not the bounds), while inequality constraints narrow the integration intervals. `ContinuousPSpace.probability` computes likelihoods of conditions: for single-variable cases it integrates over the solved domain, and for multivariate cases it falls back to converting the problem into a univariate one by computing the density of (lhs − rhs) and constructing a new single-variable space. The `sample()` method here is only a generic fallback; most named distributions in `crv_types.py` override it with specialized implementations. |
| `crv_types.py` | Continuous distribution constructors — both prebuilt and custom. Contains the `ContinuousRV` factory function for creating custom continuous random variables from an arbitrary user-supplied probability measure expression and a specified support interval. Also provides constructors, PDF definitions (including piecewise PDFs with normalization constants), and distribution-specific method overrides for over 35 named distributions including: Normal, Exponential, Gamma, Beta, Uniform, Cauchy, Chi-squared, LogNormal, Pareto, QuadraticU (U-shaped bounded distribution), Triangular, Laplace, Rayleigh, Weibull, StudentT, FisherZ, Frechet, Nakagami, WignerSemicircle (semicircular density on [-R,R] proportional to sqrt(R²-x²)), and others. Each distribution class defines its own `pdf` method with type-specific density formulas and a `set` property specifying its support domain (the interval or region where the density is nonzero). Several distributions (e.g., LogNormal, Normal, Exponential, Beta, Gamma, Uniform, Pareto) override the base class `sample()` method with specialized random-number generation using Python's `random` module (e.g., `lognormvariate`, `gauss`, `expovariate`) instead of the generic inverse-CDF sampling. Questions about how a specific distribution generates random realizations or samples should look here for the override. |
| `drv.py` | Discrete random variable infrastructure. Defines `SingleDiscreteDistribution` and `SingleDiscretePSpace` with summation-based CDF computation, sampling, and expectation. |
| `drv_types.py` | Prebuilt discrete distribution types and their factory entry point. Contains the `rv` factory function that orchestrates discrete random variable construction: sympifies parameters, instantiates the distribution object, validates via `check` after instantiation, and wraps in a `SingleDiscretePSpace`. Provides constructors and PDF definitions for the Poisson and Geometric distributions. |
| `frv.py` | Finite discrete random variable infrastructure. Implements `FiniteDomain`, `FinitePSpace`, `FiniteDensity` (a dict-based density lookup), and related domain/space classes for random variables with a finite set of outcomes. Handles enumeration over finite sample spaces, conditional domains, and product spaces — but not individual distribution definitions or their PDF logic. |
| `frv_types.py` | Prebuilt finite distribution types. Each distribution class implements its own `pdf` method with type-specific logic (e.g., handling symbolic vs numeric arguments, branching on input type). Provides constructors and distribution classes for Die, Coin, Bernoulli, Binomial, DiscreteUniform, Hypergeometric, Rademacher, and custom `FiniteRV`. |
| `symbolic_probability.py` | Symbolic (unevaluated) probability expression containers for display and algebraic manipulation. Defines `Probability`, `Expectation`, `Variance`, and `Covariance` as SymPy `Expr` subclasses used for symbolic rewriting (e.g., to integrals/sums, `expand`) and algebraic expansion of linear combinations. Their `doit()` methods apply algebraic decomposition rules (e.g., bilinear expansion of covariance into pairwise terms, sum decomposition of variance) and handle structural edge cases such as detecting whether arguments contain random symbols — deterministic (non-random) arguments cause immediate short-circuit returns (e.g., zero for covariance/variance of constants). These classes do not perform numeric/symbolic evaluation of expectations — that computation is done by the callable functions in `rv_interface.py` and `rv.py`. |
| `error_prop.py` | Arithmetic error propagation. Implements `variance_prop` to symbolically propagate variance through mathematical expressions using first-order Taylor expansion, optionally including covariance terms. |
