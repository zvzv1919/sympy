# sympy/stats — Catalog

> Part of [SymPy](../catalog.md). Symbolic probability and statistics: random variables, distributions, and expectation.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package entry point for the stats module. Re-exports all public symbols (distributions, query functions, symbolic probability classes) from submodules. |
| `rv.py` | Core random variable framework and computational engine. Defines abstract types for random domains, probability spaces (`PSpace`), and random symbols. Contains the actual implementations of `expectation`, `probability`, `density`, `given`, `where`, and `sample` that perform real computation. The `given` function builds conditional random expressions: it handles equality conditions by solving for the random variable (using `solveset`, including extracting results from `Intersection` sets containing `S.Reals`), and constructs conditional probability spaces for more complex conditions. Also includes efficiency optimizations such as exploiting linearity of expectation (distributing over sums), Monte Carlo sampling dispatch, and delegating to `PSpace.integrate` for evaluation. Does not contain distribution-specific CDF/PDF logic or CDF inversion — those live in the type-specific modules (`crv.py`, `drv.py`, `frv.py`). |
| `rv_interface.py` | User-facing interface that wraps the core `rv` functions into convenient aliases (`P`, `E`, `variance`, `std`, `skewness`, `covariance`, `correlation`, `moment`, `cmoment`, `smoment`). |
| `crv.py` | Continuous random variable infrastructure. Implements `ContinuousDomain`, `SingleContinuousDistribution`, `ContinuousPSpace`, and single/product continuous probability spaces with integration-based computation of densities, CDFs, a default inverse-CDF sampling method, and expectation. `ContinuousPSpace.probability` computes likelihoods of conditions: for single-variable cases it integrates over the solved domain, and for multivariate cases it falls back to converting the problem into a univariate one by computing the density of (lhs − rhs) and constructing a new single-variable space. Individual distributions in `crv_types.py` may override the default sampling. |
| `crv_types.py` | Prebuilt continuous distribution types. Provides constructors, PDF definitions, and distribution-specific method overrides for over 35 named distributions (Normal, Exponential, Gamma, Beta, Uniform, Cauchy, Chi-squared, LogNormal, etc.). Some distributions override the base class `sample()` method with specialized implementations (e.g., using Python's `random` module variants like `lognormvariate`) instead of the generic inverse-CDF sampling defined in `crv.py`. |
| `drv.py` | Discrete random variable infrastructure. Defines `SingleDiscreteDistribution` and `SingleDiscretePSpace` with summation-based CDF computation, sampling, and expectation. |
| `drv_types.py` | Prebuilt discrete distribution types. Provides constructors and PDF definitions for the Poisson and Geometric distributions. |
| `frv.py` | Finite discrete random variable infrastructure. Implements `FiniteDomain`, `FinitePSpace`, `FiniteDensity` (a dict-based density lookup), and related domain/space classes for random variables with a finite set of outcomes. Handles enumeration over finite sample spaces, conditional domains, and product spaces — but not individual distribution definitions or their PDF logic. |
| `frv_types.py` | Prebuilt finite distribution types. Each distribution class implements its own `pdf` method with type-specific logic (e.g., handling symbolic vs numeric arguments, branching on input type). Provides constructors and distribution classes for Die, Coin, Bernoulli, Binomial, DiscreteUniform, Hypergeometric, Rademacher, and custom `FiniteRV`. |
| `symbolic_probability.py` | Symbolic (unevaluated) probability expression containers. Defines `Probability`, `Expectation`, `Variance`, and `Covariance` as SymPy `Expr` subclasses for display and symbolic manipulation (e.g., rewriting to integrals/sums, `expand`). Contains rewrite methods (e.g., `_eval_rewrite_as_Probability`) that branch on probability space type (continuous, finite, discrete) with type-specific error handling — including the finite-space case. Their `doit()` methods implement algebraic expansion rules directly: `Variance.doit()` decomposes sums into individual variances plus pairwise covariances, and handles products by squaring deterministic factors and factoring them out (e.g., Var(aX) = a²·Var(X)); `Expectation.doit()` delegates to `rv.py` for final computation. |
| `error_prop.py` | Arithmetic error propagation. Implements `variance_prop` to symbolically propagate variance through mathematical expressions using first-order Taylor expansion, optionally including covariance terms. |
