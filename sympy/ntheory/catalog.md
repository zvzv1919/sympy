# sympy/ntheory — Catalog

> Part of [SymPy](../catalog.md). Number theory: primes, factorization, residues, continued fractions, and multiplicative functions.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package initializer that re-exports the public API from submodules (primes, factoring, residues, partitions, multinomials, continued fractions, Egyptian fractions). |
| `bbp_pi.py` | Implements the Bailey-Borwein-Plouffe (BBP) formula for computing hexadecimal digits of pi at an arbitrary starting position. |
| `continued_fraction.py` | Provides routines for periodic continued fraction expansion of quadratic irrationals, convergent computation, iterating over continued fraction terms, and reducing a continued fraction list back to a rational expression. |
| `egyptian_fraction.py` | Decomposes a positive rational number into a sum of distinct unit fractions (Egyptian fraction expansion) using selectable algorithms (Greedy, Graham-Jewett, Takenouchi, Golomb). |
| `factor_.py` | Intentional integer factorization and divisor-related functions including `factorint`, `divisors`, `totient`, Pollard rho/p-1 methods, smoothness analysis, perfect power detection, and multiplicative arithmetic functions (`divisor_sigma`, `primenu`, `primeomega`). Does not contain primality-test parameter selection or Lucas-test discriminant search — those are in `primetest.py`. |
| `generate.py` | Prime and composite number generation via a dynamically growing Sieve of Eratosthenes, plus helpers like `nextprime`, `prevprime`, `primerange`, `primepi`, `randprime`, `primorial`, `composite`, `compositepi`, and `cycle_length`. The global `sieve` object supports membership testing (`in` operator) with an even-number fast path that returns immediately without a full sieve lookup, as well as indexed access and binary-search-based bounding of primes. Note: membership/containment checks on the sieve are handled here, not in `primetest.py`. |
| `modular.py` | Solves systems of linear congruences using the Chinese Remainder Theorem (`crt`, `crt1`, `crt2`) and provides a general `solve_congruence` interface with symmetric residue support. When moduli are not pairwise coprime, `crt` detects an incorrect initial result via residual verification and falls back to `solve_congruence` as a more general solver; if even that fails, it returns None. Note: the CRT implementation and congruence-solving logic lives here, not in `residue_ntheory.py`. |
| `multinomial.py` | Computes binomial and multinomial coefficients, returning them as dictionaries or lists, with an efficient iterator variant for multinomial coefficients. |
| `partitions_.py` | Computes the integer partition function p(n) using the Hardy-Ramanujan-Rademacher series with mpmath arbitrary-precision arithmetic. |
| `primetest.py` | Primality testing routines including Miller-Rabin, Lucas probable-prime tests (standard, strong, extra-strong), a deterministic `isprime` dispatcher, and a fast perfect-square check. Also contains Lucas parameter-selection helpers (Selfridge method A and extra-strong variant) that search for a suitable discriminant D using Jacobi symbols and GCD checks — these may incidentally discover a non-trivial factor of n during the search loop, returning a sentinel `(0, 0, 0)` to signal compositeness. Note: `isprime` is a standalone boolean function — it is NOT the mechanism behind Python's `in` operator on the sieve object; membership/containment tests on the prime sieve (including the even-number shortcut) live in `generate.py`'s `Sieve.__contains__`. GCD-based factor discovery here is a side-effect of primality testing parameter selection, not intentional factorization (for that, see `factor_.py`). |
| `residue_ntheory.py` | Modular arithmetic functions: multiplicative order, primitive roots, quadratic and nth-power residues, square-root mod, Legendre symbol (`legendre_symbol`) and Jacobi symbol (`jacobi_symbol` — the multiplicative character generalizing quadratic-residue evaluation to composite odd moduli, with edge-case handling for zero arguments and modulus 1), Möbius function, and discrete logarithm algorithms (trial, baby-step giant-step, Pollard rho, Pohlig-Hellman). Note: the file is named `residue_ntheory.py`, not `residue.py`. |
