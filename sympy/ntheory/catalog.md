# sympy/ntheory — Catalog

> Part of [SymPy](../catalog.md). Number theory: primes, factorization, residues, continued fractions, and multiplicative functions.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package initializer that re-exports the public API from submodules (primes, factoring, residues, partitions, multinomials, continued fractions, Egyptian fractions). |
| `bbp_pi.py` | Implements the Bailey-Borwein-Plouffe (BBP) formula for computing hexadecimal digits of pi at an arbitrary starting position. |
| `continued_fraction.py` | Provides routines for periodic continued fraction expansion of quadratic irrationals, convergent computation, iterating over continued fraction terms, and reducing a continued fraction list back to a rational expression. |
| `egyptian_fraction.py` | Decomposes a positive rational number into a sum of distinct unit fractions (Egyptian fraction expansion) using selectable algorithms (Greedy, Graham-Jewett, Takenouchi, Golomb). |
| `factor_.py` | Integer factorization and divisor-related functions including `factorint`, `divisors`, `totient` (Euler phi), `reduced_totient` (Carmichael lambda — smallest exponent m>0 such that a^m ≡ 1 mod n for all a coprime to n, with special-case handling when prime factor 2 has multiplicity > 2), `multiplicity` (p-adic valuation), Pollard rho/p-1 factorization algorithms (self-contained implementations with random base selection, retry logic, and range restrictions on the random base to avoid degenerate gcd results), `core` (t-th power free part), `digits` (base decomposition — decomposes an integer into a list of its digits in a given base, encoding sign via a negated base marker as the first element for negative inputs), smoothness analysis, perfect power detection, divisor arithmetic functions (`divisor_sigma` — computes σ_k(n), the sum of the k-th powers of all positive divisors of n, using a product-of-geometric-series formula over the prime factorization with a fast path returning 1+n^k when n is prime; `divisor_count`; `primenu`, `primeomega`; `udivisor_sigma` — unitary divisor function), and antidivisor functions (`antidivisors` — numbers that don't divide n by the largest margin, with optional `generator` flag; `antidivisor_count`). |
| `generate.py` | Prime and composite number generation and lookup. Central `prime(nth)` function returns the nth prime (1-indexed) with a fast-path that returns directly from the cached sieve when the index is already covered, and a slower path that uses binary search with the logarithmic integral approximation for large indices. Dynamically growing Sieve of Eratosthenes that supports membership testing (containment check with short-circuit for even numbers), binary search lookup, indexed access, and range iteration over cached primes. Also provides `nextprime`, `prevprime`, `primerange`, `primepi` (prime counting function), `randprime`, `primorial`, `composite`, `compositepi`, and `cycle_length`. |
| `modular.py` | Solves systems of simultaneous linear congruences using the Chinese Remainder Theorem (`crt`, `crt1`, `crt2`) and provides a general `solve_congruence` interface. Includes `symmetric_residue` utility for mapping a residue into the symmetric range `[-m/2, m/2]`. Does NOT compute modular square roots (see `residue_ntheory.py`). |
| `multinomial.py` | Computes binomial and multinomial coefficients, returning them as dictionaries or lists, with an efficient iterator variant for multinomial coefficients. |
| `partitions_.py` | Computes the integer partition function p(n) using the Hardy-Ramanujan-Rademacher series with mpmath arbitrary-precision arithmetic. |
| `primetest.py` | Primality testing routines including Miller-Rabin, Lucas probable-prime tests (standard, strong, extra-strong), a deterministic `isprime` dispatcher, and `is_square` — a fast plain-integer perfect-square test (no modular arithmetic; checks whether n == a*a for some integer a). Contains the core modular Lucas sequence computation using a binary-ladder (doubling-and-addition) algorithm with parameter-specific optimized branches (Q=1, P=1/Q=-1, and general case) that control how the power of Q is tracked and whether to add or subtract 2 when squaring V. Also includes Selfridge and extra-strong parameter selection routines. |
| `residue_ntheory.py` | Modular arithmetic and number-theoretic symbol functions: multiplicative order of a single element a modulo n (`n_order` — smallest k such that a^k ≡ 1 mod n for one given a), primitive roots, quadratic residue testing (`is_quad_residue` — determines whether an integer is a perfect square modulo another integer; for composite odd moduli uses a Jacobi-symbol fast-rejection test before falling back to `sqrt_mod`; for primes uses Euler's criterion), nth-power residue testing, modular square root computation (`sqrt_mod` — finds roots of `x**2 ≡ a mod p`, returns root ≤ `p // 2` with special branching when root equals exactly `p // 2`; `sqrt_mod_iter` — generator that iterates over all solutions for both prime and composite moduli; for composite moduli it factors the modulus, dispatches each prime-power component to `_sqrt_mod1` when `a` is divisible by that prime or to `_sqrt_mod_prime_power` otherwise, then combines results via CRT), Legendre/Jacobi symbols, the Möbius function (`mobius` class with its own `eval` method — maps positive integers to {-1, 0, 1}; includes shortcut logic for known-prime and unit inputs before falling back to factorization for general integers), and discrete logarithm algorithms (trial, baby-step giant-step, Pollard rho, Pohlig-Hellman). |
