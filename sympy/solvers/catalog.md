# sympy/solvers — Catalog

> Part of [SymPy](../catalog.md). Equation solving: algebraic, ODE, PDE, recurrence, inequality, and Diophantine solvers.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package init that re-exports the public API from submodules (solve, dsolve, pdsolve, rsolve, diophantine, solveset, etc.). |
| `solvers.py` | Core equation-solving module providing `solve()` for algebraic/transcendental equations, `nsolve()` for numerical solving, `checksol()` for solution verification (raises ValueError when second argument is not a dict and no explicit solution value is given), and helpers for linear systems. `solve()` performs extensive preprocessing of equation sets: real/imaginary decomposition, symbol canonicalization, non-symbol entity replacement with dummies, and equation filtering that removes equations with no symbols of interest — returning `[]` (no solution) immediately if any such equation is a nonzero number, silently dropping zero-valued ones, and keeping unevaluated constant expressions. Includes `minsolve_linear_system` which finds the sparsest solution (fewest non-zero variables) to underdetermined linear systems using exhaustive combinatorial search over variable subsets of decreasing size. Also provides `solve_undetermined_coeffs` for solving polynomial identity equations by collecting terms by powers of the variable and matching coefficients; returns None if after collection the coefficient equations still depend on the main variable. Internal `_solve` handles conditionally-defined (piecewise/branch-based) expressions with branch-priority logic, polynomial generator analysis, and change-of-variable strategies; for univariate polynomials, when the standard root finder returns fewer solutions than the degree it falls back to complete root enumeration, and if that also fails with NotImplementedError the `incomplete` flag controls whether it raises or silently continues. Internal `_invert` recursively applies algebraic inversion to isolate unknowns from an expression, peeling away additive and multiplicative layers via `as_independent()` to separate the symbol-dependent part from the known part, returning a (known, unknown) tuple; also collects like terms and handles power/function inverses. Internal `_tsolve` handles transcendental equations involving powers, logarithms, and exponentials; for equations of the form `f(x)^g(x) = 0` it finds where the base is zero then excludes points where the exponent is also zero (avoiding indeterminate 0^0), and delegates Lambert W–form equations to the bivariate module. Internal `_solve_system` handles systems of equations: for underdetermined nonlinear polynomial systems (more unknowns than equations), it iterates over variable subsets of size equal to the equation count, solving each subset and discarding solutions that depend on previously resolved symbols; for all-linear systems, it skips post-solve validation against original expressions and returns a single dict rather than a list of dicts. |
| `solveset.py` | Set-based equation solving with `solveset()`, `linsolve()`, `nonlinsolve()`, and `linear_eq_to_matrix()`, operating over real or complex domains and returning solutions as SymPy sets. Provides `domain_check(f, symbol, p)` which validates whether a candidate solution point p is in the domain of expression f — returns False if p is infinite or any subexpression becomes infinite after substitution; walks the expression tree recursively; relies on the unsimplified form of the expression, so auto-simplified expressions like x/x→1 will miss singularities (use `evaluate=False` to preserve structure). `linsolve` is the primary solver for systems of linear (first-degree) equations supporting underdetermined and overdetermined cases; accepts augmented matrix, (A, b) pair, or list-of-equations input; uses Gauss-Jordan elimination to produce row echelon form; represents free variables parametrically in the returned FiniteSet of ordered tuples for underdetermined systems; does not optimize for sparsity or minimum non-zero entries. Internal `_invert_real` recursively inverts real-valued expressions by peeling off layers (Add, Mul, Pow, Abs, trig, etc.): for power expressions with rational exponents whose numerator is even, it generates both positive and negative root candidates; for irrational exponents it requires a positive base. Internal `_solve_abs` handles equations with absolute values by pattern-matching `p*|q| + r`, splitting into two sub-cases (argument non-negative vs negative), solving each with the absolute value removed or negated, and intersecting results with the corresponding sign condition; raises ValueError if the domain is not real. `solveset()` also handles inequality (Relational) inputs: for real-domain inequalities it delegates to `solve_univariate_inequality`, and if that raises NotImplementedError, falls back to returning a ConditionSet rather than propagating the exception; for complex-domain inequalities it raises NotImplementedError immediately. |
| `ode.py` | Ordinary differential equation solver (`dsolve`) supporting separable, homogeneous, exact, linear, Bernoulli, Lie group, Liouville, power series, and nth-order constant-coefficient methods (including undetermined coefficients with trial-term generation via iterative differentiation until the term set stabilizes, and variation of parameters), plus ODE classification and solution verification via `checkodesol`. The Lie group method (`ode_lie_group`) converts a first-order ODE to new coordinates via PDE solving; it contains a recursion guard that skips any infinitesimal pair whose eta/xi ratio simplifies to the ODE's right-hand side `h`, since the resulting PDE would require solving the original ODE again (ODE↔PDE infinite loop). Includes multiple Lie symmetry heuristics for finding infinitesimal generators: one assumes xi and eta are two-variable polynomials in x and y, computes the maximum polynomial degree from the total degree of the determining PDE's numerator, then iteratively constructs polynomial ansätze of increasing degree, substitutes into the PDE, collects monomial coefficients to form a linear system, solves for non-trivial coefficients, and scales free parameters to 1; another heuristic finds an auxiliary polynomial chi(x,y) satisfying a related PDE, then recovers xi and eta via polynomial division by h. |
| `pde.py` | Partial differential equation solver (`pdsolve`) for multi-variable (e.g. f(x,y)) first-order linear PDEs with constant or variable coefficients, with classification and additive/multiplicative variable separation utilities. Supports an 'all' meta-hint that iterates over every classification method, storing the exception object (e.g., NotImplementedError) as the dictionary value for any strategy that fails rather than raising it. |
| `recurr.py` | Recurrence relation (difference equation) solver providing `rsolve()` and lower-level routines (`rsolve_poly`, `rsolve_ratio`, `rsolve_hyper`) for linear inhomogeneous recurrences with polynomial or rational coefficients. |
| `polysys.py` | Solvers for *systems* (multivariate) of polynomial equations using Groebner bases, including specialized handling of bivariate biquadratic systems. Does not handle univariate polynomial root-finding or fallback logic (see `solvers.py`). |
| `inequalities.py` | Tools for solving polynomial, rational, and absolute-value inequalities and reducing systems of inequalities to solution sets. The system-level reducer preprocesses each input: Relational inputs are normalized to `lhs - rhs ≥/≤/= 0`; plain symbolic expressions (not Relational, not boolean) are wrapped as `Eq(expr, 0)` before solving; boolean True is dropped and False short-circuits to false. |
| `diophantine.py` | Solver for Diophantine equations (integer-valued polynomial equations) covering linear, quadratic, Pythagorean, and sum-of-powers forms, with classification and parametric solution support. |
| `decompogen.py` | General functional decomposition of expressions, decomposing `f(x)` into a composition chain `f_1(f_2(...f_n(x)))` for both polynomial and non-polynomial functions. |
| `bivariate.py` | Helper routines for solving bivariate equations involving transcendental functions (LambertW, exp, log), used internally by `solve()`. Provides `_linab` which decomposes an expression into the form `a*X + b` where `X` is symbol-dependent and `a`, `b` are independent, with sign normalization that negates both `a` and `X` when the dependent factor has a negative leading sign. Core function `_solve_lambert` converts transcendental equations (products of linear and exponential terms, or sums with exponential/power terms) into Lambert W form by isolating the transcendental term, performing sign normalization before taking logarithms, and then delegating to `_lambert`. Also provides `bivariate_type` for classifying composite bivariate expressions. |
| `deutils.py` | Shared utility functions for ODE and PDE solvers, including `_preprocess` for expression preparation, `ode_order` for computing differential equation order, and `_desolve` as a common dispatch wrapper. |
| `benchmarks/bench_solvers.py` | Performance benchmark for `solve_linear_system` on a trivial identity-matrix system. |
