# sympy/solvers — Catalog

> Part of [SymPy](../catalog.md). Equation solving: algebraic, ODE, PDE, recurrence, inequality, and Diophantine solvers.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package init that re-exports the public API from submodules (solve, dsolve, pdsolve, rsolve, diophantine, solveset, etc.). |
| `solvers.py` | Core equation-solving module providing `solve()` for algebraic/transcendental equations, `nsolve()` for numerical solving, `checksol()` for solution verification (raises ValueError when second argument is not a dict and no explicit solution value is given), and helpers for linear systems. `solve()` performs extensive preprocessing of equation sets: real/imaginary decomposition, symbol canonicalization, non-symbol entity replacement with dummies, and equation filtering that removes equations with no symbols of interest — returning `[]` (no solution) immediately if any such equation is a nonzero number, silently dropping zero-valued ones, and keeping unevaluated constant expressions. Includes `minsolve_linear_system` which finds the sparsest solution (fewest non-zero variables) to underdetermined linear systems using exhaustive combinatorial search over variable subsets of decreasing size. Also provides `solve_undetermined_coeffs` for solving polynomial identity equations by collecting terms by powers of the variable and matching coefficients; returns None if after collection the coefficient equations still depend on the main variable. Internal `_solve` handles conditionally-defined (piecewise/branch-based) expressions with branch-priority logic, polynomial generator analysis, and change-of-variable strategies; for univariate polynomials, when the standard root finder returns fewer solutions than the degree it falls back to complete root enumeration, and if that also fails with NotImplementedError the `incomplete` flag controls whether it raises or silently continues. Internal `_tsolve` handles transcendental equations involving powers, logarithms, and exponentials; for equations of the form `f(x)^g(x) = 0` it finds where the base is zero then excludes points where the exponent is also zero (avoiding indeterminate 0^0), and delegates Lambert W–form equations to the bivariate module. Internal `_solve_system` handles systems of equations: for underdetermined nonlinear polynomial systems (more unknowns than equations), it iterates over variable subsets of size equal to the equation count, solving each subset and discarding solutions that depend on previously resolved symbols; for all-linear systems, it skips post-solve validation against original expressions and returns a single dict rather than a list of dicts. |
| `solveset.py` | Set-based equation solving with `solveset()`, `linsolve()`, `nonlinsolve()`, and `linear_eq_to_matrix()`, operating over real or complex domains and returning solutions as SymPy sets. `linsolve` returns general solution sets but does not optimize for sparsity or minimum non-zero entries. Internal `_invert_real` recursively inverts real-valued expressions by peeling off layers (Add, Mul, Pow, Abs, trig, etc.): for power expressions with rational exponents whose numerator is even, it generates both positive and negative root candidates; for irrational exponents it requires a positive base. Internal `_solve_abs` handles equations with absolute values by pattern-matching `p*|q| + r`, splitting into two sub-cases (argument non-negative vs negative), solving each with the absolute value removed or negated, and intersecting results with the corresponding sign condition; raises ValueError if the domain is not real. |
| `ode.py` | Ordinary differential equation solver (`dsolve`) supporting separable, homogeneous, exact, linear, Bernoulli, Lie group, Liouville, power series, and nth-order constant-coefficient methods (including undetermined coefficients with trial-term generation via iterative differentiation until the term set stabilizes, and variation of parameters), plus ODE classification and solution verification via `checkodesol`. |
| `pde.py` | Partial differential equation solver (`pdsolve`) for multi-variable (e.g. f(x,y)) first-order linear PDEs with constant or variable coefficients, with classification and additive/multiplicative variable separation utilities. Supports an 'all' meta-hint that iterates over every classification method, storing the exception object (e.g., NotImplementedError) as the dictionary value for any strategy that fails rather than raising it. |
| `recurr.py` | Recurrence relation (difference equation) solver providing `rsolve()` and lower-level routines (`rsolve_poly`, `rsolve_ratio`, `rsolve_hyper`) for linear inhomogeneous recurrences with polynomial or rational coefficients. |
| `polysys.py` | Solvers for *systems* (multivariate) of polynomial equations using Groebner bases, including specialized handling of bivariate biquadratic systems. Does not handle univariate polynomial root-finding or fallback logic (see `solvers.py`). |
| `inequalities.py` | Tools for solving polynomial, rational, and absolute-value inequalities and reducing systems of inequalities to solution sets. The system-level reducer preprocesses each input: Relational inputs are normalized to `lhs - rhs ≥/≤/= 0`; plain symbolic expressions (not Relational, not boolean) are wrapped as `Eq(expr, 0)` before solving; boolean True is dropped and False short-circuits to false. |
| `diophantine.py` | Solver for Diophantine equations (integer-valued polynomial equations) covering linear, quadratic, Pythagorean, and sum-of-powers forms, with classification and parametric solution support. |
| `decompogen.py` | General functional decomposition of expressions, decomposing `f(x)` into a composition chain `f_1(f_2(...f_n(x)))` for both polynomial and non-polynomial functions. |
| `bivariate.py` | Helper routines for solving bivariate equations involving transcendental functions (LambertW, exp, log), used internally by `solve()`. Provides `_linab` which decomposes an expression into the form `a*X + b` where `X` is symbol-dependent and `a`, `b` are independent, with sign normalization that negates both `a` and `X` when the dependent factor has a negative leading sign. Core function `_solve_lambert` converts transcendental equations (products of linear and exponential terms, or sums with exponential/power terms) into Lambert W form by isolating the transcendental term, performing sign normalization before taking logarithms, and then delegating to `_lambert`. Also provides `bivariate_type` for classifying composite bivariate expressions. |
| `deutils.py` | Shared utility functions for ODE and PDE solvers, including `_preprocess` for expression preparation, `ode_order` for computing differential equation order, and `_desolve` as a common dispatch wrapper. |
| `benchmarks/bench_solvers.py` | Performance benchmark for `solve_linear_system` on a trivial identity-matrix system. |
