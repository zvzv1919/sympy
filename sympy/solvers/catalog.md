# sympy/solvers — Catalog

> Part of [SymPy](../catalog.md). Equation solving: algebraic, ODE, PDE, recurrence, inequality, and Diophantine solvers.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package init that re-exports the public API from submodules (solve, dsolve, pdsolve, rsolve, diophantine, solveset, etc.). |
| `solvers.py` | Core equation-solving module providing `solve()` for algebraic/transcendental equations, `nsolve()` for numerical solving, and legacy helpers for linear systems (`solve_linear_system`) and undetermined coefficients. The internal `_solve()` function handles multi-symbol solving by iterating over unknowns sequentially — first attempting undetermined-coefficients, then solving linearly for each variable one at a time, discarding any solution whose expression depends on a previously solved variable (circular-dependency check), and falling back to non-linear solving for remaining symbols. Note: `solve()` does NOT strictly validate that its symbol arguments are proper `Symbol` objects — for strict validation of unknowns (raising `ValueError` for numeric or non-symbol entries), see `linsolve()` in `solveset.py`. Also contains `checksol()` for verifying whether a candidate solution satisfies an equation — it returns `True`/`False`/`None`, where `None` means the check was inconclusive (it does NOT raise errors for indeterminate cases; contrast with `solveset()` in `solveset.py` which raises `NotImplementedError` for undetermined constant-zero relationships). Does NOT contain `dsolve` (see `ode.py`) or `linsolve` (see `solveset.py`). Contains `_tsolve` for transcendental equation solving, which includes the top-level Lambert W pattern recognition logic — classifying generators into exponential/logarithmic vs. polynomial, restructuring the equation, and dispatching to `bivariate.py` for the actual Lambert W reduction. |
| `solveset.py` | Set-based equation solving with `solveset()`, `linsolve()`, `nonlinsolve()`, and `linear_eq_to_matrix()`, operating over real or complex domains and returning solutions as SymPy sets. `solveset()` performs upfront edge-case handling before dispatching: boolean constants (True/False), constant expressions with no variables (checking `Eq(f, 0)` and raising `NotImplementedError` if the zero-equality relationship is unknown), auto-detection of the solve variable for univariate equations, and strict `Symbol` type validation on the unknown (raising `ValueError` for non-Symbol inputs). For constant/variable-free expressions that cannot be determined equal to zero, `solveset()` raises `NotImplementedError` — contrast with `checksol()` in `solvers.py`, which returns `None` for indeterminate cases without raising. Contains internal helpers for specific equation types: `_solve_trig` handles periodic/trigonometric equations by rewriting them in complex exponential form (`exp(I*symbol)`), substituting with a dummy variable to obtain an algebraic equation, solving that, and inverting back — if the substitution fails to eliminate the original variable, it returns a `ConditionSet` rather than raising an error; `_solve_as_rational` handles rational functions; `_solve_as_poly` uses polynomial root-finding techniques. `linsolve()` is the primary solver for simultaneous linear equation systems — accepts augmented matrices, (A, b) pairs, or equation lists and solves via Gauss-Jordan elimination. Performs strict input validation on the unknowns argument: checks that each entry is a valid `Symbol` object (raising `ValueError` with a descriptive message for numeric, string, or other non-symbol entries passed as unknowns). Also validates non-empty systems and requires symbols to be provided. Prefer `linsolve` over the older `solve_linear_system` in `solvers.py`. Note: `_invert()` in this file handles algebraic inversion of single expressions (rewriting `f(x) = y` as `x = g(y)`) — it does NOT handle multi-variable sequential solving or dependency tracking across unknowns (for that, see `_solve()` in `solvers.py`). Trigonometric/periodic equation solving via complex exponential substitution lives here in `_solve_trig`, NOT in `solvers.py`. |
| `ode.py` | Ordinary differential equation solver (`dsolve`) supporting separable, homogeneous, exact, linear, Bernoulli, Lie group, Liouville, power series, and nth-order constant-coefficient methods, plus ODE classification (`classify_ode`) and solution checking. Classification includes parsing and validating initial/boundary conditions — distinguishing derivative conditions (Subs objects) from function-value conditions (AppliedUndef), and preprocessing to normalize the leading derivative coefficient. Also handles **systems of coupled nonlinear ODEs** (two-equation first-order systems), with specialized solvers for autonomous systems, separable-product forms (where each RHS factors into univariate functions times a shared factor, enabling conserved-quantity / first-integral computation), and other structured types. Contains internal helpers for Lie symmetry analysis, including utilities that strip unevaluated symbolic function calls from expressions (handling Add, Mul, Pow cases) and `infinitesimals()` for computing Lie group infinitesimal generators. See `deutils.py` for lower-level ODE/PDE utilities (equation preprocessing, order computation); see `decompogen.py` for general functional decomposition (unrelated to ODE systems). |
| `pde.py` | Partial differential equation solver (`pdsolve`) for first-order linear PDEs with constant or variable coefficients, with classification and additive/multiplicative variable separation utilities. |
| `recurr.py` | Recurrence relation (difference equation) solver providing `rsolve()` and lower-level routines (`rsolve_poly`, `rsolve_ratio`, `rsolve_hyper`) for linear inhomogeneous recurrences with polynomial or rational coefficients. |
| `polysys.py` | Solvers for systems of polynomial equations using Groebner bases, including specialized handling of bivariate biquadratic systems. |
| `inequalities.py` | Tools for solving polynomial, rational, and absolute-value inequalities and reducing systems of inequalities to solution sets. |
| `diophantine.py` | Solver for Diophantine equations (integer-valued polynomial equations) covering linear, quadratic, Pythagorean, and sum-of-powers forms, with classification and parametric solution support. |
| `decompogen.py` | General functional decomposition of expressions, decomposing `f(x)` into a composition chain `f_1(f_2(...f_n(x)))` for both polynomial and non-polynomial functions. Unrelated to ODE/PDE solving or decomposing differential equations into separable/factorable forms — for that, see `ode.py`. |
| `bivariate.py` | Lower-level helper routines for two-variable equation solving: (1) Lambert W (product-logarithm) equation reduction for transcendental functions (LambertW, exp, log), called by `_tsolve` in `solvers.py` after generator classification; and (2) `bivariate_type()`, which classifies a two-variable expression into composite substitution forms — testing whether `f(x, y)` can be decomposed as `P(u(x,y))` where `u` is one of `x*y`, `x+y`, `x*y+x`, or `x*y+y` — and returns the substitution expression, the reduced univariate polynomial, and a dummy variable, enabling reduction of a bivariate equation to a single-variable problem. This bivariate-type decomposition is specific to two-variable substitution patterns and is distinct from the general single-variable functional decomposition in `decompogen.py`. See also `solvers.py` for the higher-level pattern recognition and dispatch logic. |
| `deutils.py` | Shared utility functions for ODE and PDE solvers, including `_preprocess` for preparing differential equation expressions (extracting function and variable), `ode_order` for computing differential equation order, and `_desolve` as a common dispatch wrapper. `_preprocess` handles hint-based derivative evaluation: when `hint` is `None`, it skips all differentiation and returns the expression unchanged (early return); otherwise it selectively applies `.doit()` based on the hint suffix and variable intersection. Does NOT contain Lie symmetry helpers or expression manipulation for stripping function calls — those are in `ode.py`. |
| `benchmarks/bench_solvers.py` | Performance benchmark for `solve_linear_system` on a trivial identity-matrix system. |
