# sympy/plotting — Catalog

> Part of [SymPy](../catalog.md). 2-D and 3-D plotting with backends for matplotlib, pyglet, and text-based output.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package init that re-exports the public plotting API: `plot`, `plot_parametric`, `plot3d`, `plot3d_parametric_line`, `plot3d_parametric_surface`, `plot_implicit`, `textplot`, and `PygletPlot`. |
| `plot.py` | Core plotting module defining the `Plot` class, data series hierarchy, and the public convenience functions `plot`, `plot_parametric`, `plot3d`, `plot3d_parametric_line`, and `plot3d_parametric_surface`. The series hierarchy includes `BaseSeries`, line series (`LineOver1DRangeSeries`, `Parametric2DLineSeries`, `Line3DBaseSeries`, `Parametric3DLineSeries`), and surface series (`SurfaceBaseSeries`, `SurfaceOver2DRangeSeries`, `ParametricSurfaceOver2DRangeSeries`). `SurfaceBaseSeries` is the base class for 3D surfaces and implements `get_color_array`, which dispatches color computation based on whether the surface color is a callable: if so, it checks the callable's arity and whether the series is parametric to decide which mesh variables to pass (parameter meshes vs. coordinate meshes, 1-arg vs. 2-arg vs. 3-arg). Also contains `MatplotlibBackend` whose `process_series` method selects the appropriate matplotlib drawing call for each series type. Each series class implements its own `get_segments`/`get_points`/`get_meshes` methods including adaptive recursive subdivision for 2D parametric curves. |
| `plot_implicit.py` | Implicit plotting that *uses* interval arithmetic from `intervalmath/` to render equations, inequalities, and boolean combinations. Defines `ImplicitSeries` (which calls into `lib_interval` for math and logic) and the `plot_implicit` convenience function. Does not itself define interval math functions or ternary logic operators. |
| `textplot.py` | Provides `textplot`, a function that renders a crude ASCII-art plot of a single-variable SymPy expression over a given interval to the terminal. |
| `experimental_lambdify.py` | Internal lambdify variant used by the plotting module to convert SymPy expressions into callable numerical functions. Translates expression strings to use math/numpy/mpmath and handles edge cases that the standard `lambdify` does not. |
| `intervalmath/__init__.py` | Package init for the interval math subpackage; re-exports the `interval` class and all interval-aware math functions (sin, cos, exp, log, sqrt, etc.). |
| `intervalmath/interval_arithmetic.py` | Defines the `interval` class representing a floating-point interval with a validity flag. Implements arithmetic operators and comparisons used by `plot_implicit` for adaptive region subdivision. |
| `intervalmath/lib_interval.py` | Implements interval-aware versions of standard math functions (exp, log, sin, cos, tan, sqrt, Abs, floor, ceil, inverse hyperbolic trig, etc.) over `interval` objects, using numpy for speed. Also defines ternary (three-valued: True/False/None) logic operators `And` and `Or` that combine 2-tuples of comparison results for range-based curve rendering. |
| `pygletplot/__init__.py` | Package init for the pyglet-based plotting backend; defines and exports the `PygletPlot` factory function. Its docstring is the primary documentation for the flexible variable-interval syntax (partial `[var, min, max, steps]` specifications where omitted parts like empty brackets `[]` or step-only `[100]` are filled from coordinate-mode defaults), coordinate mode selection, and the indexed-slot calculator interface. |
| `pygletplot/plot.py` | Implements the `PygletPlot` class for the pyglet 3-D backend. Manages window lifecycle in `show()` (reuses an existing window or creates a new one, with a special case for automated doctest runs). Provides `wait_for_calculations`, which busy-waits (polling with `sleep(0)`) under a render lock until all registered functions' asynchronous vertex and color-vertex computations have finished. Also manages plot function collections, coordinate modes, color schemes, and image saving. |
| `pygletplot/color_scheme.py` | Defines `ColorGradient` and `ColorScheme` classes for mapping surface/curve vertex data to RGB colors in the pyglet backend. `ColorScheme` provides `apply_to_curve` and `apply_to_surface` methods that iterate over vertex arrays to compute per-vertex RGB colors: they handle `None` vertices (skipping them) and silently catch color-function exceptions (the `__call__` method returns `None` on failure), then scale results to [0,1] and apply the gradient. Also supports user-defined color functions, named presets, and gradient interpolation. |
| `pygletplot/managed_window.py` | Provides `ManagedWindow`, a pyglet `Window` subclass that runs its event loop in a separate thread, serving as the base class for `PlotWindow`. |
| `pygletplot/plot_axes.py` | Implements `PlotAxes` and helper classes (`PlotAxesOrdinate`, `PlotAxesFrame`) for rendering labeled coordinate axes with tick marks in the pyglet 3-D plot window. |
| `pygletplot/plot_camera.py` | Defines `PlotCamera`, which manages the OpenGL camera (projection, rotation, zoom, panning) for the pyglet plotting window, supporting both perspective and orthographic modes. |
| `pygletplot/plot_controller.py` | Implements `PlotController`, which translates keyboard and mouse input into camera rotation, zoom, and other interactive actions in the pyglet plot window. |
| `pygletplot/plot_curve.py` | Defines `PlotCurve`, a `PlotModeBase` subclass that calculates vertex positions and renders 1-D parametric curves (wireframe line strips) in the pyglet backend. Handles vertex geometry only; per-vertex color computation is delegated to `ColorScheme` in `color_scheme.py`. |
| `pygletplot/plot_interval.py` | Defines `PlotInterval`, a helper class representing a named variable range with step count, used to generate evaluation grids for pyglet plot modes. |
| `pygletplot/plot_mode.py` | Defines `PlotMode`, the grandparent class for all pyglet plot modes. Handles mode registration, lookup by alias or variable count, argument parsing, and coordinate-mode selection. |
| `pygletplot/plot_mode_base.py` | Defines `PlotModeBase`, the intended parent class for concrete plot modes. Provides threaded vertex/color calculation, display-list management, and the base `draw` implementation. Contains the rendering style auto-selection logic: when no explicit style is given, it examines the maximum step count across intervals and uses a threshold (step_max > 40) to choose between 'both' (wireframe + solid) and 'solid' (filled only). Also manages color property changes (wrapping values into `ColorScheme`). Its `_get_evaluator` method implements evaluator selection with fallback from fast lambda-based to slower SymPy substitution-based evaluation. |
| `pygletplot/plot_modes.py` | Defines concrete plot modes for the pyglet backend: `Cartesian2D`, `Cartesian3D`, `ParametricCurve2D`, `ParametricCurve3D`, `ParametricSurface`, `Polar`, `Cylindrical`, and `Spherical`. |
| `pygletplot/plot_object.py` | Defines `PlotObject`, a minimal base class for anything that can be drawn in the pyglet plot window, providing a `visible` flag and a `draw` method stub. |
| `pygletplot/plot_rotation.py` | Utility functions for computing 3-D rotation matrices from sphere-mapped screen coordinates, used for interactive trackball-style rotation in the pyglet backend. |
| `pygletplot/plot_surface.py` | Defines `PlotSurface`, a `PlotModeBase` subclass that calculates and renders 2-D parametric surfaces (wireframe and solid quad strips) in the pyglet backend. |
| `pygletplot/plot_window.py` | Implements `PlotWindow`, the `ManagedWindow` subclass that sets up OpenGL state, coordinates the camera and controller, and drives the per-frame drawing loop for pyglet plots. In its draw loop, it selects the default viewing orientation (rotation preset) from the first rendered function and applies it to the camera, using a flag that resets when the function list becomes empty. |
| `pygletplot/util.py` | OpenGL and math utility functions for the pyglet backend: model/projection matrix retrieval, screen-to-model coordinate conversion, interpolation, billboard matrices, vector operations, and option-string parsing. |
