# sympy/assumptions — Catalog

> Part of [SymPy](../catalog.md). Assumption system for declaring and querying properties of symbols (positive, integer, etc.).

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package entry point; re-exports `AppliedPredicate`, `Predicate`, `AssumptionsContext`, `assuming`, `Q`, `ask`, `register_handler`, `remove_handler`, and `refine`. |
| `ask.py` | Defines the `AssumptionKeys` class (the `Q` object) with all predicate key definitions — scalar predicates (e.g. `Q.integer`, `Q.rational`, `Q.real`, `Q.complex`, `Q.positive`, `Q.negative`, `Q.imaginary`, `Q.nonnegative`, `Q.nonpositive`, `Q.prime`, `Q.composite`, `Q.even`, `Q.odd`, etc.), matrix-structure predicates (e.g. `Q.diagonal`, `Q.symmetric`, `Q.square`, `Q.fullrank`, `Q.positive_definite`, `Q.orthogonal`, `Q.unitary`, `Q.singular`, `Q.invertible`), and matrix-element predicates (e.g. `Q.integer_elements`, `Q.real_elements`, `Q.complex_elements`). Each predicate definition includes its mathematical docstring with precise membership semantics and edge-case behavior (e.g. `Q.composite` documents that 0, 1, and 2 are all not composite). Critically documents the semantic distinction between predicate negation (`~Q.positive`) and complement predicates (`Q.nonpositive`): negation simply means "not known positive" while complement predicates additionally require real membership, so e.g. `~Q.positive(I)` is True but `Q.nonpositive(I)` is False. Also defines the `ask()` function. This is where predicates are *defined* with their semantic boundaries and edge-case rules; handlers that *evaluate* them on specific expression types live under `handlers/`. |
| `ask_generated.py` | Auto-generated file (via `bin/ask_update.py`) containing precomputed known-fact implications between predicates in CNF and a single-fact lookup dict. |
| `assume.py` | Core infrastructure for the assumption system: `AssumptionsContext` (set of active assumptions), `AppliedPredicate` (a predicate applied to an expression), `Predicate` (with `eval` method that dispatches to `handlers/` registered handlers and raises `ValueError` on contradictory truth values), global assumptions store, and the `assuming` context manager. Does not define predicate semantics or SAT-based class-to-handler registries. |
| `refine.py` | Implements `refine()`, which simplifies expressions using assumptions, along with specialized refinement handlers for `Abs`, `Pow`, `exp`, `Q.real`, `atan2`, `Piecewise`, and sign. |
| `satask.py` | SAT-based assumption querying via `satask()`: converts a proposition and assumptions into a satisfiability problem and iteratively gathers all relevant known facts to determine truth values. |
| `sathandlers.py` | Defines `UnevaluatedOnFree`, a deferred Boolean-function base class for logical predicate wrappers, with subclasses `AllArgs`, `AnyArgs`, `ExactlyOneArg` that vectorize predicates over expression args. Also defines `ClassFactRegistry` for mapping expression classes to SAT-based inference rules, and `evaluate_old_assump`/`_old_assump_replacer` which passively translates new-style predicate queries (e.g. `Q.commutative`) into legacy `.is_*` attribute lookups without applying any default-value logic or assumption overrides. This is infrastructure for SAT-based evaluation mechanics only — active commutativity query handling with defaults and assumption overrides is in `handlers/common.py`. |
| `handlers/__init__.py` | Package init for assumption handlers; re-exports `AskHandler`, `CommonHandler`, `AskCommutativeHandler`, `TautologicalHandler`, and `test_closed_group`. |
| `handlers/calculus.py` | Query handlers for calculus-related predicates (`finite`, `infinite`) that determine boundedness of expressions built from `Add`, `Mul`, `Pow`, `Symbol`, and special constants. |
| `handlers/common.py` | Base handler classes: `AskHandler` (abstract base), `CommonHandler` (always-true/false helpers), `AskCommutativeHandler` (the authoritative handler that determines commutativity for symbols — defaults to True when `is_commutative` is None/unset, and performs a dual-check when `is_commutative` is not None by also consulting explicit assumptions so that `~Q.commutative(x)` in assumptions can override an intrinsic `is_commutative=True`), and `TautologicalHandler` which implements three-valued logic (True/False/None) for evaluating boolean connectives (`Or`, `And`, `Not`, `Implies`, `Equivalent`) under incomplete knowledge—e.g., `Or` short-circuits on True, propagates None if any arg is unknown, returns False only when all args are definitively False. Also provides `test_closed_group` for checking closure under an operation. |
| `handlers/matrices.py` | Query handlers that *evaluate* matrix-related predicates (square, symmetric, invertible, orthogonal, unitary, positive-definite, upper/lower-triangular, diagonal, fullrank, singular) on specific matrix expression types. Contains evaluation dispatch logic only — predicate semantic definitions and inter-predicate inference rules are in `ask.py`. |
| `handlers/ntheory.py` | Query handlers that *evaluate* number-theory predicates (prime, composite, even, odd, rational/irrational) on specific expression types. Contains evaluation dispatch logic only — predicate semantic definitions, edge-case rules (e.g. whether 0, 1, 2 are composite), and docstrings are in `ask.py`. |
| `handlers/order.py` | Query handlers that *evaluate* order-relation predicates (negative, nonnegative, nonzero, zero, positive, nonpositive, extended_real) on specific expression types (`Add`, `Mul`, `Pow`, numeric types, `log`, `exp`, `factorial`, `Abs`). Contains evaluation logic only — predicate semantic definitions and edge-case rules (e.g. nonnegative requires real membership) are in `ask.py`. |
| `handlers/sets.py` | Query handlers that *evaluate* set-membership predicates (integer, rational, irrational, real, extended_real, hermitian, complex, imaginary, antihermitian, algebraic) on specific expression types. Contains evaluation dispatch logic only — predicate semantic definitions and boundary rules (e.g. whether zero is imaginary) are in `ask.py`. |
