# sympy/assumptions — Catalog

> Part of [SymPy](../catalog.md). Assumption system for declaring and querying properties of symbols (positive, integer, etc.).

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package entry point; re-exports `AppliedPredicate`, `Predicate`, `AssumptionsContext`, `assuming`, `Q`, `ask`, `register_handler`, `remove_handler`, and `refine`. |
| `ask.py` | Defines the `AssumptionKeys` class (the `Q` object) with all predicate key definitions — both scalar predicates (e.g. `Q.integer`, `Q.rational`, `Q.real`, `Q.complex`, `Q.positive`, `Q.imaginary`, `Q.nonnegative`, `Q.nonpositive`, etc.) and matrix-element predicates (e.g. `Q.integer_elements`, `Q.real_elements`, `Q.complex_elements`). Each predicate definition includes its mathematical docstring with precise membership semantics and edge-case documentation — e.g. `Q.imaginary` explicitly excludes zero despite 0=0·I; `Q.nonnegative`/`Q.nonpositive` require real membership (so `Q.nonnegative(I)` is False while `~Q.negative(I)` is True). Also defines the `ask()` function. This is where predicates are *defined* with their semantic boundaries; handlers that *evaluate* them on specific expression types live under `handlers/`. |
| `ask_generated.py` | Auto-generated file (via `bin/ask_update.py`) containing precomputed known-fact implications between predicates in CNF and a single-fact lookup dict. |
| `assume.py` | Core infrastructure for the assumption system: `AssumptionsContext` (set of active assumptions), `AppliedPredicate` (a predicate applied to an expression), `Predicate` (with `eval` method that dispatches to `handlers/` registered handlers and raises `ValueError` on contradictory truth values), global assumptions store, and the `assuming` context manager. Does not define predicate semantics or SAT-based class-to-handler registries. |
| `refine.py` | Implements `refine()`, which simplifies expressions using assumptions, along with specialized refinement handlers for `Abs`, `Pow`, `exp`, `Q.real`, `atan2`, `Piecewise`, and sign. |
| `satask.py` | SAT-based assumption querying via `satask()`: converts a proposition and assumptions into a satisfiability problem and iteratively gathers all relevant known facts to determine truth values. |
| `sathandlers.py` | Defines helper Boolean-function classes (`UnevaluatedOnFree`, `AllArgs`, `AnyArgs`, `ExactlyOneArg`, `CheckOldAssump`) and `ClassFactRegistry` — a MutableMapping that maps expression classes to SAT-based inference rules, where `__getitem__` resolves inheritance by unioning handlers from all registered superclasses (so looking up a subclass returns its own handlers plus all ancestor handlers). Also contains `_old_assump_replacer` and `evaluate_old_assump`, which translate new-style predicate queries into legacy `.is_*` attribute lookups. |
| `handlers/__init__.py` | Package init for assumption handlers; re-exports `AskHandler`, `CommonHandler`, `AskCommutativeHandler`, `TautologicalHandler`, and `test_closed_group`. |
| `handlers/calculus.py` | Query handlers for calculus-related predicates (`finite`, `infinite`) that determine boundedness of expressions built from `Add`, `Mul`, `Pow`, `Symbol`, and special constants. |
| `handlers/common.py` | Base handler classes: `AskHandler` (abstract base), `CommonHandler` (always-true/false helpers), `AskCommutativeHandler`, and `TautologicalHandler` which implements three-valued logic (True/False/None) for evaluating boolean connectives (`Or`, `And`, `Not`, `Implies`, `Equivalent`) under incomplete knowledge—e.g., `Or` short-circuits on True, propagates None if any arg is unknown, returns False only when all args are definitively False. Also provides `test_closed_group` for checking closure under an operation. |
| `handlers/matrices.py` | Query handlers for matrix-related predicates such as square, symmetric, invertible, orthogonal, unitary, positive-definite, upper/lower-triangular, diagonal, fullrank, and singular. |
| `handlers/ntheory.py` | Query handlers for number-theory predicates: prime, composite, even, odd, and rational/irrational classification of expressions. |
| `handlers/order.py` | Query handlers that *evaluate* order-relation predicates (negative, nonnegative, nonzero, zero, positive, nonpositive, extended_real) on specific expression types (`Add`, `Mul`, `Pow`, numeric types, `log`, `exp`, `factorial`, `Abs`). Contains evaluation logic only — predicate semantic definitions and edge-case rules (e.g. nonnegative requires real membership) are in `ask.py`. |
| `handlers/sets.py` | Query handlers that *evaluate* set-membership predicates (integer, rational, irrational, real, extended_real, hermitian, complex, imaginary, antihermitian, algebraic) on specific expression types. Contains evaluation dispatch logic only — predicate semantic definitions and boundary rules (e.g. whether zero is imaginary) are in `ask.py`. |
