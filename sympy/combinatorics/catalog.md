# sympy/combinatorics -- Catalog

> Part of [SymPy](../catalog.md). Combinatorics: permutations, partitions, polyhedra, group theory, and Graycode.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package initializer; imports and re-exports the main public classes and functions (Permutation, Prufer, Subset, Partition, Polyhedron, PermutationGroup, GrayCode, named groups, etc.). |
| `fp_groups.py` | Defines `FpGroup` (finitely presented groups given by generators and relator words), `CosetTable` class, and Todd-Coxeter coset enumeration algorithms for enumerating cosets of a subgroup within a finitely presented group (`coset_enumeration_r` relator-based, `coset_enumeration_c` coset-table-based), low-index subgroup enumeration, Reidemeister-Schreier presentations, and permutation group isomorphism. Not for enumerating elements of permutation groups (see `perm_groups.py`). |
| `free_group.py` | Implements `FreeGroup` and `FreeGroupElement` for constructing and manipulating free groups (algebraic structures built from non-commuting generators and their inverses) and their elements (associative words). Includes `center()` which returns the center of the free group (the set of elements commuting with all others — trivially just the identity for rank ≥ 2), `contains` for membership testing, `_parse_symbols` for parsing and validating generator inputs, word-level arithmetic, element equality, and short-lex total ordering of elements. |
| `generators.py` | Generator functions that **yield every individual permutation element** (not group objects) of standard groups: `symmetric`, `cyclic`, `alternating`, `dihedral`, and `rubik` (NxN puzzle cube permutation generator that models face and plane rotations — rotating the plane at index 0 additionally rotates the corresponding face, while deeper planes only cycle edge rows across adjacent faces). The `dihedral(n)` function contains explicit special-case handling for n=1 (embeds in S2) and n=2 (Klein 4-group embedded in S4) where the standard Sn subgroup embedding doesn't work. Returns iterables of `Permutation` instances, not `PermutationGroup`. |
| `graycode.py` | Implements the `GrayCode` class for generating and manipulating raw Gray code sequences (reflected binary codes) over n-dimensional binary cubes — sequence generation, iteration, and low-level rank/unrank of binary codewords. Does not handle ranking of element collections relative to a parent set (see `subsets.py`). |
| `group_constructs.py` | Provides the `DirectProduct` convenience wrapper for computing the direct product of **three or more** permutation groups in a single batch call with generator deduplication (via `uniq`). Thin wrapper that delegates to the same index-shifting approach as `PermutationGroup.__mul__`; for exactly **two** groups or to understand how domain remapping/index shifting works, see `__mul__` in `perm_groups.py` which is the primary implementation. |
| `homomorphisms.py` | Implements `GroupHomomorphism` and a `homomorphism()` factory for creating and working with group homomorphisms between permutation groups and finitely presented groups. |
| `named_groups.py` | Factory functions that **construct `PermutationGroup` objects** (not element iterators) for standard named groups: `SymmetricGroup`, `CyclicGroup`, `DihedralGroup`, `AlternatingGroup` (with odd/even-n generator selection), `AbelianGroup`, and `RubikGroup`. Each function chooses minimal generating sets and pre-caches group properties (abelian, solvable, transitive, etc.). Returns `PermutationGroup` instances with metadata, not individual permutation elements. |
| `partitions.py` | Defines `Partition` (set partitions) and `IntegerPartition` classes, along with RGS (restricted growth string) ranking/unranking utilities. |
| `perm_groups.py` | Core `PermutationGroup` class implementing group-theoretic operations: the **constructor (`__new__`)** normalizes generators of mismatched degrees (sizes) to a common degree — detects size variety among input permutations and pads all generators to the maximum size (or a user-specified `degree` keyword), so mismatched-degree generators are reconciled here, not in `group_constructs.py`; full group element enumeration via Dimino's algorithm (incremental subgroup-building that processes one generator at a time, expanding via coset representatives) and Schreier-Sims-based generation via `generate_schreier_sims` (yields elements in coset-rank order using basic transversals — with fallback: if transversals are empty, simply yields the generators; if only one transversal level, iterates the single orbit without full backtracking), deterministic (`schreier_sims`), **incremental** (`schreier_sims_incremental` — extends a given base and generating set into a full BSGS by computing Schreier generators, sifting them through the chain via `_strip_af`, and amending the stabilizer chain when sifting fails; when a non-trivial residual fixes all current base points, it appends a new moved point to the base and extends data structures accordingly), and **randomized** (`schreier_sims_random` — probabilistic BSGS computation that calls `_strip` from `util.py` to sift random elements, then handles all sift outcomes: amends the stabilizer chain on failed sifts, extends the base when a non-trivial residual passes through all existing levels, and halts after consecutive successful sifts for a probabilistic correctness guarantee), `__mul__` computes the direct product (Cartesian product) of exactly **two** permutation groups by remapping the second group's action domain — shifts all indices of the second group's generators by n1 (the first group's degree) so the two domains don't overlap, then concatenates generators to form a group acting on n1+n2 points (for 3+ groups use the batch wrapper in `group_constructs.py`), `make_perm` composes n randomly-selected group elements starting from the identity (accepts either an integer count with optional seed, or a list of selection indices as the first argument — raises ValueError if both a sequence and a seed are provided), `random` and `random_pr` (product-replacement random element generation), order, orbits, stabilizers (single-point and **pointwise** — the pointwise stabilizer computes the subgroup fixing every point in a given set, with an incremental path using Schreier-Sims that filters strong generators and falls back to the identity permutation when none fix all points), BSGS base swapping (`baseswap` — swaps two consecutive base points with both deterministic and randomized modes; the deterministic branch iterates over orbit candidates, computes inverse images under transversal elements, prunes candidates by removing entire orbits when the inverse image falls outside the next-level basic orbit, and accumulates new stabilizer generators), basic orbits/stabilizers/transversals properties, coset decomposition with ranking/unranking (`coset_rank`, `coset_unrank`), subgroup testing, depth-first subgroup search with property predicates (`subgroup_search`), center and centralizer computation, derived series and derived subgroups, commutator of subgroups, and normal closure. |
| `permutations.py` | Core `Permutation` and `Cycle` classes for representing and manipulating **individual** permutations (bijections on finite sets) in array and cyclic notation. `__mul__` composes two permutations, padding the shorter array to reconcile different domain sizes. `cycle_structure` property returns a dictionary mapping each cycle length to its multiplicity count (with special handling for fixed points/singletons — elements mapping to themselves — counted as length-1 cycles), `cycles` returns total cycle count including singletons. Also supports inversion, parity, lexicographic ranking (`rank`), non-lexicographic linear-time ranking/unranking (`rank_nonlex`, `unrank_nonlex`), inversion-vector construction (`from_inversion_vector`), merge-sort-based inversion counting (module-level `_merge` helper), and low-level array-form helpers: `_af_rmul` (two-operand composition), `_af_rmuln` (multi-operand chained composition with hand-unrolled special cases for 3–8 inputs and recursive divide-and-conquer for 9+), `_af_commutes_with`, etc. |
| `polyhedron.py` | Implements the `Polyhedron` class for representing polyhedral symmetry groups, with pre-built instances for the five Platonic solids (tetrahedron, cube, octahedron, dodecahedron, icosahedron). |
| `prufer.py` | Implements the `Prufer` class for the bijection between labeled trees and Prufer sequences, with ranking/unranking and tree-edge conversion methods. |
| `rewritingsystem.py` | Implements `RewritingSystem` for Knuth-Bendix completion on finitely presented groups, used for word reduction and confluence checking. |
| `subsets.py` | Implements the `Subset` class for representing a chosen collection of elements relative to a parent set, with methods to compute the ordering position (rank) of that collection under binary, lexicographic, and reflected-binary-code (Gray code) orderings, as well as enumeration and unranking. |
| `tensor_can.py` | Algorithms for **tensor expression canonicalization** (simplifying indexed tensor products, not constructing symmetry groups): computes canonical forms via permutation-group double-coset representatives, builds strong generating sets for dummy-index slot symmetries (`dummy_sgs`), implements the Butler-Portugal canonicalization algorithm, and provides BSGS minimality utilities (`get_minimal_bsgs` attempts to compute a lexicographically minimal BSGS—returns None on failure—and `_is_minimal_bsgs` checks minimality). |
| `testutil.py` | Testing utilities for the combinatorics module: naive centralizer computation, brute-force tensor canonicalization (`canonicalize_naive` — normalizes metric symmetry arguments by wrapping a single integer `sym` into a list for uniform processing, generates dummy-index substitution permutations, enumerates all equivalent forms under slot symmetries and dummy-index substitutions, sorts them, and detects zero tensors when consecutive sorted representations differ only in sign position), BSGS verification, normal closure checks, and graph certificate comparison. |
| `util.py` | Internal utility functions for computational group theory: base ordering, cycle checks for alternating/symmetric detection, the low-level permutation decomposition helper `_strip` and its array-form variant `_strip_af` (which decompose a permutation element level-by-level through orbit transversals in a BSGS, returning the residual element and the level reached — these are stateless helpers that do not decide how to handle sift outcomes; the calling algorithm in `perm_groups.py` decides what to do with the result), redundant generator removal `_remove_gens` (prunes a strong generating set by iterating stabilizer levels in reverse and testing whether each generator can be dropped without shrinking the basic orbit, skipping removal when it would leave zero generators at a level), distribution of strong generators by base stabilizers (`_distribute_gens_by_base` — assigns each generator to all stabilizer levels it qualifies for based on how many leading base points it fixes, and fills any deeper stabilizer levels beyond the reach of all generators with the identity permutation as a fallback), lazy computation of missing BSGS structures (transversals, basic orbits, distributed strong generators) from precomputed data (`_handle_precomputed_bsgs`), and orbit/transversal calculation from base and strong generating sets. |
