# sympy/combinatorics -- Catalog

> Part of [SymPy](../catalog.md). Combinatorics: permutations, partitions, polyhedra, group theory, and Graycode.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package initializer; imports and re-exports the main public classes and functions (Permutation, Prufer, Subset, Partition, Polyhedron, PermutationGroup, GrayCode, named groups, etc.). |
| `fp_groups.py` | Defines `FpGroup` (finitely presented groups given by generators and relator words), `CosetTable` class with word-tracing (scanning) methods — `scan` traces a relator word through the coset table from both ends and calls the `coincidence` identification routine when an incorrectly completed traversal is detected, while `scan_check` is a boolean-returning variant (used in low-index subgroup enumeration) that returns False instead of triggering the coincidence routine — and Todd-Coxeter coset enumeration algorithms for enumerating subgroup cosets within a finitely presented group (not BSGS orbit transversals — those are in `util.py`) (`coset_enumeration_r` relator-based, `coset_enumeration_c` coset-table-based), low-index subgroup enumeration, Reidemeister-Schreier presentations, and permutation group isomorphism. Not for enumerating elements of permutation groups (see `perm_groups.py`). |
| `free_group.py` | Implements `FreeGroup` and `FreeGroupElement` for constructing and manipulating free groups (finitely-generated groups with no relations, built from non-commuting generators and their inverses) and their elements (associative words). Element-level methods include `is_independent`/`is_dependent` (checking whether two elements are independent or dependent as words), `contains_generators`, `cyclic_conjugates`, `is_cyclic_conjugate`, `cyclic_subword`, word-level arithmetic, element equality, and short-lex total ordering. Group-level methods include `center()` (trivially just the identity for rank ≥ 2), `contains` for membership testing (checks isinstance and verifies the element's parent group matches `self` — silently returns False for elements created from a different group instance of the same kind, rather than raising an error), and `_parse_symbols` for parsing generator inputs. |
| `generators.py` | Generator functions that **yield every individual permutation element** (not group objects) of standard groups: `symmetric`, `cyclic`, `alternating`, `dihedral`, and `rubik` (NxN puzzle cube permutation generator that contains the full simulation logic for modeling face rotations, single-plane slice rotations, and whole-cube rotations — whole-cube rotation from a given face rotates that face clockwise, the opposite face counterclockwise, then cycles the four adjacent faces while individually reorienting each; rotating the plane at index 0 additionally rotates the corresponding face, while deeper planes only cycle edge rows across adjacent faces). The `dihedral(n)` function contains explicit special-case handling for n=1 (embeds in S2) and n=2 (Klein 4-group embedded in S4) where the standard Sn subgroup embedding doesn't work. Returns iterables of `Permutation` instances, not `PermutationGroup`. |
| `graycode.py` | Implements the `GrayCode` class for generating and manipulating raw Gray code sequences (reflected binary codes) over n-dimensional binary cubes — sequence generation, iteration, and low-level rank/unrank of binary codewords. Does not handle ranking of element collections relative to a parent set (see `subsets.py`). |
| `group_constructs.py` | Provides the `DirectProduct` convenience wrapper for computing the direct product of **three or more** permutation groups in a single batch call with generator deduplication (via `uniq`). Thin wrapper that delegates to the same index-shifting approach as `PermutationGroup.__mul__`; for exactly **two** groups or to understand how domain remapping/index shifting works, see `__mul__` in `perm_groups.py` which is the primary implementation. |
| `homomorphisms.py` | Implements `GroupHomomorphism` and a `homomorphism()` factory for creating and working with group homomorphisms between permutation groups and finitely presented groups. |
| `named_groups.py` | Factory functions that **construct `PermutationGroup` objects** (not element iterators) for standard named groups: `SymmetricGroup`, `CyclicGroup`, `DihedralGroup`, `AlternatingGroup` (with odd/even-n generator selection), `AbelianGroup`, and `RubikGroup`. Each function chooses minimal generating sets and pre-caches group properties (abelian, solvable, transitive, etc.). Small-n special cases select different generators but do not address embedding-degree concerns. Returns `PermutationGroup` instances with metadata, not individual permutation elements. |
| `partitions.py` | Defines `Partition` (a set of disjoint sets whose union equals a given set — i.e. a set partition into disjoint blocks) and `IntegerPartition` classes. The **constructor** performs strict type validation: each group/block argument must be a `list` or `FiniteSet` — tuples and other iterables are rejected with a ValueError; also checks for duplicate elements across blocks. `Partition` supports **modular arithmetic on rank** — `__add__`/`__sub__` increment or decrement the partition's ordinal position with automatic wraparound (modulo the total number of partitions of the same elements, computed via `RGS_enum`), so incrementing beyond the maximum wraps back to the beginning. Also provides comparison via `sort_key`, and a cached `rank` property that returns the numerical position of a partition among all partitions of the same set — uses a `_rank is not None` guard to avoid recomputation, delegating to `RGS_rank` on first access. Also provides RGS (restricted growth string) conversion, and standalone `RGS_rank`/`RGS_unrank` utility functions for mapping between set partitions and their integer ranks. |
| `perm_groups.py` | Core `PermutationGroup` class and standalone helper functions including `_stabilizer` (computes the stabilizer subgroup of a point using Schreier's lemma — builds forward and inverse coset representative tables, then derives Schreier generators as compositions of inverse table entries, group generators, and forward table entries) and `_orbit_transversal` (computes a transversal for the orbit of a point). The class implements group-theoretic operations: the **constructor (`__new__`)** normalizes generators of mismatched degrees (sizes) to a common degree — detects size variety among input permutations and pads all generators to the maximum size (or a user-specified `degree` keyword), so mismatched-degree generators are reconciled here, not in `group_constructs.py`; full group element enumeration via Dimino's algorithm (incremental subgroup-building that processes one generator at a time, expanding via coset representatives) and Schreier-Sims-based generation via `generate_schreier_sims` (yields elements in coset-rank order using basic transversals — with fallback: if transversals are empty, simply yields the generators; if only one transversal level, iterates the single orbit without full backtracking), `orbit_rep` (finds a group element sending one point to another via Schreier vectors — returns False if the target is not in the orbit, and returns the identity permutation when source and destination are the same point), deterministic (`schreier_sims`), **incremental** (`schreier_sims_incremental` — extends a given base and generating set into a full BSGS by computing Schreier generators, sifting them through the chain via `_strip_af`, and amending the stabilizer chain when sifting fails; when a non-trivial residual fixes all current base points, it appends a new moved point to the base and extends data structures accordingly), and **randomized** (`schreier_sims_random` — probabilistic BSGS computation that calls `_strip` from `util.py` to sift random elements, then handles all sift outcomes: amends the stabilizer chain on failed sifts, extends the base when a non-trivial residual passes through all existing levels, and halts after consecutive successful sifts for a probabilistic correctness guarantee), `__mul__` computes the direct product (Cartesian product) of exactly **two** permutation groups by remapping the second group's action domain — shifts all indices of the second group's generators by n1 (the first group's degree) so the two domains don't overlap, then concatenates generators to form a group acting on n1+n2 points (for 3+ groups use the batch wrapper in `group_constructs.py`), `make_perm` composes n randomly-selected group elements starting from the identity (accepts either an integer count with optional seed, or a list of selection indices as the first argument — raises ValueError if both a sequence and a seed are provided), `random` and `random_pr` (product-replacement random element generation), order, orbits, stabilizers (single-point and **pointwise** — `pointwise_stabilizer` returns a `PermutationGroup` subgroup fixing every point in a given set, using incremental Schreier-Sims with those points as a base prefix), BSGS base swapping (`baseswap` — swaps two consecutive base points with both deterministic and randomized modes; the deterministic branch iterates over orbit candidates, computes inverse images under transversal elements, prunes candidates by removing entire orbits when the inverse image falls outside the next-level basic orbit, and accumulates new stabilizer generators), `max_div` property (maximum proper divisor of the group's degree — returns degree divided by its smallest prime factor, with a degree-1 edge case returning 1), basic orbits/stabilizers/transversals properties, coset decomposition with ranking/unranking (`coset_rank` maps a group element to its numerical index, `coset_unrank` converts a numerical index back into a group element by decomposing through BSGS stabilizer-chain transversals via repeated divmod — returns None for out-of-range indices), subgroup testing, depth-first subgroup search with property predicates (`subgroup_search` — traverses a search tree using BSGS structure with minimality bounds mu/nu at each level; when backtracking above the current frontier level, recomputes orbit representatives and updates the upper bound nu: if the computed index exceeds the sorted orbit entries, assigns a sentinel fallback value `base_ordering[degree]` representing an element larger than all points to effectively remove the upper bound constraint), center and centralizer computation (`centralizer` — computes the subgroup of elements that commute with a given input via optimized subgroup search (for brute-force/naive centralizer testing, see `testutil.py`)), derived series and derived subgroups, commutator of two subgroups (group-level, not element-level — for the element-level group-theoretic bracket of two individual permutations, see `permutations.py`), and normal closure. |
| `permutations.py` | Core `Permutation` and `Cycle` classes for representing and manipulating **individual** permutations (bijections on finite sets) in array and cyclic notation. `Cycle` is a **dict subclass** representing a single cycle as a dictionary-based circular element mapping — its `__init__` builds key-value pairs using negative-index iteration so the last element wraps around to map back to the first element; supports composition via `__call__`. `__mul__` composes two permutations, padding the shorter array to reconcile different domain sizes. `cycle_structure` property returns a dictionary mapping each cycle length to its multiplicity count (with special handling for fixed points/singletons — elements mapping to themselves — counted as length-1 cycles), `cycles` returns total cycle count including singletons, `transpositions` decomposes a permutation into a product of 2-element swaps (transpositions) — this is purely a representation conversion, not related to BSGS sifting or orbit transversals. Also supports inversion, parity, element-level `commutator` (computes the group-theoretic bracket ~x*~self*x*self for two individual permutations — raises ValueError if domain sizes differ, unlike `__mul__` which pads to reconcile sizes), combinatorial (not group-theoretic) ranking of individual permutations: lexicographic ranking (`rank`), non-lexicographic linear-time ranking/unranking (`rank_nonlex`, `unrank_nonlex`), Trotter-Johnson ranking/unranking (`rank_trotterjohnson`, `unrank_trotterjohnson`) — these rank permutations in enumeration orderings, not via stabilizer-chain decomposition, inversion-vector construction (`from_inversion_vector`), merge-sort-based inversion counting (module-level `_merge` helper), and low-level array-form helpers: `_af_rmul` (two-operand composition), `_af_rmuln` (multi-operand chained composition with hand-unrolled special cases for 3–8 inputs and recursive divide-and-conquer for 9+), `_af_commutes_with`, etc. |
| `polyhedron.py` | Implements the `Polyhedron` class for representing 3D polyhedral (solid) symmetry groups — specifically the five Platonic solids (tetrahedron, cube, octahedron, dodecahedron, icosahedron) with their face/vertex permutations. Not for 2D regular polygon symmetries or dihedral groups (see `generators.py` for dihedral group element generation, `named_groups.py` for `DihedralGroup` construction). |
| `prufer.py` | Implements the `Prufer` class for the bijection between labeled trees and Prufer sequences, with ranking/unranking and tree-edge conversion methods. |
| `rewritingsystem.py` | Implements `RewritingSystem` for Knuth-Bendix completion on finitely presented groups, used for word reduction and confluence checking. |
| `subsets.py` | Implements the `Subset` class for representing a chosen sub-collection of elements relative to a universal parent set (superset). The **constructor (`__new__`)** validates that (1) the subset is not larger than the superset, and (2) every element in the subset exists in the superset — the membership-check error message uses `%i` integer format specifier to interpolate the offending element, which causes a TypeError when the element is a non-integer type such as a string. Provides methods to compute the ordering position (rank) of that sub-collection under binary, lexicographic, and reflected-binary-code (Gray code) orderings, as well as enumeration and unranking. The lexicographic ranking uses a recursive algorithm that walks through the parent set positions: when an element is present in the sub-collection it adds 1 and recurses, when absent it adds 2^(n-i-1) (skipping the entire subtree of subsets containing that element) and recurses — this power-of-2 skip logic determines the dictionary-order position. |
| `tensor_can.py` | Low-level algorithms for **tensor expression canonicalization** (simplifying indexed tensor products into canonical forms — operates on raw permutation representations of tensor slot symmetries, not on graphs or network structures): computes canonical forms via permutation-group double-coset representatives, builds slot-symmetry generators for dummy indices (`dummy_sgs`), `transversal2coset` (converts BSGS transversals into a coset representation for tensor canonicalization — positions in the base use actual transversal values, non-base positions are filled with the full symmetric group identity list, then trailing entries equal to the full group are trimmed off), and implements the Butler-Portugal canonicalization algorithm. Also provides `get_minimal_bsgs` (attempts to compute a lexicographically minimal BSGS — recomputes the stabilizer chain via `schreier_sims_incremental`, checks minimality with `_is_minimal_bsgs`, and **returns None** if the recomputed chain is not minimal; has a TODO note about using baseswap as an alternative recovery strategy but currently does not attempt it) and `_is_minimal_bsgs` (checks whether a given BSGS has a lexicographically minimal base by rebuilding the base from scratch and comparing). Does **not** contain permutation sifting algorithms, stabilizer-chain construction, or BSGS computation — those live in `util.py` (`_strip`, `_strip_af`) and `perm_groups.py` (`schreier_sims`, `schreier_sims_random`, `schreier_sims_incremental`). |
| `testutil.py` | Testing utilities for the combinatorics module: brute-force naive centralizer computation (`_naive_list_centralizer` — enumerates all group elements via Dimino's algorithm and filters those that commute with every generator; dispatches on input type via `hasattr` checks: if the second argument has `generators` it treats it as a group, if it has `getitem` it wraps the collection into a PermutationGroup, and if it has `array_form` it wraps the single element into a one-element PermutationGroup, then recurses), brute-force tensor canonicalization (`canonicalize_naive` — normalizes metric symmetry arguments by wrapping a single integer `sym` into a list for uniform processing, generates dummy-index substitution permutations, enumerates all equivalent forms under slot symmetries and dummy-index substitutions, sorts them, and detects zero tensors when consecutive sorted representations differ only in sign position), BSGS verification, normal closure checks, and `graph_certificate` — computes an isomorphism-invariant identifier for an undirected graph by encoding it as a multi-index tensor contraction problem (each vertex becomes a symmetric tensor whose rank equals the vertex degree, edges become contracted index pairs with even/odd assignment based on vertex priority after sorting by degree), then finds the canonical form of the resulting permutation to produce a certificate that is identical for isomorphic graphs. |
| `util.py` | Internal utility functions for computational group theory: `_base_ordering` (assigns a priority position to each point in {0,...,n-1} for backtrack searches — base points receive positions 0..k-1 in base order, non-base points are assigned positions starting from k in increasing natural order, so all base points sort before all non-base points), `_check_cycles_alt_sym` (checks whether a permutation contains a cycle of prime length p with n/2 < p < n-2, used for alternating/symmetric group identification — iterates through points to trace cycles, with an early-termination guard `i < n//2 - total_len` that stops the loop when accumulated cycle lengths make it impossible for any remaining cycle to exceed n/2), the low-level permutation **sifting** helpers `_strip` and its optimized array-form variant `_strip_af` (which sift a permutation element level-by-level through orbit transversals in a BSGS chain, returning the residual element and the level reached; `_strip_af` has a special identity short-circuit: when the current element exactly equals the transversal element at a level, it returns `False` instead of an array form to signal the identity — this edge case is absent from the non-optimized `_strip`; both are stateless helpers that do not decide how to handle sift outcomes; the calling algorithm in `perm_groups.py` decides what to do with the result), **post-hoc redundant generator elimination** via `_remove_gens` — the dedicated function for trimming an already-computed strong generating set down to a smaller subset that still generates the same group; works by iterating stabilizer levels in reverse and testing whether each generator can be dropped without shrinking the basic orbit at that level, skipping removal when it would leave zero generators (based on Holt, Eick, O'Brien p.95); this is a *pruning/reduction* operation on an existing BSGS, not a BSGS construction algorithm), distributing permutation group generators into basic stabilizer chains (`_distribute_gens_by_base` — returns a list of generator lists, one per base point; assigns each generator to all stabilizer levels it qualifies for based on how many leading base points it fixes; for stabilizer levels deeper than any generator actually stabilizes (i.e., remaining entries beyond the deepest level any generator reaches), fills those entries with the identity permutation as a placeholder), lazy computation of missing BSGS structures (transversals, basic orbits, distributed strong generators) from precomputed data (`_handle_precomputed_bsgs`), and `_orbits_transversals_from_bsgs` which computes basic orbits and transversal dictionaries (coset representative mappings) from a base and distributed strong generators — accepts a `transversals_only` flag that changes the return type: when True returns only the transversals list, when False (default) returns a tuple of (basic_orbits, transversals). |
