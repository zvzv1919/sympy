# sympy/combinatorics -- Catalog

> Part of [SymPy](../catalog.md). Combinatorics: permutations, partitions, polyhedra, group theory, and Graycode.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package initializer; imports and re-exports the main public classes and functions (Permutation, Prufer, Subset, Partition, Polyhedron, PermutationGroup, GrayCode, named groups, etc.). |
| `coset_table.py` | Implements the `CosetTable` class and Todd-Coxeter coset enumeration algorithms (relator-based and coset-table-based) for finitely presented groups. |
| `fp_groups.py` | Defines `FpGroup` (finitely presented groups) and related algorithms including low-index subgroup enumeration, Reidemeister-Schreier presentations, and permutation group isomorphism. |
| `free_groups.py` | Implements `FreeGroup` and `FreeGroupElement` for constructing and manipulating free groups and their elements with word-level arithmetic. |
| `generators.py` | Provides generator functions that **yield individual `Permutation` elements** (not `PermutationGroup` objects) of standard groups: `symmetric`, `cyclic`, `alternating`, `dihedral`, and Rubik's cube generators. The `dihedral(n)` generator includes special-case handling for degenerate polygons (n=1, n=2) where the group cannot naturally embed in Sn, hardcoding embeddings in S2 and S4 respectively. The `rubik(n)` function generates permutations for an arbitrary n×n Rubik's cube using face-matrix manipulation; when rotating the outermost slice (index 0), it additionally rotates the corresponding face itself, unlike deeper interior slices which only cycle adjacent strips. For constructing named group *objects* (`PermutationGroup`) with pre-set algebraic properties, see `named_groups.py`. |
| `graycode.py` | Implements the `GrayCode` class for generating and manipulating Gray codes (reflected binary codes) over n-dimensional binary cubes. |
| `group_constructs.py` | Provides the `DirectProduct` function for computing the direct product of multiple `PermutationGroup` objects (high-level group API). For BSGS-level direct products used in tensor canonicalization, see `tensor_can.py`. |
| `homomorphisms.py` | Implements `GroupHomomorphism` and a `homomorphism()` factory for creating and working with group homomorphisms between permutation groups and finitely presented groups. |
| `named_groups.py` | Factory functions for constructing standard named `PermutationGroup` objects: `SymmetricGroup`, `CyclicGroup`, `DihedralGroup`, `AlternatingGroup`, `AbelianGroup`, and `RubikGroup`. Each factory **pre-sets algebraic properties** (commutativity, nilpotency, solvability) on the returned group based on element-count thresholds (e.g., the alternating group is marked non-solvable at n≥5, non-abelian/non-nilpotent at n≥4). Small degenerate cases (n=1, n=2) receive special handling with trivial generators. For yielding individual permutation elements rather than group objects, see `generators.py`. |
| `partitions.py` | Defines `Partition` (set partitions) and `IntegerPartition` classes, along with RGS (restricted growth string) ranking/unranking utilities. |
| `perm_groups.py` | Core `PermutationGroup` class implementing group-theoretic operations: order, orbits, stabilizers, centralizer computation, Schreier-Sims algorithm (including `schreier_sims_incremental` — the polynomial-time incremental variant that extends a partial base/generating set to a full BSGS, handling edge cases like generators that fix all existing base points by appending new moved points, identity removal, and trivial-group shortcuts), coset decomposition, subgroup testing, and general `subgroup_search` (backtrack search with per-level pruning predicates built from orbit representatives and transversals). Also contains standalone module-level orbit functions that do **not** require BSGS data: `_orbit` computes the set of elements reachable from a starting point via BFS-like expansion over generators (supports action modes for unions, tuples, and frozensets), using a boolean `used` array to track visited indices; `_orbits` partitions the full index set {0,…,degree−1} into disjoint equivalence classes by repeatedly picking the smallest unassigned index, computing its orbit via `_orbit`, removing those indices from the remaining set, and repeating until all indices are assigned. The constructor (`__new__`) accepts generators of different sizes and automatically pads them to a uniform degree, reconciling domain-size mismatches. For building a group as a direct product of existing groups, see `group_constructs.py`. For BSGS-specific orbit/transversal computation from a base and distributed strong generators, see `util.py::_orbits_transversals_from_bsgs`. |
| `permutations.py` | Core `Permutation` and `Cycle` classes for representing and manipulating individual permutations in array and cyclic notation, with support for composition, inversion, parity, and lexicographic ranking. The `rank()` method computes the lexicographic position of a permutation using the Lehmer code (factorial number system) and caches the result in `_rank` for repeated lookups. Also provides `unrank_lex`/`unrank_nonlex` for reconstructing permutations from rank, and `next_lex`/`next_nonlex` for iteration. For subset-level lexicographic ranking, see `subsets.py`. |
| `polyhedron.py` | Implements the `Polyhedron` class for representing polyhedral symmetry groups, with pre-built instances for the five Platonic solids (tetrahedron, cube, octahedron, dodecahedron, icosahedron). Includes internal helper functions such as a shorthand string parser (`_string_to_perm`) that composes face-rotation permutations for the dodecahedron pgroup — characters '0'/'1' select base rotations while other digit characters act as repeat-count multipliers for the previous rotation. Also contains `_pgroup_of_double` for computing dual-polyhedron permutation groups. The constructor docstring demonstrates how applying symmetry group elements generates all valid orientations of a solid and verifies that sequential transformation application equals composite permutation application. |
| `prufer.py` | Implements the `Prufer` class for the bijection between labeled trees and Prufer sequences, with ranking/unranking and tree-edge conversion methods. |
| `rewritingsystem.py` | Implements `RewritingSystem` for Knuth-Bendix completion on finitely presented groups, used for word reduction and confluence checking. |
| `subsets.py` | Implements the `Subset` class for enumerating subsets of a set via binary, lexicographic, and Gray code orderings with ranking/unranking support. Includes `rank_gray`/`unrank_gray` and `rank_binary`/`unrank_binary` for converting between ordinal positions and actual subset (power-set element) objects. The unranking methods (e.g., `unrank_gray`) compose a bit-pattern lookup with `subset_from_bitlist` to return a full `Subset` object — they live here, not in `graycode.py`. See `graycode.py` only for raw Gray code bit-pattern generation and ranking at the code level. |
| `tensor_can.py` | Algorithms for tensor canonicalization using permutation group double-coset representatives, including dummy-index symmetry handling. Also provides BSGS *composition* utilities specific to tensor contexts: `bsgs_direct_product` for combining two BSGS structures, `perm_af_direct_product` for generator-level direct products, and `get_symmetric_group_sgs` for minimal BSGS of (anti)symmetric tensors. Does **not** contain general BSGS construction algorithms (Schreier-Sims, incremental BSGS) — those live in `perm_groups.py`; low-level BSGS helpers (orbit/transversal computation, strip, distribution) are in `util.py`. |
| `testutil.py` | Testing/verification utilities for the combinatorics module. Contains naive (brute-force) reference implementations used to validate the optimized algorithms in `perm_groups.py` and `tensor_can.py`. Key functions: (1) `canonicalize_naive` — brute-force tensor canonicalization that enumerates all slot and dummy symmetry permutations, sorts them, and detects zero tensors by finding consecutive sorted permutations that agree on all positions except the last (differing sign); this is the naive counterpart to `tensor_can.py::double_coset_can_rep`. (2) Verification helpers for centralizer, BSGS, and normal closure — each accepts flexible input via duck-typing `hasattr` checks to distinguish a `PermutationGroup` (has `.generators`), a list/sequence of elements (has `__getitem__`), or a single `Permutation` (has `.array_form`), then computes the result naively for comparison. (3) `graph_certificate` — computes a graph certificate via canonical tensor forms. For production (optimized) algorithms, see `tensor_can.py` and `perm_groups.py`. |
| `util.py` | Internal low-level utility functions for computational group theory: base ordering, cycle checks for alternating/symmetric detection, BSGS-related strip and distribution routines, BSGS-specific orbit/transversal computation (`_orbits_transversals_from_bsgs` computes basic orbits and coset-representative transversals from a base and distributed strong generators — requires pre-computed BSGS data, with a flag to return transversals only), and redundant generator removal (`_remove_gens`). Does **not** contain general orbit-partitioning functions that work from raw generators without BSGS — those standalone `_orbit`/`_orbits` functions live in `perm_groups.py`. Does not contain high-level group algorithms (centralizer, normalizer, subgroup search, Schreier-Sims) — those also live in `perm_groups.py`. |
