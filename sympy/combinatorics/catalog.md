# sympy/combinatorics -- Catalog

> Part of [SymPy](../catalog.md). Combinatorics: permutations, partitions, polyhedra, group theory, and Graycode.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package initializer; imports and re-exports the main public classes and functions (Permutation, Prufer, Subset, Partition, Polyhedron, PermutationGroup, GrayCode, named groups, etc.). |
| `coset_table.py` | Implements the `CosetTable` class and Todd-Coxeter coset enumeration algorithms (relator-based and coset-table-based) for finitely presented groups. |
| `fp_groups.py` | Defines `FpGroup` (finitely presented groups) and related algorithms including low-index subgroup enumeration, Reidemeister-Schreier presentations, and permutation group isomorphism. |
| `free_groups.py` | Implements `FreeGroup` and `FreeGroupElement` for constructing and manipulating free groups and their elements with word-level arithmetic. |
| `generators.py` | Provides generator functions that **yield individual `Permutation` elements** (not `PermutationGroup` objects) of standard groups: `symmetric`, `cyclic`, `alternating`, `dihedral`, and Rubik's cube generators. The `dihedral(n)` generator includes special-case handling for degenerate polygons (n=1, n=2) where the group cannot naturally embed in Sn, hardcoding embeddings in S2 and S4 respectively. The `rubik(n)` function generates permutations for an arbitrary n×n Rubik's cube using face-matrix manipulation; when rotating the outermost slice (index 0), it additionally rotates the corresponding face itself, unlike deeper interior slices which only cycle adjacent strips. For constructing named group *objects* (`PermutationGroup`) with pre-set algebraic properties, see `named_groups.py`. |
| `graycode.py` | Implements the `GrayCode` class for generating and manipulating Gray codes (reflected binary codes) over n-dimensional binary cubes. The `rank` property gives the ordinal position of a raw bit-pattern string within the Gray code sequence — it does **not** accept subset objects (for ranking a chosen subset within Gray code order, see `subsets.py::Subset.rank_gray`). Also provides standalone module-level conversion functions: `gray_to_bin` (converts reflected binary encoding back to standard positional binary using cumulative XOR), `bin_to_gray` (converts standard binary to reflected binary), `get_subset_from_bitstring` (extracts a subset from a set using a bitmask string), and `graycode_subsets` (enumerates all subsets in Gray code order). |
| `group_constructs.py` | Provides the `DirectProduct` function for computing the direct product of multiple `PermutationGroup` objects (high-level group API); operates on group objects, not on raw BSGS base/generator pairs, and does not filter identity permutations. For BSGS-level direct products that combine base-and-strong-generating-set structures (with identity filtering and signed-permutation support), see `tensor_can.py::bsgs_direct_product`. |
| `homomorphisms.py` | Implements `GroupHomomorphism` and a `homomorphism()` factory for creating and working with group homomorphisms between permutation groups and finitely presented groups. |
| `named_groups.py` | Factory functions for constructing standard named `PermutationGroup` objects: `SymmetricGroup`, `CyclicGroup`, `DihedralGroup`, `AlternatingGroup`, `AbelianGroup`, and `RubikGroup`. Each factory **pre-sets algebraic properties** (commutativity, nilpotency, solvability) on the returned group based on element-count thresholds (e.g., the alternating group is marked non-solvable at n≥5, non-abelian/non-nilpotent at n≥4). Small degenerate cases (n=1, n=2) receive special handling with trivial generators. For yielding individual permutation elements rather than group objects, see `generators.py`. |
| `partitions.py` | Defines `Partition` (set partitions) and `IntegerPartition` classes, along with RGS (restricted growth string) ranking/unranking utilities. |
| `perm_groups.py` | Core `PermutationGroup` class implementing group-theoretic operations: order, orbits, stabilizers, centralizer computation, normal closure (`normal_closure` computes the smallest normal subgroup containing a given input — uses `hasattr`-based type dispatch at the end of the method to accept a `PermutationGroup`, a list/sequence of permutations, or a single `Permutation` element, wrapping the latter cases into a `PermutationGroup` and recursing), orbit representative computation (`orbit_rep` finds a group element mapping one point to another using the Schreier vector — when the source and target points are identical, the while-loop accumulator stays empty and the method returns an identity permutation via `range(degree)` instead of composing generators), Schreier-Sims algorithm (including `schreier_sims_incremental` — the polynomial-time incremental variant that extends a partial base/generating set to a full BSGS, handling edge cases like generators that fix all existing base points by appending new moved points, identity removal, and trivial-group shortcuts), coset decomposition, subgroup testing, and general `subgroup_search` (backtrack search with per-level pruning predicates built from orbit representatives and transversals). Also contains standalone module-level orbit functions that do **not** require BSGS data: `_orbit` computes the set of elements reachable from a starting point via BFS-like expansion over generators (supports action modes for unions, tuples, and frozensets), using a boolean `used` array to track visited indices; `_orbits` partitions the full index set {0,…,degree−1} into disjoint equivalence classes by repeatedly picking the smallest unassigned index, computing its orbit via `_orbit`, removing those indices from the remaining set, and repeating until all indices are assigned. The constructor (`__new__`) accepts generators of different sizes and automatically pads them to a uniform degree, reconciling domain-size mismatches. For building a group as a direct product of existing groups, see `group_constructs.py`. For BSGS-specific orbit/transversal computation from a base and distributed strong generators, see `util.py::_orbits_transversals_from_bsgs`. |
| `permutations.py` | Core `Permutation` and `Cycle` classes for representing and manipulating individual permutations in array and cyclic notation, with support for composition, inversion, parity, and lexicographic ranking. The `rank()` method computes the lexicographic position of a permutation using the Lehmer code (factorial number system) and caches the result in `_rank` for repeated lookups. Also provides `unrank_lex`/`unrank_nonlex` for reconstructing permutations from rank, and `next_lex`/`next_nonlex` for iteration. Includes the `josephus` classmethod — a deque-based simulation of the Josephus circular elimination problem (every m-th element is removed from a ring of n elements) that returns the elimination order as a `Permutation`; has a parameter `s` that switches the step size to 1 when `s` items remain, selecting the remainder one-by-one. Also provides permutation distance metrics: `get_positional_distance` (L1/element-wise), `get_precedence_distance`, and `get_adjacency_distance`. For subset-level lexicographic ranking, see `subsets.py`. |
| `polyhedron.py` | Implements the `Polyhedron` class for representing polyhedral symmetry groups, with pre-built instances for the five Platonic solids (tetrahedron, cube, octahedron, dodecahedron, icosahedron). Includes internal helper functions such as a shorthand string parser (`_string_to_perm`) that composes face-rotation permutations for the dodecahedron pgroup — characters '0'/'1' select base rotations while other digit characters act as repeat-count multipliers for the previous rotation. Also contains `_pgroup_of_double` for computing dual-polyhedron permutation groups. The constructor docstring demonstrates how applying symmetry group elements generates all valid orientations of a solid and verifies that sequential transformation application equals composite permutation application. |
| `prufer.py` | Implements the `Prufer` class for the bijection between labeled trees and Prufer sequences, with ranking/unranking and tree-edge conversion methods. |
| `rewritingsystem.py` | Implements `RewritingSystem` for Knuth-Bendix completion on finitely presented groups, used for word reduction and confluence checking. |
| `subsets.py` | Implements the `Subset` class for enumerating subsets of a set via binary, lexicographic, and Gray code orderings with ranking/unranking support. Includes `rank_gray`/`unrank_gray` and `rank_binary`/`unrank_binary` for converting between ordinal positions and actual subset (power-set element) objects. `rank_gray` determines the ordinal position of a chosen collection of elements within Gray code ordering by converting the subset to a bit-list and delegating to `GrayCode.rank`. The unranking methods (e.g., `unrank_gray`) compose a bit-pattern lookup with `subset_from_bitlist` to return a full `Subset` object — they live here, not in `graycode.py`. Any question about ranking or unranking a **subset** (collection of elements from a universal set) in Gray code order belongs here; see `graycode.py` only for raw bit-pattern-level Gray code generation, conversion between binary and reflected binary encodings, and bit-string ranking without subset semantics. |
| `tensor_can.py` | Algorithms for tensor canonicalization using permutation group double-coset representatives, including dummy-index symmetry handling. Also provides BSGS *composition* utilities specific to tensor contexts: `bsgs_direct_product` for combining two base-and-strong-generating-set (BSGS) structures into a single BSGS — operates on base/generator pairs (not `PermutationGroup` objects), filters out identity permutations from the combined generators, and falls back to returning a single identity generator when all combined generators reduce to the identity; `perm_af_direct_product` for generator-level direct products in array form; and `get_symmetric_group_sgs` for minimal BSGS of (anti)symmetric tensors. Does **not** contain general BSGS construction algorithms (Schreier-Sims, incremental BSGS) — those live in `perm_groups.py`; low-level BSGS helpers (orbit/transversal computation, strip, distribution) are in `util.py`. |
| `testutil.py` | Testing/verification utilities for the combinatorics module. Contains **only** naive (brute-force) reference implementations used in test suites to validate the optimized algorithms in `perm_groups.py` and `tensor_can.py` — never called in production codepaths. Key functions: (1) `canonicalize_naive` — brute-force tensor canonicalization that enumerates all slot and dummy symmetry permutations, sorts them, and detects zero tensors by finding consecutive sorted permutations that agree on all positions except the last (differing sign); this is the naive counterpart to `tensor_can.py::double_coset_can_rep`. (2) `_verify_centralizer`, `_verify_bsgs`, `_verify_normal_closure` — naive verification wrappers that mirror the `hasattr`-based duck-typing dispatch found in the production `perm_groups.py` methods but compute results via brute-force enumeration for correctness checking. (3) `graph_certificate` — computes a graph certificate via canonical tensor forms. For production (optimized) algorithms including normal closure computation, orbit representatives, and type-dispatch logic, see `perm_groups.py`. |
| `util.py` | Internal low-level utility functions for computational group theory: base ordering, cycle checks for alternating/symmetric detection, BSGS-related strip and distribution routines, BSGS-specific orbit/transversal computation (`_orbits_transversals_from_bsgs` computes basic orbits and coset-representative transversals from a base and distributed strong generators — requires pre-computed BSGS data, with a flag to return transversals only), and redundant generator removal (`_remove_gens`). Does **not** contain general orbit-partitioning functions that work from raw generators without BSGS — those standalone `_orbit`/`_orbits` functions live in `perm_groups.py`. Does not contain high-level group algorithms (centralizer, normalizer, subgroup search, Schreier-Sims) — those also live in `perm_groups.py`. |
