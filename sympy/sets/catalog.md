# sympy/sets — Catalog

> Part of [SymPy](../catalog.md). Set theory: intervals, unions, intersections, finite sets, and conditional sets.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package entry point that re-exports the public API: `Set`, `Interval`, `Union`, `Intersection`, `EmptySet`, `FiniteSet`, `ProductSet`, `Complement`, `SymmetricDifference`, `ImageSet`, `Range`, `ComplexRegion`, `Contains`, `ConditionSet`, and the `imageset` helper. |
| `sets.py` | Core set-theory classes including the `Set` base class, `Interval`, `Union`, `Intersection` (the generic container/reducer for multi-set intersections), `Complement`, `SymmetricDifference`, `EmptySet`, `UniversalSet`, `FiniteSet`, and `ProductSet`, plus the `imageset` top-level helper function. The `imageset()` function is the primary entry point for computing forward images of sets under transformations — it is the **sole place** where different callable forms are normalized into a canonical representation: native Python `lambda` functions, symbolic `FunctionClass` objects (like `sin`), and explicit `(variable, expression)` pairs are all converted into symbolic `Lambda` wrappers (generating uniquely named variables as needed) before delegating to `ImageSet`; it also includes an identity-mapping shortcut. `Union.__iter__` implements element-by-element iteration over a combined collection of sets using a round-robin interleaving strategy, and raises `TypeError("Not all constituent sets are iterable")` when any member set does not support enumeration — this is distinct from `Range.__iter__` in `fancysets.py` which handles iteration over integer sequences. For the `ImageSet` class itself, see `fancysets.py`. `FiniteSet._eval_Eq` implements equality comparison for discrete sets: when the other operand is not also a `FiniteSet`, it returns indeterminate (`None`) for compound set types (`Union`, `Complement`, `Intersection`, `ProductSet`) but definitively `false` for all other set types (e.g., `Interval`). `Interval` implements `_union` with logic to merge overlapping continuous ranges — including the subtle case where a half-open endpoint is "filled in" (closed) when the other operand (e.g., a `FiniteSet`) contains that boundary point. `Interval._contains` builds logical expressions checking membership against open/closed bounds. Each set class implements `as_relational(symbol)` to rewrite itself as relational/logical expressions (e.g., `FiniteSet` becomes a disjunction of equalities, `Interval` becomes a conjunction of inequalities). `FiniteSet._contains` implements membership testing with three-valued logic: it iterates over elements comparing via `Eq(e, other)`, returning `true` immediately on a match, accumulating `None` if any comparison is indeterminate (symbolic equality that can't be resolved to true or false even after simplification), and returning that `None` (rather than `false`) at the end — this is the canonical place for handling indeterminate/symbolic membership in explicitly enumerated sets. Also includes set comparison operators and powerset evaluation. Note: type-specific `_intersect` methods for extended set types like `Range` live in `fancysets.py`, not here. |
| `fancysets.py` | Extended ("fancy") set types: `Naturals`, `Naturals0`, `Integers`, `Reals`, `ImageSet`, `Range` (finite or infinite integer sequences), `ComplexRegion` (polar/rectangular regions of the complex plane), and `normalize_theta_set`. `ImageSet` stores and evaluates a pre-normalized `Lambda` transformation over a base set — it does **not** handle conversion of raw Python callables or function classes into Lambda form (that normalization is performed by the `imageset()` helper in `sets.py`). `Range.__iter__` iterates over integer sequences and raises errors for infinite ranges, but iteration over *combined* collections of sets (with non-iterable member handling) is in `Union.__iter__` in `sets.py`. Each fancy set class implements its own `_intersect` method with type-specific logic — for example, `Range._intersect` handles intersection of a discrete integer sequence with a continuous `Interval`, adjusting effective start/end boundaries when the interval has open endpoints at integer values (ceiling/floor with membership checks). For the generic `Intersection` container class, see `sets.py`. |
| `contains.py` | Defines the `Contains` Boolean function, which represents the symbolic assertion that an element belongs to a set (element-of predicate). Does NOT convert sets into relational/logical form — see `as_relational` in `sets.py` for that. |
| `conditionset.py` | Defines `ConditionSet`, a set comprehension class representing `{x | condition(x) is True for x in S}`, with support for intersection and membership testing. `ConditionSet.__new__` handles the special case where the base set is a `FiniteSet` by sifting elements into definitely-true, definitely-false, and indeterminate buckets *at construction time* — this is distinct from runtime membership containment checks, which live in each set class's `_contains` method in `sets.py`. |
