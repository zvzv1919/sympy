# sympy/sets — Catalog

> Part of [SymPy](../catalog.md). Set theory: intervals, unions, intersections, finite sets, and conditional sets.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package entry point that re-exports the public API: `Set`, `Interval`, `Union`, `Intersection`, `EmptySet`, `FiniteSet`, `ProductSet`, `Complement`, `SymmetricDifference`, `ImageSet`, `Range`, `ComplexRegion`, `Contains`, `ConditionSet`, and the `imageset` helper. |
| `sets.py` | Core set-theory classes including the `Set` base class, `Interval`, `Union`, `Intersection`, `Complement`, `SymmetricDifference`, `EmptySet`, `UniversalSet`, `FiniteSet`, and `ProductSet`. The `Set` base class defines the `contains` method which handles element-membership queries: it delegates to `_contains` and, when membership is indeterminate (returns `None`), returns an unevaluated symbolic `Contains` expression instead of raising an error. `FiniteSet._contains` implements three-valued membership logic. `Intersection._handle_finite_sets` handles uncertain membership when computing the **intersection** of multiple sets (not condition-based filtering — that is in `conditionset.py`). Set classes here also implement `_eval_Eq` for symbolic equality (`Eq`) comparisons between sets — e.g., `Interval._eval_Eq` returns `None` (unevaluated) when the other object is a compound set type (Union, Complement, Intersection, ProductSet) but returns `false` for all other non-Interval types, enabling three-valued equality dispatch. Set classes here also implement `as_relational(symbol)` methods that rewrite a set as an equivalent logical/relational expression over `symbol` — e.g., `FiniteSet.as_relational` produces a disjunction (`Or`) of equality constraints (`Eq(symbol, elem)` for each element), while `Interval.as_relational` produces a conjunction of inequalities. This is the conversion path from set-theoretic representations to Boolean/relational form. Also contains the `imageset` top-level helper function — the primary entry point for constructing image sets. This function handles all input normalization — it **converts** native Python lambdas (`lambda x: ...`) and built-in math functions (like `sin`, `cos`, any `FunctionClass`) into symbolic `Lambda` objects by generating a uniquely named variable symbol to avoid name collisions, then wrapping the call into `Lambda(var, f(var))`. It also handles identity-function short-circuiting, and critically, **composition/flattening of nested image sets**: when the input set is itself an image set and both transformations are single-variable, it composes them into a single transformation over the underlying base set, avoiding nested wrappers. |
| `fancysets.py` | Extended ("fancy") set types: `Naturals`, `Naturals0`, `Integers`, `Reals`, `ImageSet`, `Range`, `ComplexRegion`, and `normalize_theta_set`. Each number-set class (`Naturals`, `Naturals0`, `Integers`) implements its own `_contains` method with three-valued membership logic — e.g., `Naturals._contains` returns `True` when the element is both positive and integer, `False` when it is definitely not an integer or definitely not positive, and implicitly `None` (indeterminate) when the element is known to be an integer but its positivity is unknown (and similarly `Naturals0._contains` checks `is_nonnegative`). `Range._contains` also propagates `None` when the candidate's integer nature is unknown, and uses `self.stop` as the reference point for infinite-start ranges. `ImageSet` represents {f(x) | x ∈ S} and implements its own `_contains` method with substantial membership-checking logic: it solves for candidate pre-image values (using equation solving for both scalar→scalar and scalar→vector mappings, and linear solving for multivariate cases), then iterates over solutions to verify each lies in the domain set. This verification loop includes `TypeError` exception handling — when the `in` operator raises `TypeError` on a candidate solution, the code falls back to numerical evaluation via `evalf()` and `contains()`. Note: `ImageSet` does **not** convert Python lambdas or perform composition/flattening (that lives in the `imageset()` helper in `sets.py`). `ComplexRegion` handles polar/rectangular regions of the complex plane with a `_contains` that iterates over internal `psets`. `Integers` includes `_eval_imageset` which simplifies image-set expressions over ℤ. |
| `contains.py` | Defines the `Contains` Boolean function — a symbolic element-of predicate. Its `eval` classmethod delegates to the set's `contains` method and guards against infinite recursion by returning `None` if the result is already a `Contains` instance. |
| `conditionset.py` | Defines `ConditionSet`, a set comprehension class representing `{x | condition(x) is True for x in S}`. The constructor (`__new__`) is where condition-based filtering and simplification happens: when the base set is a `FiniteSet`, it evaluates the user-supplied condition on each element using `fuzzy_bool` and `sift`, partitioning elements into True/False/None buckets. If all elements resolve, it returns a plain `FiniteSet` of the True elements; if some are indeterminate (`None`), it returns a `Union` of the definitely-true `FiniteSet` and a residual `ConditionSet` wrapping only the indeterminate elements. This is the file to look at for any question about constructing condition-filtered sets or partial evaluation of membership conditions. Note: this file does NOT handle converting sets into relational/logical form (that is `as_relational` in `sets.py`). Also supports intersection narrowing and condition-based symbolic membership testing (checking whether the condition predicate holds for a given element within the base set). |
