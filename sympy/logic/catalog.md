# sympy/logic — Catalog

> Part of [SymPy](../catalog.md). Boolean algebra, propositional logic, satisfiability (DPLL), and inference.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package entry point; re-exports core Boolean operations (And, Or, Not, Xor, Implies, etc.), normal-form converters (to_cnf, to_dnf, to_nnf), and the `satisfiable` function. |
| `boolalg.py` | Core Boolean algebra module defining the `Boolean` base class and all gate classes (And, Or, Not, Xor, Nand, Nor, Implies, Equivalent, ITE), plus normal-form conversions, simplification, truth tables, SOP/POS form construction. Includes Quine-McCluskey (QM) two-level logic minimization helpers: pairwise comparison of binary minterms/maxterms to find pairs differing in exactly one bit, merging such pairs by replacing the differing position with a don't-care sentinel, collecting unmerged (prime) implicants, and eliminating redundant implicants via a prime-implicant table. Also defines the CNF-to-integer encoding used by SAT solvers: `to_int_repr` converts CNF clauses into sets of signed integers, and `term_to_integer`/`integer_to_term` convert between integers and binary-term lists. |
| `inference.py` | Propositional logic inference — the **central dispatcher for satisfiability checking**. `satisfiable(expr, algorithm, all_models)` converts to CNF, then selects which backend solver to invoke based on the `algorithm` parameter (`"dpll"` or `"dpll2"`), and passes through the `all_models` flag to support returning all satisfying assignments as a generator. Also provides `valid`, `entails`, `pl_true` (evaluate a boolean expression under a partial truth assignment — in deep mode, when substitution is indeterminate, constructs an all-True heuristic assignment for remaining atoms and uses the result to branch between a tautology check and an unsatisfiability check), `literal_symbol`, and a simple `PropKB` knowledge base. |
| `algorithms/dpll.py` | Original **recursive-backtracking** DPLL satisfiability solver — the only file that implements the classic recursive branching/backtracking search. `dpll_satisfiable(expr)` converts expression to CNF then delegates to `dpll_int_repr`. The core recursive functions `dpll()` (symbolic) and `dpll_int_repr()` (integer representation) implement the search: apply unit-clause propagation and pure-symbol elimination loops, then evaluate each clause against the current partial model to collect unknown clauses, return the model if all clauses are satisfied, and otherwise **pop an unassigned variable, try assigning True first, and if that recursive branch returns False, backtrack and recurse with False** (simple chronological backtracking via Python call stack). Does **not** support `all_models`; always returns a single model or `False`. Includes `pl_true_int_repr` (three-valued clause evaluator) and standalone helper functions (each with a symbolic and an `_int_repr` variant): `find_unit_clause` / `find_unit_clause_int_repr` detect a clause where all but one variable are already assigned in the model; `find_pure_symbol` / `find_pure_symbol_int_repr` locate a symbol appearing only positive or only negative across clauses; `unit_propagate` / `unit_propagate_int_repr` simplify clauses given a propagated literal. These helpers are **only used by the recursive DPLL algorithm** in this file, not by the iterative solver in `dpll2.py`. |
| `algorithms/dpll2.py` | Improved **iterative** (non-recursive) DPLL SAT solver backend (invoked by `inference.satisfiable`). Built around the `SATSolver` class with clause learning, VSIDS branching heuristic, and two-watched-literal (sentinel) propagation. `dpll_satisfiable(expr, all_models=False)` converts to CNF and delegates to `SATSolver._find_model()`, which uses an explicit decision-level stack and conflict-driven **non-chronological backjumping** — all state is managed iteratively. The `_initialize_clauses` method sets up the watched-literal data structures: **unit clauses** (single-literal disjunctions) are immediately queued for propagation, while **multi-literal clauses** have their first and last literals registered as sentinels and their literal occurrence counts recorded. Does **not** expose standalone helper functions like `unit_propagate`, `find_unit_clause`, or `find_pure_symbol`; instead, unit-clause detection and clause simplification are handled through internal sentinel bookkeeping and `SATSolver`'s propagation queue. Supports enumerating all satisfying assignments via a generator. |
| `utilities/__init__.py` | Utilities sub-package init; re-exports `load_file` from the DIMACS module. |
| `utilities/dimacs.py` | Parser for the DIMACS CNF standard benchmark file format. `load(s)` parses a string and `load_file` reads from disk, both producing SymPy Boolean expressions (And of Or clauses). Handles DIMACS format details: skips comment lines (`c …`), discards the problem header (`p cnf …`), treats zero literals as clause terminators (skips them), and maps signed integers to positive/negated `cnf_N` Symbols. |
