# sympy/functions — Catalog

> Part of [SymPy](../catalog.md). Elementary and special mathematical functions (trig, exponential, Bessel, combinatorial, etc.).

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Top-level package init that imports and re-exports all public functions from the combinatorial, elementary, and special subpackages. |
| `combinatorial/__init__.py` | Subpackage init for combinatorial functions; imports the `factorials` and `numbers` modules. |
| `combinatorial/factorials.py` | Implements discrete combinatorial factorial-related functions and the binomial coefficient: `factorial` (integer n!), `factorial2`, `subfactorial`, `RisingFactorial`, `FallingFactorial`, and `binomial` (the raw C(n,k) coefficient computation). These are discrete/integer operations only — the continuous complex-plane extension of the factorial (the Γ function) is in `special/gamma_functions.py`. Does NOT implement named counting-number sequences like Catalan, Bell, or Bernoulli (those are in `combinatorial/numbers.py`). |
| `combinatorial/numbers.py` | Implements combinatorial number sequences and counting functions: Fibonacci, Lucas, harmonic, Bernoulli, Bell, Euler, Catalan, Genocchi numbers/polynomials, and Stirling numbers of the first and second kind. Catalan numbers C_n = (2n choose n)/(n+1) include eval-time special-case handling for negative integers (returns 0 for n ≤ -2, returns -1/2 for n = -1) and support rewriting to binomial, factorial, gamma, and hypergeometric forms. Harmonic numbers support `expand_func` expansion at rational arguments (splitting n = u + p/q) into closed-form Gauss-digamma-type sums involving cosine, cotangent, log-sine, and log terms. Harmonic numbers also support rewriting to polygamma/digamma/trigamma forms. Bernoulli number evaluation uses modulo-6 caching; indices > 500 delegate to mpmath's `bernfrac`. |
| `elementary/__init__.py` | Subpackage init for elementary functions; imports complexes, exponential, hyperbolic, integers, trigonometric, and miscellaneous modules. |
| `elementary/complexes.py` | Implements complex-number component-extraction operations: `re` (real part), `im` (imaginary part), `sign`, `Abs`, `conjugate`, `arg`, `polar_lift`, `periodic_argument`, `transpose`, `adjoint`, and related helpers. Does NOT contain realness/domain predicates for other function classes. |
| `elementary/exponential.py` | Implements exponential and logarithmic functions (`exp`, `exp_polar`, `log`, `LambertW`) with series expansion support for the Gruntz limit algorithm. |
| `elementary/hyperbolic.py` | Implements hyperbolic functions (`sinh`, `cosh`, `tanh`, `coth`, `sech`, `csch`) and their inverses (`asinh`, `acosh`, `atanh`, `acoth`, `asech`, `acsch`). Each function's `eval` classmethod defines evaluation rules for special values (Zero, Infinity, NegativeInfinity, ComplexInfinity/zoo, NaN) and symbolic simplifications (e.g., imaginary-argument conversion to trigonometric counterparts, inverse-function cancellation). Primary functions support trig-style expansion (`_eval_expand_trig`) using addition formulas. Reciprocal functions (`csch`, `sech`, `coth`) share a `ReciprocalHyperbolicFunction` base class that delegates rewrites to the underlying function. Inverse hyperbolic functions convert purely imaginary arguments into circular counterparts (e.g., `asinh(ix) = i*asin(x)`). |
| `elementary/integers.py` | Implements rounding functions: `floor`, `ceiling`, and `frac` (fractional part). `frac` handles complex-valued arguments by decomposing into real and imaginary components and applying the fractional-part operation to each independently. |
| `elementary/miscellaneous.py` | Implements miscellaneous elementary functions: `sqrt`, `cbrt`, `root`, `real_root`, `Min`, `Max`, and the `IdentityFunction`. |
| `elementary/piecewise.py` | Implements the `Piecewise` function for piecewise-defined expressions and the `piecewise_fold` simplification utility. |
| `elementary/trigonometric.py` | Implements trigonometric functions (`sin`, `cos`, `tan`, `cot`, `sec`, `csc`, `sinc`) and their inverses (`asin`, `acos`, `atan`, `acot`, `asec`, `acsc`, `atan2`). Each forward trig function's `eval` classmethod includes composition-simplification rules that reduce trig-of-inverse-trig expressions to algebraic forms (e.g., `cos(atan2(y,x))` → `x/sqrt(x²+y²)`, `sin(acos(x))` → `sqrt(1-x²)`). Each inverse trig class includes domain-analysis predicates (e.g., realness checks that short-circuit for non-real/complex inputs) and rewrite rules. |
| `elementary/benchmarks/bench_exp.py` | Benchmark for `exp.subs()` performance on exponential expression substitution. |
| `special/__init__.py` | Subpackage init for special functions; imports gamma, error, zeta, tensor, delta, elliptic, beta, Mathieu, singularity, and polynomial modules. |
| `special/bessel.py` | Implements Bessel functions (`besselj`, `bessely`, `besseli`, `besselk`), Hankel functions, spherical Bessel functions (`jn`, `yn`) via a `SphericalBesselBase` class (which restricts numerical evaluation `_eval_evalf` and polynomial expansion to integer orders only, delegating to a rewrite into ordinary Bessel functions), and Airy functions (`airyai`, `airybi`) with a shared `AiryBase` class that provides Airy-specific real/imaginary decomposition (handling the `deep` parameter to control expansion depth). |
| `special/beta_functions.py` | Implements the Euler beta function `B(x, y)` with differentiation, conjugation, and numerical evaluation support. |
| `special/bsplines.py` | Implements B-spline basis functions (`bspline_basis`, `bspline_basis_set`) as piecewise polynomials over a knot vector. |
| `special/delta_functions.py` | Implements the `DiracDelta` distribution (with rewrite methods to `Piecewise` and `SingularityFunction`, the latter raising `TypeError` for multi-variable arguments) and the `Heaviside` step function (accepts an optional second argument H0 for the value at zero; when omitted, the constructor stores only one arg, changing how the object's `.args` tuple is built). Rewrite/conversion logic for DiracDelta lives here, not in `singularity_functions.py`. |
| `special/elliptic_integrals.py` | Implements complete and incomplete elliptic integrals of the first (`elliptic_k`, `elliptic_f`), second (`elliptic_e`), and third kind (`elliptic_pi`). |
| `special/error_functions.py` | Implements error functions (`erf`, `erfc`, `erfi`, `erf2`, `erfinv`, `erfcinv`), exponential integrals (`Ei`, `expint`, `E1`, `li`, `Li` — where `Li` is the logarithmic integral offset li(x)−li(2), NOT the polylogarithm Li_s), trigonometric and hyperbolic integrals (`Si`, `Ci`, `Shi`, `Chi`) sharing a `TrigonometricIntegral` base class whose `eval` method handles polar-lift-conditional extraction of imaginary (`I`, `-I`) and negative multiplicative factors from arguments (skipping the polar requirement when the underlying trig function vanishes at the origin), and Fresnel integrals (`fresnels`, `fresnelc`). `expint.eval` performs its own branch factor extraction from the second argument (`z.extract_branch_factor()`), with separate paths for integer vs non-integer order and a guard that returns unevaluated when an integer order's positivity is unknown. Each integral class includes branch-cut-aware `_eval_conjugate` methods (e.g., `li` excludes the negative real axis `(-∞, 0)` from conjugation). Note: `Chi` (hyperbolic cosine integral) and `Shi` (hyperbolic sine integral) are integral transforms distinct from the elementary `cosh`/`sinh` in `elementary/hyperbolic.py`. |
| `special/gamma_functions.py` | Implements the gamma function (the complete factorial-extension Γ(x) = (x−1)! generalized to the complex plane, with `fdiff` raising `ArgumentIndexError` for invalid parameter indices), upper/lower incomplete gamma functions (`uppergamma`, `lowergamma`), log-gamma (`loggamma`), polygamma (`digamma`, `trigamma`), and related utilities. Polygamma includes rewrite rules that convert to harmonic-number form and to Hurwitz zeta form. Does NOT handle branch-cut logic for the generalized exponential integral E_ν(z) (that is in `error_functions.py`). |
| `special/hyper.py` | Implements the generalized hypergeometric function `hyper` (pFq) and the Meijer G-function `meijerg`. |
| `special/mathieu_functions.py` | Implements Mathieu functions (`mathieus`, `mathieuc`) and their derivatives (`mathieusprime`, `mathieucprime`) for the Mathieu differential equation. |
| `special/polynomials.py` | Implements special orthogonal polynomials: Jacobi, Gegenbauer, Chebyshev (T and U), Legendre, `assoc_legendre` (associated Legendre P_n^m(x), with eval-time negative-order conversion using factorial ratio identity, derivative via recurrence, and polynomial rewrite), Hermite, Laguerre, and associated Laguerre. Also provides `chebyshevt_root` and `chebyshevu_root` classes for computing zeros of Chebyshev polynomials of the first and second kind given degree n and zero index k, with input validation (0 <= k < n). |
| `special/singularity_functions.py` | Implements the `SingularityFunction` (Macaulay bracket notation) used in structural engineering beam analysis. |
| `special/spherical_harmonics.py` | Implements spherical harmonic functions `Ynm(n, m, theta, phi)`, `Ynm_c` (conjugate), and `Znm` (real form). Handles negative-m for Ynm via exponential phase factor identity; delegates to `assoc_legendre` from `polynomials.py` for the underlying P_n^m polynomial. |
| `special/tensor_functions.py` | Implements the `KroneckerDelta` discrete delta (1 if indices equal, 0 otherwise) and `LeviCivita` (Levi-Civita symbol / `Eijk`) tensor-index functions. `KroneckerDelta` includes fermi-level properties for second-quantization physics (`is_above_fermi`, `is_below_fermi`, `is_only_above_fermi`, `is_only_below_fermi`) that classify index pairs by their energy-region assumptions — generic unconstrained indices default to True for both above and below. |
| `special/zeta_functions.py` | Implements the Riemann `zeta` function, `dirichlet_eta`, Lerch transcendent (`lerchphi`), `polylog` (polylogarithm Li_s, the generalized logarithmic sum; supports `expand_func` to reduce to elementary rational expressions for non-positive integer order via iterated differential operations), and Stieltjes constants. |
| `special/benchmarks/bench_special.py` | Benchmark for spherical harmonics (`Ynm`) evaluation performance. |
