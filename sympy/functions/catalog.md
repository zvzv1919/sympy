# sympy/functions — Catalog

> Part of [SymPy](../catalog.md). Elementary and special mathematical functions (trig, exponential, Bessel, combinatorial, etc.).

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Top-level package init that imports and re-exports all public functions from the combinatorial, elementary, and special subpackages. |
| `combinatorial/__init__.py` | Subpackage init for combinatorial functions; imports the `factorials` and `numbers` modules. |
| `combinatorial/factorials.py` | Implements combinatorial factorial-related functions: `factorial`, `factorial2`, `subfactorial` (derangement/fixed-point-free permutation counting), `RisingFactorial`, `FallingFactorial`, and `binomial`. `subfactorial` includes a rewrite rule (`_eval_rewrite_as_uppergamma`) expressing the result as Γ(n+1, -1)/e (upper incomplete gamma divided by Euler's number) — this rewrite lives here, not in `special/gamma_functions.py`. Note: logarithmic derivatives of the factorial/gamma function and their sign properties are handled by polygamma in `special/gamma_functions.py`. |
| `combinatorial/numbers.py` | Implements combinatorial number sequences: Fibonacci, Lucas, harmonic, Bernoulli, Bell, Euler, Catalan, and Genocchi numbers/polynomials. The `harmonic` class models generalized harmonic numbers H_{n,m} = Σ_{k=1}^{n} 1/k^m (a generalized number-theoretic summation with upper limit n and order parameter m). Its `eval` method contains explicit branching for the infinite upper-limit case (n = ∞): negative order m → NaN, m ≤ 1 → ∞, m > 1 → ζ(m). All of this edge-case evaluation logic (including the NaN return for negative order) lives here, not in `special/zeta_functions.py`. The class also supports rational arguments via a Gauss-digamma-style trigonometric closed form (splitting n = u + p/q and using cosine, log-sine, and cotangent terms), memoized computation for integer arguments, and provides rewrite rules to polygamma. Despite the zeta connection, harmonic number logic lives here — not in `special/zeta_functions.py`, which implements the standalone Riemann zeta, Lerch transcendent, and polylogarithm functions. |
| `elementary/__init__.py` | Subpackage init for elementary functions; imports complexes, exponential, hyperbolic, integers, trigonometric, and miscellaneous modules. |
| `elementary/complexes.py` | Implements complex-number operations: `re`, `im`, `sign`, `Abs`, `conjugate`, `arg`, `polar_lift`, `periodic_argument`, `principal_branch`, `transpose`, `adjoint`, and related helpers. `polar_lift` lifts values onto the Riemann surface (multi-sheeted covering surface) of the complex logarithm — its `eval` method classifies multiplicative factors into three bins (already-polar, strictly positive real, and everything else needing recursive lifting) and recombines them accordingly. `periodic_argument` represents the argument on a quotient of this Riemann surface with a given period. Note: branch-cut logic for specific functions (e.g., `log` branch selection for imaginary arguments) is handled within those functions' own `eval` methods (see `elementary/exponential.py`), not here — `polar_lift` handles the lifting/wrapping onto the covering surface, while `log.eval` handles branch selection for evaluation. Similarly, conjugation and branch-cut handling for special-function integrals (`li`, `Ei`, `Si`, `Ci`, etc.) lives in `special/error_functions.py`. |
| `elementary/exponential.py` | Implements exponential and logarithmic functions (`exp`, `exp_polar`, `log`, `LambertW`) with series expansion support for the Gruntz limit algorithm. The `log.eval` classmethod contains branch-cut selection logic for complex arguments: it detects negative real inputs (returning `πi + log(-arg)`) and purely imaginary inputs with rational coefficients (returning `±πi/2 + log(|coeff|)` depending on sign), determining which branch of the complex logarithm to use. See `elementary/complexes.py` for general complex-number operations like `arg`, `polar_lift`, and `Abs` — but branch-cut logic specific to `log` evaluation lives here. |
| `elementary/hyperbolic.py` | Implements hyperbolic functions (`sinh`, `cosh`, `tanh`, `coth`, `sech`, `csch`) and their inverses (`asinh`, `acosh`, `atanh`, `acoth`, `asech`, `acsch`). Each inverse hyperbolic function's `eval` method contains logic to detect purely imaginary arguments and rewrite the result in terms of the corresponding circular trigonometric inverse (e.g., `atanh(i*x)` → `i*atan(x)`, `acoth(i*x)` → `-i*acot(x)`). Also defines the `ReciprocalHyperbolicFunction` base class (parent of `csch`, `sech`, `coth`) which provides a delegation pattern for reciprocal functions: `_rewrite_reciprocal` delegates rewrite calls (e.g., rewrite-as-exp, rewrite-as-tractable) to the underlying non-reciprocal function and returns the reciprocal of the result, but includes a guard that returns `None` if the rewrite produced an unchanged expression (preventing no-op or infinite-loop rewrites). This reciprocal rewrite delegation logic lives here, not in `elementary/exponential.py`. |
| `elementary/integers.py` | Implements rounding functions: `floor`, `ceiling`, and `frac` (fractional part). |
| `elementary/miscellaneous.py` | Implements miscellaneous elementary functions: `sqrt`, `cbrt`, `root`, `real_root`, `Min`, `Max`, and the `IdentityFunction`. |
| `elementary/piecewise.py` | Implements the `Piecewise` function for piecewise-defined expressions and the `piecewise_fold` simplification utility. |
| `elementary/trigonometric.py` | Implements trigonometric functions (`sin`, `cos`, `tan`, `cot`, `sec`, `csc`, `sinc`) and their inverses (`asin`, `acos`, `atan`, `acot`, `asec`, `acsc`, `atan2`). |
| `elementary/benchmarks/bench_exp.py` | Benchmark for `exp.subs()` performance on exponential expression substitution. |
| `special/__init__.py` | Subpackage init for special functions; imports gamma, error, zeta, tensor, delta, elliptic, beta, Mathieu, singularity, and polynomial modules. |
| `special/bessel.py` | Implements Bessel functions (`besselj`, `bessely`, `besseli`, `besselk`), Hankel functions (`hankel1`, `hankel2`), spherical Bessel functions (`jn`, `yn`), spherical Hankel functions (`hn1`, `hn2`), and Airy functions (`airyai`, `airybi`). Each class contains an `eval` classmethod with special-case evaluation logic for boundary/edge-case arguments (e.g., zero argument behavior branching on order parameter properties like real/imaginary part). The spherical Hankel classes (`hn1`, `hn2`) inherit from `SphericalHankelBase`, whose `_eval_expand_func` branches on whether the order is an integer: integer orders get fully reduced to trigonometric terms (sin/cos) via an internal `_expand` helper, while non-integer orders decompose into a symbolic sum of component spherical Bessel functions (`jn ± i*yn`). Rewrite methods (`_eval_rewrite_as_bessely`, `_eval_rewrite_as_jn`, `_eval_rewrite_as_yn`) also live here. This is where return values for specific inputs are determined — not in the test files. |
| `special/beta_functions.py` | Implements the Euler beta function `B(x, y)` with differentiation, conjugation, and numerical evaluation support. |
| `special/bsplines.py` | Implements B-spline basis functions (`bspline_basis`, `bspline_basis_set`) as piecewise polynomials over a knot vector. |
| `special/delta_functions.py` | Implements the `DiracDelta` distribution (continuous delta) and the `Heaviside` step function. For the discrete delta (KroneckerDelta, 1 when indices match, 0 otherwise), see `special/tensor_functions.py`. |
| `special/elliptic_integrals.py` | Implements complete and incomplete elliptic integrals of the first (`elliptic_k`, `elliptic_f`), second (`elliptic_e`), and third kind (`elliptic_pi`). |
| `special/error_functions.py` | Implements error functions (`erf`, `erfc`, `erfi`, `erf2`, `erfinv`, `erfcinv`), exponential integrals (`Ei`, `expint`, `E1`, `li`, `Li`), trig integrals (`Si`, `Ci`, `Shi`, `Chi`), and Fresnel integrals (`fresnels`, `fresnelc`). Each integral class is self-contained with its own evaluation, conjugation/branch-cut handling (`_eval_conjugate` checks for branch-cut arguments), rewrite methods (`_eval_rewrite_as_expint` converts trig integrals to exponential integrals using `E1`/`exp_polar`), and imaginary-argument transformation identities (`_Ifactor` maps e.g. `Ci(iz)` → `Chi(z) + iπ/2` and `Shi(iz)` → `i·Si(z)`). These methods live here — not in `elementary/trigonometric.py`, `elementary/exponential.py`, or `special/hyper.py`. Each error function class (including the Gaussian integral-based `erf`) also contains its own `as_real_imag` method for decomposing complex-valued inputs into real and imaginary parts — for purely real arguments it short-circuits to `(self, 0)`, while for complex arguments it uses an algebraic decomposition via `sq = -y²/x²` to split the result into real and imaginary components. This logic lives here, not in `elementary/complexes.py` (which only provides the generic `re`/`im` extraction operations). The `expint` class's `eval` method includes half-integer order detection (`(2*nu).is_Integer`) that reduces half-integer orders to error functions via `uppergamma`. |
| `special/gamma_functions.py` | Implements the gamma function, upper/lower incomplete gamma functions (`uppergamma`, `lowergamma`), log-gamma, polygamma (`digamma`, `trigamma`), and related utilities. Polygamma represents higher-order logarithmic derivatives of the factorial/gamma function; includes sign-determination logic (`_eval_is_positive`, `_eval_is_negative`) that decides positivity or negativity based on whether the derivative order is even or odd. Note: rewrite rules that express other functions *in terms of* uppergamma (e.g., subfactorial as Γ(n+1,-1)/e) live in those functions' own files (e.g., `combinatorial/factorials.py`), not here. |
| `special/hyper.py` | Implements the generalized hypergeometric function `hyper` (pFq), the Meijer G-function `meijerg`, and the `HyperRep` base class for analytic continuation representations. `HyperRep._eval_rewrite_as_nonrep` extracts the branch factor (winding number) from the argument to decide between "negative argument" and standard expression variants, then constructs a `Piecewise` result based on magnitude. Concrete `HyperRep` subclasses (e.g., `HyperRep_power1`, `HyperRep_log1`, etc.) supply the small/big expressions for each regime. |
| `special/mathieu_functions.py` | Implements Mathieu functions (`mathieus`, `mathieuc`) and their derivatives (`mathieusprime`, `mathieucprime`) for the Mathieu differential equation. |
| `special/polynomials.py` | Implements special orthogonal polynomials: Jacobi, Gegenbauer, Chebyshev (T and U), Legendre, associated Legendre, Hermite, Laguerre, and associated Laguerre. |
| `special/singularity_functions.py` | Implements the `SingularityFunction` (Macaulay bracket notation) used in structural engineering beam analysis. |
| `special/spherical_harmonics.py` | Implements spherical harmonic functions `Ynm`, `Ynm_c` (conjugate), and `Znm` (real form). `Ynm._eval_expand_func` expands the angular (theta/phi) part of a spherical harmonic into associated Legendre polynomials and exponentials — this is unrelated to radial wave-function expansion, which lives in `special/bessel.py`. |
| `special/tensor_functions.py` | Implements the `KroneckerDelta` (discrete delta: 1 when indices match, 0 otherwise) and `LeviCivita` (Levi-Civita symbol / `Eijk`) tensor-index functions. `KroneckerDelta` includes power-evaluation logic (`_eval_power`) with a subtle edge case for the reciprocal (exponent -1) vs. other negative exponents, as well as fermi-level index assumptions. Not to be confused with the continuous `DiracDelta` distribution in `special/delta_functions.py`. |
| `special/zeta_functions.py` | Implements the Riemann `zeta` function, `dirichlet_eta`, Lerch transcendent (`lerchphi`), `polylog`, and Stieltjes constants. Note: partial sums of reciprocal powers (generalized harmonic numbers H_{n,m} = Σ 1/k^m) and their expansion/evaluation logic live in `combinatorial/numbers.py`, not here — even though H_{∞,m} converges to ζ(m). |
| `special/benchmarks/bench_special.py` | Benchmark for spherical harmonics (`Ynm`) evaluation performance. |
