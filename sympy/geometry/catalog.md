# sympy/geometry — Catalog

> Part of [SymPy](../catalog.md). Computational geometry: points, lines, polygons, circles, ellipses, and curves.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package initializer that imports and re-exports all public geometry classes (Point, Line, Ellipse, Circle, Polygon, Plane, Curve, Parabola) and utility functions. |
| `entity.py` | Defines `GeometryEntity`, the base class for all geometric objects, and `GeometrySet`, a base for entities that can also act as SymPy Sets. Provides default implementations of rotation, scaling, translation, reflection, intersection, and symbolic substitution (`_eval_subs` handles sequence-to-Point conversion, dispatching to Point3D or Point2D based on the entity type). Subclasses like Ellipse and Circle override these defaults when geometry-specific constraints apply. |
| `point.py` | Implements `Point`, `Point2D`, and `Point3D` classes representing points in n-dimensional Euclidean space, with operations like distance, midpoint, collinearity checks (`is_collinear`, `are_collinear`), a per-point coplanarity method (`Point3D.are_coplanar`), and coordinate transformations. |
| `line.py` | Implements 2D line-like entities: `LinearEntity`, `Line`, `Ray`, `Segment` (all 2D only). `LinearEntity.intersection` computes crossing points using Cramer's rule for non-parallel entities, then validates candidates via coordinate-betweenness (for segments) and direction-consistency (for rays) rather than fragile equality-based containment; also handles parallel/collinear overlap cases. Supports perpendicularity, parallelism, angle computation, projections, and containment checks. |
| `line3d.py` | Implements 3D line-like entities: `LinearEntity3D`, `Line3D`, `Ray3D`, `Segment3D`. Provides 3D-specific direction properties, distance calculations, perpendicular segments (`perpendicular_segment` for computing shortest segment from a point to a 3D line), perpendicular lines, projections onto 3D lines, containment checks, and parallel/perpendicular tests in 3D space. |
| `plane.py` | Implements the `Plane` class for 3D planes, constructed from three points or a point and normal vector. Supports intersection with lines and other planes, distance calculations, point projection (`projection`), and line/ray/segment projection onto the plane (`projection_line` — projects both endpoints; returns a single Point3D when both endpoints map to the same location, e.g. when the entity is parallel to the plane's normal). |
| `polygon.py` | Implements `Polygon`, `RegularPolygon`, and `Triangle` classes. Provides area, perimeter, centroid, angle computations, point enclosure testing (`encloses_point` — returns False for boundary points, None for symbolic coordinates), polygon-to-polygon minimum distance via rotating calipers (`_do_poly_distance`), and specialized `Triangle` properties: circumcenter (found by intersecting perpendicular bisectors of edges), circumradius, circumcircle, incircle, medians, nine-point circle, orthocenter, altitudes, bisectors, and Euler line. |
| `ellipse.py` | Implements `Ellipse` and `Circle` classes with support for tangent lines, focal properties, eccentricity, and arbitrary point generation. `Ellipse.__contains__` (the `in` operator) checks if a Point satisfies the ellipse equation, but for another Ellipse it only checks equality — not geometric containment. `Circle.__new__` supports construction from center+radius. `Ellipse.rotate` overrides the base rotation: only allows multiples of pi/2 for non-circular ellipses (swaps semi-axis lengths for odd pi/2 multiples, raises NotImplementedError otherwise). `Ellipse.reflect` overrides base reflection: handles axis-aligned lines directly but raises NotImplementedError for non-axis-aligned lines. `Ellipse.scale` overrides base scaling to transform semi-axis lengths directly. Each class has its own `intersection` method with type-based dispatch, delegating to internal helpers like `_do_line_intersection` and `_do_ellipse_intersection`. |
| `curve.py` | Implements the `Curve` class for parametrically-defined 2D curves, supporting arc length computation, arbitrary point generation, and plotting-related methods. |
| `parabola.py` | Implements the `Parabola` class defined by a focus and directrix. Supports vertex, axis of symmetry, focal length, and equation generation for vertical and horizontal parabolas. |
| `util.py` | Module-level utility functions (not class methods): `intersection` (thin convenience wrapper that delegates to the first entity's own `intersection` method — actual intersection logic lives in the entity classes in `line.py`, `ellipse.py`, etc.), `convex_hull`, `closest_points`, `farthest_points`, `are_coplanar` (the primary coplanarity check for 3D points and entities — strips collinear points before constructing a plane; returns False when all points are collinear since no unique plane is determined), `are_similar`, `centroid`, and `idiff` (implicit differentiation). |
| `exceptions.py` | Defines `GeometryError`, the exception class raised by geometry module classes. |
