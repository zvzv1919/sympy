# sympy/geometry — Catalog

> Part of [SymPy](../catalog.md). Computational geometry: points, lines, polygons, circles, ellipses, and curves.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package initializer that imports and re-exports all public geometry classes (Point, Line, Ellipse, Circle, Polygon, Plane, Curve, Parabola) and utility functions. |
| `entity.py` | Defines `GeometryEntity`, the base class for all geometric objects, and `GeometrySet`, a base for entities that can also act as SymPy Sets. Provides common methods such as rotation, scaling, translation, and intersection. |
| `point.py` | Implements `Point`, `Point2D`, and `Point3D` classes representing points in n-dimensional Euclidean space, with operations like distance, midpoint, collinearity checks, and coordinate transformations. Arithmetic dunder methods (`__add__`, `__sub__`, `__mul__`, `__div__`, `__neg__`, `__abs__`) are defined on `Point` and perform coordinate-wise operations; `__add__` validates that both operands have matching dimensionality and raises `ValueError` (not `GeometryError`) when dimensions differ. `Point2D` and `Point3D` override `scale`, `rotate`, and `translate` from `GeometryEntity` with point-specific implementations — notably, `scale` with a reference point decomposes into translate-to-origin, scale, translate-back. `Point3D` also provides static `are_collinear` and `are_coplanar` methods (coplanarity via triple scalar product / volume test, with handling of degenerate collinear subsets). |
| `line.py` | Implements **2D** line-like entities: `LinearEntity`, `Line`, `Ray`, `Segment` (all operating in 2D Euclidean space). Supports intersection, perpendicularity, parallelism, angle computation, projections, and `coefficients` for 2D line equations. `LinearEntity.arbitrary_point` generates a parameterized coordinate representation along the entity (returns `p1 + (p2 - p1)*t`) and validates that the chosen parameter symbol does not conflict with the object's existing `free_symbols`, raising `ValueError` on collision — the same pattern used by `Ellipse.arbitrary_point` in `ellipse.py`. See `line3d.py` for 3D counterparts. |
| `line3d.py` | Implements **3D** line-like entities: `LinearEntity3D`, `Line3D`, `Ray3D`, `Segment3D`. Provides 3D-specific `contains` — notably `Ray3D.contains` uses x/y/z-direction properties to test whether a point lies in the forward half of the ray — along with `distance`, `equation`, direction ratios/cosines, and intersection/parallelism in 3D space. |
| `plane.py` | Implements the `Plane` class for 3D planes, constructed from three points or a point and normal vector. `Plane.intersection` is the central dispatch for plane-vs-entity intersections: handles points, all linear entities (lines, rays, **segments** — with parametric boundary validation that returns empty when the solved point falls outside a bounded entity's extent), and plane-plane intersections (using a coordinate-substitution fallback chain: tries z=0, then y=0, then x=0 to find a point on the intersection line). Also supports distance calculations and projections. |
| `polygon.py` | Implements `Polygon`, `RegularPolygon`, and `Triangle` classes. Provides area, perimeter, centroid, angle computations, and specialized `Triangle` geometric-center properties: circumcenter (computed by intersecting perpendicular bisectors of sides), orthocenter (intersection of altitudes), incircle, circumcircle, circumradius, medians, and nine-point circle. `RegularPolygon` overrides `scale` and `rotate` from `GeometryEntity`: `scale` with equal x/y factors preserves the `RegularPolygon` type (scaling the radius), but asymmetric scaling (x ≠ y) degrades the result to a plain `Polygon` by expanding vertices first. |
| `ellipse.py` | Implements `Ellipse` and `Circle` classes with support for tangent lines, focal properties, eccentricity, intersection with lines and other conics, and arbitrary point generation (including parameter-symbol collision validation that raises `ValueError` when the chosen parameter name conflicts with existing free symbols). Note: `line.py` (`LinearEntity`) and `curve.py` (`Curve`) also provide `arbitrary_point` with the same collision-check pattern. |
| `curve.py` | Implements the `Curve` class for parametrically-defined 2D curves, supporting arc length computation, arbitrary point generation, and plotting-related methods. |
| `parabola.py` | Implements the `Parabola` class defined by a focus and directrix. Supports vertex, axis of symmetry, focal length, and equation generation for vertical and horizontal parabolas. |
| `util.py` | Utility functions for geometry: `intersection`, `convex_hull`, `closest_points`, `farthest_points`, `are_coplanar`, `are_similar`, `centroid`, and `idiff` (implicit differentiation). |
| `exceptions.py` | Defines `GeometryError` (a `ValueError` subclass), the custom exception for geometry module classes. Note: not all geometry errors use this — e.g., `Point.__add__` raises plain `ValueError` for dimension mismatches rather than `GeometryError`. |
