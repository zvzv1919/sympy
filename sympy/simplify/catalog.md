# sympy/simplify -- Catalog

> Part of [SymPy](../catalog.md). Expression simplification: trigsimp, radsimp, powsimp, collect, CSE, hypergeometric simplification.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package init that re-exports public APIs from submodules (simplify, trigsimp, radsimp, powsimp, combsimp, gammasimp, ratsimp, fu, sqrtdenest, cse, hyperexpand, epathtools, traversaltools). |
| `simplify.py` | Core general-purpose simplification. The main `simplify` function is the top-level expression reducer: for non-arithmetic types (not Add/Mul/Pow/Exp) it detects single-argument function-inverse compositions (e.g., asin(sin(x)) → x) and recursively simplifies sub-expressions; for arithmetic types it orchestrates multiple strategies (cancel, together, factor_terms, hyperexpand, trigsimp, logcombine, combsimp, powsimp, etc.) and picks the shortest result. Also provides `separatevars`, `nsimplify`, `besselsimp`, `hypersimp`, `hypersimilar`, `posify`, `signsimp`, and `bottom_up`. Contains `logcombine(expr, force)` which merges sums and products of log expressions (log(x)+log(y)→log(x*y), a*log(x)→log(x**a)) with assumption guards: coefficients must be real and arguments positive; a complex scalar multiplier (e.g. 2+3i) prevents merging even under `force=True` because it fails the real-coefficient check. Also contains `_nthroot_solve` which denests `p**(1/n)`: when `n` is a power of 2 it repeatedly square-root-denests and halves `n`, returning early without computing a minimal polynomial or solving; otherwise it falls back to `_minimal_polynomial_sq` and `solve`. |
| `trigsimp.py` | Top-level trigonometric simplification dispatcher via `trigsimp` and `exptrigsimp`; does NOT contain individual trig identity transform rules (those are the TR-series in fu.py). Includes a recursive `__trigsimp` helper that applies pattern-matched identity substitutions to trig/hyperbolic expressions and falls back to exponential rewriting if trig functions remain. Contains `_replace_mul_fpowxgpow` and `_match_div_rewrite` for rewriting within single-term products of trig functions (not ratio-to-tan conversion, which is TR2i in fu.py). Also provides `trigsimp_groebner` for polynomial Groebner-basis-based trig reduction. |
| `radsimp.py` | Radical simplification and term collection: `collect`, `rcollect`, `radsimp`, `collect_const` for rationalizing denominators and grouping terms. Also provides `fraction(expr, exact)` which decomposes a product expression into (numerator, denominator) by splitting terms with negative exponents into the denominator — with an `exact` flag that changes handling of non-constant symbolic exponents and disables evaluation. `numer`, `denom`, `numer_expand`, `denom_expand`, `fraction_expand` are thin wrappers around `fraction`. Also provides `split_surds` for decomposing surd sums. |
| `powsimp.py` | Power simplification via `powsimp` (combine bases/exponents of Pow expressions, e.g. x**a * x**b → x**(a+b)) and `powdenest` (simplify nested power expressions like (x**a)**b). Does not handle logarithm combining (see `logcombine` in simplify.py). |
| `ratsimp.py` | Rational expression simplification via `ratsimp` (common denominator, cancel, reduce) and `ratsimpmodprime` (simplification modulo a polynomial prime ideal using Groebner bases). |
| `combsimp.py` | Combinatorial simplification via `combsimp`, which reduces expressions involving factorials, binomials, and Pochhammer symbols by rewriting through gamma functions. |
| `gammasimp.py` | Gamma function simplification via `gammasimp`, applying rising-factorial rewriting, reflection theorem, and multiplication theorem to minimize gamma function count. |
| `sqrtdenest.py` | Denesting of nested square roots via `sqrtdenest`, with helpers for measuring sqrt depth and checking algebraic structure of radical expressions. |
| `fu.py` | Implementation of the Fu et al. trigonometric simplification algorithm, providing a library of numbered transform rules (TR0--TR22, TR111, TRmorrie) applied in heuristic order. This is the canonical location for all individual trig identity transform rules. Key transforms include: TR0 performs basic rational polynomial simplification of trig expressions using `.normal().factor().expand()` instead of `cancel` (because cancel doesn't work with noncommutative expressions); `_TR56` (helper for TR5/TR6) replaces even powers of a trig function with its Pythagorean identity complement (e.g., sin²→1−cos², sin⁸→(1−cos²)⁴), controlled by a `max` exponent cap and a `pow` flag that restricts rewrites to exponents that are perfect powers of 2; TR2 replaces tan/cot with sin/cos ratios; TR2i converts sin/cos ratios back to tan (and optionally half-angle tan), refusing the conversion when the exponent is symbolic non-integer and the base lacks positivity assumptions; TR9 converts sums of sin/cos into products via sum-to-product identities, handling 3+ term sums by greedy pairwise combination (marking consumed terms as None) with recursive re-application; TR10 expands cos/sin of argument sums (e.g., sin(a+b+c)) into products of sin/cos of individual terms via angle-addition identities, recursively decomposing multi-term sums with a `first` flag controlling whether summands are canonically sorted; TR14 simplifies factored difference-of-squares trig identities like (cos(x)−1)*(cos(x)+1) into simpler trig powers, with special handling to split numerator/denominator separately (using a `first` flag to prevent infinite recursion on fractional expressions); TR8 expands products of sin/cos to sums. TR111 converts negative integer powers of basic trig functions (tan, sin, cos) to positive powers of their reciprocals (cot, csc, sec); reciprocal trig bases like cot, csc, sec are not matched and are left unchanged. Also provides `process_common_addends(rv, do, key2, key1)` which groups addends sharing a common absolute coefficient and optional secondary key, applies a transformation `do` to each group, and raises `ValueError('must have at least one key')` when both `key1` is False and `key2` is None. Also provides combination routines (`fu`, `CTR1`–`CTR4`) orchestrating rule sequences. Includes `trig_split(a, b, two=False)` which decomposes two terms into (gcd, n1, n2, a, b, is_sum) for sum-to-product or product-to-sum trig identities; its inner helper `pow_cos_sin` parses each term into (radical, cos-factor, sin-factor) but rejects products of trig functions (e.g., cos(x)*sin(y)) when `two=False`. Also includes helper `as_f_sign_1` that decomposes a two-term addition into `g*(a + s)` where `s` is ±1, and `_osborne`/`_osbornei` for converting between hyperbolic and trig functions via the Osborne rule. |
| `cse_main.py` | Common subexpression elimination via `cse`, identifying repeated subexpressions and replacing them with temporary variables to reduce redundant computation. |
| `cse_opts.py` | Pre- and post-processing optimizations for CSE (`sub_pre`, `sub_post`) that canonicalize subtraction expressions to expose more common-subexpression opportunities. |
| `hyperexpand.py` | Expands hypergeometric and Meijer G-functions into named special functions using lookup tables and shift-operator algorithms based on Roach (1997). |
| `hyperexpand_doc.py` | Auto-generates a Sphinx docstring listing all known hypergeometric function formulas from `FormulaCollection` for documentation purposes. |
| `traversaltools.py` | Provides the `use` function for applying a transformation to an expression at a specified depth level in the expression tree. |
| `epathtools.py` | Expression path tools: the `EPath` class and `epath` function for selecting and applying functions to parts of an expression tree using a path-based DSL. |
