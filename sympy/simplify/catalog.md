# sympy/simplify -- Catalog

> Part of [SymPy](../catalog.md). Expression simplification: trigsimp, radsimp, powsimp, collect, CSE, hypergeometric simplification.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package init that re-exports public APIs from submodules (simplify, trigsimp, radsimp, powsimp, combsimp, gammasimp, ratsimp, fu, sqrtdenest, cse, hyperexpand, epathtools, traversaltools). |
| `simplify.py` | Core general-purpose simplification. The main `simplify` function is the top-level expression reducer: for non-arithmetic types (not Add/Mul/Pow/Exp) it detects single-argument function-inverse compositions (e.g., asin(sin(x)) → x) and recursively simplifies sub-expressions; for arithmetic types it orchestrates multiple strategies (cancel, together, factor_terms, hyperexpand, trigsimp, logcombine, combsimp, powsimp, etc.) and picks the shortest result. Also provides `separatevars`, `nsimplify`, `besselsimp`, `hypersimp`, `hypersimilar`, `posify`, and `bottom_up`. Contains `signsimp(expr, evaluate)` which canonicalizes the sign of all Add sub-expressions: if an Add can have a sign extracted (via `could_extract_minus_sign`), it is replaced with `Mul(-1, a, evaluate=False)`, allowing signs to propagate through powers and products; it also replaces Mul atoms where double negation `-(- m)` yields a different form, enabling expressions like `n/x/(-n)**2 - 1/n/x` to reduce to zero. Contains `logcombine(expr, force)` which merges sums and products of log expressions (log(x)+log(y)→log(x*y), a*log(x)→log(x**a)) with assumption guards: coefficients must be real and arguments positive; a complex scalar multiplier (e.g. 2+3i) prevents merging even under `force=True` because it fails the real-coefficient check. Also contains `_nthroot_solve` which denests `p**(1/n)`: when `n` is a power of 2 it repeatedly square-root-denests and halves `n`, returning early without computing a minimal polynomial or solving; otherwise it falls back to `_minimal_polynomial_sq` and `solve`. |
| `trigsimp.py` | **Main entry point** for trigonometric/hyperbolic simplification. The `trigsimp` function is the top-level dispatcher: it first attempts to delegate to the expression's own `_eval_trigsimp` method (custom reduction logic), and if that is absent, dispatches to one of several internal strategies selected by the `method` parameter — 'matching' (default, uses `futrig`), 'fu', 'groebner' (uses `trigsimp_groebner`), 'combined', or 'old'. Also provides `exptrigsimp` for converting between exponential and trig/hyperbolic representations by comparing operation counts. Does NOT contain individual trig identity transform rules (those are the TR-series in fu.py). Includes a recursive `__trigsimp` helper that applies pattern-matched identity substitutions to trig/hyperbolic expressions and falls back to exponential rewriting if trig functions remain. Contains `_replace_mul_fpowxgpow` and `_match_div_rewrite` for rewriting within single-term products of trig functions. Also provides `trigsimp_groebner` for Groebner-basis-based trig/hyperbolic simplification using algebraic ideals of trig identities — it replaces the imaginary unit with a dummy symbol and adds the relation dummy²+1=0 to the ideal to prevent spurious simplifications involving `i`, then substitutes back after reduction. |
| `radsimp.py` | Radical simplification and term collection: `collect`, `rcollect`, `radsimp`, `collect_const` for rationalizing denominators and grouping terms. Also provides `fraction(expr, exact)` which decomposes a product expression into (numerator, denominator) by splitting terms with negative exponents into the denominator — with an `exact` flag that changes handling of non-constant symbolic exponents and disables evaluation. `numer`, `denom`, `numer_expand`, `denom_expand`, `fraction_expand` are thin wrappers around `fraction`. Also provides `split_surds` for decomposing surd sums. |
| `powsimp.py` | Power simplification via `powsimp` (combine bases/exponents of Pow expressions, e.g. x**a * x**b → x**(a+b)) and `powdenest` (simplify nested power expressions like (x**a)**b). Does not handle logarithm combining (see `logcombine` in simplify.py). |
| `ratsimp.py` | Rational expression simplification via `ratsimp` (common denominator, cancel, reduce) and `ratsimpmodprime` (simplification modulo a polynomial prime ideal using Groebner bases). |
| `combsimp.py` | Combinatorial simplification via `combsimp`, which reduces expressions involving factorials, binomials, and Pochhammer symbols by rewriting through gamma functions. |
| `gammasimp.py` | Gamma function simplification via `gammasimp`, applying rising-factorial rewriting, reflection theorem, and multiplication theorem to minimize gamma function count. |
| `sqrtdenest.py` | Denesting of nested square roots via `sqrtdenest`, with helpers for measuring sqrt depth and checking algebraic structure of radical expressions. |
| `fu.py` | Implementation of the Fu et al. trigonometric simplification algorithm: a library of individual numbered transform rules (TR0–TR22, TR111, TRmorrie) applied in heuristic order. This is the canonical location for all individual trig identity transform rules — it does NOT contain the top-level `trigsimp` dispatcher (that is in trigsimp.py). Key transforms: TR0 (rational polynomial simplification of trig), TR2/TR2i (tan↔sin/cos ratio conversion), TR5/TR6 via `_TR56` (Pythagorean identity rewrites for even powers), TR8 (product-to-sum), TR9 (sum-to-product), TR10 (angle-addition expansion), TR11 (double-angle rewrite), TR12 (expand tan of a sum into a rational expression of individual tans, with canonical sorting on first call), TR12i (combine rational tan expressions back into tan of a sum), TR14 (difference-of-squares trig identities), TR111 (negative powers of tan/sin/cos to reciprocals). Also provides combination routines (`fu`, `CTR1`–`CTR4`) orchestrating rule sequences, `process_common_addends` for grouping addends by common coefficient, `trig_split` for sum/product identity decomposition, `as_f_sign_1` for two-term sign decomposition, and `_osborne`/`_osbornei` for hyperbolic↔trig conversion via Osborne rule. |
| `cse_main.py` | Common subexpression elimination via `cse`, identifying repeated subexpressions and replacing them with temporary variables to reduce redundant computation. |
| `cse_opts.py` | Pre- and post-processing optimizations for CSE (`sub_pre`, `sub_post`) that canonicalize subtraction expressions to expose more common-subexpression opportunities. |
| `hyperexpand.py` | Expands hypergeometric and Meijer G-functions into named special functions using lookup tables and shift-operator algorithms based on Roach (1997). |
| `hyperexpand_doc.py` | Auto-generates a Sphinx docstring listing all known hypergeometric function formulas from `FormulaCollection` for documentation purposes. |
| `traversaltools.py` | Provides the `use` function for applying a transformation to an expression at a specified depth level in the expression tree. |
| `epathtools.py` | Expression path tools: the `EPath` class and `epath` function for selecting and applying functions to parts of an expression tree using a path-based DSL. |
