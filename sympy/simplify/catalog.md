# sympy/simplify -- Catalog

> Part of [SymPy](../catalog.md). Expression simplification: trigsimp, radsimp, powsimp, collect, CSE, hypergeometric simplification.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package init that re-exports public APIs from submodules (simplify, trigsimp, radsimp, powsimp, combsimp, gammasimp, ratsimp, fu, sqrtdenest, cse, hyperexpand, epathtools, traversaltools). |
| `simplify.py` | Core general-purpose simplification. The main `simplify` function is the top-level expression reducer: for non-arithmetic types (not Add/Mul/Pow/Exp) it detects single-argument function-inverse compositions (e.g., asin(sin(x)) → x) and recursively simplifies sub-expressions; for arithmetic types it orchestrates multiple strategies (cancel, together, factor_terms, hyperexpand, trigsimp, logcombine, combsimp, powsimp, etc.) and picks the shortest result. Also provides `separatevars`, `nsimplify`, `besselsimp`, `posify`, and `bottom_up`. Contains `hypersimp(f, k)` which computes the consecutive term ratio f(k+1)/f(k) of a combinatorial term by rewriting in terms of gamma functions, expanding, and power-simplifying — if the result is a rational function of k (i.e. the term is hypergeometric), returns the simplified rational ratio; otherwise returns None indicating the term is not hypergeometric. Contains `hypersimilar(f, g, k)` which tests whether f and g are hyper-similar (their quotient is rational in k after gamma rewriting). Contains `signsimp(expr, evaluate)` which canonicalizes the sign of all Add sub-expressions: if an Add can have a sign extracted (via `could_extract_minus_sign`), it is replaced with `Mul(-1, a, evaluate=False)`, allowing signs to propagate through powers and products; it also replaces Mul atoms where double negation `-(- m)` yields a different form, enabling expressions like `n/x/(-n)**2 - 1/n/x` to reduce to zero. Contains `logcombine(expr, force)` which merges sums and products of log expressions (log(x)+log(y)→log(x*y), a*log(x)→log(x**a)) with assumption guards: coefficients must be real and arguments positive; a complex scalar multiplier (e.g. 2+3i) prevents merging even under `force=True` because it fails the real-coefficient check. Contains `nthroot(expr, n)` which computes a real nth-root of a sum of surds: it validates that all terms are rational-coefficient surds, then uses `nsimplify` with the surd constants; when the expression is negative and the root degree is odd, it negates the expression, computes the root of the positive version, verifies, and returns the negated result. Also contains `_nthroot_solve` which denests `p**(1/n)`: when `n` is a power of 2 it repeatedly square-root-denests and halves `n`, returning early without computing a minimal polynomial or solving; otherwise it falls back to `_minimal_polynomial_sq` and `solve`. |
| `trigsimp.py` | **Main entry point** for trigonometric/hyperbolic simplification. The `trigsimp` function is the top-level dispatcher: it first attempts to delegate to the expression's own `_eval_trigsimp` method (custom reduction logic), and if that is absent, dispatches to one of several internal strategies selected by the `method` parameter — 'matching' (default, uses `futrig`), 'fu', 'groebner' (uses `trigsimp_groebner`), 'combined', or 'old'. Supports a `recursive` mode that first applies CSE to extract common subexpressions, simplifies the reduced expression, then back-substitutes each subexpression one at a time with re-simplification after every single substitution (not just once at the end). Also provides `exptrigsimp` for converting between exponential and trig/hyperbolic forms: it detects reciprocal exponential pairs (e^a and e^(-a)) and substitutes sinh/cosh, then converts ratio patterns like (e^a - 1)/(e^a + 1) into tanh(a/2) or i*tan(c/2) for imaginary arguments — this is the canonical location for exp-to-hyperbolic and exp-ratio-to-half-angle-tangent conversion. Does NOT contain individual trig identity transform rules (those are the TR-series in fu.py) — in particular, sin/cos ratio-to-tan conversion with assumption guards (TR2i) and difference-of-squares trig pairing (TR14) live in fu.py, not here. Includes a recursive `__trigsimp` helper that applies pattern-matched identity substitutions to trig/hyperbolic expressions and falls back to exponential rewriting if trig functions remain. Contains `_replace_mul_fpowxgpow` for rewriting products like f(x)^a * g(x)^b into h(x)^c within pattern-matched trig identities (not Pythagorean identity substitution — that is `_TR56` in fu.py), and `_match_div_rewrite` for rewriting within single-term products of trig functions. Also provides `trigsimp_groebner` for Groebner-basis-based trig/hyperbolic simplification using algebraic ideals of trig identities — it replaces the imaginary unit with a dummy symbol and adds the relation dummy²+1=0 to the ideal to prevent spurious simplifications involving `i`, then substitutes back after reduction. |
| `radsimp.py` | Radical simplification and term collection: `collect`, `rcollect`, `radsimp`, `collect_const` for rationalizing denominators and grouping terms. `collect` groups additive terms by common factors — internally it parses each multiplicative term into (base, rational_exponent, symbolic_exponent, derivative) tuples via a `parse_term` helper, with special-case handling for the natural exponential `exp()`: when the argument is rational, E becomes the base with the argument as exponent; when the argument is a product, the rational coefficient is split off as exponent and exp(remaining) becomes the base. Also provides `fraction(expr, exact)` which decomposes a product expression into (numerator, denominator) by splitting terms with negative exponents into the denominator — with an `exact` flag that changes handling of non-constant symbolic exponents and disables evaluation. `numer`, `denom`, `numer_expand`, `denom_expand`, `fraction_expand` are thin wrappers around `fraction`. Also provides `split_surds` for decomposing surd sums. |
| `powsimp.py` | Power simplification via `powsimp` (combine bases/exponents of Pow expressions, e.g. x**a * x**b → x**(a+b)) and `powdenest` (simplify nested power expressions like (x**a)**b). Does not handle logarithm combining (see `logcombine` in simplify.py). |
| `ratsimp.py` | Rational expression simplification via `ratsimp` (common denominator, cancel, reduce) and `ratsimpmodprime` (simplification modulo a polynomial prime ideal using Groebner bases). |
| `combsimp.py` | Combinatorial simplification via `combsimp`, which reduces expressions involving factorials, binomials, and Pochhammer symbols by rewriting through gamma functions to minimize the number and argument size of combinatorial functions. Does NOT compute consecutive term ratios or test hypergeometric character (those are `hypersimp`/`hypersimilar` in simplify.py). |
| `gammasimp.py` | Gamma function simplification via `gammasimp`, applying rising-factorial rewriting, reflection theorem, and multiplication theorem to minimize gamma function count. |
| `sqrtdenest.py` | Denesting of nested square roots via `sqrtdenest`, with helpers for measuring sqrt depth and checking algebraic structure of radical expressions. Contains `_sqrt_match(p)` which decomposes a sum expression into the form [a, b, r] matching a + b*sqrt(r) by selecting the addend with maximal sqrt nesting depth as the radical part — when the expression is an Add but all addends have zero radical nesting depth, returns an empty list (no match); when all squared terms are rational, delegates to `split_surds`. |
| `fu.py` | Implementation of the Fu et al. trigonometric simplification algorithm: a library of individual numbered transform rules (TR0–TR22, TR111, TRmorrie) applied in heuristic order. This is the canonical location for all individual trig identity transform rules — it does NOT contain the top-level `trigsimp` dispatcher (that is in trigsimp.py). Key transforms: TR0 (rational polynomial simplification of trig), TR2/TR2i (tan↔sin/cos ratio conversion — TR2i converts sin(x)/cos(x) ratios to tan(x) but guards on assumptions: the base must be positive or the exponent must be an integer for both numerator and denominator, otherwise the transformation is skipped), TR5/TR6 via `_TR56` (Pythagorean identity sin²↔1-cos² / cos²↔1-sin² rewrites for even-power expressions, with a `pow` flag that when enabled restricts replacement to exponents that are perfect powers of 2, so e.g. exponent 6 is left unchanged), TR8 (product-to-sum), TR9 (sum-to-product), TR10 (angle-addition expansion of sin/cos of sums, with a `first` flag: on the initial call arguments are canonically sorted via `ordered()`, but recursive sub-expansions pass `first=False` to preserve existing argument order), TR10i (inverse of TR10: combines sums of sin/cos products back into compound-angle sin/cos functions — for sums with more than two terms, uses a greedy pairwise strategy that iterates over all pairs, attempts to combine each pair via `trig_split`, marks consumed terms as None and updates in place, then reconstructs the Add and recurses until no more pairs combine), TR11 (double-angle rewrite), TR12 (expand tan of a sum into a rational expression of individual tans, with canonical sorting on first call), TR12i (combine rational tan expressions back into tan of a sum), TR14 (difference-of-squares trig identities: pairs (trig±1) factors with opposite signs and combines them via Pythagorean identities, e.g. (cos(x)+1)(cos(x)-1)→-sin²(x); when paired factors have different numeric exponents it takes the minimum exponent for combination and reinserts the remainder back into the processing queue; also handles equal symbolic exponents), TR111 (negative powers of tan/sin/cos to reciprocals). Also provides combination routines (`fu`, `CTR1`–`CTR4`) orchestrating rule sequences, `process_common_addends` for grouping summation addends by the absolute value of their coefficient magnitude and an optional secondary key, then applying a transformation to groups with more than one member — negative coefficients are handled by negating both the coefficient and the argument so the sign is transferred onto the argument, `trig_split` for decomposing a sum of two terms into gcd*(s1*f(a1) + s2*f(a2)) by extracting a GCD factor and classifying each remainder as a trig function — operates in single-function mode (default, each term after GCD must be a bare trig function, products return None) or double-function mode (`two=True`, allows cos*sin products for angle-addition identities), `as_f_sign_1` for two-term sign decomposition, and `_osborne`/`_osbornei` for hyperbolic↔trig conversion via Osborne rule. |
| `cse_main.py` | Common subexpression elimination via `cse`, identifying repeated subexpressions and replacing them with temporary variables to reduce redundant computation. |
| `cse_opts.py` | Pre- and post-processing optimizations for CSE (`sub_pre`, `sub_post`) that canonicalize subtraction expressions to expose more common-subexpression opportunities. |
| `hyperexpand.py` | Expands hypergeometric and Meijer G-functions into named special functions using lookup tables and shift-operator algorithms based on Roach (1997). |
| `hyperexpand_doc.py` | Auto-generates a Sphinx docstring listing all known hypergeometric function formulas from `FormulaCollection` for documentation purposes. |
| `traversaltools.py` | Provides the `use` function for applying a transformation to an expression at a specified depth level in the expression tree. |
| `epathtools.py` | Expression path tools: the `EPath` class and `epath` function for selecting and applying functions to parts of an expression tree using a path-based DSL. |
