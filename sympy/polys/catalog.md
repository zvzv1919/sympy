See also `domains/domain.py` for the abstract `Domain.unify` (which unifies domain types only, not polynomial representations), and `numberfields.py` for algebraic field theory (minimal polynomials, primitive elements), which does NOT contain ANP arithmetic or unification. |

| `fglmtools.py` | Implementation of the matrix FGLM algorithm for converting a reduced Groebner basis from one monomial ordering to another. | `factortools.py` | Polynomial factorization routines in characteristic zero: Zassenhaus, Wang's EEZ, and multivariate factorization over ZZ, QQ, and GF(p). `dmp_zz_factor` orchestrates complete multivariate integer factorization by extracting ground content, computing the primitive part with respect to the main variable via `dmp_primitive`, then recursively factoring the content polynomial in fewer variables. Includes trial division for determining factor multiplicities (`dup_trial_division` uses simple falsiness for zero-remainder checks; `dmp_trial_division` uses `dmp_zero_p` because multivariate dense zero representations cannot be tested with `not r`), Mignotte bounds, and Hensel lifting. See also `sqfreetools.py` for square-free decomposition (which is a *step within* factorization, not the full irreducible factorization). |
| `euclidtools.py` | Euclidean algorithms for GCD, LCM, extended GCD, resultants, discriminants, subresultants, and polynomial remainder sequences over **dense recursive coefficient-list** representations (`dup_`/`dmp_` functions). Includes heuristic GCD for dense polynomials (`dup_zz_heu_gcd`/`dmp_zz_heu_gcd` with interpolation and three fallback recovery paths per iteration: first tries interpolating the GCD directly, then interpolating each cofactor separately and dividing to recover the GCD, raising `HeuristicGCDFailed` if all iterations exhaust), the GCD interpolation functions (`_dup_zz_gcd_interpolate`/`_dmp_zz_gcd_interpolate` which recover polynomial coefficients from integer images using symmetric remainder—adjusting values exceeding half the evaluation point to get correct signed coefficients), trivial GCD handlers (`_dup_rr_trivial_gcd` which normalizes the sign of the leading coefficient when one input is zero; `_dup_ff_trivial_gcd` which makes the result monic), and Collins modular resultant methods (`dmp_zz_collins_resultant` which computes the eliminant of two multivariate integer polynomials by accumulating modular images—skipping primes that divide either leading coefficient and catching `HomomorphismFailed` to skip bad primes—then reconstructing via CRT until a factorial-based norm bound is exceeded). See also `heuristicgcd.py` for heuristic GCD on *sparse* `PolyElement` representations, `modulargcd.py` for modular GCD over algebraic number fields, and `subresultants_qq_zz.py` for symbolic/exact PRS using Pell-Gordon and AMV theorems. |
| `sqfreetools.py` | Square-free decomposition algorithms: `dup_sqf_p`, `dup_sqf_list`, `dup_sqf_part`, and their multivariate (`dmp_`) counterparts. |
| `rootoftools.py` | Implementation of `CRootOf` and `RootSum` classes for representing and evaluating individual roots of irreducible polynomials. |
| `rootisolation.py` | Real and complex root isolation and refinement algorithms based on Sturm sequences, Descartes' rule, and interval arithmetic. Operates on dense coefficient lists. See also `subresultants_qq_zz.py` for symbolic Sturm sequence construction using Pell-Gordon/AMV theorems on `Poly` expressions. |
| `solvers.py` | Low-level linear systems solver using polynomial ring elements; converts equations to matrix form and solves via row reduction. |
