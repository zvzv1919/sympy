# sympy/polys — Catalog

> Part of [SymPy](../catalog.md). Polynomial algebra: factorization, GCD, Groebner bases, algebraic number fields, polynomial rings and domains.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package init that re-exports the public API from submodules (polytools, polyfuncs, rationaltools, numberfields, monomials, orderings, rootoftools, polyroots, domains, constructor, specialpolys, orthopolys, partfrac, polyerrors, dispersion, ring_series). |
| `polytools.py` | User-friendly public interface to polynomial functions; defines the `Poly` class (including `count_roots` for root counting in mixed real/complex intervals with automatic bound format conversion, `terms_gcd` method for extracting shared monomial GCD from terms, `ltrim` for stripping unused leading generators with monomial-collision error detection, `_from_poly` for deciding reorder vs rebuild-from-expression when target generators differ, `sturm` method that auto-converts ring domains to field domains before computing the Sturm sequence, `cancel` method that converts the unified domain to its associated ring before converting content coefficients to SymPy objects for the ratio), `Groebner` basis wrapper, and top-level helpers like `factor`, `gcd`, `resultant`, `discriminant`, `pquo` (pseudo-quotient that catches `ExactQuotientFailed` and re-raises with original expression args), `pexquo` (exact pseudo-quotient that lets the exception propagate directly from internal Poly method), `div`, `rem`, `quo`, `exquo`, public `terms_gcd` function (returns original expression unchanged when coefficient and monomial GCD are both trivial), `_parallel_poly_from_expr` which constructs multiple polynomials simultaneously by collecting all coefficients into a single flat list to infer one unified coefficient domain shared across all results, `to_rational_coeffs` which attempts rescaling x→αx then translation x→x+β to eliminate square-root coefficients from univariate polynomials, `roots` (in `polyroots.py`) calls `to_rational_coeffs` and post-processes solutions by reversing the rescaling or translation, `Poly.all_roots`/`Poly.real_roots` (return roots with `multiple=True` as a flat list with repetitions, or with `multiple=False` as (root, count) pairs via `group`), and the top-level `intervals` function (computes isolating intervals for roots — for a list of expressions, forces domain to QQ, rejects multivariate inputs, and delegates to `dup_isolate_real_roots_list`). |
| `polyclasses.py` | OO layer for low-level polynomial representations: `DMP` (dense multivariate polynomials, with `__eq__` that silently returns False on `UnificationFailed` instead of raising; `all_monoms`/`all_coeffs`/`all_terms` methods that return a single zero-degree entry `[(0,)]` for the zero polynomial instead of an empty list, and raise `PolynomialError` for multivariate inputs), `DMF` (dense multivariate fractions, with `per`/`poly_unify`/`frac_unify` methods that return raw scalar `num/den` instead of a DMF when the `kill` flag is set and variable level is zero), and `ANP` (algebraic number field elements). |
| `polyoptions.py` | Options manager for `Poly` and public API functions; defines `Options`, `Flag`, and various option classes (Domain, Order, Extension, etc.) with validation and preprocessing. |
| `polyutils.py` | Utility functions for higher-level polynomial classes: generator sorting, expression-to-dict conversion, `PicklableWithSlots` mixin, and numerical root sorting. |
| `polyroots.py` | Algorithms for computing symbolic roots of polynomials, including solvers for linear, quadratic, cubic, quartic, and quintic equations. Also includes `_integer_basis` which finds an integer rescaling factor so that substituting x=k*y minimizes coefficient magnitudes of a univariate polynomial over ZZ (reverses the coefficient ordering when the leading coefficient is unity before searching for the scaling constant). The main `roots` function handles algebraic-extension coefficients by calling `to_rational_coeffs` to simplify, then reverses the variable substitution (rescaling or translation) on all solutions before returning. |
| `polyerrors.py` | Definitions of exception classes for the polys module (e.g., `PolynomialError`, `DomainError`, `CoercionFailed`, `ExactQuotientFailed`). |
| `polyconfig.py` | Configuration utilities for polynomial algorithms; manages settings such as GCD method, factorization method, and Groebner basis algorithm via `setup`/`query`/`using`. |
| `polyfuncs.py` | High-level symbolic polynomial helper functions: `symmetrize` (rewrite in elementary symmetric polynomials), `horner` (rewrite expression in Horner form — does NOT evaluate), `interpolate`/`rational_interpolate` (symbolic interpolation from point sets), and `viete` (generate Viète's formulas relating coefficients to roots). These are expression-level wrappers, not the low-level evaluation/GCD/interpolation engines. |
| `polymatrix.py` | `PolyMatrix` (alias `MutablePolyDenseMatrix`), a mutable matrix class whose entries are `Poly` objects, supporting polynomial-aware matrix arithmetic. |
| `polyquinticconst.py` | Constants and resolvent polynomial computations for solving solvable quintics via Dummit's algorithm. Defines `PolyQuintic` class with properties for massive coefficient arrays (`b`, `o`, `a`, `c`) and methods `T` (evaluates coefficient arrays at a root and divides by the discriminant-related invariant `F` to compute resolvent T-values for the radical solution), `l0`, `order`, and `uv`. |
| `rings.py` | Sparse polynomial rings: `PolyRing` and `PolyElement` classes with constructors `ring`, `xring`, `vring`, `sring`. `PolyRing` provides `to_ground` which strips the coefficient domain to its base (handles both composite domains and algebraic number fields that have a `.domain` attribute but aren't formally composite), `drop`/`__getitem__` for removing generators. `PolyElement` provides `coeff` (extracts the scalar multiplier for a specific monomial — accepts the integer 1 for the constant term, raises ValueError for non-monomial arguments), `_term_div` (creates a term-division closure: for field coefficients only checks monomial divisibility; for non-field integral domains additionally requires the coefficient to divide evenly via modular check), `div` (multivariate long division from CLO p64), `rem` (remainder-only variant that directly manipulates the internal dictionary for efficiency without tracking quotients), `evaluate` (reduces number of indeterminates, returns domain scalar for univariate), `subs` (preserves ring structure, keeps same number of indeterminates, returns constant polynomial for univariate via `ground_new`), `compose`, in-place arithmetic (`_iadd_monom`, `_iadd_poly_monom`) that copies self first when it is a canonical ring generator to prevent mutation, and degree/tail_degree methods. |
| `fields.py` | Sparse rational function fields: `FracField` and `FracElement` classes with constructors `field`, `xfield`, `vfield`, `sfield` for building fraction field objects. |
| `ring_series.py` | Power series evaluation and manipulation using sparse polynomials; provides `_invert_monoms` for reciprocal variable substitution (computing x^n * p(1/x) to reverse coefficient ordering of a sparse univariate polynomial), and functions for series arithmetic, composition, inversion, and elementary function expansions (exp, log, sin, cos, etc.). |
| `monomials.py` | Low-level monomial tuple data structures and enumeration: `itermonomials`, `monomial_count`, `Monomial` class (constructor validates that symbolic expressions are proper monomials with unit coefficient — raises ValueError for inputs like `2*x` that have a non-unit scalar multiplier), and pairwise monomial arithmetic (mul, div, gcd, lcm on exponent tuples). Does not operate on polynomials — for polynomial-level term GCD extraction see `polytools.py`. |
| `orderings.py` | Definitions of monomial orderings: `lex`, `grlex`, `grevlex` and their inverses, plus `ProductOrder` for block orderings and the `monomial_key` helper. |
| `groebnertools.py` | Groebner basis algorithms: improved Buchberger and F5B implementations operating on sparse polynomial ring elements. |
| `fglmtools.py` | Implementation of the matrix FGLM algorithm for converting a reduced Groebner basis from one monomial ordering to another. |
| `factortools.py` | Polynomial factorization routines primarily in characteristic zero: Zassenhaus (over ZZ), Wang's EEZ (multivariate over ZZ), and factorization dispatchers for ZZ, QQ, algebraic extensions (with `dup_ext_factor`/`dmp_ext_factor` that use norm-based reduction — if the norm factors into a single irreducible piece the original is declared irreducible as a shortcut), and GF(p) (thin wrappers that delegate GF(p) factoring to `galoistools`). |
| `euclidtools.py` | Euclidean algorithms for GCD (including `dup_qq_heu_gcd`/`dmp_qq_heu_gcd` which clear denominators and delegate to integer heuristic GCD, with trivial-case early returns for zero inputs), LCM, extended GCD, modular multiplicative inverse (`dup_invert`, raises `NotInvertible` when GCD is not unity), resultants, subresultants, and polynomial remainder sequences over dense list representations (coefficient lists, not symbolic expressions — for expression-level PRS variants including Pell-Gordon, Van Vleck, and sign sequence extraction, see `subresultants_qq_zz.py`). |
| `sqfreetools.py` | Square-free decomposition algorithms for dense recursive polynomials over characteristic-zero domains: `dup_sqf_list` decomposes a univariate polynomial into irreducible factors with distinct multiplicities using an iterative GCD loop (Yun's algorithm), extracting primitive content and forcing positive leading coefficient for integral domains before the loop; `dup_sqf_norm` computes a square-free norm over algebraic number field extensions by iteratively shifting the polynomial (f(x) → f(x-s·α)) and recomputing the resultant until the result has no repeated factors; `dup_sqf_p`, `dup_sqf_part`, and their multivariate (`dmp_`) counterparts. `dmp_sqf_list` normalizes sign for non-field domains by negating both the polynomial and content when the leading ground coefficient is negative. For GF(p) square-free operations, see `galoistools.py`. |
| `rootoftools.py` | Implementation of `CRootOf` (indexed algebraic root representation with isolation and refinement) and `RootSum` (sum of a function over all roots, with `_rational_case` that uses Viète's formulas and symmetric function decomposition to evaluate sums of rational expressions over roots without computing them explicitly). |
| `rootisolation.py` | Real and complex root isolation and refinement algorithms based on Sturm sequences (including `dup_sturm` which computes the Sturm sequence for root counting — raises `DomainError` if the coefficient domain is not a field), Descartes' rule, and interval arithmetic. |
| `solvers.py` | Low-level linear systems solver using polynomial ring elements; converts equations to matrix form and solves via row reduction. |
| `constructor.py` | Tools for constructing coefficient domains from expressions; `construct_domain` auto-detects whether ZZ, QQ, RR, algebraic, or composite domains are appropriate. Internally, `_construct_composite` builds composite domains (e.g., ZZ[x], QQ(x)) by examining expression coefficients: when the `field` option is enabled it unconditionally uses a fraction field, otherwise it inspects each denominator to decide between a polynomial ring (all denominators are trivial constants) and a fraction field (non-trivial denominators). |
| `partfrac.py` | Algorithms for partial fraction decomposition of rational functions: undetermined coefficients method and Bronstein's full partial fraction algorithm. |
| `numberfields.py` | Computational algebraic field theory: minimal polynomials, primitive elements, field isomorphisms, algebraic number recognition, and `to_number_field`. |
| `specialpolys.py` | Functions for generating special and benchmark polynomials: Swinnerton-Dyer, cyclotomic, symmetric, random, and the Fateman benchmark polynomials. |
| `orthopolys.py` | Efficient generation of classical orthogonal polynomials: Jacobi, Gegenbauer, Chebyshev (T and U), Hermite, Legendre, Laguerre, and Spherical Bessel. |
| `rationaltools.py` | Tools for manipulation of rational expressions; provides `together` for combining rational subexpressions by denesting. |
| `galoistools.py` | Dense univariate polynomials with coefficients in Galois fields (GF(p)): arithmetic (`gf_add` adds two polynomials modulo p, calling `gf_strip` to remove leading zeros when both inputs have equal degree since leading terms may cancel; `gf_sub`, `gf_mul`, `gf_neg`), ground element operations (`gf_add_ground`/`gf_sub_ground`/`gf_mul_ground` for scalar-polynomial arithmetic in GF(p) — for constant polynomials, when the result is zero mod p, returns empty list `[]` rather than `[0]`), composition (`gf_compose` with constant-polynomial shortcut, `gf_compose_mod`), GCD, LCM (`gf_lcm` returns empty list when either input is zero), cofactors, extended Euclidean algorithm, square-free testing (`gf_sqf_p` — returns True for zero polynomial) and decomposition (`gf_sqf_list`), complete factorization of non-square-free polynomials (`gf_factor` combines sqf decomposition with per-component irreducible splitting to track multiplicities), irreducibility testing (Ben-Or, Rabin), and CRT. |
| `densebasic.py` | Basic tools for dense recursive polynomial representations in K[x] or K[X]: degree, leading/trailing coefficients, conversion between dict and dense list formats (`dup_from_dict` which dispatches on whether keys are plain integers or single-element tuples, `dmp_from_dict` for multivariate), constant polynomial construction (`dmp_ground` which returns the zero polynomial representation when the constant is falsy instead of wrapping zero in nested lists, `dmp_grounds`/`dmp_zeros`), inflation/deflation (including `dmp_multi_deflate` for deflating sets of multivariate polynomials — replaces zero GCD entries with 1 to prevent division-by-zero when a variable has all-zero exponents across the set), and list manipulations. |
| `densearith.py` | Arithmetic operations for dense recursive polynomials over general domains (not GF(p) — for finite field polynomial arithmetic see `galoistools.py`): addition, subtraction, multiplication, division, ground element operations (`dup_add_ground`, `dup_sub_ground`, etc.), power, pseudo-division, and norm computations. |
| `densetools.py` | Advanced tools for dense recursive polynomials (K[x]/K[X]): integration, differentiation, Horner-scheme evaluation (`dup_eval`/`dmp_eval` — returns trailing coefficient directly when evaluating at zero), composition, truncation, monic/primitive normalization, and real/imaginary part extraction. |
| `heuristicgcd.py` | Heuristic polynomial GCD algorithm (HEUGCD) for sparse polynomials strictly in Z[X] (integer coefficients only), based on evaluation-interpolation. For the Q[X] wrappers that clear denominators before delegating here, see `euclidtools.py`. |
| `modulargcd.py` | Modular GCD algorithms for polynomials over ZZ and algebraic number fields, using Chinese Remainder Theorem, evaluation/interpolation (`_interpolate_multivariate` for Lagrange reconstruction over Z_p with a `ground` flag for coefficient-ring variables), and domain conversion utilities (`_to_ZZ_poly` to convert from Q(α)[x] to integer-coefficient Z[x,z] by clearing denominators and replacing the algebraic element with a formal indeterminate). |
| `distributedmodules.py` | Low-level sparse distributed representation of free module elements over polynomial rings; implements `sdm_groebner` (Buchberger-style standard basis computation with sugar strategy, returning `([], [])` or `[]` for all-zero generators depending on extended mode), Mora's normal form algorithm (`sdm_nf_mora`), and monomial/vector arithmetic for the `sdm_` (sparse distributed module) data format. |
| `compatibility.py` | Compatibility interface (sparse-dense bridging layer) between dense and sparse polynomial representations; re-exports all dense operations and defines the `IPolys` wrapper class with methods like `dmp_LC`/`dmp_TC` that extract multivariate leading/trailing coefficients — when the coefficient is itself a sub-expression in fewer indeterminates (a list), it slices the ring via `self[1:]` and converts through the sub-ring; when it's a ground element, it returns the scalar directly. | `dispersion.py` | Computation of the dispersion set and dispersion of two polynomials, measuring how far apart integer-shifted roots can be shared. |
| `subresultants_qq_zz.py` | Standalone implementations of Euclidean, Sturmian, and (modified) subresultant polynomial remainder sequences operating on SymPy expressions (not dense list representations). Unlike `euclidtools.py` which uses dense list representations, this module works directly with symbolic polynomial expressions and provides multiple algorithmic variants. Includes `sign_seq` (extracts the sequence of signs of leading coefficients from a polynomial remainder chain), `sturm_pg` (Pell-Gordon 1917 theorem with mode parameter), `sturm_q` (Q[x] sign-flipping with trailing zero/nan cleanup), `sturm_amv` (constructs sign-alternating Sturm sequences from a Euclidean division chain by applying the pattern "-, -, +, +, -, -, +, +,..." to successive remainders, with optional scaling by the leading coefficient's power for modified subresultants), `euclid_pg` (Euclidean PRS via Pell-Gordon theorem — returns early if the Sturm sequence is empty or has only two polynomials), `euclid_amv` (AMV Euclidean PRS using Collins-Brown-Traub coefficient reduction formula — removes trailing NaN/zero entries from the output sequence), `subresultants_rem` (subresultant PRS using Euclidean division in Q[x] with sign correction via determinant evaluation — swaps inputs when the first polynomial has lower degree), `modified_subresultants_pg` (modified subresultant PRS via the 1917 Pell-Gordon theorem — denominator calculation for the sign-determining fraction differs between complete and incomplete sequences based on degree gaps), `subresultants_vv` / `subresultants_vv_2` (Van Vleck triangularization method for subresultant PRS — triangularizes smaller matrices iteratively, with special handling for the final triangularized matrix when it has exactly 2 rows vs. more rows), `rem_z` (integer polynomial remainder that premultiplies by the absolute value of the divisor's leading coefficient raised to a power, unlike `prem` which uses the signed leading coefficient), `bezout` (constructs symmetric bilinear Bezout matrix from two univariate polynomials with a mode parameter: 'prs' reverses row/column indices so highest-degree coefficients appear first, 'bz' uses natural ordering), `find_degree` (determines the polynomial degree from the last row of a triangularized matrix — returns 0 instead of negative when leading zeros exceed the dividend degree, returns None for all-zero rows), and Sylvester matrix methods. |
| `agca/__init__.py` | Package init for algebraic geometry and commutative algebra (AGCA); re-exports the `homomorphism` function. |
