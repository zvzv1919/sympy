Also defines `GroebnerBasis` with `fglm` method (converts a Groebner basis from one monomial ordering to another using the FGLM algorithm—returns self unchanged if source and target orderings match; raises `NotImplementedError` if the associated ideal is not zero-dimensional; promotes the domain to a field before delegating to `matrix_fglm` in `fglmtools.py`) and `is_zero_dimensional` (checks if the ideal is zero-dimensional by verifying that for every variable there exists a basis element whose leading monomial is a pure power of that variable). `div` returns different types for the zero-dividend case: a single `ring.zero` quotient when given a single divisor, but an empty list `[]` when given a list of divisors; `coeff` extracts the coefficient for a given monomial, with a special case where passing the integer `1` retrieves the constant (degree-zero) term by looking up the zero monomial—raises `ValueError` if the input is a term with a non-unit scalar coefficient (e.g., `2*x` instead of `x`), since it requires a pure monomial with coefficient equal to one; | `factortools.py` | Polynomial factorization routines: Zassenhaus, Wang's EEZ, and multivariate factorization over ZZ, QQ, GF(p), and algebraic number fields. `dup_factor_list` is the main entry point for univariate irreducible decomposition, with domain-aware branching: for inexact/approximate coefficient domains (e.g., floating-point), it first converts to the associated exact domain via `get_exact()`, performs all factorization in exact arithmetic, then converts results back to the original inexact domain; for field domains, it clears denominators and works in the associated ring (with special handling for inexact fields: instead of dividing the leading coefficient by the cleared denominator, it divides each individual factor by the denominator and converts each factor back to the inexact domain separately); for ZZ it delegates to `dup_zz_factor`; for polynomial coefficient domains it uses injection/ejection. Also includes `dup_ext_factor`/`dmp_ext_factor` for factoring over algebraic number fields—these compute the square-free norm to reduce factorization to the base domain (e.g., ZZ), factor the norm, then recover the original factors via inner GCD and shift operations with trial division for multiplicities. Also includes `dup_cyclotomic_p` (tests whether a univariate integer polynomial is cyclotomic—i.e., a minimal annihilating polynomial whose roots are primitive complex roots of unity—using a recursive algorithm: first validates leading/trailing coefficients are ±1 and optionally checks irreducibility, then splits coefficients by index parity into even-indexed and odd-indexed groups, squares each group, computes F = g² - x·h², and recursively checks if F matches the original, its mirror, or the square of its square-free part; the recursion terminates when a match is found or all branches fail), `dup_zz_cyclotomic_poly` (generates the n-th cyclotomic polynomial), and `_dup_cyclotomic_decompose`. `dmp_zz_factor` orchestrates complete multivariate integer factorization by extracting ground content, computing the primitive part with respect to the main variable via `dmp_primitive`, then recursively factoring the content polynomial in fewer variables. Includes trial division for determining factor multiplicities (`dup_trial_division` uses simple falsiness for zero-remainder checks; `dmp_trial_division` uses `dmp_zero_p` because multivariate dense zero representations cannot be tested with `not r`), Mignotte bounds, and Hensel lifting.
