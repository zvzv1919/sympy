# SymPy — Catalog

SymPy is a pure-Python library for symbolic mathematics. It aims to be a full-featured computer algebra system (CAS) while keeping its code simple, comprehensible, and easily extensible. Its only hard dependency is mpmath (arbitrary-precision arithmetic). This version is **1.1.2.dev**.

## Subdirectories

| Directory | Description |
|-----------|-------------|
| [algebras/](algebras/catalog.md) | Abstract algebra structures (e.g. quaternions) |
| [assumptions/](assumptions/catalog.md) | Assumption *query handlers* (`AskHandler` classes) that evaluate predicates like `Q.positive`, `Q.finite`, `Q.imaginary` on composite expressions by dispatching on expression type (Add, Mul, Pow, exp, log). For example, `AskFiniteHandler.Pow` decides boundedness of exponentiation by checking base magnitude vs unity and exponent sign. **Not** where assumption *rules/facts* are defined — the implication/equivalence rules (e.g. `integer -> rational`, `zero -> even & finite`) and the `_assume_rules`/`_assume_defined` fact sets live in `core/assumptions.py`. |
| [benchmarks/](benchmarks/catalog.md) | Performance benchmarks for SymPy internals |
| [calculus/](calculus/catalog.md) | Calculus operations: finite differences (`finite_diff.py` with `as_finite_diff`), singularities, continuity utilities, and `calculus/util.py` with `AccumulationBounds` (`__contains__` for membership testing — **not** `sets/sets.py` `Set.contains`), `not_empty_in` (finding non-empty domain portions — **not** `solvers/solveset.py` `domain_check`). See also `series/` for limits and `core/expr.py` for the `series()` method. |
| [categories/](categories/catalog.md) | Category theory: objects, morphisms (`NamedMorphism.__new__`, `Morphism.__mul__` for abstract morphism composition), diagrams, and Xy-pic diagram drawing. **Not** for ring-module homomorphisms — those are in `polys/agca/homomorphisms.py`. |
| [codegen/](codegen/catalog.md) | Code generation **infrastructure**: abstract syntax tree nodes (`ast.py` with `Assignment`, `CodeBlock`, `Variable`, `Type`), code wrappers, and algorithm-to-code translation scaffolding. **Not** where language-specific code *printers* live — Julia/Octave/Fortran/C/LLVM/Rust/JS/GLSL printers are in `printing/`. **Not** the higher-level routine-generation API — `make_routine` and `CCodeGen`/`FCodeGen` live in `utilities/codegen.py`. |
| [combinatorics/](combinatorics/catalog.md) | Discrete structures and group theory: `Permutation`, `PermutationGroup` (with `is_subgroup`, orbit/stabilizer algorithms), `Polyhedron` (3D solid symmetry groups), `free_group.py` (`FreeGroup.contains`), `Partition`/`IntegerPartition` (`partitions.py` with `Partition.__eq__` — **not** `utilities/enumerative.py` which has `PartComponent` for low-level multiset partition enumeration), Graycode, and tensor canonicalization. **Not** for combinatorial *number sequences* or *counting functions* — those live in `functions/combinatorial/`. |
| [concrete/](concrete/catalog.md) | Concrete mathematics: symbolic sums (`summations.py` with `Sum._eval_derivative`), products, `gosper.py` (`gosper_sum` for Gosper's algorithm), and the `ExprWithLimits` base class (`expr_with_limits.py` with `ExprWithLimits._eval_subs` for substitution in bounded expressions — **not** `core/basic.py` `Basic._eval_subs`). |
| [core/](core/catalog.md) | Core symbolic engine: `Symbol`, `Number`, `Expr`, `Add`, `Mul`, `Pow`, caching, evaluation, and compatibility. Key details: `core/expr.py` has `Expr.series()` and `Expr._eval_lseries` (lazy series term generator — **not** in `series/formal.py`), `extract_additively`/`extract_multiplicatively`; `core/add.py` has `Add._eval_as_leading_term`; `core/mul.py` has `Mul.flatten` (product flattening, numeric base combination, power merging — **not** in `simplify/powsimp.py` which is a user-facing simplification), `Mul._eval_is_infinite`; `core/function.py` has the `expand()` public API function and `Application._eval_subs` (substitution into unevaluated functions — **not** in `simplify/`); `core/exprtools.py` has `factor_nc` for noncommutative factoring; `core/numbers.py` has `AlgebraicNumber`, `igcd`, `ilcm`; `core/assumptions.py` has the master `_assume_rules` fact table and `_assume_defined` set (including the standalone 'polar' property with no inference rules); `core/power.py` has `Pow._eval_as_leading_term`, `Pow._eval_nseries`; `core/compatibility.py` has `ordered()` (canonical ordering function — **not** in `utilities/iterables.py`); `core/basic.py` has `Basic.__eq__`, `Basic._eval_subs`. |
| [crypto/](crypto/catalog.md) | Classical cryptographic ciphers (Caesar, Vigenere, RSA, etc.) |
| [deprecated/](deprecated/catalog.md) | Deprecated modules with import-time warnings pointing to replacements |
| [diffgeom/](diffgeom/catalog.md) | Differential geometry: `Manifold`, `Patch` (auto-registers with parent manifold during `__new__`), `CoordSystem` (coordinate transformations, Jacobians, point mapping), and `rn.py` (predefined manifolds/coordinate systems for R^2 and R^3, e.g. `R2`, `R2_r`, `R2_p`). **Not** for coordinate-system vector algebra — that's in `vector/`. |
| [external/](external/catalog.md) | Utilities for importing and probing optional external dependencies |
| [functions/](functions/catalog.md) | Elementary and special mathematical function **definitions** — their `eval()` classmethod logic for automatic simplification, special-value dispatch, branch-cut handling, `fdiff` derivatives, `_eval_rewrite_as_*`, and `_eval_aseries` asymptotic expansions. Includes: `functions/elementary/exponential.py` (`exp.eval` with single-log-factor simplification in Mul args), `functions/elementary/trigonometric.py` (trig function definitions — **not** trig identity rewriting rules which are in `simplify/fu.py`), `functions/elementary/complexes.py` (`_polarify`/`_unpolarify` for polar-lift transformations, `Abs`, `re`, `im`, `arg`, `conjugate`, `polar_lift`), `functions/elementary/miscellaneous.py` (`cbrt`, `root`, `Min`, `Max`); `functions/special/gamma_functions.py` (`lowergamma.eval` with branch-factor extraction, `uppergamma.eval`/`uppergamma.fdiff`, `polygamma._eval_rewrite_as_harmonic`, `loggamma._eval_aseries`), `functions/special/elliptic_integrals.py` (`elliptic_f.eval` with special values at ±∞), `functions/special/hyper.py` (`meijerg` constructor — notably does *not* check convergence conditions), `functions/special/bessel.py` (`BesselBase._eval_expand_func` for Bessel function expansion), `functions/special/singularity_functions.py` (`SingularityFunction.fdiff` with special n=0/-1 derivative rules); `functions/combinatorial/factorials.py` (`subfactorial.eval` with Infinity→Infinity, `binomial._eval` using prime decomposition for exact integer results), `functions/combinatorial/numbers.py` (`harmonic.eval` with NaN for negative order at infinity, `euler._eval_rewrite_as_Sum` returns None for odd args, `nT` partition counting with identical-element optimization). **Not** for integration algorithms using special functions — those live in `integrals/meijerint.py`. **Not** for discrete group structures (permutations, etc.) — those are in `combinatorics/`. |
| [geometry/](geometry/catalog.md) | Computational geometry: points, lines, polygons, circles, ellipses, curves, and `geometry/util.py` (`idiff` for implicit differentiation — **not** `calculus/finite_diff.py` `as_finite_diff`, `_uniquely_named_symbol`, `_symbol`). |
| [holonomic/](holonomic/catalog.md) | Holonomic functions represented via linear differential equations with polynomial coefficients. `HolonomicFunction` class with `__init__`, `__repr__` (accumulated prime marks), `__pow__` (power of holonomic functions), `_extend_y0` (extending initial conditions for power-series solutions at regular singular points via indicial equation roots). Also `holonomicerrors.py` with `BaseHolonomicError.new` for custom exception construction, and `linearsolver.py` with `NewMatrix.gauss_jordan_solve`. **Not** the same as `solvers/ode.py` which solves general ODEs — holonomic/ specifically handles the differential-operator algebra and power-series methods for holonomic (D-finite) functions. |
| [integrals/](integrals/catalog.md) | Symbolic integration *algorithms*: `integrals.py` (`Integral._eval_derivative` for differentiating under the integral sign), `rde.py` (`spde` — special polynomial differential equation solver for Risch algorithm), `meijerint.py` (Meijer G-function integration — `meijerint_definite`, `meijerint_inversion`), `manualintegrate.py`, transforms (Laplace, Fourier, Mellin), and the Risch algorithm. **Not** where special function *definitions*/evaluation/special values/branch cuts/`fdiff`/`_eval_rewrite_as_*` are defined — those `eval()` methods live in `functions/special/`. **Not** for polynomial integration — `dup_integrate` lives in `polys/densetools.py`. |
| [interactive/](interactive/catalog.md) | Interactive session helpers (`isympy` startup, printing configuration, IPython integration) |
| [liealgebras/](liealgebras/catalog.md) | Lie algebras and root systems for classical groups (A, B, C, D, E, F, G) |
| [logic/](logic/catalog.md) | Boolean algebra (`boolalg.py` with `eliminate_implications`, `to_dnf`), propositional logic, satisfiability (DPLL), and inference. **Not** for converting probability domains to boolean expressions — that's `stats/frv.py`. |
| [matrices/](matrices/catalog.md) | Symbolic and numeric matrix algebra: `matrices.py` (`MatrixBase.col_insert`), dense (`dense.py` with `DenseMatrix.equals`), sparse (`sparse.py` with `SparseMatrix.__getitem__`), immutable, and block matrices; `expressions/matmul.py` (`refine_MatMul`); eigenvalues, decompositions. **Not** for sparse N-dimensional arrays — those are in `tensor/array/sparse_ndim_array.py`. |
| [ntheory/](ntheory/catalog.md) | Number theory: primes, factorization, `residue_ntheory.py` (`sqrt_mod`), `modular.py` (general Chinese Remainder Theorem `crt`), `egyptian_fraction.py` (`egyptian_fraction` for greedy Egyptian fraction decomposition), continued fractions, and multiplicative functions. **Not** for polynomial modular GCD algorithms — those are in `polys/modulargcd.py`. |
| [parsing/](parsing/catalog.md) | Parsing mathematical expressions from strings, LaTeX, Mathematica (with `translateFunction` that strips "Arc" prefix for inverse trig: ArcSin→asin), and other formats |
| [physics/](physics/catalog.md) | Physics subpackages: `physics/quantum/` (quantum operator algebra — `commutator.py` with `Commutator._eval_expand_commutator`, `anticommutator.py` with `AntiCommutator.eval`, `pauli.py` with `SigmaZ._eval_power`, `spin.py` with `SpinOpBase._represent_base` for spin-operator matrix representations, `identitysearch.py` with `is_scalar_sparse_matrix` for gate identity verification, `matrixutils.py` with `_sympy_tensor_product` for quantum tensor products, Clebsch-Gordan `cg_simp`, Shor's algorithm `shor.py`, circuit utilities `circuitutils.py`), `physics/vector/` (reference-frame-based vector mechanics — `Vector.diff` with DCM-aware frame re-expression, `Dyadic` cross/dot/pretty-printing via `dyadic.py`), `physics/hep/gamma_matrices.py` (Kahane simplification with virtual index insertion for consecutive dummy indices), `physics/secondquant.py` (`wicks` for Wick's theorem normal-ordering with dummy index renaming), `physics/unitsystems/` (unit system definitions including `systems/natural.py` for natural units where c=ℏ=1), `physics/mechanics/` (Kane's method, Lagrangian mechanics), optics, hydrogen wave functions. See also `vector/` for the separate coordinate-system-based vector algebra module. |
| [plotting/](plotting/catalog.md) | 2-D and 3-D plotting with backends for matplotlib, pyglet, and text-based output. Also contains `experimental_lambdify.py` (`vectorized_lambdify.__call__` for array-aware expression evaluation — **not** `utilities/lambdify.py` which is the general-purpose lambdify) with `Lambdifier` class for translating symbolic expressions to numeric strings, and `pygletplot/plot_rotation.py` (3D rotation utilities). |
| [polys/](polys/catalog.md) | Polynomial algebra: factorization (`factortools.py` with `dup_zz_zassenhaus`), GCD, Groebner bases, algebraic number fields, polynomial rings, domains, `polyutils.py` (`_dict_from_expr` for expression-to-polynomial conversion), `densetools.py` (`dup_integrate` for polynomial integration), `modulargcd.py` (`_integer_rational_reconstruction`, `_chinese_remainder_reconstruction_multivariate` — **not** the same as `ntheory/modular.py` `crt` which is for general CRT), and `ring_series.py` (truncated power series arithmetic in polynomial rings — `rs_pow`, `rs_log`, `rs_cos`/`rs_sin`). Also `polys/agca/` for abstract algebra: `agca/homomorphisms.py` (`ModuleHomomorphism.__eq__`, `__mul__` for composition — **not** the category-theoretic morphisms in `categories/baseclasses.py`), `agca/modules.py` (`Module.__eq__`). Also `polys/benchmarks/` (`bench_solvers.py` with large linear-system benchmarks like `sol_165x165`). Also `polys/domains/__init__.py` for arithmetic backend selection. Also `polys/orthopolys.py` for spherical Bessel function coefficients. Also `polys/polytools.py` `cancel()` with noncommutative fallback. **Not** for formal power series coefficient formulas — those are in `series/formal.py`. |
| [printing/](printing/catalog.md) | Expression-to-string serialization and **language-specific code printers**: LaTeX, MathML, pretty-print, `julia.py` (Julia printer with `_print_SparseMatrix`, `_print_Mul`), `octave.py` (Octave/MATLAB printer with `_print_MatrixBase`), `fcode.py` (Fortran printer — raises ValueError if Piecewise lacks a True default condition), `ccode.py` (C), `jscode.py` (JS), `rust.py` (Rust), `glsl.py` (GLSL), `llvmjitcode.py` (LLVM JIT with `_convert_expr`), `repr.py` (`ReprPrinter._print_MatrixBase`), `str.py` (`_print_DMP` with ring-to-sympy fallback on SympifyError). These printers convert SymPy expressions to target-language strings. **Not** the code-generation AST infrastructure (`Assignment`, `CodeBlock`) — that lives in `codegen/ast.py`. For Xy-pic diagram arrow rendering, see `categories/diagram_drawing.py`. |
| [sandbox/](sandbox/catalog.md) | Experimental / sandbox modules (indexed objects, tensors prototype) |
| [series/](series/catalog.md) | Series expansions (including `approximants.py` with `approximants` for Padé-like rational approximation of series), limits, formal power series (`formal.py` with `rational_algorithm` — for computing formal series coefficients, **not** for `_eval_lseries`/`_eval_aseries` which live on functions in `core/expr.py` and `functions/`), Fourier series, sequences (`sequences.py` with `SeqBase.free_symbols`), and `order.py` (`Order.__new__`). Key files: `limits.py` (public `limit` function with `heuristics` fast-path), `gruntz.py` (Gruntz algorithm). For truncated power series *arithmetic* in polynomial rings, see `polys/ring_series.py`. The `series()` method itself lives in `core/expr.py`. |
| [sets/](sets/catalog.md) | Set theory: intervals, unions, intersections, finite sets, `sets.py` (`Set.contains`), and `conditionset.py` (`ConditionSet.__new__`). **Not** for `AccumulationBounds` containment (that's `calculus/util.py`) or finite random variable domains (that's `stats/frv.py`). |
| [simplify/](simplify/catalog.md) | Expression simplification: trigsimp (including Groebner-basis approach with `build_ideal`), radsimp, powsimp (user-facing power simplification — **not** the core `Mul.flatten` in `core/mul.py`), collect, CSE, hypergeometric simplification, `fu.py` (trig identity rewriting rules like `TR3` and `_osborne` for hyperbolic conversions — **not** trig function *definitions* which are in `functions/elementary/trigonometric.py`), `simplify.py` (`simplify` entry point, `bottom_up` tree walker — **not** the `bottom_up` in `strategies/traverse.py`), `ratsimp.py` (`ratsimpmodprime`), and `epathtools.py` (XPath-like `EPath.apply`). **Not** where `expand()` lives — that's in `core/function.py`. |
| [solvers/](solvers/catalog.md) | Equation solving: algebraic (`solvers.py` with `_simple_dens` for denominator extraction), ODE (`ode.py` with `dsolve`, `check_linear_2eq_order1`, `lie_heuristic_abaco2_unique_general`, `ode_2nd_power_series_regular` — for general ODE solving, **not** holonomic/D-finite functions which are in `holonomic/`), PDE, recurrence, inequality, `solveset.py` (`domain_check`), and Diophantine solvers (including `diophantine.py` with `prime_as_sum_of_two_squares`). |
| [stats/](stats/catalog.md) | Symbolic probability and statistics: random variables, distributions, expectation, `frv.py` (finite random variables — `FiniteDomain.as_boolean` converts domains to DNF boolean expressions, `ConditionalFiniteDomain.__new__` for conditional probability domains — **not** `sets/conditionset.py` or `logic/boolalg.py`), and `error_prop.py` (`variance_prop` for symbolic uncertainty propagation). |
| [strategies/](strategies/catalog.md) | Rule-based expression rewriting strategies: tree traversal (`traverse.py` with generic `bottom_up`/`top_down` — **not** `simplify/simplify.py` `bottom_up` which is a separate implementation), branching (`core.py` with `switch`), and composition |
| [tensor/](tensor/catalog.md) | Tensor algebra: indexed objects, index conventions (`index_methods.py` with `get_contraction_structure`), and multi-dimensional array operations (`array/arrayop.py` with `tensorproduct` for general array tensor products — **not** quantum tensor products which are in `physics/quantum/matrixutils.py`, `array/sparse_ndim_array.py` with `SparseNDimArray.__getitem__`, `array/ndim_array.py` with `NDimArray._parse_index`) |
| [unify/](unify/catalog.md) | Unification algorithms (structural and expression-level pattern matching) |
| [utilities/](utilities/catalog.md) | General utilities: `iterables.py` (`multiset_partitions`, `has_dups`, `sift` for partitioning iterables by predicate — **not** `strategies/core.py` `switch`), `enumerative.py` (`PartComponent.__eq__` for multiset partition enumeration components — **not** `combinatorics/partitions.py`), `codegen.py` (`make_routine` and `CCodeGen`/`FCodeGen` for high-level code generation — **not** `codegen/ast.py`), `runtests.py` (`_test` for test runner), `lambdify.py`, decorators, memoization, testing. Also `autowrap.py` (compiles generated code into Python-callable binaries), and `misc.py` (`find_executable`). |
| [vector/](vector/catalog.md) | Vector algebra and calculus in curvilinear coordinate systems (the "new" vector module). `vector/coordsysrect.py` has `CoordSysCartesian` with `orient_new_axis` and other orientation methods. `vector/functions.py` has `express()` for re-expressing vectors/dyadics/scalars and `_path` for finding coordinate-system transformation paths. `vector/orienters.py` has `QuaternionOrienter.__new__` for quaternion-based orientation. **Not** the same as `physics/vector/` which provides reference-frame-based vector mechanics (`ReferenceFrame.orientnew`). **Not** the same as `diffgeom/` which handles differential geometry on manifolds. |

## Root Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package entry point; checks for mpmath, imports all public submodules, initializes the evalf table, and sets `SYMPY_DEBUG` from the environment |
| `abc.py` | Exports all single Latin and Greek letters as pre-defined `Symbol` objects for convenient interactive use (`from sympy.abc import x, y`) |
| `conftest.py` | Pytest configuration: test-splitting (`--split`), cache clearing between modules, architecture/ground-type reporting, and disabled-module skipping |
| `galgebra.py` | Deprecated stub that raises `ImportError` directing users to the standalone `galgebra` package |
| `release.py` | Defines the version string `__version__ = "1.1.2.dev"` |
| `this.py` | Easter egg — prints "The Zen of SymPy" (ROT-13 encoded aphorisms about the project's philosophy) |
