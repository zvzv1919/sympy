# SymPy — Catalog

SymPy is a pure-Python library for symbolic mathematics. It aims to be a full-featured computer algebra system (CAS) while keeping its code simple, comprehensible, and easily extensible. Its only hard dependency is mpmath (arbitrary-precision arithmetic). This version is **1.1.2.dev**.

| [core/](core/catalog.md) | Core symbolic engine: expression tree nodes (Symbol, Number, Expr, Add, Mul, Pow), basic arithmetic dispatch, evaluation protocol, caching, and Python compatibility shims. successively only when needed, raises ValueError for unresolved ties when warn=True and default=False (checks via uniq whether tied items are actually distinct). `trace.py` has Tr class for trace detection. `assumptions.py` has _ask for recursive property resolution with anti-recursion guard (stores None) and shuffled prerequisites. `multidimensional.py` has vectorize decorator that lifts extrapolation for polynomial convergence, direct summation for geometric/faster). `function.py` has _coeff_isneg which checks if the leading numeric coefficient is negative (returns False for a Symbol with negative=True because its implicit coefficient is 1), expand_log and other single-hint expand wrappers (expand_log explicitly disables mul hint to prevent interference with log splitting). `add.py` Add.flatten filters out non-negative or real-finite terms when accumulated coefficient is ±∞. `basic.py` has dummy_eq for comparing expressions differing only in anonymous placeholder (Dummy) variables (raises ValueError if more than one Dummy on LHS), and matches for recursive structural pattern matching that ensures wildcard consistency by applying accumulated substitutions via xreplace before matching each argument. `expr.py` has _eval_lseries providing default adaptive lazy series iteration (increments n until nseries returns non-Order terms, yields incremental differences). `relational.py` has Relational.as_set which converts a univariate inequality to a real set (raises NotImplementedError for multivariate). Add._eval_as_leading_term recursively subtracts when simplified leading terms are zero but not provably zero. `exprtools.py` provides `gcd_terms` which masks non-commutative parts with Dummy symbols. `operations.py` has AssocOp._matches_commutative which decomposes x**n into Mul(x, x**(n-1)). ## Root Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package entry point; checks for mpmath, imports all public submodules, initializes the evalf table, and sets `SYMPY_DEBUG` from the environment |
| `abc.py` | Exports all single Latin and Greek letters as pre-defined `Symbol` objects for convenient interactive use (`from sympy.abc import x, y`); also provides `clashing()` to detect namespace collisions between letter symbols and other SymPy exports |
| `conftest.py` | Pytest configuration: test-splitting (`--split`), cache clearing between modules, architecture/ground-type reporting, and disabled-module skipping |
| `galgebra.py` | Deprecated stub that raises `ImportError` directing users to the standalone `galgebra` package |
| `release.py` | Defines the version string `__version__ = "1.1.2.dev"` |
| `this.py` | Easter egg — prints "The Zen of SymPy" (ROT-13 encoded aphorisms about the project's philosophy) |
