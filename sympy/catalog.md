# SymPy — Catalog

SymPy is a pure-Python library for symbolic mathematics. It aims to be a full-featured computer algebra system (CAS) while keeping its code simple, comprehensible, and easily extensible. Its only hard dependency is mpmath (arbitrary-precision arithmetic). This version is **1.1.2.dev**.

## Subdirectories

| Directory | Description |
|-----------|-------------|
| [algebras/](algebras/catalog.md) | Abstract algebra structures (e.g. quaternions) |
| [assumptions/](assumptions/catalog.md) | Assumption system: declaring and querying properties of symbols (positive, integer, etc.), SAT-based inference rule registration (ask_generated), specific handlers for determining properties of compound expressions (e.g., log/exp/pow real/imaginary checks), `handlers/matrices.py` with handlers for matrix predicates (orthogonal MatMul requires scalar factor==1, unitary MatMul requires abs(factor)==1 — this is the key distinction between orthogonal and unitary checks; diagonal MatrixSlice returns None for off-diagonal), and `refine.py` for assumption-based expression simplification (refine_atan2, refine_Pow, refine_abs) — note: the core assumption property resolution engine (_ask with anti-recursion guard and shuffled prerequisites) lives in `core/assumptions.py`, not here |
| [benchmarks/](benchmarks/catalog.md) | Performance benchmarks for SymPy internals |
| [calculus/](calculus/catalog.md) | Calculus operations: finite differences (differentiate_finite, apply_finite_diff), singularities, continuity utilities, `euler.py` with euler_equations deriving Euler-Lagrange stationary-condition equations from an action integrand (detects max differentiation order across all Derivative atoms and iterates combinations_with_replacement of independent variables), and `util.py` with AccumulationBounds class for interval arithmetic (__new__ returns the scalar directly when min==max; __pow__ neglects complex part when lower bound is negative; log returns None when lower bound is not positive) — for symbolic integration see `integrals/`, for series/limits see `series/` |
| [categories/](categories/catalog.md) | Category theory: objects, morphisms, diagrams, and diagram drawing |
| [codegen/](codegen/catalog.md) | Code generation AST node types only (Assignment, CodeBlock, For, Variable, Type, Declaration) and specialized C/Fortran math function wrappers (expm1, log1p, etc.) — does NOT contain routine/function generation logic, language-specific code generators, function-signature construction, code emission, Piecewise handling, or special-function translation; compilable routine generation and function signatures live in `utilities/codegen.py`; expression-to-code-string rendering (including Piecewise restructuring, spherical Bessel rewrites, conditional expressions) lives in `printing/` |
| [combinatorics/](combinatorics/catalog.md) | Combinatorics: permutations, partitions, polyhedra, group theory (named groups, symmetry groups), Graycode, prufer sequences, subsets (with subset_indices using for/else control flow), and `tensor_can.py` which contains the actual Butler-Portugal double-coset canonicalization algorithm implementation (double_coset_can_rep), dummy_sgs for generating symmetry group strong generators of contracted index pairs (encodes anticommuting sign change by swapping sign positions n↔n+1, vs commuting which only swaps the pair), _dumx_remove for paired-index elimination (uses even/odd position to find partner), and get_symmetric_group_sgs — `tensor/tensor.py` delegates canonicalization here |
| [concrete/](concrete/catalog.md) | Concrete mathematics: symbolic sums (Sum with eval_sum_hyper decomposing finite-range sums into differences of semi-infinite hypergeometric series), products (Product), gosper and hypergeometric summation algorithms, delta operators, and `guess.py` for heuristic generating-function guessing (falls back to log-derivative approach when direct rational guess fails) |
| [core/](core/catalog.md) | Core symbolic engine: expression tree nodes (Symbol, Number, Expr, Add, Mul, Pow), basic arithmetic dispatch, evaluation protocol, caching, and Python compatibility shims. `numbers.py` has Rational with as_content_primitive (returns (S.One, self) when value is zero). `compatibility.py` has `ordered` — a conservative tie-breaking sort utility that applies keys successively only when needed, raises ValueError for unresolved ties when warn=True and default=False (checks via uniq whether tied items are actually distinct). `trace.py` has Tr class for trace operations (__new__ returns just the commutative product when all factors in a Mul are commutative, no trace wrapper). `logic.py` has AndOr_Base __new__ which filters identity elements and returns `not cls.op_x_notx` when no args remain. `facts.py` has deduce_alpha_implications for computing transitive closure of single-premise inference chains with contrapositives and inconsistency detection. `assumptions.py` has _ask for recursive property resolution with anti-recursion guard (stores None) and shuffled prerequisites. `multidimensional.py` has vectorize decorator that lifts scalar functions to nested collections (temporarily disables wrapping flags during recursive calls for nested iterables). `evalf.py` has hypsum for summing hypergeometric series (uses Richardson extrapolation for polynomial convergence, direct summation for geometric/faster). `function.py` also has expand_log and other single-hint expand wrappers (expand_log explicitly disables mul hint to prevent interference with log splitting). Add._eval_as_leading_term recursively subtracts when simplified leading terms are zero but not provably zero. `exprtools.py` provides `gcd_terms` which masks non-commutative parts with Dummy symbols. `operations.py` has AssocOp._matches_commutative which decomposes x**n into Mul(x, x**(n-1)). Does NOT contain specialized simplification, polynomial algorithms, code generation, or domain-specific logic |
| [crypto/](crypto/catalog.md) | Classical cryptographic ciphers (Caesar, Vigenere, RSA, etc.) |
| [deprecated/](deprecated/catalog.md) | Deprecated modules with import-time warnings pointing to replacements |
| [diffgeom/](diffgeom/catalog.md) | Differential geometry: manifolds, coordinate systems, differential forms |
| [external/](external/catalog.md) | Utilities for importing and probing optional external dependencies |
| [functions/](functions/catalog.md) | Elementary and special mathematical functions: trig (with npi_key pi-coefficient extraction), `elementary/exponential.py` with log.eval (handles AccumBounds — returns None when lower bound not positive; rewrites negative arguments via pi*I offset), `elementary/integers.py` with RoundFunction.eval base class for floor/ceiling (handles imaginary arguments — falls back to unevaluated form if im() still contains I; splits integral/numerical/symbolic parts), hyperbolic, Bessel and Airy functions (with _eval_expand_func), combinatorial (harmonic numbers, nP multiset permutation counting, `numbers.py` nC for multiset combination counting with closed-form product((m+1) for m in multiplicities) when k=None), `special/error_functions.py` with TrigonometricIntegral base class for Si/Ci-type integrals (_eval_nseries distinguishes f(0)==0 vs f(0)≠0 by conditionally adding EulerGamma+log(x)), elliptic integrals, upper/lower incomplete gamma, tensor functions (Levi-Civita, KroneckerDelta with Fermi-level properties), delta/Heaviside, Piecewise expressions, and `special/polynomials.py` for orthogonal polynomial symbolic classes — for efficient polynomial *generation* returning Poly/PurePoly see `polys/orthopolys.py` |
| [geometry/](geometry/catalog.md) | Computational geometry: points, lines, polygons, circles, ellipses, and curves |
| [holonomic/](holonomic/catalog.md) | Holonomic functions represented via linear differential equations with polynomial coefficients |
| [integrals/](integrals/catalog.md) | Symbolic integration: definite/indefinite integrals, transforms (Laplace, Fourier, Mellin, Hankel with HankelTypeTransform base class overriding _as_integral to pass extra order parameter), the Risch algorithm, `meijerint.py` with _get_coeff_exp for extracting c*x**b form with custom error on non-conforming expressions, Meijer G-function integration, trigonometric integration, and manualintegrate (step-by-step) |
| [interactive/](interactive/catalog.md) | Interactive session helpers (`isympy` startup, printing configuration, IPython integration) |
| [liealgebras/](liealgebras/catalog.md) | Lie algebras and root systems for classical groups (A, B, C, D, E, F, G) |
| [logic/](logic/catalog.md) | Boolean algebra (symbolic boolean expressions: And, Or, Not, Implies, Equivalent), propositional logic, satisfiability (DPLL), and inference — handles high-level symbolic boolean algebra only; for the low-level internal boolean logic engine (AndOr_Base conjunction/disjunction with identity-element filtering) see `core/logic.py`; for mathematical property inference on symbolic expressions see `assumptions/` |
| [matrices/](matrices/catalog.md) | Symbolic and numeric matrix algebra: dense, sparse, immutable, and block matrices; `matrices.py` MatrixBase with is_symmetric (computes difference with transpose, simplifies, checks equals zero to avoid false negatives from unsimplified expressions), eigenvalues, decompositions, matrix expressions (Trace, MatAdd, MatMul, MatPow), and common matrix constructors |
| [ntheory/](ntheory/catalog.md) | Number theory: primes, factorization, residues, continued fractions, multiplicative functions, Egyptian fractions, partitions, and `generate.py` with cycle_length (Brent's cycle detection for iterated function sequences with nmax early termination) |
| [parsing/](parsing/catalog.md) | Parsing mathematical expressions from strings, LaTeX, Mathematica, and other formats |
| [physics/](physics/catalog.md) | Physics subpackages: quantum mechanics (spin, Wigner 3j/Clebsch-Gordan/Gaunt coefficients, Hilbert spaces, QExpr base class with adjoint/Hilbert-space preservation, `quantum/dagger.py` Dagger.__new__ with dispatch chain: adjoint→conjugate+transpose→unevaluated (has uninitialized variable bug when neither path exists), `quantum/identitysearch.py` bfs_identity_search for breadth-first enumeration of minimal-length gate identities (prunes decomposable sequences via is_reducible with begin=1), `quantum/circuitplot.py` render_label for wire labels with optional initial-state mapping, gate identity search with LR/RL/LL operations, tensor product simplification, matrix caching), `hep/gamma_matrices.py` with _kahane_simplify implementing Kahane's 1968 algorithm for contracted Dirac matrix simplification (handles consecutive contracted indices by inserting virtual indices), `secondquant.py` with Commutator.eval that extracts scalar (commutative) prefactors from [xA,yB]→xy*[A,B] using args_cnc, optics (lens_formula, mirror_formula), classical mechanics (Lagrangian/Hamiltonian), `units.py` with Unit class, hydrogen wave functions, `vector/frame.py` ReferenceFrame with ang_acc_in (falls back to differentiating angular velocity when no explicit value stored), and `vector/printing.py` with Newton dot notation |
| [plotting/](plotting/catalog.md) | 2-D and 3-D plotting with backends for matplotlib, pyglet, and text-based output; `experimental_lambdify.py` with translate_func that temporarily disables float/complex wrapping flags during recursive calls so numeric type conversion only applies to outermost expression |
| [polys/](polys/catalog.md) | Polynomial algebra: factorization, GCD, Groebner bases, algebraic number fields, polynomial rings and domains, `rings.py` with PolyElement including _iadd_poly_monom (copies self before mutation if self is a canonical generator to protect shared objects), `fields.py` with FracElement arithmetic (__mul__ dispatches between nested quotient-of-quotient structures by checking if one domain wraps the other — delegates to __rmul__ of the inner structure), dense polynomial tools (densetools), polynomial fraction classes (DMF/DMP), `ring_series.py` for truncated power series arithmetic, `orthopolys.py` for efficient generation of orthogonal polynomial objects, `polyroots.py` for symbolic root computation (plus preprocess_roots which detects auxiliary symbols whose exponent patterns are proportional to the main variable's degree), `polytools.py` with Poly.div (auto-promotes integer coefficients to rationals then attempts retraction back), Poly.dispersion (largest non-negative integer translation giving common factor, returns -oo when empty), public `degree` function, `modulargcd.py` with Chinese remainder reconstruction for univariate integer polynomials (combines residue representations over coprime moduli into symmetric representation), `domains/mpelements.py` with MPContext.__init__ (sets max_denom=1000000 when tolerance is zero, otherwise 1/tolerance for rational approximation), AGCA `agca/homomorphisms.py` with restrict_codomain (raises ValueError if submodule doesn't contain image, returns self if submodule equals codomain), `domains/modularinteger.py` with symmetric representation, and root isolation |
| [printing/](printing/catalog.md) | Output formatting and code string rendering: LaTeX, MathML, pretty-print (ASCII/Unicode 2-D layout with stringPict picture stacking; _print_RandomDomain has triple-fallback: as_boolean → symbols+set → None), C/Fortran/JS code printers, `julia.py` JuliaCodePrinter (_print_Assignment restructures Piecewise RHS into per-branch assignments when not inline), `octave.py` OctaveCodePrinter (_print_jn rewrites spherical Bessel functions as sqrt(π/(2x))*J(n+½,x) since Octave lacks native support), `theanocode.py` TheanoPrinter (_print_Piecewise uses np.nan as fallback for single-branch conditionals), Rust/GLSL code printers, Python code printer, lambda/anonymous function printing, LLVM JIT code emission, Fortran-specific type handling, and str/repr printers — note: physics-specific derivative rendering with Newton dot notation lives in `physics/vector/printing.py`, not here |
| [sandbox/](sandbox/catalog.md) | Experimental / sandbox modules (indexed objects, tensors prototype) |
| [series/](series/catalog.md) | Series expansions, limits (Gruntz algorithm), `formal.py` with formal power series and DE-to-recurrence conversion (exp_re, hyper_re with index normalization), Fourier series, `sequences.py` with SeqAdd.reduce (pairwise reduction loop using dual-type new_args variable — bool False signals no more simplifications, list signals found reduction), and order term (O) handling — for ring-based truncated power series arithmetic (tanh, atan, exp, etc.) see `polys/ring_series` |
| [sets/](sets/catalog.md) | Set theory: intervals, unions, intersections, `sets.py` with FiniteSet.as_relational (converts membership to Or of Eq predicates), Set.__pow__ for repeated Cartesian product (has operator-precedence bug in exponent validation — negative integers pass through), SymmetricDifference, conditional sets, image sets, and complex region sets |
| [simplify/](simplify/catalog.md) | Expression simplification: `trigsimp.py` (including Groebner-basis approach, _replace_mul_fpowxgpow which rewrites f(b)**c*g(b)**rexp(c)→h(b)**rexph(c) only when base is positive or exponent is integer), radsimp, powsimp, collect, CSE, `hyperexpand.py` for expanding hypergeometric/Meijer G-functions into named special functions (Hyper_Function._is_suitable_origin checks: no ai==bj+non-negative-integer, no ai==0, no bj non-positive-integer), sign canonicalization (signsimp), `combsimp.py` for gamma/factorial/binomial simplification (factor absorption loop: when denominator factor partially matches g-1, leftover ratio (g-1)/y goes to numerator), `simplify.py` with logcombine (splits negative rationals into -1 and abs value; gooda excludes -1 from valid log exponent coefficients), `fu.py` Fu trigonometric identity engine (as_f_sign_1 decomposes two-term sum into g*(a+s) where s=±1 via GCD factoring), square-root denesting, EPath-based expression selection/transformation, and `refine.py` with assumption-based simplification handlers |
| [solvers/](solvers/catalog.md) | Equation solving: algebraic, ODE, PDE, recurrence (rsolve_poly handles empty constraint equations by leaving all constants free), inequality, and Diophantine solvers, `solvers.py` with unrad for radical elimination (_canonical normalizes by stripping numeric constants/power factors and canonicalizing sign; two-radical-term case tries substitution in both orderings, raises NotImplementedError if both fail), `polysys.py` with solve_biquadratic (raises SolveFailed if Groebner basis has ≠2 elements, returns None for ground constant) and solve_generic (entry=True returns None for inconsistent system vs entry=False returns []), `solveset.py` with linear_eq_to_matrix, undetermined coefficient matching, bivariate type classification, Gaussian elimination, and rounding/divisibility utilities for integer solutions |
| [stats/](stats/catalog.md) | Symbolic probability and statistics: random variables, distributions, and expectation |
| [strategies/](strategies/catalog.md) | Rule-based expression rewriting strategies (tree traversal, branching, and composition) |
| [tensor/](tensor/catalog.md) | Tensor algebra: indexed objects (Idx, IndexedBase), index conventions, multi-dimensional array operations (NDimArray dense/sparse — __getitem__ with plain slice returns flat storage directly, tuple-of-slices does multi-dimensional slicing), and tensor contraction/products. Note: tensor.py delegates actual canonicalization to `combinatorics/tensor_can.py` |

## Root Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package entry point; checks for mpmath, imports all public submodules, initializes the evalf table, and sets `SYMPY_DEBUG` from the environment |
| `abc.py` | Exports all single Latin and Greek letters as pre-defined `Symbol` objects for convenient interactive use (`from sympy.abc import x, y`); also provides `clashing()` to detect namespace collisions between letter symbols and other SymPy exports |
| `conftest.py` | Pytest configuration: test-splitting (`--split`), cache clearing between modules, architecture/ground-type reporting, and disabled-module skipping |
| `galgebra.py` | Deprecated stub that raises `ImportError` directing users to the standalone `galgebra` package |
| `release.py` | Defines the version string `__version__ = "1.1.2.dev"` |
| `this.py` | Easter egg — prints "The Zen of SymPy" (ROT-13 encoded aphorisms about the project's philosophy) |
