# SymPy — Catalog

SymPy is a pure-Python library for symbolic mathematics. It aims to be a full-featured computer algebra system (CAS) while keeping its code simple, comprehensible, and easily extensible. Its only hard dependency is mpmath (arbitrary-precision arithmetic). This version is **1.1.2.dev**.

## Subdirectories

| Directory | Description |
|-----------|-------------|
| [algebras/](algebras/catalog.md) | Abstract algebra structures (e.g. quaternions) |
| [assumptions/](assumptions/catalog.md) | Assumption system: declaring and querying properties of symbols (positive, integer, etc.), SAT-based inference rule registration (ask_generated), specific handlers for determining properties of compound expressions (e.g., log/exp/pow real/imaginary checks), `handlers/matrices.py` with handlers for matrix predicates (orthogonal MatMul requires scalar factor==1, diagonal MatrixSlice returns None for off-diagonal), and `refine.py` for assumption-based expression simplification (refine_atan2, refine_Pow, refine_abs) |
| [benchmarks/](benchmarks/catalog.md) | Performance benchmarks for SymPy internals |
| [calculus/](calculus/catalog.md) | Calculus operations: finite differences (differentiate_finite, apply_finite_diff), singularities, continuity utilities, and `util.py` with AccumulationBounds class for interval arithmetic (__pow__ handles fractional exponents with even denominators by clipping negative lower bounds to zero for real-root safety) — for symbolic integration see `integrals/`, for series/limits see `series/` |
| [categories/](categories/catalog.md) | Category theory: objects, morphisms, diagrams, and diagram drawing |
| [codegen/](codegen/catalog.md) | Code generation AST node types only (Assignment, CodeBlock, For, Variable, Type, Declaration) and specialized C/Fortran math function wrappers (expm1, log1p, etc.) — does NOT contain routine/function generation logic, language-specific code generators, or function-signature construction (those live in `utilities/codegen.py`); for expression-to-code-string rendering see `printing/` |
| [combinatorics/](combinatorics/catalog.md) | Combinatorics: permutations, partitions, polyhedra, group theory (named groups, symmetry groups), Graycode, prufer sequences, subsets (with subset_indices using for/else control flow), and `tensor_can.py` which contains the actual Butler-Portugal double-coset canonicalization algorithm implementation (double_coset_can_rep) and get_symmetric_group_sgs for tensor symmetry BSGS generation — `tensor/tensor.py` delegates canonicalization here |
| [concrete/](concrete/catalog.md) | Concrete mathematics: symbolic sums (Sum with eval_sum_hyper decomposing finite-range sums into differences of semi-infinite hypergeometric series), products (Product), gosper and hypergeometric summation algorithms, delta operators, and `guess.py` for heuristic generating-function guessing (falls back to log-derivative approach when direct rational guess fails) |
| [core/](core/catalog.md) | Core symbolic engine: expression tree nodes (Symbol, Number, Expr, Add, Mul, Pow), basic arithmetic dispatch, evaluation protocol, caching, and Python compatibility shims. Add and Mul contain their own `_eval_as_leading_term` methods for dominant-term extraction (Add recursively subtracts when simplified leading terms are zero but not provably zero). `exprtools.py` provides `gcd_terms` which masks non-commutative parts with Dummy symbols during GCD computation. `function.py` defines Lambda with alpha-equivalence equality (renames bound variables before comparison), conjugate._eval_derivative branches on real vs imaginary differentiation variable, and `operations.py` has AssocOp._matches_commutative which decomposes x**n into Mul(x, x**(n-1)) to retry pattern matching. `mul.py` has as_content_primitive using self.func(*args) to combine duplicate factors. Does NOT contain specialized simplification, polynomial algorithms, code generation, or domain-specific logic |
| [crypto/](crypto/catalog.md) | Classical cryptographic ciphers (Caesar, Vigenere, RSA, etc.) |
| [deprecated/](deprecated/catalog.md) | Deprecated modules with import-time warnings pointing to replacements |
| [diffgeom/](diffgeom/catalog.md) | Differential geometry: manifolds, coordinate systems, differential forms |
| [external/](external/catalog.md) | Utilities for importing and probing optional external dependencies |
| [functions/](functions/catalog.md) | Elementary and special mathematical functions: trig (with npi_key pi-coefficient extraction), exponential, hyperbolic, rounding (floor/ceiling with _eval_nseries leading-term direction logic), Bessel and Airy functions (with _eval_expand_func for argument pattern transformations), combinatorial (harmonic numbers with infinite-limit zeta evaluation, nP multiset permutation counting), elliptic integrals, upper/lower incomplete gamma (with fdiff for differentiation including Meijer G-function for parameter derivatives), tensor functions (Levi-Civita, KroneckerDelta with Fermi-level properties: above_fermi, below_fermi, preferred_index, killable_index, indices_contain_equal_information), delta/Heaviside distributions, Piecewise expressions, and `special/polynomials.py` which contains symbolic function *classes* for orthogonal polynomials (eval, rewrite, series expansion) — for efficient polynomial *generation* returning Poly/PurePoly objects see `polys/orthopolys.py` |
| [geometry/](geometry/catalog.md) | Computational geometry: points, lines, polygons, circles, ellipses, and curves |
| [holonomic/](holonomic/catalog.md) | Holonomic functions represented via linear differential equations with polynomial coefficients |
| [integrals/](integrals/catalog.md) | Symbolic integration: definite/indefinite integrals, transforms (Laplace, Fourier, Mellin, Hankel with HankelTypeTransform base class overriding _as_integral to pass extra order parameter), the Risch algorithm, `meijerint.py` with _get_coeff_exp for extracting c*x**b form with custom error on non-conforming expressions, Meijer G-function integration, trigonometric integration, and manualintegrate (step-by-step) |
| [interactive/](interactive/catalog.md) | Interactive session helpers (`isympy` startup, printing configuration, IPython integration) |
| [liealgebras/](liealgebras/catalog.md) | Lie algebras and root systems for classical groups (A, B, C, D, E, F, G) |
| [logic/](logic/catalog.md) | Boolean algebra, propositional logic, satisfiability (DPLL), and inference — handles symbolic boolean expressions only; for mathematical property inference on symbolic expressions see `assumptions/` |
| [matrices/](matrices/catalog.md) | Symbolic and numeric matrix algebra: dense, sparse, immutable, and block matrices; `matrices.py` MatrixBase with is_symmetric (computes difference with transpose, simplifies, checks equals zero to avoid false negatives from unsimplified expressions), eigenvalues, decompositions, matrix expressions (Trace, MatAdd, MatMul, MatPow), and common matrix constructors |
| [ntheory/](ntheory/catalog.md) | Number theory: primes, factorization, residues, continued fractions, multiplicative functions, Egyptian fractions, partitions, and `generate.py` with cycle_length (Brent's cycle detection for iterated function sequences with nmax early termination) |
| [parsing/](parsing/catalog.md) | Parsing mathematical expressions from strings, LaTeX, Mathematica, and other formats |
| [physics/](physics/catalog.md) | Physics subpackages: quantum mechanics (spin, Wigner 3j/Clebsch-Gordan/Gaunt coefficients, Hilbert spaces, QExpr base class with adjoint/Hilbert-space preservation, operator-to-eigenstate mapping, gate identity search with LR/RL/LL operations, tensor product simplification for non-commutative Kronecker products, circuit diagram plotting with measurement-wire doubling, matrix caching across numpy/scipy formats), second quantization (fermion/boson operators, canonical ordering of dummy indices), optics (lens_formula with infinity handling via symbolic limits, mirror_formula), classical mechanics (smart_subs for nan avoidance, Lagrangian/Hamiltonian), `units.py` with Unit class (is_positive=True enabling sqrt(m**2)→m), hydrogen wave functions, vector algebra (curl, divergence, gradient), and `vector/printing.py` with specialized VectorLatexPrinter/VectorPrettyPrinter that render time-derivatives using Newton dot notation (\\dot, \\ddot, \\dddot for 1st-3rd order; Unicode combining dots inserted at string midpoint) |
| [plotting/](plotting/catalog.md) | 2-D and 3-D plotting with backends for matplotlib, pyglet, and text-based output |
| [polys/](polys/catalog.md) | Polynomial algebra: factorization, GCD, Groebner bases, algebraic number fields, polynomial rings and domains, dense polynomial tools (densetools), polynomial fraction classes (DMF/DMP), `ring_series.py` for truncated power series arithmetic on sparse polynomials (exp, log, sin, cos, tanh, atan and all elementary functions with constant-term decomposition via addition formulas and Newton iteration), `orthopolys.py` for efficient generation of orthogonal polynomial objects (Jacobi, Gegenbauer, Hermite, Legendre, Chebyshev) returning Poly/PurePoly with Dummy variable when no variable specified, `polyroots.py` for symbolic root computation (quadratic with discriminant perfect-square extraction, cubic, quartic), `polytools.py` with public `degree` function (returns -oo for zero polynomial), expression domain wrapping, AGCA module homomorphisms (with container-level element conversion for sub-structures), `domains/modularinteger.py` with symmetric representation (to_int returns negative representative when val > mod//2), and root isolation |
| [printing/](printing/catalog.md) | Output formatting and code string rendering: LaTeX, MathML, pretty-print (ASCII/Unicode 2-D layout with stringPict picture stacking), C/Fortran/JS/Julia/Rust/GLSL code printers, Python code printer, lambda/anonymous function printing, LLVM JIT code emission, Fortran-specific type handling and line wrapping, and str/repr printers — note: physics-specific derivative rendering with Newton dot notation for time-dependent generalized coordinates lives in `physics/vector/printing.py`, not here |
| [sandbox/](sandbox/catalog.md) | Experimental / sandbox modules (indexed objects, tensors prototype) |
| [series/](series/catalog.md) | Series expansions, limits (Gruntz algorithm), `formal.py` with formal power series and DE-to-recurrence conversion (exp_re, hyper_re with index normalization), Fourier series, sequences, and order term (O) handling — for ring-based truncated power series arithmetic (tanh, atan, exp, etc.) see `polys/ring_series` |
| [sets/](sets/catalog.md) | Set theory: intervals, unions, intersections, finite sets, conditional sets, image sets, and complex region sets |
| [simplify/](simplify/catalog.md) | Expression simplification: trigsimp (including Groebner-basis approach with build_ideal generating tan(n*x)*cos(n*x)-sin(n*x) relations instead of trig expansion for tangent), radsimp, powsimp, collect, CSE, `hyperexpand.py` for expanding hypergeometric/Meijer G-functions into named special functions using shift-operator algorithms and ReduceOrder for cancelling matching upper/lower parameters (guards against non-positive-integer lower parameter causing division by zero), sign canonicalization (signsimp), combinatorial simplification (combsimp), Fu trigonometric identity engine (with trig_split for decomposing sum-of-trig into canonical form), square-root denesting, EPath-based expression selection/transformation (reconstructs via expr.func for Basic vs expr.__class__ for iterables), and `refine.py` with assumption-based simplification handlers (refine_atan2 returns NaN when both args are zero) |
| [solvers/](solvers/catalog.md) | Equation solving: algebraic, ODE, PDE, recurrence (rsolve_poly handles empty constraint equations by leaving all constants free), inequality, and Diophantine solvers, `solveset.py` with linear_eq_to_matrix (converts linear equations to augmented coefficient matrix with negated free term as RHS), undetermined coefficient matching, bivariate type classification, Gaussian elimination, and rounding/divisibility utilities for integer solutions |
| [stats/](stats/catalog.md) | Symbolic probability and statistics: random variables, distributions, and expectation |
| [strategies/](strategies/catalog.md) | Rule-based expression rewriting strategies (tree traversal, branching, and composition) |
| [tensor/](tensor/catalog.md) | Tensor algebra: indexed objects (Idx, IndexedBase), index conventions, multi-dimensional array operations (NDimArray dense/sparse — __getitem__ with plain slice returns flat storage directly, tuple-of-slices does multi-dimensional slicing), and tensor contraction/products. Note: tensor.py delegates actual canonicalization to `combinatorics/tensor_can.py` |
| [unify/](unify/catalog.md) | Unification algorithms (structural and expression-level pattern matching) |
| [utilities/](utilities/catalog.md) | General utilities: iterables (Bell permutations, integer partition generation as dictionaries, numbered_symbols generator, deduplication), decorators, autowrap/Cython code generation, lambdify, memoization, test runner and reporter, source code inspection, timing/benchmarking harness, and `codegen.py` which contains the complete compilable routine generation framework (Routine, CodeGen, CCodeGen, FCodeGen, OctaveCodeGen, JuliaCodeGen) that assembles function signatures, variable declarations, and code bodies for C/Fortran/Octave/Julia — distinct from `codegen/` which only has AST node types |
| [vector/](vector/catalog.md) | Vector algebra and calculus in curvilinear coordinate systems; `dyadic.py` BaseDyadic.__new__ returns zero dyadic when either vector argument is the zero vector |

## Root Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package entry point; checks for mpmath, imports all public submodules, initializes the evalf table, and sets `SYMPY_DEBUG` from the environment |
| `abc.py` | Exports all single Latin and Greek letters as pre-defined `Symbol` objects for convenient interactive use (`from sympy.abc import x, y`); also provides `clashing()` to detect namespace collisions between letter symbols and other SymPy exports |
| `conftest.py` | Pytest configuration: test-splitting (`--split`), cache clearing between modules, architecture/ground-type reporting, and disabled-module skipping |
| `galgebra.py` | Deprecated stub that raises `ImportError` directing users to the standalone `galgebra` package |
| `release.py` | Defines the version string `__version__ = "1.1.2.dev"` |
| `this.py` | Easter egg — prints "The Zen of SymPy" (ROT-13 encoded aphorisms about the project's philosophy) |
