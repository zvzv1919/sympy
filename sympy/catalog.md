# SymPy — Catalog

SymPy is a pure-Python library for symbolic mathematics. It aims to be a full-featured computer algebra system (CAS) while keeping its code simple, comprehensible, and easily extensible. Its only hard dependency is mpmath (arbitrary-precision arithmetic). This version is **1.1.2.dev**.

## Subdirectories

| Directory | Description |
|-----------|-------------|
| [algebras/](algebras/catalog.md) | Abstract algebra structures (e.g. quaternions) |
| [assumptions/](assumptions/catalog.md) | Assumption *query handlers* (`AskHandler` classes) that evaluate predicates like `Q.positive`, `Q.finite`, `Q.imaginary` on composite expressions by dispatching on expression type (Add, Mul, Pow, exp, log). For example, `AskFiniteHandler.Pow` decides boundedness of exponentiation by checking base magnitude vs unity and exponent sign. **Not** where assumption *rules/facts* are defined — the implication/equivalence rules (e.g. `integer -> rational`, `zero -> even & finite`) and the `_assume_rules`/`_assume_defined` fact sets live in `core/assumptions.py`. |
| [benchmarks/](benchmarks/catalog.md) | Performance benchmarks for SymPy internals |
| [calculus/](calculus/catalog.md) | Calculus operations: finite differences, singularities, continuity utilities, and `AccumBounds` (accumulated bounds / interval arithmetic with three-valued comparison logic returning True/False/None for overlapping ranges). See also `series/` for limits and `core/expr.py` for the `series()` method. |
| [categories/](categories/catalog.md) | Category theory: objects, morphisms, diagrams, and Xy-pic diagram drawing (`ArrowStringDescription`, `XypicDiagramDrawer` for rendering commutative diagrams with arrows, loops, and curving) |
| [codegen/](codegen/catalog.md) | Code generation for C, Fortran, Julia, Rust, and other languages |
| [combinatorics/](combinatorics/catalog.md) | Discrete structures and group theory: `Permutation`, `PermutationGroup` (with `is_subgroup`, orbit/stabilizer algorithms), `Polyhedron` (3D solid symmetry groups with default identity when no transforms given), `Partition`/`IntegerPartition`, Graycode, and tensor canonicalization (`tensor_can.py` with BSGS for tensor slot symmetries). **Not** for combinatorial *number sequences* or *counting functions* — those live in `functions/combinatorial/`. |
| [concrete/](concrete/catalog.md) | Concrete mathematics: symbolic sums, products, and the `ExprWithLimits` base class that handles variable scoping, dummy-variable substitution with limit reversal for correct mathematical scoping, and detection of illegal dummy dependencies in bounded expressions (sums, products, integrals). |
| [core/](core/catalog.md) | Core symbolic engine: `Symbol`, `Number`, `Expr`, `Add`, `Mul`, `Pow`, caching, evaluation, and compatibility. Key details: `core/expr.py` has `Expr.series()` (with adaptive retry for truncated expansions and infinity-point handling via 1/x substitution), `extract_additively`/`extract_multiplicatively`; `core/mul.py` has `Mul._eval_is_infinite` (returns NaN.is_infinite for 0*oo indeterminate); `core/numbers.py` has `AlgebraicNumber` (with `to_algebraic_integer` monic conversion and negative-root sign adjustment), `igcd` (validates all args even on early-exit), `ilcm`; `core/assumptions.py` has the master `_assume_rules` fact table and `_assume_defined` set (including the standalone 'polar' property with no inference rules); `core/power.py` has `Pow._eval_as_leading_term` (rewrites base^exp as exp(exp*log(base)) when exponent depends on expansion variable). |
| [crypto/](crypto/catalog.md) | Classical cryptographic ciphers (Caesar, Vigenere, RSA, etc.) |
| [deprecated/](deprecated/catalog.md) | Deprecated modules with import-time warnings pointing to replacements |
| [diffgeom/](diffgeom/catalog.md) | Differential geometry: `Manifold`, `Patch` (auto-registers with parent manifold during `__new__`), `CoordSystem` (coordinate transformations, Jacobians, point mapping). **Not** for coordinate-system vector algebra — that's in `vector/`. |
| [external/](external/catalog.md) | Utilities for importing and probing optional external dependencies |
| [functions/](functions/catalog.md) | Elementary and special mathematical functions with their `eval()` classmethod logic for automatic simplification, special-value dispatch, and branch-cut handling. Includes: `functions/elementary/exponential.py` (`exp.eval` with single-log-factor simplification in Mul args), `functions/elementary/trigonometric.py`; `functions/special/gamma_functions.py` (`lowergamma.eval` with branch-factor extraction for winding numbers), `functions/special/elliptic_integrals.py` (special values at ±∞), `functions/special/hyper.py` (`meijerg` constructor — notably does *not* check convergence conditions), `functions/special/singularity_functions.py` (`SingularityFunction.fdiff` with special n=0/-1 derivative rules); `functions/combinatorial/factorials.py` (`subfactorial.eval` with Infinity→Infinity, `binomial._eval` using prime decomposition for exact integer results), `functions/combinatorial/numbers.py` (`harmonic.eval` with NaN for negative order at infinity, `euler._eval_rewrite_as_Sum` returns None for odd args, `nT` partition counting with identical-element optimization). **Not** for discrete group structures (permutations, etc.) — those are in `combinatorics/`. |
| [geometry/](geometry/catalog.md) | Computational geometry: points, lines, polygons, circles, ellipses, curves, and `geometry/util.py` (helpers like `_uniquely_named_symbol` for collision-free variable names via underscore-prepending, `idiff` for implicit differentiation, `_symbol`). |
| [holonomic/](holonomic/catalog.md) | Holonomic functions represented via linear differential equations with polynomial coefficients. `HolonomicFunction` class with `__repr__` that formats initial derivative values using accumulated prime marks (f(0), f'(0), f''(0), ...). |
| [integrals/](integrals/catalog.md) | Symbolic integration *algorithms*: definite/indefinite integrals, transforms (Laplace, Fourier, Mellin), the Risch algorithm, and Meijer G-function integration. **Not** where special function evaluation/special values/branch cuts are defined — those `eval()` methods live in `functions/special/`. |
| [interactive/](interactive/catalog.md) | Interactive session helpers (`isympy` startup, printing configuration, IPython integration) |
| [liealgebras/](liealgebras/catalog.md) | Lie algebras and root systems for classical groups (A, B, C, D, E, F, G) |
| [logic/](logic/catalog.md) | Boolean algebra, propositional logic, satisfiability (DPLL), and inference |
| [matrices/](matrices/catalog.md) | Symbolic and numeric matrix algebra: dense, sparse, immutable, and block matrices; eigenvalues, decompositions |
| [ntheory/](ntheory/catalog.md) | Number theory: primes, factorization, residues, continued fractions, and multiplicative functions |
| [parsing/](parsing/catalog.md) | Parsing mathematical expressions from strings, LaTeX, Mathematica (with `translateFunction` that strips "Arc" prefix for inverse trig: ArcSin→asin), and other formats |
| [physics/](physics/catalog.md) | Physics subpackages: `physics/quantum/` (Clebsch-Gordan coefficient simplification `cg_simp` with type-based dispatch on Add/Sum/Mul/Pow, Shor's factoring algorithm in `shor.py`, circuit utilities for symbolic↔numeric index conversion in `circuitutils.py`, operator algebra with `HermitianOperator._eval_power` handling unitary+hermitian even/odd exponents), `physics/vector/` (vector differentiation `Vector.diff` with DCM-aware frame re-expression, `Dyadic` cross/dot products), `physics/hep/gamma_matrices.py` (Kahane simplification with virtual index insertion for consecutive dummy indices), `physics/secondquant.py` (dummy index renaming with cycle detection and temporary variables to avoid clobbering), optics, classical mechanics, units, hydrogen wave functions. |
| [plotting/](plotting/catalog.md) | 2-D and 3-D plotting with backends for matplotlib, pyglet, and text-based output. Also contains `experimental_lambdify.py` with `Lambdifier` class for translating symbolic expressions to numeric strings (numpy/math/cmath backends), where later-registered backend constants overwrite earlier ones in `get_dict_str`. |
| [polys/](polys/catalog.md) | Polynomial algebra: factorization, GCD, Groebner bases, algebraic number fields, polynomial rings, domains, and `ring_series.py` (truncated power series arithmetic in polynomial rings — `rs_pow` with fractional exponents via nth-root + binary exponentiation, `rs_log` raising NotImplementedError for missing constant term, `rs_cos`/`rs_sin` with half-angle tangent optimization for >20-term polynomials, `rs_series_from_list` with baby-step/giant-step and squaring optimization for polynomials ≥20 terms). Also `polys/agca/homomorphisms.py` for module homomorphisms (ring compatibility validation, kernel-containment checks for quotient domains). Also `polys/domains/__init__.py` for arithmetic backend selection (gmpy vs python) with `_GROUND_TYPES_MAP` dispatch at package load time. Also `polys/orthopolys.py` for spherical Bessel function coefficients (negative-order dispatch to separate recurrence). Also `polys/polytools.py` `cancel()` with noncommutative fallback via `preorder_traversal` skipping tuples/BooleanAtom, and `Poly.refine_root` defaulting to 1 step when neither eps nor steps given. **Not** for formal power series coefficient formulas — those are in `series/formal.py`. |
| [printing/](printing/catalog.md) | Output formatting: LaTeX, MathML, pretty-print, C/Fortran/JS/Julia/Rust/GLSL code generation, and more. Includes `str.py` (`_print_DMP` with ring-to-sympy fallback on SympifyError), `fcode.py` (Fortran printer — raises ValueError if Piecewise lacks a True default condition). For Xy-pic diagram arrow rendering, see `categories/diagram_drawing.py`. |
| [sandbox/](sandbox/catalog.md) | Experimental / sandbox modules (indexed objects, tensors prototype) |
| [series/](series/catalog.md) | Series expansions, limits, formal power series, Fourier series, and sequences. Key files: `limits.py` (public `limit` function with `heuristics` fast-path that aborts on infinite-with-unknown-finiteness sub-results), `gruntz.py` (Gruntz algorithm with `sign(e, x)` for asymptotic sign — reduces log(f) to sign(f-1), exp always→1, Mul splits recursively). For truncated power series *arithmetic* in polynomial rings (rs_pow, rs_log, rs_sin, rs_cos), see `polys/ring_series.py`. The `series()` method itself lives in `core/expr.py`. |
| [sets/](sets/catalog.md) | Set theory: intervals, unions, intersections, finite sets, and conditional sets |
| [simplify/](simplify/catalog.md) | Expression simplification: trigsimp (including Groebner-basis approach with `build_ideal` constructing Pythagorean/ratio/multi-angle relations), radsimp, powsimp, collect, CSE, hypergeometric simplification, `ratsimp.py` (`ratsimpmodprime` with DomainError for fields without quotient), and `epathtools.py` (XPath-like `EPath.apply` for transforming matched sub-expressions, reconstructing Basic nodes via `expr.func(*args)` vs plain iterables via `expr.__class__(args)`). |
| [solvers/](solvers/catalog.md) | Equation solving: algebraic, ODE, PDE, recurrence, inequality, and Diophantine solvers (including `diophantine.py` with `prime_as_sum_of_two_squares` using different initial base for p≡5 mod 8 vs other 1 mod 4 primes). |
| [stats/](stats/catalog.md) | Symbolic probability and statistics: random variables, distributions, expectation, and `error_prop.py` (`variance_prop` for symbolic uncertainty propagation through Add/Mul/Pow/exp expressions with a fallback to wrapping unknown expression types in Variance). |
| [strategies/](strategies/catalog.md) | Rule-based expression rewriting strategies (tree traversal, branching, and composition) |
| [tensor/](tensor/catalog.md) | Tensor algebra: indexed objects, index conventions, and multi-dimensional array operations |
| [unify/](unify/catalog.md) | Unification algorithms (structural and expression-level pattern matching) |
| [utilities/](utilities/catalog.md) | General utilities: iterables (including `multiset_partitions` which returns empty for m>n on integer input), decorators, code generation helpers, lambdify, memoization, testing. Also `autowrap.py` (compiles generated code into Python-callable binaries via f2py/Cython backends, with `_validate_backend_language` raising ValueError for incompatible backend+language pairs), and `misc.py` (`find_executable` with Windows PATHEXT extension-matching logic). |
| [vector/](vector/catalog.md) | Vector algebra and calculus in curvilinear coordinate systems. `vector/functions.py` has `express()` for re-expressing vectors/dyadics/scalars in different coordinate frames (raises ValueError if system2 given for non-Dyadic expressions). **Not** the same as `physics/vector/` which provides reference-frame-based vector mechanics. |

## Root Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package entry point; checks for mpmath, imports all public submodules, initializes the evalf table, and sets `SYMPY_DEBUG` from the environment |
| `abc.py` | Exports all single Latin and Greek letters as pre-defined `Symbol` objects for convenient interactive use (`from sympy.abc import x, y`) |
| `conftest.py` | Pytest configuration: test-splitting (`--split`), cache clearing between modules, architecture/ground-type reporting, and disabled-module skipping |
| `galgebra.py` | Deprecated stub that raises `ImportError` directing users to the standalone `galgebra` package |
| `release.py` | Defines the version string `__version__ = "1.1.2.dev"` |
| `this.py` | Easter egg — prints "The Zen of SymPy" (ROT-13 encoded aphorisms about the project's philosophy) |
