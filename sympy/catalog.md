# SymPy Root Catalog

## Architecture Overview

SymPy is organized into submodules by mathematical domain. Key routing rules:
- **Expression tree internals** (Pow, Add, Mul, Expr, Basic, Symbol, Number, _eval_subs, _eval_power) → `core/`
- **Polynomial algebra** (Gröbner bases, factorization, domains, modules, number fields) → `polys/`
- **Mathematical function classes** (trig, hyperbolic, piecewise, elliptic, combinatorial number sequences) → `functions/`
- **Expression transformation/simplification** (fu, trigsimp, hyperexpand, combsimp) → `simplify/`
- **Pretty/code/string printing** (LaTeX, Fortran, C, Python, MathML, lambda repr) → `printing/`
- **Equation solving** (algebraic, ODE, recurrence, diophantine, bivariate) → `solvers/`
- **Numeric code generation from expressions** (lambdify, autowrap, codegen, ufuncify) → `utilities/`
- **AST node definitions for code generation** (not expression printing) → `codegen/`
- **Property inference on symbols** (handlers, sathandlers, fact rules) → `assumptions/`
- **Propositional/boolean logic** (And, Or, satisfiability, DPLL) → `logic/`
- **Probability and statistics** (random variables, distributions, PDF/CDF) → `stats/`
- **New-style 3D vector algebra** (CoordSysCartesian, Point, divergence, curl) → `vector/`
- **Classical mechanics vectors** (ReferenceFrame, dynamicsymbols, mechanics printing) → `physics/vector/`

## Glossary

- **_eval_subs / _eval_power / _eval_is_***: internal hooks on expression classes. `Pow._eval_power` is in `core/power.py`.
  - Function classes (e.g. `Abs`, `exp`) define their own `_eval_power` AND `_eval_is_*` (e.g. `_eval_is_rational`) in `functions/`. Core types define `_eval_is_*` in `core/`, NOT `assumptions/handlers/`.
- **handlers**: assumption inference callbacks in `assumptions/handlers/`, NOT in `logic/`.
- **lambdify / lambdastr / ufuncify / autowrap**: numeric callable generation in `utilities/`, NOT `codegen/` or `printing/`.
- **codegen (utilities/)**: generates Fortran/C/Julia **source files** with `Routine`, `FCodeGen`, `CCodeGen`.
- **codegen/ (submodule)**: defines AST node classes (`ast.py`). Does NOT generate source or callable code.
- **fcode / FCodePrinter**: Fortran expression printer in `printing/fcode.py`, NOT in `codegen/`.
- **ring_series**: formal power series via polynomial ring operations, in `polys/`, NOT `series/`.

## Top-Level Files

### [`__init__.py`](__init__.py)
Package entry point: version check, mpmath dependency guard, submodule re-exports.
- `__sympy_debug`: reads `SYMPY_DEBUG` env var; only accepts `'True'`/`'False'`, raises RuntimeError on other values.
- `SYMPY_DEBUG` global flag set at import time.

### [`abc.py`](abc.py)
Pre-defined single-letter Symbol instances (latin and greek) for interactive convenience.
- `clashing` — dict of multi-letter clashing names that conflict with SymPy objects.
- NOT where Symbol or Dummy classes are defined (those are in `core/symbol.py`).

### [`galgebra.py`](galgebra.py)
Deprecated stub redirecting to the external `galgebra` package.

## Submodules

### [`core/`](core/catalog.md)
Foundational expression tree: base classes, arithmetic operations, and evaluation hooks.
- `basic.py` — `Basic` base class: `subs` (simultaneous mode uses product of two Dummy placeholders to trigger `Subs` on bound variables), `_has`, `matches`, `atoms`, `xreplace`, `replace` (pattern-driven substitution; `exact` flag gates multi-Wild matches to reject zero-valued placeholder bindings; `simultaneous` mode shields new subexpressions from re-matching during bottom-up traversal by substituting Dummy placeholders, then restores in reverse order after traversal completes), structural traversal.
  - `preorder_traversal`: depth-first parent-before-children tree walk with `skip()` control; `keys=None` → arbitrary sibling order (uses `_argset` directly for LatticeOp nodes to avoid unnecessary sorting), `keys=True` → deterministic via `ordered()`.
  - `rewrite`/`_eval_rewrite`: recursive rule-dispatch expression transformation; `deep` hint controls descent into sub-expressions; checks node type against pattern before applying.
  - `_compare_pretty`: display ordering for printing; Order terms pushed to end; rationals compared by cross-multiplication; non-rational expressions pattern-matched as coeff*base**exp to compare by exponent before falling back to canonical `compare`.
  - `as_poly`: convert expression to `Poly` or return None; catches `PolynomialError` and checks `is_Poly` flag.
- `expr.py` — `Expr` class: `coeff` (extract prefactor of x**n from a sum; n=0 returns x-independent terms), `as_coefficient`, `leadterm`, `extract_multiplicatively`, `as_leading_term`; `equals` (symbolic equality: computes difference, attempts zero-proof via nsimplify then integer-base surds sorted by descending base value, solving difference for each surd; falls back to minimal_polynomial); `is_rational_function` (checks if expression is ratio of polynomials; returns False for NaN/infinities), `is_algebraic_expr`; `series` (iterative retry with linear prediction when internal nseries returns fewer terms; raises ValueError after 8 failed attempts; expansion at ±∞ substitutes x→1/x reducing to expansion around zero, then back-substitutes); ordering operators `__ge__`, `__le__`, `__gt__`, `__lt__` (validate operands: reject non-real complex and NaN with TypeError; real operands → compute difference and check sign properties; otherwise return unevaluated relational).
  - `as_coefficients_dict`: map terms to their Rational coefficient; non-Add treated as single term; non-Rational leading factor (irrational/float) → resets coefficient to 1 and treats entire expression as the term key.
  - `_eval_adjoint`: Hermitian adjoint fallback chain — hermitian→self, antihermitian→−self, else tries conjugate then transpose, or transpose then conjugate.
  - `_eval_interval`: definite evaluation self.subs(x,b)−self.subs(x,a) with limit fallback on NaN/∞; if lower-bound limit yields NaN, returns NaN immediately (short-circuits before evaluating upper bound).
  - `could_extract_minus_sign`: canonical sign choice between expr and −expr; tie-breaking: Add→count negative-signed args, Mul→parity of negative factors, fallback→`sort_key()` comparison.
  - `extract_branch_factor`: decompose polar exponential into winding number and remainder; `allow_half` also extracts half-turn (pi*I) components.
  - `_random`: numerical probe with random substitutions; returns None if result lacks precision (`_prec` attr missing, e.g. `exp_polar(2*I*pi)`), or if no significance achieved after iterative precision increase.
  - `is_constant`: invariance check with assertion guard for is_number/free_symbols inconsistency; numerical evaluation + differentiation fallback.
  - `getn`: extract truncation order from O(...) term; handles product expressions (x^n*log^n) by substituting positive Dummy.
  - `as_independent`: separate expression into parts independent/dependent on given symbols; mismatched type (Add vs Mul) returns (identity, self) immediately.
  - `invert`: modular multiplicative inverse dispatch; uses `getattr(g, 'is_number', True)` so plain Python int modulus (lacking `is_number`) defaults to numeric path via `mod_inverse`, not polynomial path.
  - `compute_leading_term`: wrapper that computes first nonzero series term; introduces temporary Dummy for log(x) to avoid evaluating log at zero, substitutes back after `calculate_series`.
  - `lseries`/`_eval_lseries`: lazy series term iterator; default implementation adaptively increases `n` in `_eval_nseries` — if initial result is pure Order (no concrete terms), loops incrementing `n` until concrete terms appear; yields successive differences.
  - `round`: numerical rounding to p decimal places; adds half-unit for rounding then checks if result crossed zero — if so, reverses direction (subtracts instead of adds); complex inputs decomposed into real/imag parts rounded independently; non-number raises TypeError.
  - `as_ordered_terms`: sort terms with O(...) handling; when Order terms present, always uses reverse=True regardless of order spec.
  - `expand`: applies rewriting hints in sorted order; special key ensures multinomial runs before mul; `denom`/`numer`/`frac` flags split expression via `fraction()` and selectively expand only denominator, numerator, or both; `modulus` param reduces term coefficients mod positive integer (raises ValueError if non-positive/non-integer), drops zero-coefficient terms.
- `power.py` — `Pow` class: `__new__` (auto-simplification when base has negative leading coefficient and exponent is integer: even exp → negates base (strips sign), odd exp → returns −Pow(−base, exp); only triggers when both base and exponent are Symbol or number), `_eval_power`, `_eval_subs` (exponent splitting for substitution), `_eval_expand_power_base` (distribute exponent over product; imaginary unit count mod 4), `_eval_transpose` (checks `is_complex` first — differs from adjoint/conjugate which check `is_positive`; complex base → return unchanged, integer exp → wrap base in transpose), `_eval_adjoint`, `_eval_conjugate`, `as_numer_denom` (split base into n/d then apply exponent; refuses to separate n/d when denominator sign is indeterminate and exponent is non-integer, e.g. sqrt(a/b) stays unsplit; nonpositive denominator → negates both n,d first).
  - `_eval_is_zero`: nonzero base + infinite exponent → compares |base| vs 1 (|base|<1 + positive exp → True; |base|>1 + negative exp → True).
  - `_eval_is_imaginary`: real base + real exp: positive base→False; rational exp with 2*exp integer (half-integer)→returns base.is_negative; integer exp→False; non-rational→not imaginary. NOT `assumptions/handlers/sets.py` (that's the `ask()` pathway).
  - `_eval_evalf`: numerical evaluation; complex (non-real) base with negative exponent → rewrites via conjugate: base→conj(base)/|base|², exp→−exp, then expands.
  - `_taylor_term`: cached binomial-coefficient terms for (1+x)^e expansion; returns binomial(e, n) * x^n. Used by `_eval_nseries` for non-trivial base limits.
  - `_eval_nseries`: truncated asymptotic expansion for Pow; non-integer exponent with base→0: corrects inner term count via leading-term order, factors out dominant term as lt^e·(rest/lt)^e.
  - base→1 checks residual sign; helper `e2int` converts exponent limit to integer.
  - `integer_nthroot`: exact floor n-th root of nonneg integer; overflow-safe initial estimate via log₂ + bit-shifting when float exponentiation raises OverflowError; Newton iteration for large values, linear compensate for small.
  - `as_content_primitive`: extract positive Rational from Pow; rational base + fractional exponent → divmod separates integer/remainder exponent parts; Mul base → recursive content extraction.
- `add.py` — `Add` class: `flatten` (infinity filtering, order processing; reconstruction phase: Mul-typed symbolic parts use fast rawargs slot-0 insertion, Add-typed parts use unevaluated Mul to avoid flattening, other types use full Mul machinery), `as_numer_denom` (convert sum to single fraction: groups terms by denominator, cross-multiplies to assemble numerator/denominator; zero-denominator terms (infinity) moved to numerator; single shared denominator → quick exit), `_eval_as_leading_term` (zero result → falls back to `compute_leading_term` via series; NaN result → reconstructs from infinite terms; simplified-to-zero with non-zero plain → recursively retries on remainder), `primitive`, `as_content_primitive` (radical factoring: extracts common nth-root factors from integer bases raised to fractional exponents across additive terms).
  - `_eval_is_negative`/`_eval_is_positive`: primary sign-property dispatch for sums; tracks conflicting infinite summands, returns indeterminate on ±∞ conflict. NOT `assumptions/handlers/order.py` (that's the `ask()` pathway).
  - `_eval_is_zero`: non-commutative sum → immediately returns None (indeterminate); commutative: classifies terms as real-zero/real-nonzero/imaginary/ambiguous; all zero→True, nonzero-sum-is-zero with no imaginary→True, with definite imaginary→False.
  - `_combine_inverse`: static method computing lhs−rhs for pattern matching; treats oo−oo and oo*I−oo*I as zero instead of NaN.
  - `_unevaluated_Add`: construct well-formed unevaluated sum; flattens nested Adds, collects numeric constants into slot 0, sorts remaining args. Used when args changed but evaluation is unwanted.
- `mul.py` — `Mul` class: `flatten` (2-arg fast path: Rational × Add → distributes rational over sum terms; if inner Add already has a rational coefficient extracted via `as_coeff_Mul`, wraps as unevaluated Mul to avoid re-flattening ("2-arg hack"); general path: separates commutative/non-commutative factors), `as_content_primitive`, `as_two_terms`, `_eval_expand_mul` (distribute product over sums; auto-reciprocal expressions like 1/(x*(x+1)) → expands numerator and denominator independently via `fraction()` before distributing; `_expandsums` divide-and-conquer helper for multi-factor Cartesian product), `_eval_is_infinite` (any infinite factor: checks for zero factor → NaN.is_infinite, unknown zero → None, else True).
  - `_eval_subs`: substitution in products; pre-step splits numerator/denominator so terms below the fraction bar get substituted independently before main pattern matching; coefficient extraction, commutative/non-commutative breakup, and quick rejection tests.
  - `_eval_is_real`/`_eval_real_imag` (shared helper for both is_real and is_imaginary; toggles real/imag flag each time an imaginary factor is seen; at most one neither-real-nor-imaginary factor tolerated — two such factors → None; zero factors with all-finite → True). NOT `assumptions/handlers/sets.py` `AskRealHandler` (that's the `ask()` pathway).
  - `_eval_is_positive`/`_eval_pos_neg`: product sign determination; distinguishes nonnegative (saw_NON: blocks True but allows False) from "not negative" (saw_NOT: two such factors → indeterminate None). NOT `assumptions/handlers/order.py`.
  - `_eval_conjugate`: applies conjugate to each factor in original order. `_eval_transpose`/`_eval_adjoint`: applies transpose/adjoint to each factor in **reversed** order (reflecting (AB)^T = B^T A^T for non-commutative products).
  - `_eval_is_prime`: primality of product; numeric unsimplified input → manually multiplies args (avoids doit() infinite recursion), checks result; symbolic positive integer → counts factors guaranteed >1, returns False if ≥2.
  - `_eval_is_hermitian`/`_eval_herm_antiherm`: hermiticity check for products; toggles real↔antihermitian per factor; zero factor with all-finite → True, zero with infinite → None (0·∞ indeterminate). NOT `assumptions/handlers/matrices.py`.
- `numbers.py` — `Number.as_coeff_mul` (split into coefficient × remainder: Rational→(self,()), negative non-rational→(−1,(−self,)), else→(1,(self,)); `rational` kwarg controls whether non-Rational numbers are extracted or left as unit coefficient). `Integer`, `Rational` (`__new__`: string input with `/` splits via rsplit and converts each side through `fractions.Fraction`, e.g. `'1e-2/3.2'` → 1/320; rejects >1 slash; `gcd`: other is Zero → returns Zero (bug: should return |self|); normal case → igcd of numerators over ilcm of denominators), `Float` (tuple+hex-string reconstruction from pickle), `ImaginaryUnit`, `AlgebraicNumber` (`__new__`: no coeffs given → defaults to [1,0]; negative root → negates to [-1,0]; supplied coeffs with degree ≥ minpoly degree → reduced via polynomial remainder; computes minimal polynomial via `minimal_polynomial` when not passed as tuple), `Exp1`, `_eval_power`, `mod_inverse` (modular multiplicative inverse; integer path via igcdex; rational/symbolic fallback: catches ValueError from as_int, checks m>1, returns 1/a as result), `igcd`, `igcdex` (extended Euclidean returning Bézout coefficients x,y and gcd; handles zero inputs), `ilcm`.
  - `NumberSymbol` constants (`Pi`, `EulerGamma`, `Catalan`, `GoldenRatio`, `NegativeInfinity`, `Infinity`): `approximation_interval` returns bounding rational/integer intervals for efficient comparison without full numerical evaluation.
  - `NumberSymbol.__gt__`/`__ge__`: negate both sides and delegate to `__lt__`/`__le__`; if result is symbolic (not true/false), falls back to `Expr.__gt__`/`Expr.__ge__`.
  - `NegativeInfinity`/`Infinity`: ordering operators (`__lt__`, `__le__`, `__gt__`, `__ge__`) with explicit subcases for finite, nonneg, and same-sign infinite operands.
- `function.py` — `FunctionClass` (metaclass for Function; `__init__` validates nargs: empty sequence → ValueError suggesting 0 or None), `Function` (`__new__`: auto-evalf when ALL args have float precision — uses min precision > 0 as trigger, max precision for evaluation depth; NumPy-compatible error message format), `Lambda` (anonymous callable: `__eq__` implements alpha-equivalence by renaming bound variables before body comparison), `Derivative.__new__`, `expand()` (extensible via `_eval_expand_hint()` methods on user-defined classes — each hint method handles only top-level expression, `expand()` handles recursive descent when `deep=True`; objects must satisfy `obj.func(*obj.args) == obj`), `_mexpand` (combined multinomial+mul expansion, optionally iterating to fixed point), `AppliedUndef`, `WildFunction` (wildcard callable pattern; `matches`: returns None if expr is not an applied function or arg count not in `nargs` set; only matches `AppliedUndef`/`Function` instances — plain symbols/numbers never match), `nfloat`; `_coeff_isneg`.
  - `Function._eval_nseries`: series expansion for applied functions; divergent argument → `_eval_aseries` if leading term still diverges, else substitution around logarithmic growth term.
  - `count_ops`: operation counter for expressions; Add handling: records SUB−ADD correction when first arg is negative but not all are (i.e. −x+y is subtraction, not addition); Pow with exp=−1 counted as DIV; visual mode returns symbolic operation tally.
  - `Function.fdiff` (first derivative w.r.t. argindex-th positional argument; when target arg is a Symbol appearing in other args' free_symbols, introduces Dummy placeholder to avoid incorrect naive differentiation — returns Subs-wrapped result).
  - `Function._eval_evalf`: mpmath function lookup by name; falls back to `MPMATH_TRANSLATIONS` dict, then `_imp_` attached implementation; silently returns None if all fail.
  - `expand_power_base` (split (a*b)**n → a**n * b**n; refuses unless base is non-negative or exponent is integer; `force=True` overrides), `expand_trig`, `expand_func`, `expand_complex`: selective expansion wrappers.
- `containers.py` — `Tuple` (`tuple_count`, `index` (element search with conditional dispatch: Python bug #13340 — passing None as start/stop to builtin tuple.index raises TypeError, so dispatches based on which optional args are None)), `Dict` (immutable key-value mapping wrapping Python dict; `__setitem__` raises NotImplementedError to enforce immutability; `__getitem__`/`get`/`__contains__` auto-sympify keys so plain Python ints match symbolic Integer keys); `cache.py` — `cacheit` memoization decorator (`__cacheit` fallback when fastcache unavailable: LRU-cached call wrapped in try/except TypeError — unhashable args silently bypass cache and call original function directly), `__cacheit_debug`.
- `relational.py` — `Relational`, `Equality`, `Unequality` (`Ne`; `__new__`: delegates to Equality — if result is BooleanAtom, negates it; non-boolean → returns unevaluated Unequality instead of negating), `GreaterThan`, `StrictLessThan`; `as_set` (univariate inequality → real set; raises NotImplementedError for multivariate); `Relational.canonical` (normalize inequality to standard form: Gt/Ge→reversed to Lt/Le, Eq/Ne→ordered args; number moved to RHS; symbol moved to LHS; negative leading coefficient on LHS → negates both sides and reverses direction, e.g. −2x<3 → x>−3/2).
- `exprtools.py` — `gcd_terms`, `_gcd_terms` (extracts shared divisor from additive components; returns zero/zero/one for empty input), `factor_terms`: GCD extraction with non-commutative masking; `decompose_power` (split power expression into symbolic base + integer exponent; Rational exp → extracts p from base^(1/q), non-Rational numeric exp → falls back to (expr, 1) without decomposing), `decompose_power_rat` (similar but preserves rational exponents).
  - `_monotonic_sign`: value closest to zero for uniformly-signed expression; prime: odd→3, even→2; positive integer→1, negative→−1; univariate polynomials checked via derivative roots; multivariate linear with constant: substitutes each free variable with its sign-boundary representative, combines with constant to infer overall sign.
  - `Factors`: power-factor dictionary wrapper; `__init__` (from Rational: stores numerator with exponent 1, denominator with exponent −1; negative values prepend NegativeOne factor); `normal` (remove GCD from two factor dicts; symbolic exponent fallback via `extract_additively` then numeric coefficient comparison), `mul`, `div`, `gcd` (intersection of factors with min exponent; indeterminate exponent comparison (is_negative→None) silently drops the factor), `lcm` (union of factors with max exponent).
  - `Term`: efficient `coeff*(numer/denom)` representation; `__init__` decomposes factors via `decompose_power` — when a factor's base is a sum (is_Add), extracts primitive content and folds it into coefficient; positive exponents → numer, negative → denom.
  - `_mask_nc`: replace non-commutative entities with Dummy placeholders before polynomial factoring; single nc-entity → commutative Dummy (standard factor works), multiple → non-commutative Dummies preserving order.
  - `factor_nc`: non-commutative factoring; delegates to standard `factor` when `_mask_nc` returns substitutions, else manual common-prefix/suffix extraction.
- `evalf.py` — `hypsum` (infinite hypergeometric series summation; polynomial convergence with exponent p==1 only converges if alternating), `evalf_sum` (numerical infinite series: tries fast hypergeometric summation first; non-hypergeometric fallback uses Euler-Maclaurin with progressively doubled parameters 2^i*prec for i=1..4 until error < 2^(-prec)), `evalf_prod` (numerical product evaluation; non-integer-width bounds → rewrite as Sum): numerical evaluation, precision.
  - `pure_complex`: decompose symbolic expression into (real, imag) numeric pair via as_coeff_Add + as_coeff_Mul; returns None for irrational/non-numeric terms like √2; `or_real` flag returns (h, 0) for purely real inputs.
  - `evalf_trig`: numerical sin/cos of complex args; zero-argument dispatch returns (1, None) for cos, (None, None) for sin; iterative precision refinement loop near multiples of π.
  - `do_integral`: numerical definite integration; optimizes constant-integrand case by simplifying bounds difference; oscillatory quadrature (`quad='osc'`): validates integrand matches sin(A*x+B)*D or cos(A*x+B)*D pattern via Wild matching, raises ValueError if no match.
  - `evalf_log`: numerical log evaluation; near-1 argument precision guard — when result magnitude is much smaller than working precision, rewrites as log(1+(x−1)) by evaluating arg−1 via `evalf_add` for accurate cancellation, then adds 1 back before taking log.
  - `evalf_piecewise`: piecewise numerical eval; applies subs, handles collapse to Python float/int by wrapping in Float/Integer; raises NotImplementedError if unevaluated symbols remain.
  - `get_integer_part`: floor/ceiling numerical computation; near-integer handling: computes residual (expr−nearest_int), checks sign; raises PrecisionExhausted if precision insufficient unless expr equals 0 exactly.
- `mod.py` — `Mod`: symbolic modulo operation; `eval` handles float coefficient extraction (e.g. `Mod(.6*x, .3*y)` → `0.3*Mod(2*x, y)`), ratio-based computation (int(p/q) truncation with sign correction: if remainder has opposite sign from divisor, adds q to enforce Python same-sign-as-divisor convention), GCD simplification, denesting, and Add-term reduction.
- `logic.py` — fuzzy logic (`fuzzy_bool` (convert to True/False/None; non-boolean truthy values like int 1 or symbolic objects return None, unlike Python `bool()`), `fuzzy_and` (three-valued conjunction; accepts generators for lazy evaluation — short-circuits on first False without consuming remaining items), `fuzzy_or`, `fuzzy_not`) AND internal propositional `Logic` class with `fromstring` (space-delimited boolean formula parser), `And`/`Or`/`AndOr_Base` (`__new__`: auto-simplifies contradictions — if both a proposition and its negation are present, returns annihilating value (False for And, True for Or); skips identity elements, deduplicates, flattens nested same-type ops), `Not` (`__new__`: double negation elimination — Not(Not(x)) → x; bool arg → Python negation; Logic arg → propagates via `_eval_propagate_not`). NOT `logic/boolalg.py` (which defines the user-facing boolean algebra classes).
  - `_fuzzy_group`: like `fuzzy_and` but conservative; `quick_exit=True` returns None on second False (one exception tolerable, two makes result indeterminate).
  - `And.expand`: distributes conjunction over disjunction to convert to sum-of-products (disjunctive normal) form. NOT `logic/boolalg.py` `to_dnf`.
- `symbol.py` — `Symbol`, `Dummy`, `Wild` class definitions; `var` (create symbols and inject into caller's global namespace; FunctionClass results use `__name__` for global variable name, Basic results use `.name`); `Symbol._sanitize` (in-place assumption cleanup: translates deprecated property names — `bounded`→`finite`, `unbounded`→`infinite`, `infinitesimal`→`zero` — with deprecation warnings; converts values to bool, removes None entries); `Wild.matches` (checks `exclude` list via `has`, checks `properties` predicate callables — any failing predicate returns None/no-match); `symbols` (batch creation from comma/space-separated names; colon range notation with letter-inclusive/digit-exclusive endpoints); `operations.py` — `AssocOp` (`_new_rawargs`: reconstruct from subset of args without full flatten/validate; if self is non-commutative, recomputes commutativity by default (`reeval=True`) to avoid inheriting stale non-commutative flag; `_matches_commutative`: Add/Mul pattern matching; filters exact-part free symbols against target; `_eval_evalf`: separates numeric/symbolic parts, evaluates numeric at binary precision; recursion guard prevents infinite loop when extracted numeric part is itself an AssocOp Function), `LatticeOp` (join/meet for algebraic lattices; `__new__`: `_new_args_filter` raises `ShortCircuit` on absorbing element → returns `zero` immediately; empty args → `identity`; single → unwrap).
- `sympify.py` — `sympify()`: convert arbitrary objects to SymPy types; `locals` param overrides namespace for string parsing (e.g. prevent `O`/`I`/`E` from resolving to built-in constants; `_clash1`/`_clash2` dicts from `abc` module provide ready-made single-letter/Greek overrides); `kernS` (string-to-expression with placeholder insertion to prevent autosimplification of products with parenthesized sums; falls back to original string on parse error). NOT `parsing/sympy_parser.py` (lower-level tokenizer).
- `compatibility.py` — `ordered`: conservative tie-breaking sort with successive keys; fallback/warn on unresolved ties. `lru_cache` (bounded LRU memoization decorator; circular doubly-linked list for recency tracking; eviction reuses oldest node's list slot instead of allocating new node). `default_sort_key`: canonical ordering key for any object; sympifies non-string items to Basic for sort_key; non-sympifiable non-string non-iterable objects (e.g. lambda) fall back to string-based key with cls_index=0.
  - `GROUND_TYPES`/`HAS_GMPY`: multi-precision integer backend selection at startup; reads `SYMPY_GROUND_TYPES` env var (auto/gmpy/gmpy1/python); tries gmpy2 then gmpy1, falls back to python with warning if requested backend unavailable.
  - `as_int`: convert to builtin int with equality guarantee; raises ValueError if `int(n) != n` (catches truncation of irrationals like √10→3).
  - `iterable` (check if object should be recursively mapped as finite collection; `_iterable` attribute override bypasses all checks including exclusion list; default excludes strings/dicts), `NotIterable` (mixin to opt out), `is_sequence`.
- `assumptions.py` — `_assume_rules`: `FactRules` definition encoding logical implications between number-theoretic properties (e.g. integer→rational→real→complex, positive→real).
  - `StdFactKB`: specialized `FactKB` for built-in rules; `__init__` three-way dispatch: falsy/empty→empty `_generator` (no deduction), `FactKB` instance→copies its `.generator`, plain dict→stores copy and runs full deduction.
  - `_ask`: recursive property resolution with anti-recursion guard and shuffled prerequisites.
  - `make_property`: copy-on-write property factory (copies shared class-level assumptions dict before mutation).
  - `ManagedProperties` metaclass: protects subclasses from inheriting parent's cached static assumption values by replacing with dynamic descriptors.
- `rules.py` — `Transform`: immutable computed-mapping (callable-based dict); `__getitem__` raises KeyError when filter predicate rejects key; `get` provides safe fallback; `__contains__` delegates to filter.
  - Used as generic transformation rule for substitution.
- `singleton.py` — `SingletonRegistry` (`S`): lazy-instantiation registry; `__getattr__` creates instance on first access, installs as attribute to bypass future lookups; `Singleton` metaclass auto-registers classes.

- `solvers.py` — `solve`, `_solve`, `unrad` (remove radicals from equations; inner `_canonical` normalizes sign: single free symbol → checks leading coefficient, multiple → checks whole expression; inner `_take` filters generators by exponent denominator), `checksol` (verify candidate root satisfies equation; returns False for NaN/∞/ComplexInfinity values; multi-stage substitution+simplification loop), `nsolve` (numerical root finding via mpmath `findroot`; scalar expressions: strips denominator via `as_numer_denom()[0]` before lambdifying — can cause verification failure for steep functions near roots; systems: symbolically computes Jacobian matrix), `solve_linear_system` (Gaussian elimination with symbolic RHS row deduplication: all-zero-LHS rows with symbolic RHS are compared pairwise via `as_content_primitive` to detect equivalent rows before declaring inconsistency; NOT `matrices/dense.py` `gauss_jordan_solve`), `solve_linear_system_LU` (solves augmented matrix [A|b] via LU decomposition; enforces rows == cols−1 constraint), `minsolve_linear_system` (find sparsest solution to underdetermined linear system; exhaustive mode uses quick-method result as upper bound, iterates decreasing subset sizes trying all variable combinations; quick mode heuristically zeros free variables), `solve_undetermined_coeffs` (find parameter values in parametric univariate polynomial equality by collecting powers of the variable and solving the resulting coefficient system; returns None if variable not fully eliminated), `check_assumptions` (validate candidate value against property constraints like real/positive/integer; does NOT short-circuit on inconclusive (None) — continues checking remaining properties since a later one may definitively contradict (False); only returns None if no property contradicts), `sub_func_doit`.

  - `det_quick`: determinant dispatch — all-symbolic + <8 rows → permutation-based `det_perm`, mixed symbolic → cofactor `det_minor`, pure numeric → `Matrix.det`.
  - `inv_quick`: fast symbolic matrix inverse via cofactor expansion; selects det strategy (det_perm vs det_minor) based on whether all entries are symbolic; raises ValueError if determinant is zero.
- `solveset.py` — `solveset`, `linsolve`, `linear_eq_to_matrix`: new-style set-based solver API; `_invert` (reduce f(x)=y to simpler equations; domain intersection applied only when result is FiniteSet — infinite ImageSet results returned without domain restriction); `_invert_real` (invert power/trig/exp expressions; even-numerator rational exponents yield both ± roots).

- `recurr.py` — `rsolve`, `rsolve_poly`, `rsolve_ratio` (rational solutions via Abramov's algorithm; non-polynomial resultant fallback: decomposes into numer/denom and takes polynomial quotient), `rsolve_hyper`: linear recurrence equation solvers.

- `diophantine.py` — `diophantine`, `classify_diop` (categorize integer-coefficient equation by structure: linear, binary_quadratic, homogeneous_ternary_quadratic vs _normal form (only pure squared terms, no cross products), general_sum_of_squares, etc.), `square_factor` (largest perfect-square divisor; accepts integer or factorization dict, returns product of p^(e//2)), `sqf_normal` (normalize ternary quadratic to square-free pairwise-prime form), `sum_of_four_squares`, `power_representation` (enumerate k-tuples whose p-th powers sum to n; Fermat's Last Theorem guard: k=2, p>2, n is perfect power → immediate empty return), `diop_DN` (generalized Pell equation x²−Dy²=N solver; N=−1 with even CF period length → empty list (no solution); N=1 uses CF convergents), `PQa` (generator yielding six recurrence sequences {P,Q,a,A,B,G} from (P+√D)/Q for generalized Pell equation solving; NOT `ntheory/continued_fraction.py` which computes CF representations), `transformation_to_DN`/`_transformation_to_DN` (convert general ax²+bxy+cy²+dx+ey+f=0 to X²−DY²=N via recursive affine transforms; each recursion composes transformation matrices), `ldescent` (Lagrange descent for w²=Ax²+By²; returns None when both A,B are −1 since sum of negative squares cannot be positive; normalizes abs(A)≤abs(B) via swap; recursive via divisor decomposition), `descent` (lattice-reduction variant): integer/diophantine solving.

- `inequalities.py` — `solve_poly_inequality`, `solve_rational_inequalities`, `reduce_rational_inequalities` (system of rational inequalities; non-ZZ/QQ coefficient domain falls back to `solve_univariate_inequality` instead of rational-intersection method), `reduce_abs_inequality` (nested absolute-value decomposition into piecewise cases via Cartesian product of branches).
- `pde.py` — `pde_separate` (variable separation for PDEs; `strategy` param selects additive/multiplicative; bug: unknown strategy silently passes due to `assert ValueError` instead of `raise`), `pde_separate_add`, `pde_separate_mul`; `_separate` (two-pass internal routine: first pass extracts derivative coefficients as divisors and divides equation — FIXME: sums divisors instead of computing LCM; second pass splits normalized equation into lhs/rhs by variable dependence).

### [`logic/`](logic/catalog.md)

### [`tensor/`](tensor/catalog.md)
Abstract index notation for tensors: `TensorHead`, `TensorIndex`, `TIDS`, Einstein summation.
- `tensor.py` — `_TensorManager` (manages tensor commutation groups; `comm_symbols2i`: auto-registers unknown group symbols on lookup — appends new entry, sets bidirectional commutation with group 0, returns new index; `set_comm` configures pairwise commutation rules), `TensExpr.get_matrix` (convert ndarray component data to Matrix; rank 1→column vector, rank 2→matrix, rank>2→raises NotImplementedError), `Tensor.__call__` (replace free indices with new labels; detects newly introduced contractions — when replacement indices contain an up/down pair of the same abstract index, rebuilds object via `func(*args)` so contracted pairs are recognized as dummies), `Tensor.canon_bp` (single-tensor canonicalization; returns `S.Zero` when canonical permutation result is 0, indicating tensor vanishes due to symmetry), `TensMul.canon_bp` (canonicalization), `TensAdd` (`__new__`: single TensMul arg skips canonicalization; multiple args are canon_bp'd, potentially cancelling to zero), `TensorIndexType` (`data` setter: 1D array auto-expanded to 2D diagonal matrix for metric; also sets Kronecker delta data; `get_epsilon`: construct Levi-Civita epsilon tensor; returns None when eps_dim is symbolic/non-integer), `TIDS.from_components_and_indices`; `TIDS.sorted_components` (bubble-sort by commutation group; undefined commutation relation (neither 0 nor 1) → skips swap via `continue`, leaving original order; anticommuting swap flips sign); `TIDS.canon_args` (prepares permutation mapping, dummy index groups by type, and metric symmetry info for Butler-Portugal canonicalization in `combinatorics/tensor_can.py`); `TIDS.contract_metric` (metric contraction with sign correction; antisymmetric metric flips sign based on index position to bring to contravariant form); `TensorSymmetry` (monoterm slot symmetry via BSGS; `__new__` accepts 1 tuple or 2 args; raises TypeError on >2 args), `tensorsymmetry` (factory from Young tableaux shapes).
  - `TensMul.equals`: canonicalizes both sides via `canon_bp`, compares tuple of (coefficient, components, sorted free indices, sorted dummy pairs).
  - `TensMul.__mul__`: scalar→scales coeff; TensAdd→distributes as TensAdd(*[self*x for x in other.args]); TensMul→combines TIDS index structures.
  - `TensAdd.equals`: tensor sum equality; zero-coeff TensMul → checks all self.args have zero coeff; TensAdd→set comparison of args; fallback subtracts and checks all coefficients zero.
  - `tensor_indices`: create named indices from comma-separated string; returns bare object for single name, list for multiple.
  - `tensorhead`: convenience factory — accepts index type list and nested-list symmetry spec, internally constructs `tensorsymmetry` and `TensorType`, returns named `TensorHead`(s).
- `index_methods.py` — `get_contraction_structure` (recursive analysis of repeated/dummy indices in expressions; returns nested dict mapping index tuples to term sets; Pow/exp recurse base and exponent independently), `get_indices`; `_get_indices_Add` (validates consistent outer indices across additive terms; scalar terms (empty index set) are broadcast-compatible with non-scalar terms; raises IndexConformanceException on mismatch).
- `indexed.py` — `Idx` (integer subscript for array access; single dimension arg→lower=0, upper=dim-1; numeric label short-circuits to number), `Indexed`, `IndexedBase`.
- `array/` — N-dimensional arrays (dense/sparse, mutable/immutable): `Array`, `tensorproduct`, `tensorcontraction` (index summation), `derive_by_array` (element-wise symbolic derivatives); `NDimArray._scan_iterable_shape` (recursive nested-collection validator: infers shape from iterable structure, raises ValueError "could not determine shape unambiguously" on ragged/inconsistent nesting depths); `NDimArray._parse_index` (convert multi-axis coordinate tuple to flat storage index via row-major linearization; validates rank and per-axis bounds).
  - `DenseNDimArray.__getitem__`: tuple-of-slices → new typed array with computed shape; plain (non-tuple) slice → raw `self._array[index]` elements directly (NOT a new array object).
  - `NDimArray.__mul__`: scalar-only; raises ValueError("scalar expected, use tensorproduct(...)") for iterables, other arrays, or Matrix inputs.
  - `DenseNDimArray.tomatrix` / `SparseNDimArray.tomatrix`: convert N-dim array to Matrix; raises ValueError if rank ≠ 2.
  - `MutableSparseNDimArray.__new__`: dict input stores entries directly (does NOT filter zeros); list input iterates and stores only nonzero elements.
  - `array/arrayop.py` — `tensorproduct`, `tensorcontraction` (validates contraction axis pairs: raises ValueError if same axis specified twice or axes have different dimensions), `derive_by_array`: array operation implementations; `_arrayfy` converts MatrixBase/list/tuple to ImmutableDenseNDimArray.
- NOT quantum tensor products (those are `physics/quantum/tensorproduct.py`).
- NOT tensor canonicalization / slot symmetry BSGS (that's `combinatorics/tensor_can.py`).
- NOT second quantization index ordering (that's `physics/secondquant.py`).

### [`sets/`](sets/catalog.md)
Set theory: intervals, finite sets, unions, complements, images.
- `sets.py` — `Set` base class (`_infimum_key`: sorting key via infimum; returns ∞ on failure), `Interval` (`_contains`: rejects ∞, −∞, NaN, ComplexInfinity, and non-real values immediately before any comparison; full-real-line fast path returns `other.is_real`; then builds conjunction of boundary comparisons respecting open/closed endpoints), `FiniteSet` (`as_relational`: converts to Or-of-Eq expressions — `Or(*[Eq(symbol, elem) for elem in self])`), `Union` (with `reduce`: merge FiniteSets then iterative pairwise simplification; `__iter__`: round-robin interleaving of constituent set iterators for fair ordering), `Complement`, `ProductSet` (Cartesian product of sets; `_union`: simplifies only when first or last factor matches — middle-only match returns None; `_intersect`: pairwise intersection of corresponding factors); `imageset` (compute image of set under transformation; normalizes lambda/FunctionClass/Python-lambda inputs; composes nested ImageSet transformations into single Lambda; identity map → returns base set unchanged). NOT `calculus/util.py` `AccumBounds` (which is for limit computation interval arithmetic, not set-theoretic membership).
  - `Interval._eval_Eq`: returns None (unevaluated) for compound set types (Union/Complement/Intersection/ProductSet), returns false for all other non-Interval types.
  - `Interval._eval_imageset`: piecewise function image via progressive domain removal; continuous function image via critical points (finds extrema via derivative roots); boundary openness swap: when function reverses ordering (_start > _end), left_open inherits from right_open and vice versa.
- `conditionset.py` — `ConditionSet`: set defined by a condition over a base set; FiniteSet base → sifts elements via fuzzy_bool into true/false/indeterminate; indeterminate elements remain wrapped in a new ConditionSet.
- `contains.py` — `Contains`: element-membership predicate (delegates to set's `contains`; returns None to break mutual recursion).
- `fancysets.py` — `ImageSet` (image of a set under a Lambda function; `__iter__` deduplicates via seen-set; constructor returns base set for identity map, FiniteSet for constant expression; `_intersect`: ImageSet-ImageSet over Integers uses diophantine solver — returns None (gives up) when solution has multiple tuples), `Range` (`_contains`: membership check — picks whichever endpoint (start or stop) is finite as the reference for modular arithmetic `(ref - other) % step`; infinite values → False, non-integer → delegates to `is_integer`; `__getitem__`: slice access for both finite and infinite ranges; infinite left-end with step>1 and no explicit start/stop raises ValueError "cannot unambiguously re-stride"; step==1 returns self; delegates right-infinite ranges to reversed counterpart; `_intersect`: Range-Range intersection via Diophantine solver for coincident point, then `_first_finite_point` adjusts for step-direction mismatch with off-by-one correction; Range-Interval intersection via ceiling/floor clamping; `_eval_imageset`: reparametrize linear function application — finite start uses f(step*x+start), infinite start uses f(-step*x+last) to re-index from zero; returns imageset over Range(self.size)), `Naturals` (`_contains`: positive+integer→true, not-integer or not-positive→false, indeterminate→returns None implicitly), `Naturals0` (`_contains`: nonneg+integer check), `Integers` (`_eval_imageset`: canonicalizes linear functions a*n+b over ℤ by reducing offset b modulo a; picks between f(n) and f(−n) based on negative coefficient count to ensure canonical form), `Reals`; `ComplexRegion` (polar/rectangular complex sets); `normalize_theta_set` (angular interval normalization to [0,2π), splits wrap-around).

### [`calculus/`](calculus/catalog.md)
Calculus utilities: finite differences, Euler equations, singularities, accumulation bounds.
- `util.py` — `AccumBounds`: symbolic interval arithmetic for limit computation; `__pow__`, `__add__`, `__sub__` (∞−∞ returns full real line), `__mul__` (zero × semi-infinite interval returns semi-infinite range instead of zero, e.g. 0×[a,∞)→[0,∞); only finite intervals yield plain zero), `__contains__` with ±∞ pairing semantics.
  - `__lt__`/`__le__`/`__gt__`/`__ge__`: compare ranges; overlapping → None; unknown finiteness/sign falls through to Expr base class.
  - `function_range` (output range over a domain; limits at open endpoints, substitution at closed); `continuous_domain`; `not_empty_in` (find domain where FiniteSet intersection is non-empty; plain FiniteSet input defaults to S.Reals as domain set). NOT plotting interval math.
- `singularities.py` — `singularities`: find points where a univariate rational function is undefined; solves `1/expr=0` via solveset; raises NotImplementedError for non-rational inputs.
  - `is_increasing`, `is_decreasing`, `is_strictly_increasing`, `is_strictly_decreasing`, `is_monotonic`: monotonicity tests via derivative sign analysis.
  - Constants (no free symbols): non-strict variants return True, strict variants return False.
- `finite_diff.py` — `finite_diff_weights` (Fornberg algorithm for FD coefficients on arbitrary grids; raises ValueError for fractional derivative orders), `apply_finite_diff`, `differentiate_finite`.
- `euler.py` — `euler_equations`: derive Euler-Lagrange stationary-condition equations from a Lagrangian.
- NOT ODE solving (that's `solvers/ode.py`). NOT limits (that's `series/limits.py`).

### [`diffgeom/`](diffgeom/catalog.md)
Differential geometry: manifolds, forms, connections, tensor products.
- `diffgeom.py` — `CoordSystem` (coordinate charts with auto-generated labels), `Manifold`, `Patch`, `BaseScalarField` (`__call__`: evaluates field at a Point by transforming point coords to field's coord system, extracting indexed component, then applying simplify+doit); `contravariant_order`/`covariant_order` (compute tensor degree of expr; Mul rejects products of two nonzero-order fields); `twoform_to_matrix` (convert rank-2 covariant form to matrix by evaluating on basis vector pairs; validates covariant order==2 and single coord system); `Commutator` (Lie bracket of vector fields; evaluates explicitly when both fields use single coord system, returns unevaluated symbolic object when multiple coord systems involved); `TensorProduct` (differential form tensor product; filters scalars from forms, returns scalar*form if only one form), `WedgeProduct`, `LieDerivative` (`__new__`: scalar expr with no vector field atoms → eagerly evaluates by applying v_field to expr, returning immediate result instead of symbolic object), `Differential`.
- `rn.py` — predefined Euclidean spaces `R2`, `R3` with coordinate systems (rectangular, polar/cylindrical/spherical); all pairwise transition maps explicitly specified with `inverse=False, fill_in_gaps=False`.

### [`liealgebras/`](liealgebras/catalog.md)
Lie algebra representations, root systems, and Weyl groups.
- `type_a.py`, `type_b.py`, `type_c.py`, `type_d.py`, `type_f.py` — classical Lie algebra families: `simple_root`, `positive_roots`, `cartan_matrix`, `dimension`.
- `type_e.py` — exceptional E₆/E₇/E₈: `positive_roots` generates half-integer coordinate vectors via nested binary-variable loops with even-parity filter. Known bug: root vector mutated in-place without reset between iterations.
- `type_g.py` — exceptional G₂ (rank-2 only): `positive_roots` (NOTE: docstring/example erroneously references A_n series — copy-paste error), `simple_root`, `cartan_matrix`.
- `weyl_group.py` — `WeylGroup`, `element_order` (matrix exponentiation for A/B/C/D/E/F types; G2 (dihedral symmetry of the hexagon) uses string-reduction via `delete_doubles` + LCM-based order from reduced reflection length instead of matrix multiplication), `delete_doubles`.
- `cartan_type.py` — `CartanType` factory, `Standard_Cartan` base class.
- NOT permutation groups (those are `combinatorics/perm_groups.py`).

### [`categories/`](categories/catalog.md)
Category theory: objects, morphisms, diagrams.
- `baseclasses.py` — `Morphism` (base arrow: `compose`/`__mul__` for sequential composition in mathematical order g∘f), `IdentityMorphism`, `NamedMorphism`, `CompositeMorphism`, `Object`, `Class`.
- `diagram_drawing.py` — `_GrowableGrid` (dynamically expandable 2D array; grows in all four directions via `append_row`/`prepend_row`/`append_column`/`prepend_column`; prepending shifts existing coordinates), `DiagramGrid` (2D lattice layout with disconnected-component handling; `_handle_groups`: lay out each logical cluster independently as sub-grid, create dummy morphisms between clusters for top-level positioning, compute row heights/column widths as max of nested sub-grid dimensions, stitch into composite grid), `XypicDiagramDrawer`, `ArrowStringDescription`.
  - `_juxtapose_edges`: construct new edge from pair sharing one endpoint; identical edges → None. `_build_skeleton`/`_list_triangles` decompose morphism graphs into triangles.
  - `_grow_pseudopod`: when triangle-welding stalls, extends existing grid structure by finding a placed object sharing exactly one vertex with an unplaced triangle, adds an edge to an empty neighbor cell to enable further attachment.
  - `_weld_triangle`: attach a triangle to the grid fringe by placing its third vertex adjacent to an existing edge.

### [`parsing/`](parsing/catalog.md)
Expression parsing: string-to-SymPy conversion, Mathematica/Maxima translators.
- `sympy_parser.py` — `parse_expr`, `implicit_multiplication`, `implicit_application`; `evaluateFalse` (rewrite AST with `evaluate=False` on all operators), `EvaluateFalseTransformer` (AST node visitor: maps binary ops to SymPy calls with evaluate=False; division with negated numerator swaps Pow(-1) to left operand and performs additional swap when both operands are negated).
  - `lambda_notation`: converts `lambda` keyword to `Lambda()` call; raises `TokenError` on starred arguments (`*`/`**`) in lambda parameters.
  - `function_exponentiation`: rearrange `sin**4(x)` → `sin(x)**4` by collecting exponent tokens between `**` and `(`; handles implicit multiplication `)*(`  by detecting `*` token and removing it from exponent.
  - `split_symbols_custom`: break multi-char names into chars for implicit multiplication; known names emitted as direct refs, unknown wrapped in Symbol().
  - `convert_equals_signs`: nested `=` to `Eq()` via recursive parenthesis grouping.
- `mathematica.py` — `mathematica`, `parse`: Mathematica-to-SymPy parser; `translateFunction` (Arc-prefix → 'a' + lowercase for inverse trig, else lowercase), `translateOperator`.

Interactive session setup: `init_session`, `init_printing`.
- `session.py` — `int_to_Integer` (wrap integer literals with `Integer()` via Python tokenizer; inner `_is_int` distinguishes integers from float/complex/scientific by checking for '.', 'j', 'e' in token string), `enable_automatic_int_sympification` (patches IPython shell to apply `int_to_Integer` to all cell input).

### [`unify/`](unify/catalog.md)
Unification algorithms for expression pattern matching.
- `core.py` — generic tree unification (AIMA-based): `Variable` (unconstrained wildcard), `CondVariable` (wildcard with predicate filter: `valid(x)` must return True for match), `Compound`, `unify`/`unify_var`, `occur_check` (prevents circular substitutions: recursively checks whether a wildcard variable appears inside a candidate expression before binding — if found, silently rejects the match to avoid infinite substitution chains), `allcombinations` (enumerate restructurings of two arg sequences for associative/commutative matching).
- `usympy.py` — `unify` (structural unification with commutative/associative matching), `is_commutative` (for Mul: checks all args, not hardcoded), `deconstruct`/`construct` (SymPy↔Compound; construct uses three-way dispatch: AssocOp/Pow/FiniteSet→evaluate=False, MatrixExpr→Basic.__new__, else normal constructor).
- `rewrite.py` — `rewriterule`: create pattern-matching transformation rules; unifies source pattern against input, applies variable substitutions to target, optionally filters via `condition` callable or `assume` predicate with `ask`; non-Expr substituted results skip `rebuild` and are yielded directly.
- NOT `core/basic.py` `_has`/`matches` (those are tree-structural matching).

### [`strategies/`](strategies/catalog.md)
Rule-based expression transformation strategies.
- `tools.py` — `subs` (full simultaneous exact substitution via top_down traversal with do_one combinator; empty mapping → returns identity function), `canon` (canonicalization via bottom_up exhaust), `typed` (type-based rule dispatch).
- `tree.py` — `treeapply` (recursive dispatch: maps container types to combining functions via a dict; non-matching leaf elements get identity/leaf function), `greedy` (execute strategic tree greedily: tuples=chained sequence, lists=select alternative minimizing objective), `allresults`.
- `core.py` — `exhaust` (apply rule to fixed point), `chain`, `do_one`, `tryit`, `condition`, `minimize`, `memoize`, `switch`.
- `rl.py` — `rebuild` (recursively re-invoke constructors for canonicalization; silently returns original node if constructor raises), `rm_id` (strip identity/neutral elements from compound expression children; all-children-neutral → retains one to avoid empty expression), `flatten`, `unpack`, `distribute`, `subs`, `sort`, `glom`.
- `branch/core.py` — nondeterministic (branching) strategies: `exhaust` (repeated application with cycle detection via seen-set), `multiplex`, `condition`, `sfilter`, `notempty`, `do_one`, `chain`.
- `traverse.py` — `top_down`, `bottom_up`, `sall`: tree traversal combinators for applying rules.
