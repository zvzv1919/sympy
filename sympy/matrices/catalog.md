# sympy/matrices — Catalog

> Part of [SymPy](../catalog.md). Symbolic and numeric matrix algebra: dense, sparse, immutable, and block matrices; eigenvalues, decompositions.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package init that re-exports all public matrix classes (Matrix, SparseMatrix, ImmutableMatrix) and matrix expression types. |
| `common.py` | Base classes and shared infrastructure for all matrix types, including `MatrixRequired`, `MatrixShaping`, `MatrixProperties`, `MatrixOperations`, `MatrixArithmetic`, `MatrixSpecial`, error classes, and the `MatrixCommon` composite class. |
| `matrices.py` | Core `MatrixBase` class with all concrete matrix operations on Matrix objects: item assignment (`_setitem` is a dispatch-only helper that routes assignment requests to the copyin methods defined in `dense.py` — does not itself validate types or shapes or raise errors), indexing helpers (`key2bounds` converts mixed integer/slice keys into row/column boundary tuples with zero-dimension edge cases, `key2ij`), property predicates (`is_hermitian` using fuzzy three-valued logic for symbolic entries, `is_lower`, `is_upper`, `is_diagonal`, Hessenberg checks), arithmetic operators (`__pow__` raises a concrete dense matrix to a power — uses exponentiation-by-squaring for integers and Jordan normal form decomposition for non-integer symbolic/float exponents, exponentiating each Jordan cell with binomial coefficients; `__mul__` performs concrete matrix multiplication and returns `NotImplemented` when the right operand lacks a `tolist` method on its transpose (e.g. MatrixSymbol), allowing Python dispatch to fall back; `__add__`), concatenation methods (`row_join` horizontally concatenates two matrices along columns — when the left operand is empty/null it returns the right operand cast to the same type, enabling incremental construction from nothing; `col_join` vertically concatenates along rows with the same null-matrix edge case; `hstack`/`vstack` apply these repeatedly via reduce), norm computation (`norm` dispatches based on ord parameter — for vectors computes various p-norms; for 2D matrices with default ord=None reshapes to a column vector via `vec()` and recursively computes the 2-norm as Frobenius norm, ord=2 uses max singular value, ord=-2 uses min singular value), determinant computation (`det_bareis` implements Bareis' fraction-free Gaussian elimination that avoids accumulating fractions by dividing intermediate results by the previous pivot `M[k-1,k-1]`, with row-swapping when the current pivot is zero; also dispatches to Berkowitz/LU methods; returns 1 for empty 0×0 matrices before any elimination), row reduction (RREF), subspace methods (nullspace, columnspace), eigenvalue/eigenvector routines, diagonalizability testing, matrix decompositions (QRdecomposition using Gram-Schmidt with full-column-rank validation via RREF before factorization, LUdecomposition, LDLdecomposition, cholesky), matrix inverse algorithms (`inverse_GE` via Gaussian elimination, `inverse_LU` via LU decomposition, `inverse_ADJ` via adjugate-and-determinant — when `equals()` returns None for the determinant zero-check, `inverse_ADJ` falls back to RREF to determine invertibility by checking diagonal entries), pseudoinverse computation (`pinv` computes Moore-Penrose pseudoinverse — uses different paths for tall vs wide matrices, catches ValueError from inv() on rank-deficient matrices and raises NotImplementedError), linear system solvers operating on MatrixBase objects (pinv_solve, gauss_jordan_solve, cholesky_solve, LUsolve, LDLsolve, QRsolve), Jordan form, element extraction, element-level utilities (`atoms` collects irreducible sub-expressions from all entries defaulting to `Atom` type when no filter is given, `free_symbols`, `subs`, `xreplace`, `expand`), tabular string formatting (`table` converts a matrix to an aligned text table used by the string printer — handles zero-dimension edge case by returning `'[]'` immediately when rows or cols is zero, before any element formatting; `_format_str` similarly short-circuits for zero-dimension matrices returning `'Matrix(%s, %s, [])'`), text-based sparsity visualization (`print_nonzero` prints a character grid showing locations of zero vs non-zero entries for quick visual inspection of matrix structure), and calculus operations (diff, integrate, limit). |
| `dense.py` | `DenseMatrix` and `MutableDenseMatrix` (aliased as `Matrix`) implementations with symbolic element-wise `equals` (three-valued: True/False/None for undecidable), inversion dispatcher (`_eval_inverse` selects among GE/LU/ADJ methods defined in `matrices.py` — does not contain the actual inversion algorithms), dense triangular solvers as DenseMatrix instance methods (`_lower_triangular_solve` using forward substitution raising TypeError on singular diagonal, `_upper_triangular_solve` using backward substitution raising ValueError on singular diagonal — note the inconsistent exception types; for standalone function-based triangular solvers on raw nested lists, see `densesolve.py`), `_diagonal_solve`, `applyfunc`, `reshape`, type conversion methods (`as_immutable` converts to ImmutableMatrix — when either rows or cols is zero, uses `cls._new(rows, cols, [])` instead of `cls._new(self.tolist())` to handle empty/zero-dimension matrices; `as_mutable` converts back to mutable Matrix), mutable slice-assignment copy-in methods (`copyin_matrix` validates that the source matrix shape matches the target sub-region dimensions via `key2bounds` and raises ShapeError on mismatch before element-wise copy; `copyin_list` checks that the value is an ordered iterable and raises TypeError for non-iterables like plain integers, then delegates to `copyin_matrix`), plus top-level helpers: `matrix_multiply_elementwise` (concrete Hadamard/elementwise product that raises ShapeError on dimension mismatch), `eye`, `zeros`, `ones`, `diag` (concrete block-diagonal construction function that accepts a mix of scalars, plain lists, and Matrix objects — auto-converts lists to Matrix, accumulates total output dimensions by summing each block's rows and cols, places blocks along the diagonal of a sparse intermediate matrix, then converts to the target class), `randMatrix`, rotation matrices, `GramSchmidt` (orthogonalizes a list of vectors, not a matrix factorization), `wronskian`, `hessian`, `casoratian`, and NumPy conversion utilities at module level: `list2numpy` (converts a Python list of SymPy expressions to a NumPy array), `matrix2numpy` (converts a SymPy Matrix to a NumPy array by element-wise copying into an empty ndarray), and `symarray` (creates a NumPy object array of SymPy Symbols with index-based naming). |
| `sparse.py` | `SparseMatrix` (`MutableSparseMatrix`) backed by a dictionary-of-keys storage optimized for mostly-zero entries, with `_eval_inverse` (sparse matrix inversion that handles non-symmetric matrices by pre-multiplying by the transpose to create a symmetric product M^T*M, solves via CH or LDL decomposition, then applies a post-processing scaling correction using the first row for non-symmetric inputs), sparse-specific LIL/row-list access, row/column swapping, row_join/col_join concatenation (handles both sparse and dense operands by adapting internal representation), symbolic non-zero structure analysis (`row_structure_symbolic_cholesky` via elimination trees, `liupc`), Cholesky and LDL sparse decomposition — both exploit the pre-computed symbolic non-zero structure from `row_structure_symbolic_cholesky` to iterate only over structurally non-zero positions (`_LDL_sparse` decomposes a symmetric matrix into unit lower-triangular L and diagonal D factors using this pre-determined sparsity pattern; `_cholesky_sparse` similarly produces L*L^T), both detect non-positive-definite inputs post-factorization by checking for NaN/infinity in computed L and D matrices rather than pre-checking definiteness; sparse triangular solvers (`_lower_triangular_solve` using forward substitution, `_upper_triangular_solve` using backward substitution that reverses each row's stored column entries to ensure right-to-left processing order) exploiting sparsity of the dictionary-of-keys storage, `_diagonal_solve`, and solve pipelines (`_LDL_solve` chains L forward-solve → D diagonal-solve → L^T back-solve; `_cholesky_solve` chains L forward-solve → L^T back-solve), and applyfunc. |
| `immutable.py` | `ImmutableDenseMatrix` and `ImmutableSparseMatrix` — hashable, read-only matrix variants that can be used as keys and within SymPy expressions. |
| `normalforms.py` | Smith Normal Form computation (`smith_normal_form`) and abelian invariant factors (`invariant_factors`) for matrices over a principal ideal domain. |
| `densearith.py` | Deprecated list-of-lists (nested Python lists, not Matrix objects) dense arithmetic helpers: `add`, `sub`, `mulmatmat` (matrix-matrix multiplication that first transposes the second operand from row-lists to column-lists via `zip`, then delegates to `mulrowcol`), `mulrowcol` (computes inner product of a row vector and a column vector — notably uses a flat-list representation for the column instead of the standard nested single-element-list format, and initializes the summation accumulator from `K.zero` of the algebraic domain), `mulmatscaler`, `mulrowscaler`, `negate`/`negaterow`. |
| `densesolve.py` | **Deprecated** list-of-lists (nested Python lists, not Matrix objects) dense solvers — standalone functions operating on raw nested-list coefficient arrays with a domain parameter K (not DenseMatrix methods). Includes LU decomposition (`LU`), `lower_triangle`/`upper_triangle` factor extraction (which call `LU` with a `reverse` flag), row echelon, RREF, `LU_solve` (generates intermediate symbolic placeholder variables `y0, y1, ...` via `symbols('y:%i' % nrow)` to bridge forward and backward substitution phases), `cholesky` decomposition (computes L and conjugate-transpose using `isqrt` for diagonal entries — only works for perfect-square values), `LDL` decomposition, `cholesky_solve` (decomposes into L and L* via `cholesky`, then generates intermediate symbolic variables `y0, y1, ...` using `symbols()` and solves via sequential forward/backward substitution on nested lists), `forward_substitution` (iterates rows top-to-bottom, accumulating contributions from previously solved unknowns and dividing by the diagonal to resolve each variable in turn), `backward_substitution` (iterates rows bottom-to-top). |
| `densetools.py` | **Deprecated** list-of-lists (nested Python lists, not Matrix objects) dense utilities: trace, transpose, conjugate, `conjugate_transpose` (operates on raw nested lists only, not symbolic expressions — for symbolic Hermitian adjoint see `expressions/adjoint.py`), eye construction, row operations (rowadd, rowmul), column extraction, and augmentation. |
| `sparsetools.py` | Conversion between dictionary-of-keys (DOK) and Compressed Sparse Row (CSR) formats (`_doktocsr`, `_csrtodok`). |
| `benchmarks/bench_matrix.py` | Micro-benchmarks for `Matrix.__getitem__` and `zeros` construction. |
| `expressions/__init__.py` | Package init for the matrix-expressions sub-package; re-exports all symbolic matrix expression classes. |
| `expressions/matexpr.py` | `MatrixExpr` base class for symbolic matrix expressions, plus `MatrixSymbol`, `Identity`, `ZeroMatrix`, `MatrixElement`. Implements arithmetic operator dispatch (`__pow__` with special-case handling for exponents 0, 1, -1 and non-square check), `as_explicit` conversion to dense ImmutableMatrix, `as_mutable`, and generic expression infrastructure (shape, transpose, inverse, indexing). `ZeroMatrix` (the additive identity) overrides `__pow__` directly with its own edge-case logic: raises `ValueError("Matrix det == 0; not invertible.")` for negative exponents, raises `ShapeError` for non-square matrices with exponent ≠ 1, returns `Identity` for exponent 0, and returns self for positive exponents. |
| `expressions/matmul.py` | `MatMul` — symbolic product of matrix expressions with canonicalization rules (flatten, combine scalars, identity removal, zero detection), simplification rules for adjacent matrix-inverse pairs (`xxinv` detects X * X.I patterns and replaces with Identity, catching ValueError when a matrix is not invertible and silently skipping), trace evaluation (delegates when scalar coefficient exists, raises NotImplementedError otherwise), determinant, and inverse evaluation (`_eval_inverse` reverses factor order and inverts each, but catches ShapeError from incompatible dimensions and falls back to wrapping in an `Inverse` object). |
| `expressions/matadd.py` | `MatAdd` — symbolic sum of matrix expressions with canonicalization rules (merge, flatten, sort, zero removal). |
| `expressions/matpow.py` | `MatPow` — unevaluated symbolic matrix power node in expression trees (created after `MatrixExpr.__pow__` dispatches); `doit` evaluates only for concrete integer exponents. Note: `ZeroMatrix` and `Identity` have their own `__pow__` methods in `matexpr.py` that handle power operations directly before `MatPow` is ever created, so `MatPow.doit` only handles cases that bypass those class-level overrides. Does not contain Jordan form or decomposition-based exponentiation logic. |
| `expressions/inverse.py` | `Inverse` — symbolic multiplicative inverse of a matrix expression (subclass of `MatPow` with `exp = -1`). Also contains `refine_Inverse`, a refinement handler that simplifies the inverse under assumption predicates: returns transpose for orthogonal matrices, conjugate for unitary matrices, and raises ValueError for singular matrices. |
| `expressions/transpose.py` | `Transpose` — symbolic transpose of a matrix expression, with `doit` evaluation and canonicalization rules. |
| `expressions/adjoint.py` | `Adjoint` — unevaluated symbolic node representing the Hermitian adjoint (conjugate transpose) of a matrix expression; element access via `_entry(i, j)` returns `conjugate(arg._entry(j, i))` (swaps indices and conjugates), shape is reversed from the argument's shape; does not perform concrete hermiticity checks (see `matrices.py` for `is_hermitian`). |
| `expressions/trace.py` | `Trace` — symbolic matrix trace expression with rewrite-as-Sum support and a convenience `trace()` function. |
| `expressions/determinant.py` | `Determinant` — unevaluated symbolic node for matrix determinant in expression trees; does not contain concrete numerical determinant algorithms (see `matrices.py` for Bareis/Berkowitz/LU computation and 0×0 edge cases). |
| `expressions/slice.py` | `MatrixSlice` — unevaluated symbolic node for slicing a matrix expression by row/column ranges in expression trees; does not convert index keys to bounds (see `matrices.py` `key2bounds` for concrete index/slice-to-boundary conversion). |
| `expressions/blockmatrix.py` | `BlockMatrix` and `BlockDiagMatrix` — unevaluated symbolic block-structured matrix expression nodes (not concrete constructors — see `dense.py` `diag` for concrete block-diagonal construction from scalars/lists/matrices) with `block_collapse` and simplification rules: `bc_matmul` handles pairwise matrix multiplication where if only one of two adjacent factors is a BlockMatrix it wraps the non-block factor in a 1×1 BlockMatrix before delegating to `_blockmul`; `bc_matadd` for block addition; `bc_dist` for scalar distribution into blocks; `bc_transpose`; `bc_inverse` orchestrates block matrix inversion by first trying `blockinverse_1x1` and then falling back to `blockinverse_2x2` after restructuring via `reblock_2x2`; `blockinverse_2x2` computes the symbolic inverse of a 2×2 partitioned (block) matrix using the Schur complement formula (from The Matrix Cookbook Section 9.1.3), producing a BlockMatrix result with entries involving terms like (A - B*D.I*C).I; `reblock_2x2` restructures a BlockMatrix with more than 2×2 blocks into a 2×2 block-of-blocks form to enable the Schur complement inversion; `blockcut`, trace, and determinant rules. |
| `expressions/funcmatrix.py` | `FunctionMatrix` — a matrix expression whose entries are defined by a user-supplied Lambda function of (i, j) indices; only handles construction and validation, not conversion of other expression types. |
| `expressions/diagonal.py` | `DiagonalMatrix` and `DiagonalOf` — symbolic wrappers that treat a matrix as diagonal or extract its diagonal, using Kronecker deltas for element access. |
| `expressions/hadamard.py` | `HadamardProduct` and `hadamard_product()` — unevaluated symbolic node for elementwise (Hadamard) product in expression trees; does not compute concrete elementwise products (see `dense.py` `matrix_multiply_elementwise` for actual computation and ShapeError on mismatch). |
| `expressions/dotproduct.py` | `DotProduct` — symbolic dot product of two vector matrices, evaluated by delegating to MatMul with appropriate transposes. |
| `expressions/fourier.py` | `DFT` and `IDFT` — symbolic Discrete Fourier Transform and its inverse as matrix expressions. |
| `expressions/factorizations.py` | Symbolic matrix factorization placeholder classes (LU, Cholesky, QR, SVD, Eigen) — abstract type stubs with assumption predicates only, no actual computation or algorithm logic. |
