| `expressions/transpose.py` | `Transpose` — symbolic transpose of a matrix expression. `doit` attempts to call the argument's `_eval_transpose()` method and returns an unevaluated `Transpose` wrapper when the result is None or when the argument lacks that method entirely (catches `AttributeError`), serving as the fallback path for non-standard expression types that don't implement transpose evaluation. | `expressions/factorizations.py` | Symbolic matrix factorization component classes and helper functions for the assumption-query mechanism. Each component class is a `Factorization` subclass of `MatrixExpr` that carries a `predicates` tuple of `Q.*` assumptions automatically associated with each component for symbolic reasoning. LU components: `LofLU` (predicates: `Q.lower_triangular`) and `UofLU` (predicates: `Q.upper_triangular`). Cholesky components: `LofCholesky` inherits from `LofLU` (not directly from `Factorization`) and `UofCholesky` inherits from `UofLU` — both are `pass` classes that define no properties of their own, instead inheriting their triangularity predicates from the LU parent classes; there is no module-level `cholesky()` helper function, unlike the other decompositions.
