# sympy/matrices — Catalog

> Part of [SymPy](../catalog.md). Symbolic and numeric matrix algebra: dense, sparse, immutable, and block matrices; eigenvalues, decompositions.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package init that re-exports all public matrix classes (Matrix, SparseMatrix, ImmutableMatrix) and matrix expression types. |
| `common.py` | Base classes and shared infrastructure for all matrix types, including `MatrixRequired`, `MatrixShaping`, `MatrixProperties`, `MatrixOperations`, `MatrixArithmetic`, `MatrixSpecial`, error classes, and the `MatrixCommon` composite class. |
| `matrices.py` | Core `MatrixBase` class providing: matrix property checks (`is_hermitian`, `is_upper`, `is_lower`, `is_diagonal`, `is_symmetric`, etc. using fuzzy three-valued logic), `__pow__` exponentiation (integer exponents via binary exponentiation, negative exponents via inverse, non-integer symbolic/float exponents via Jordan normal form decomposition using binomial-coefficient power formulas on Jordan cells), inverse computation algorithms (`inverse_GE` via Gaussian elimination with augmented identity, `inverse_LU`, `inverse_ADJ`), Moore-Penrose pseudoinverse (`pinv`) that computes the generalized inverse via `(A^H A).inv() * A^H` or `A^H * (A A^H).inv()` — catches `ValueError` from inner `inv()` on rank-deficient matrices and re-raises as `NotImplementedError`, matrix exponential (`exp`) via Jordan canonical form decomposition — decomposes into Jordan blocks, computes exponential per block: 1×1 scalar blocks return `exp(eigenvalue)` directly while larger blocks split into diagonal + nilpotent parts using truncated Taylor series, LU decomposition variants (`LUdecomposition`, `LUdecomposition_Simple`, `LUdecompositionFF` — the fraction-free variant returns P, L, D, U such that PA = L D⁻¹ U, raises `ValueError("Matrix is not full rank")` when a zero diagonal pivot has no nonzero element below it for row swapping), determinant computation (Berkowitz, LU, Bareiss — the dispatcher `det` returns `S.One` for empty/zero-dimensional matrices as the base case before delegating to the chosen algorithm; `det_bareis` implements fraction-free Gaussian elimination with special-cased 1×1/2×2/3×3 formulas), the full `berkowitz` algorithm implementation (division-free characteristic polynomial computation with edge cases: empty/zero-dimensional matrix returns `((1,),)` before square-matrix validation, non-square raises `NonSquareMatrixError`), cofactor/minor computation (`cofactorMatrix`, `minorEntry`, `minorMatrix`), row/column insertion methods (`row_insert`, `col_insert` — insert rows or columns at a given position with negative-index wrapping and boundary clamping: negative positions are wrapped by adding the dimension size, and if still negative after wrapping, clamped to 0; positions beyond the dimension are clamped to the maximum; null/empty matrices return the inserted matrix directly; `col_insert` at pos=0 delegates to `row_join`), row reduction (RREF), subspace methods (nullspace, columnspace), eigenvalue/eigenvector routines, `pinv_solve` (least-squares via pseudoinverse), and calculus operations (diff, integrate, limit). Note: this is for concrete numeric matrices; for symbolic (unevaluated) matrix power expressions, see `expressions/matpow.py`. For symbolic determinant expressions, see `expressions/determinant.py`. For symbolic factorization placeholders (not concrete algorithms), see `expressions/factorizations.py`. See `dense.py` for concrete matrix constructors and mutable element-assignment methods, and `expressions/` for symbolic matrix expressions. |
| `dense.py` | `DenseMatrix` and `MutableDenseMatrix` (aliased as `Matrix`) implementations. `DenseMatrix` provides element-wise symbolic equivalence via `equals` (three-valued: True/False/None — short-circuits on False but accumulates undecided results), structural `__eq__`/`__ne__`, and private decomposition helpers (`_cholesky`, `_LDLdecomposition`, `_lower_triangular_solve`, `_upper_triangular_solve`). `MutableDenseMatrix` adds in-place mutation methods: `copyin_matrix` (copy a matrix into a sub-region with shape validation), `copyin_list` (copy from an iterable into a sub-region — raises `TypeError` if value is not an ordered iterable, e.g. a plain integer), `zip_row_op`, `row_op`, `col_op` for in-place row/column operations. Also contains `_force_mutable`, a coercion utility that converts various types to mutable matrices — notably handles objects supporting the numpy array protocol (`__array__`), where zero-dimensional (scalar-like) arrays are sympified rather than wrapped in a Matrix. Top-level concrete constructor helpers: `eye`, `zeros`, `ones`, `diag` (builds a concrete block-diagonal matrix from scalars, sub-matrices, or plain Python lists — lists/sequences are detected via `is_sequence` and auto-coerced to Matrix objects before placement on the diagonal, so e.g. `[1,2,3]` becomes a column vector and `[[1,2,3]]` becomes a row vector; this is the concrete constructor, not to be confused with `expressions/diagonal.py` or `expressions/blockmatrix.py::BlockDiagMatrix` which are symbolic/unevaluated), `randMatrix`, rotation matrices, `GramSchmidt`, `wronskian`, `hessian`, and `casoratian`. Note: `DenseMatrix._eval_inverse` dispatches to the actual inverse algorithms (`inverse_GE`, `inverse_LU`, `inverse_ADJ`) defined in `matrices.py`. |
| `sparse.py` | `SparseMatrix` (`MutableSparseMatrix`) backed by a dictionary-of-keys (`_smat`) storage (memory-efficient for matrices with many zero entries), with sparse-specific LIL/row-list access, Cholesky and LDL decomposition (sparse-specific implementations that validate positive-definiteness *after* computing factors by checking for `nan`/`oo` in the result matrices, raising `ValueError` if found — distinct from the dense versions in `matrices.py`), `is_Identity` property (checks square, diagonal entries == 1, then verifies no off-diagonal nonzeros by comparing `len(self._smat)` to `self.rows` — exploits the sparse dict storing only nonzero entries), `solve_least_squares` (computes the minimum-norm least-squares solution for overdetermined systems using the normal equations identity `(A^T A)^{-1} A^T b` in a single expression, with configurable inversion method — distinct from `matrices.py::MatrixBase.pinv_solve` which uses the Moore-Penrose pseudoinverse approach), `solve` (delegates to inversion methods), and `applyfunc`. |
| `immutable.py` | `ImmutableDenseMatrix` and `ImmutableSparseMatrix` — hashable, read-only matrix variants that can be used as keys and within SymPy expressions. |
| `normalforms.py` | Smith Normal Form computation (`smith_normal_form`) and abelian invariant factors (`invariant_factors`) for matrices over a principal ideal domain. |
| `densearith.py` | Deprecated list-of-lists dense arithmetic helpers (`add`, `sub`, `mulmatmat`, `mulmatscaler`, `negatemat`). |
| `densesolve.py` | Deprecated list-of-lists dense solvers operating on raw nested Python lists (not Matrix objects): row echelon, RREF, `LU_solve`, `cholesky_solve` (decomposes via Cholesky then chains forward and backward substitution — creates intermediate symbolic variable vector `y`, relies on `forward_substitution` mutating `y` in-place, then passes the mutated `y` as constants to `backward_substitution`), `forward_substitution` (solves a lower-triangular system by in-place mutation of the variable vector — notably initializes a `result = []` list that is dead code/never populated; the actual solution overwrites `variable[i][0]` in-place and returns the mutated variable), `backward_substitution` (same in-place mutation pattern for upper-triangular systems). These are raw list-of-lists routines distinct from `DenseMatrix._lower_triangular_solve`/`_upper_triangular_solve` in `dense.py` which operate on proper Matrix objects. |
| `densetools.py` | Deprecated list-of-lists dense utilities operating on nested Python lists (not Matrix objects): `eye` (identity construction), `row` (row extraction by index — trivial list lookup), `col` (column extraction — transposes the entire nested-list structure via `zip(*)` then wraps the target column, noted as "currently very expensive"), `trace`, `transpose`, `conjugate`/`conjugate_transpose`, elementary row operations (`rowswap`, `rowmul`, `rowadd`), `isHermitian` check, and `augment`. These are raw list-of-lists routines distinct from the `DenseMatrix`/`MutableDenseMatrix` methods in `dense.py` which operate on proper Matrix objects. |
| `sparsetools.py` | Conversion between dictionary-of-keys (DOK) and Compressed Sparse Row (CSR) formats (`_doktocsr`, `_csrtodok`). |
| `benchmarks/bench_matrix.py` | Micro-benchmarks for `Matrix.__getitem__` and `zeros` construction. |
| `expressions/__init__.py` | Package init for the matrix-expressions sub-package; re-exports all symbolic matrix expression classes. |
| `expressions/matexpr.py` | `MatrixExpr` base class for symbolic matrix expressions, plus `MatrixSymbol`, `Identity`, `ZeroMatrix`, `MatrixElement`, and generic expression infrastructure (shape, transpose, inverse, indexing). `ZeroMatrix` and `Identity` are special symbolic matrix types with their own arithmetic methods — notably `ZeroMatrix.__pow__` handles edge cases: non-square check, zero exponent returns `Identity`, negative exponent raises `ValueError` (det==0, not invertible), positive returns self. These power methods are defined directly on the special matrix classes here, not in `matpow.py`. |
| `expressions/matmul.py` | `MatMul` — symbolic product of matrix expressions with canonicalization rules (flatten, combine scalars, identity removal, zero detection, inverse cancellation via `xxinv` which iterates consecutive matrix pairs checking `X == Y.inverse()` and catches `ValueError` when a matrix is non-invertible — gracefully skipping that pair rather than failing, and square-factor grouping). Also contains helper rule functions (`validate` for shape checks, `newmul`, `any_zeros`, `merge_explicit` for merging consecutive explicit MatrixBase arguments, `remove_ids` for stripping Identity matrices) and `refine_MatMul` for simplifying products under orthogonal/unitary assumptions. Note: this handles simplification of symbolic matrix product expressions; for concrete numeric inverse algorithms (Gaussian elimination, LU, adjugate) that raise `ValueError` on singular matrices, see `matrices.py`. |
| `expressions/matadd.py` | `MatAdd` — symbolic sum of matrix expressions with canonicalization rules (merge, flatten, sort, zero removal). |
| `expressions/matpow.py` | `MatPow` — symbolic (unevaluated) matrix power expression node in the expression tree, with `doit` evaluation for integer exponents. This represents the abstract expression `X**n`; for concrete numeric matrix exponentiation (binary exponentiation, Jordan form), see `matrices.py::MatrixBase.__pow__`. For power methods on special symbolic matrices (`ZeroMatrix`, `Identity`), see `expressions/matexpr.py`. |
| `expressions/inverse.py` | `Inverse` — symbolic (unevaluated) multiplicative inverse of a matrix expression (subclass of `MatPow` with `exp = -1`). This is an expression-tree node only; for concrete inverse algorithms (Gaussian elimination, LU, adjugate) see `matrices.py`, and for the Moore-Penrose pseudoinverse (generalized inverse with rank-deficiency error handling) see `matrices.py::MatrixBase.pinv`. |
| `expressions/transpose.py` | `Transpose` — symbolic transpose of a matrix expression, with `doit` evaluation and canonicalization rules. |
| `expressions/adjoint.py` | `Adjoint` — symbolic Hermitian adjoint (conjugate transpose) of a matrix expression. |
| `expressions/trace.py` | `Trace` — symbolic matrix trace expression with rewrite-as-Sum support and a convenience `trace()` function. |
| `expressions/determinant.py` | `Determinant` — symbolic (unevaluated) matrix determinant expression node, a convenience `det()` function, and assumption-based refinement. This represents the abstract expression `det(X)` in the expression tree; for concrete numeric determinant computation (Bareiss, Berkowitz, LU algorithms, empty-matrix edge cases), see `matrices.py::MatrixBase.det`. |
| `expressions/slice.py` | `MatrixSlice` — symbolic slicing of a matrix expression by row and column ranges. |
| `expressions/blockmatrix.py` | `BlockMatrix` and `BlockDiagMatrix` — symbolic (unevaluated) block-structured (partitioned) matrix expressions with `block_collapse` (the main simplification entry point for compound block-matrix algebra — applies exhaustive bottom-up rewriting with type-based dispatch: `MatAdd` → block addition, `MatMul` → block multiplication/distribution, `Transpose` → block transpose, `Inverse` → block inversion, `BlockMatrix` → unpacking/deblocking), `blockcut`, transpose, trace, determinant rules, and block-level inversion (`blockinverse` for 2×2 block partitions using Schur complements). These are structural block operations, not pairwise product simplification — for cancellation of adjacent inverse pairs (`X * X.I → I`) in matrix products, see `expressions/matmul.py::xxinv` instead. For concrete block-diagonal matrix construction from scalars/lists/sub-matrices, see `dense.py::diag` instead. |
| `expressions/funcmatrix.py` | `FunctionMatrix` — a matrix expression defined by a Lambda function applied to index pairs, enabling lazy evaluation. |
| `expressions/diagonal.py` | `DiagonalMatrix` and `DiagonalOf` — symbolic (unevaluated) wrappers that treat a matrix as diagonal or extract its diagonal, using Kronecker deltas for element access. For concrete diagonal matrix construction from values/lists, see `dense.py::diag` instead. |
| `expressions/hadamard.py` | `HadamardProduct` and `hadamard_product()` — symbolic elementwise (Hadamard) product of matrix expressions. |
| `expressions/dotproduct.py` | `DotProduct` — symbolic dot product of two vector matrices, evaluated by delegating to MatMul with appropriate transposes. |
| `expressions/fourier.py` | `DFT` and `IDFT` — symbolic Discrete Fourier Transform and its inverse as matrix expressions. |
| `expressions/factorizations.py` | Symbolic matrix factorization placeholders (LU, Cholesky, QR, SVD, Eigen) with associated assumption predicates. These are unevaluated expression-tree nodes only — they do not contain concrete factorization algorithms or error handling. For concrete LU decomposition (including fraction-free LU with pivot failure errors), see `matrices.py`. For concrete sparse Cholesky/LDL, see `sparse.py`. |
