# sympy/matrices — Catalog

> Part of [SymPy](../catalog.md). Symbolic and numeric matrix algebra: dense, sparse, immutable, and block matrices; eigenvalues, decompositions.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package init that re-exports all public matrix classes (Matrix, SparseMatrix, ImmutableMatrix) and matrix expression types. |
| `common.py` | Base classes and shared infrastructure for all matrix types, including `MatrixRequired`, `MatrixShaping`, `MatrixProperties`, `MatrixOperations`, `MatrixArithmetic`, `MatrixSpecial`, error classes, and the `MatrixCommon` composite class. |
| `matrices.py` | Core `MatrixBase` class with all concrete matrix operations on Matrix objects: indexing helpers (`key2bounds` converts mixed integer/slice keys into row/column boundary tuples with zero-dimension edge cases, `key2ij`), property predicates (`is_hermitian` using fuzzy three-valued logic for symbolic entries, `is_lower`, `is_upper`, `is_diagonal`, Hessenberg checks), arithmetic operators (`__pow__` raises a concrete dense matrix to a power — uses exponentiation-by-squaring for integers and Jordan normal form decomposition for non-integer symbolic/float exponents, exponentiating each Jordan cell with binomial coefficients; `__mul__`, `__add__`), determinant computation (dispatches to Bareis/Berkowitz/LU methods, returns 1 for empty 0×0 matrices before any elimination), row reduction (RREF), subspace methods (nullspace, columnspace), eigenvalue/eigenvector routines, diagonalizability testing, matrix decompositions (QRdecomposition using Gram-Schmidt with full-column-rank validation via RREF before factorization, LUdecomposition, LDLdecomposition, cholesky), pseudoinverse computation (`pinv` computes Moore-Penrose pseudoinverse — uses different paths for tall vs wide matrices, catches ValueError from inv() on rank-deficient matrices and raises NotImplementedError), linear system solvers operating on MatrixBase objects (pinv_solve, gauss_jordan_solve, cholesky_solve, LUsolve, LDLsolve, QRsolve), Jordan form, element extraction, element-level utilities (`atoms` collects irreducible sub-expressions from all entries defaulting to `Atom` type when no filter is given, `free_symbols`, `subs`, `xreplace`, `expand`), text-based sparsity visualization (`print_nonzero` prints a character grid showing locations of zero vs non-zero entries for quick visual inspection of matrix structure), and calculus operations (diff, integrate, limit). |
| `dense.py` | `DenseMatrix` and `MutableDenseMatrix` (aliased as `Matrix`) implementations with symbolic element-wise `equals` (three-valued: True/False/None for undecidable), inversion methods (GE, LU, ADJ), dense triangular solvers (`_lower_triangular_solve` using forward substitution raising TypeError on singular diagonal, `_upper_triangular_solve` using backward substitution raising ValueError on singular diagonal — note the inconsistent exception types), `_diagonal_solve`, `applyfunc`, `reshape`, mutable slice-assignment copy-in methods (`copyin_matrix` validates that the source matrix shape matches the target sub-region dimensions via `key2bounds` and raises ShapeError on mismatch before element-wise copy; `copyin_list` checks that the value is an ordered iterable and raises TypeError for non-iterables like plain integers, then delegates to `copyin_matrix`), plus top-level helpers: `matrix_multiply_elementwise` (concrete Hadamard/elementwise product that raises ShapeError on dimension mismatch), `eye`, `zeros`, `ones`, `diag`, `randMatrix`, rotation matrices, `GramSchmidt` (orthogonalizes a list of vectors, not a matrix factorization), `wronskian`, `hessian`, `casoratian`, and NumPy conversion utilities at module level: `list2numpy` (converts a Python list of SymPy expressions to a NumPy array), `matrix2numpy` (converts a SymPy Matrix to a NumPy array by element-wise copying into an empty ndarray), and `symarray` (creates a NumPy object array of SymPy Symbols with index-based naming). |
| `sparse.py` | `SparseMatrix` (`MutableSparseMatrix`) backed by a dictionary-of-keys storage optimized for mostly-zero entries, with sparse-specific LIL/row-list access, row/column swapping, row_join/col_join concatenation (handles both sparse and dense operands by adapting internal representation), Cholesky and LDL sparse decomposition (both detect non-positive-definite inputs post-factorization by checking for NaN/infinity in computed L and D matrices, rather than pre-checking definiteness), sparse triangular solvers (`_lower_triangular_solve`, `_upper_triangular_solve`) exploiting sparsity, `_diagonal_solve`, and solve pipelines (`_LDL_solve` chains L forward-solve → D diagonal-solve → L^T back-solve; `_cholesky_solve` chains L forward-solve → L^T back-solve), and applyfunc. |
| `immutable.py` | `ImmutableDenseMatrix` and `ImmutableSparseMatrix` — hashable, read-only matrix variants that can be used as keys and within SymPy expressions. |
| `normalforms.py` | Smith Normal Form computation (`smith_normal_form`) and abelian invariant factors (`invariant_factors`) for matrices over a principal ideal domain. |
| `densearith.py` | Deprecated list-of-lists dense arithmetic helpers (`add`, `sub`, `mulmatmat`, `mulmatscaler`, `negatemat`). |
| `densesolve.py` | **Deprecated** list-of-lists (nested Python lists, not Matrix objects) dense solvers operating on raw nested-list coefficient arrays with a domain parameter K; includes LU decomposition (`LU`), `lower_triangle`/`upper_triangle` factor extraction (which call `LU` with a `reverse` flag), row echelon, RREF, `LU_solve`, `cholesky` decomposition (computes L and conjugate-transpose using `isqrt` for diagonal entries — only works for perfect-square values), `LDL` decomposition, `cholesky_solve` (factors then forward/backward substitutes on nested lists), `forward_substitution`, `backward_substitution`. |
| `densetools.py` | Deprecated list-of-lists dense utilities: trace, transpose, conjugate, eye construction, row operations, and augmentation. |
| `sparsetools.py` | Conversion between dictionary-of-keys (DOK) and Compressed Sparse Row (CSR) formats (`_doktocsr`, `_csrtodok`). |
| `benchmarks/bench_matrix.py` | Micro-benchmarks for `Matrix.__getitem__` and `zeros` construction. |
| `expressions/__init__.py` | Package init for the matrix-expressions sub-package; re-exports all symbolic matrix expression classes. |
| `expressions/matexpr.py` | `MatrixExpr` base class for symbolic matrix expressions, plus `MatrixSymbol`, `Identity`, `ZeroMatrix`, `MatrixElement`. Implements arithmetic operator dispatch (`__pow__` with special-case handling for exponents 0, 1, -1 and non-square check), `as_explicit` conversion to dense ImmutableMatrix, `as_mutable`, and generic expression infrastructure (shape, transpose, inverse, indexing). `ZeroMatrix` (the additive identity) overrides `__pow__` directly with its own edge-case logic: raises `ValueError("Matrix det == 0; not invertible.")` for negative exponents, raises `ShapeError` for non-square matrices with exponent ≠ 1, returns `Identity` for exponent 0, and returns self for positive exponents. |
| `expressions/matmul.py` | `MatMul` — symbolic product of matrix expressions with canonicalization rules (flatten, combine scalars, identity removal, zero detection), trace evaluation (delegates when scalar coefficient exists, raises NotImplementedError otherwise), determinant, and inverse evaluation (`_eval_inverse` reverses factor order and inverts each, but catches ShapeError from incompatible dimensions and falls back to wrapping in an `Inverse` object). |
| `expressions/matadd.py` | `MatAdd` — symbolic sum of matrix expressions with canonicalization rules (merge, flatten, sort, zero removal). |
| `expressions/matpow.py` | `MatPow` — unevaluated symbolic matrix power node in expression trees (created after `MatrixExpr.__pow__` dispatches); `doit` evaluates only for concrete integer exponents. Note: `ZeroMatrix` and `Identity` have their own `__pow__` methods in `matexpr.py` that handle power operations directly before `MatPow` is ever created, so `MatPow.doit` only handles cases that bypass those class-level overrides. Does not contain Jordan form or decomposition-based exponentiation logic. |
| `expressions/inverse.py` | `Inverse` — symbolic multiplicative inverse of a matrix expression (subclass of `MatPow` with `exp = -1`). Also contains `refine_Inverse`, a refinement handler that simplifies the inverse under assumption predicates: returns transpose for orthogonal matrices, conjugate for unitary matrices, and raises ValueError for singular matrices. |
| `expressions/transpose.py` | `Transpose` — symbolic transpose of a matrix expression, with `doit` evaluation and canonicalization rules. |
| `expressions/adjoint.py` | `Adjoint` — unevaluated symbolic node representing the Hermitian adjoint (conjugate transpose) of a matrix expression; does not perform concrete hermiticity checks (see `matrices.py` for `is_hermitian`). |
| `expressions/trace.py` | `Trace` — symbolic matrix trace expression with rewrite-as-Sum support and a convenience `trace()` function. |
| `expressions/determinant.py` | `Determinant` — unevaluated symbolic node for matrix determinant in expression trees; does not contain concrete numerical determinant algorithms (see `matrices.py` for Bareis/Berkowitz/LU computation and 0×0 edge cases). |
| `expressions/slice.py` | `MatrixSlice` — unevaluated symbolic node for slicing a matrix expression by row/column ranges in expression trees; does not convert index keys to bounds (see `matrices.py` `key2bounds` for concrete index/slice-to-boundary conversion). |
| `expressions/blockmatrix.py` | `BlockMatrix` and `BlockDiagMatrix` — symbolic block-structured matrices with `block_collapse`, `blockcut`, transpose, trace, and determinant rules. |
| `expressions/funcmatrix.py` | `FunctionMatrix` — a matrix expression whose entries are defined by a user-supplied Lambda function of (i, j) indices; only handles construction and validation, not conversion of other expression types. |
| `expressions/diagonal.py` | `DiagonalMatrix` and `DiagonalOf` — symbolic wrappers that treat a matrix as diagonal or extract its diagonal, using Kronecker deltas for element access. |
| `expressions/hadamard.py` | `HadamardProduct` and `hadamard_product()` — unevaluated symbolic node for elementwise (Hadamard) product in expression trees; does not compute concrete elementwise products (see `dense.py` `matrix_multiply_elementwise` for actual computation and ShapeError on mismatch). |
| `expressions/dotproduct.py` | `DotProduct` — symbolic dot product of two vector matrices, evaluated by delegating to MatMul with appropriate transposes. |
| `expressions/fourier.py` | `DFT` and `IDFT` — symbolic Discrete Fourier Transform and its inverse as matrix expressions. |
| `expressions/factorizations.py` | Symbolic matrix factorization placeholder classes (LU, Cholesky, QR, SVD, Eigen) — abstract type stubs with assumption predicates only, no actual computation or algorithm logic. |
