| `expressions/funcmatrix.py` | `FunctionMatrix` — a matrix expression whose entries are defined by a user-supplied Lambda function of (i, j) indices; element access evaluates the Lambda at the given indices; provides its own `_eval_trace` that delegates to `Trace._eval_rewrite_as_Sum` and calls `.doit()` to produce a symbolic summation rather than iterating diagonal elements directly. |
| `expressions/diagonal.py` | `DiagonalMatrix` and `DiagonalOf` — symbolic matrix expression wrappers for diagonal promotion and extraction. `DiagonalMatrix` promotes a column vector into a square diagonal matrix expression whose shape is (n, n) derived from the vector's row count; its `_entry(i, j)` returns `S.Zero` for off-diagonal elements (i != j) and indexes into the underlying column vector at `arg[i, 0]` for diagonal elements. `DiagonalOf` extracts the diagonal of a square matrix into a column vector expression with shape (n, 1); its `_entry(i, j)` returns `arg[i, i]`. |
| `expressions/hadamard.py` | `HadamardProduct` and `hadamard_product()` — unevaluated symbolic node for elementwise (Hadamard) product in expression trees; does not compute concrete elementwise products (see `dense.py` `matrix_multiply_elementwise` for actual computation and ShapeError on mismatch). |
| `expressions/dotproduct.py` | `DotProduct` — symbolic dot product of two 1×n or n×1 vector matrices; `doit` handles four orientation cases (both row, both column, mixed) by applying the necessary transpositions before multiplying via MatMul and extracting the scalar element; constructor validates both arguments are vectors and checks length compatibility via set comparison of shape tuples. |
| `expressions/fourier.py` | `DFT` and `IDFT` — symbolic Discrete Fourier Transform and its inverse as matrix expressions. |
| `expressions/factorizations.py` | Symbolic matrix factorization component classes and helper functions for the assumption-query mechanism. Each component class (e.g., `UofSVD`, `SofSVD`, `VofSVD`, `QofQR`, `RofQR`, `LofLU`, `UofLU`, `EigenValues`, `EigenVectors`) is a `Factorization` subclass of `MatrixExpr` that carries a `predicates` tuple of `Q.*` assumptions (e.g., `Q.orthogonal`, `Q.diagonal`, `Q.upper_triangular`, `Q.lower_triangular`) automatically associated with each component for symbolic reasoning. Module-level helper functions `svd(expr)`, `lu(expr)`, `qr(expr)`, `eig(expr)` return tuples of these typed symbolic components — e.g., `svd` returns `(UofSVD, SofSVD, VofSVD)` representing the three SVD factors with two orthogonal and one diagonal predicate. No actual numerical decomposition algorithms — purely symbolic type stubs for assumption propagation. |
