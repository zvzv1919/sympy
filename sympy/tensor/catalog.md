# sympy/tensor — Catalog

> Part of [SymPy](../catalog.md). Tensor algebra: indexed objects, index conventions, and multi-dimensional array operations.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package initializer; exports `IndexedBase`, `Idx`, `Indexed`, index-method helpers, and all N-dim array classes and operations. |
| `indexed.py` | Defines `IndexedBase`, `Indexed`, and `Idx` for representing simple component-level indexed objects (e.g. matrix elements `M[i, j]`) with optional shape and range information. `IndexedBase.__getitem__` is the subscript entry point for symbolic array stems — it performs rank validation against the stored shape: if the `IndexedBase` was created with a shape (e.g. `IndexedBase('A', shape=(m,n))`) and the number of subscript indices doesn't match, it raises `IndexException("Rank mismatch.")`; for a single (non-sequence) index, it checks that the shape length is exactly 1. `Indexed.__new__` validates the base argument (strings/Symbols are auto-wrapped into `IndexedBase`; otherwise checks for `__getitem__`, raising `TypeError` if absent). Note: `Indexed` represents component-level subscript access like `A[i,j]`, not a tensor head. `Indexed.shape` returns the dimensions of each index: if the `IndexedBase` defines a shape, that shape is returned directly; otherwise it falls back to inferring dimensions from the index bounds (`upper - lower + 1` for each `Idx`), and raises `IndexException` if indices lack range attributes (`AttributeError` path) or have `None`/undefined range bounds (`TypeError` path). `Indexed._eval_derivative` handles symbolic differentiation of one indexed element w.r.t. another: when both share the same base, it checks that the number of subscript indices matches (raises `IndexException` if they differ) and returns a product of `KroneckerDelta` over paired indices; otherwise returns zero. `Idx` is a plain integer subscript for array element access with optional lower/upper bounds; its `__new__` constructor short-circuits when the label is a numeric integer (e.g. `Idx(5)` returns the plain `Integer(5)`, not an `Idx` instance), and raises `TypeError` for non-integer labels. It does not support abstract tensor index notation, covariant/contravariant distinction, auto-generated dummy names, or tensor symmetry. |
| `index_methods.py` | Provides functions for purely symbolic/structural analysis of indices in `Indexed`-based (not abstract tensor) expressions — no numeric computation or array data evaluation. `_remove_repeated(inds)` is the core deduplication helper: it counts occurrences of each index via a dict counter, filters out ALL indices appearing more than once (regardless of multiplicity — 2, 3, or more times are treated identically), and returns (set of free indices, tuple of repeated indices); it does not validate Einstein convention or distinguish pair-wise contraction from higher multiplicity. `get_indices` dispatches to expression-type-specific handlers (`_get_indices_Mul`, `_get_indices_Add`, `_get_indices_Pow`) to determine free/outer indices; for generic `Function` expressions (not Add/Mul/Pow), it unions indices from all arguments but does NOT treat repeated indices across arguments as summation/contraction — this is a deliberate ufunc-like design choice. `_get_indices_Add` enforces that all terms in a sum share the same outer indices, but allows scalar terms (no indices) to broadcast — scalars are filtered out before the consistency check; if all terms are scalars it returns an empty set. `get_contraction_structure` returns a nested dictionary describing the hierarchical summation structure of an expression — keys are tuples of repeated (dummy) indices mapping to sets of terms sharing those summations, `None` keys collect non-contracted terms, and nested contractions within products or powers are captured recursively. |
| `tensor.py` | Implements tensors with abstract index notation (Penrose formalism), separate from the `Indexed`/`IndexedBase` system. Key index classes: `TensorIndexType` (defines a type of tensor index, e.g. Lorentz); `TensorIndex` (represents a single tensor index — accepts a name string, Symbol, or `True` to auto-generate a dummy name like `_i0`; tracks covariant/contravariant via `is_up`); `tensor_indices` (helper that creates `TensorIndex` objects from a comma-separated string of names — returns a single `TensorIndex` when only one name is given, or a list for multiple names). Core expression classes: `TIDS` (internal data structure pairing contracted indices); `TensExpr` (abstract base class for symbolic tensor expressions — provides `get_matrix()` which converts stored ndarray component data into a SymPy `Matrix`, restricted to expressions with at most 2 indices, raising `NotImplementedError` for higher rank); `TensorHead` (the 'head' of an abstract tensor expression — its `__new__` constructor accepts only a string or `Symbol` as the name identifier, raising `ValueError("invalid name")` for any other type; carries index types, symmetry, rank, and commutativity; when called with fewer indices than its declared slot count, `_check_auto_matrix_indices_in_call` auto-fills the missing trailing slots with implicit summation labels — the first missing slot of a given index type gets `auto_left`, the second gets `-auto_right`, enabling matrix-like multiplication behavior; raises `ValueError` if more than 2 slots are missing or if the tensor has no matrix behavior enabled); `TensMul`/`TensAdd` (products and sums); `TensAdd` implements arithmetic operators including `__div__`/`__rdiv__` that enforce division restrictions — scalar division is distributed across summands, but dividing by a `TensExpr` raises `ValueError('cannot divide by a tensor')`, and reverse division always raises the same error. Tensor expression classes provide an `equals` method for structural equality: it canonicalizes both sides via `canon_bp()` and compares tuples of (coefficient, components, sorted free indices, sorted dummy indices), with special-case handling for comparison to zero (checks `coeff == 0`) and plain scalars (asserts no components, compares against `S.One`). Also covers symmetries (`TensorSymmetry`), canonicalization via Butler-Portugal, Einstein summation, and index replacement. Includes `_TensorDataLazyEvaluator`, the lazy evaluation system for numeric component data associated with abstract tensors — its `__setitem__` validates that assigned ndarray dimensions match the declared `TensorIndexType.dim` (raises `ValueError("wrong dimension of ndarray")`), which is unrelated to inferring array shape from nested iterables (see `array/ndim_array.py` for that); its `data_product_tensors` method iteratively multiplies ndarray data for multi-factor `TensMul` products using `reduce`, pairing each array with its expression, contracting matched indices at each step via `_contract_ndarray`, and its `_get` method handles `TensAdd` sums by transposing arrays to align free indices before adding. |
| `array/__init__.py` | Package initializer and primary documentation entry point for the N-dim array submodule. Contains the module-level docstring that serves as a comprehensive tutorial covering: array construction from nested lists; slicing and element access; element-wise differentiation (`.diff`); tensor products between arrays of different ranks; **tensor contraction as paired-index summation** — including computing the matrix trace by contracting both axes of a rank-2 array (`sum_k A[k,k]`), emulating matrix multiplication via tensor product followed by contraction of inner axes, and validating that contracted axis dimensions match; array derivatives (`derive_by_array`); and conversion to matrices/lists. Also exports dense/sparse and mutable/immutable array classes along with `tensorproduct`, `tensorcontraction`, `derive_by_array`, and `permutedims`. |
| `array/ndim_array.py` | Defines the `NDimArray` base class with common functionality for N-dimensional arrays such as element access, shape validation, arithmetic, and transpose. `_parse_index` converts a tuple of per-axis subscripts into a single flat storage offset using row-major (C-order) linearization, validating that the number of indices matches the rank and each index is within its axis bounds (raises `ValueError` otherwise); for a plain integer index it checks against the total element count. `_get_tuple_index` performs the inverse conversion from a flat integer offset back to a multi-dimensional index tuple. Handles parsing of creation inputs (flat lists with shape tuples, nested lists, Matrix instances) into internal flat storage via `_handle_ndarray_creation_inputs`. `_scan_iterable_shape` recursively infers the shape from a nested iterable (e.g. `[[1,2],[3,4]]`) and raises `ValueError("could not determine shape unambiguously")` if sub-lists have inconsistent lengths (jagged arrays like `[[1,2],[3,4,5]]`); this is the sole location for nested-iterable shape validation during array construction. Operates on concrete numeric arrays, not abstract indexed tensor expressions or subscript bound defaults (for those, see `indexed.py` and `tensor.py`). |
| `array/dense_ndim_array.py` | Implements `ImmutableDenseNDimArray` and `MutableDenseNDimArray`, which store all elements in a flat list (`_array`) for dense N-dimensional array representations. Provides `tomatrix()` which converts to a SymPy `Matrix` but enforces a rank-2 check (raises `ValueError` if `rank() != 2`), `reshape()` with total-size validation, a `zeros` factory, and slice-based `__getitem__`. The immutable variant subclasses `Basic`; the mutable variant allows item assignment. |
| `array/sparse_ndim_array.py` | Implements `ImmutableSparseNDimArray` and `MutableSparseNDimArray`, which store only non-zero elements via a dictionary-backed (`Dict`) sparse representation. Also provides `tomatrix()` (rank-2 enforced, converts to `SparseMatrix`) and slice-based `__getitem__`. |
| `array/arrayop.py` | Provides concrete N-dim array operations (not abstract tensor index notation). `tensorproduct(*args)` computes the outer (tensor) product of scalars or array-like objects — returns `S.One` when called with zero arguments, returns the arrayified single argument when called with one, and when exactly two arguments are given but at least one is a plain scalar (not an `NDimArray`), falls back to simple scalar multiplication `a*b` instead of constructing an array. `tensorcontraction(array, *contraction_axes)` contracts an array on specified axis pairs, with validation that raises `ValueError` for repeated dimension indices or mismatched axis dimensions. Also provides `derive_by_array` (elementwise differentiation) and `permutedims` (axis permutation). |
| `array/mutable_ndim_array.py` | Defines the `MutableNDimArray` base class that serves as the mixin for mutable N-dimensional arrays. |
