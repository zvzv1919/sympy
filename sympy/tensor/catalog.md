# sympy/tensor — Catalog

> Part of [SymPy](../catalog.md). Tensor algebra: indexed objects, index conventions, and multi-dimensional array operations.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package initializer; exports `IndexedBase`, `Idx`, `Indexed`, index-method helpers, and all N-dim array classes and operations. |
| `indexed.py` | Defines `IndexedBase`, `Indexed`, and `Idx` for representing simple component-level indexed objects (e.g. matrix elements `M[i, j]`) with optional shape and range information. `Idx` is a plain integer subscript for array element access with optional lower/upper bounds; its `__new__` constructor short-circuits when the label is a numeric integer (e.g. `Idx(5)` returns the plain `Integer(5)`, not an `Idx` instance), and raises `TypeError` for non-integer labels. It does not support abstract tensor index notation, covariant/contravariant distinction, auto-generated dummy names, or tensor symmetry. |
| `index_methods.py` | Provides functions for analyzing indices of `Indexed`-based (not abstract tensor) expressions: `get_indices` dispatches to expression-type-specific handlers (`_get_indices_Mul`, `_get_indices_Add`, `_get_indices_Pow`) to determine free/outer indices. `_get_indices_Add` enforces that all terms in a sum share the same outer indices, but allows scalar terms (no indices) to broadcast — scalars are filtered out before the consistency check; if all terms are scalars it returns an empty set. `get_contraction_structure` returns a nested dictionary describing the hierarchical summation structure of an expression — keys are tuples of repeated (dummy) indices mapping to sets of terms sharing those summations, `None` keys collect non-contracted terms, and nested contractions within products or powers are captured recursively. |
| `tensor.py` | Implements tensors with abstract index notation (Penrose formalism), separate from the `Indexed`/`IndexedBase` system. Key index classes: `TensorIndexType` (defines a type of tensor index, e.g. Lorentz); `TensorIndex` (represents a single tensor index — accepts a name string, Symbol, or `True` to auto-generate a dummy name like `_i0`; tracks covariant/contravariant via `is_up`); `tensor_indices` (helper that creates `TensorIndex` objects from a comma-separated string of names — returns a single `TensorIndex` when only one name is given, or a list for multiple names). Core expression classes: `TIDS` (internal data structure pairing contracted indices); `TensExpr` (abstract base class for symbolic tensor expressions — provides `get_matrix()` which converts stored ndarray component data into a SymPy `Matrix`, restricted to expressions with at most 2 indices, raising `NotImplementedError` for higher rank); `TensorHead` (the 'head' of a tensor expression — constructed with a name that must be a string or Symbol, validated in `__new__`; carries index types, symmetry, rank, and commutativity); `TensMul`/`TensAdd` (products and sums). Also covers symmetries (`TensorSymmetry`), canonicalization via Butler-Portugal, Einstein summation, and index replacement. |
| `array/__init__.py` | Package initializer and primary documentation entry point for the N-dim array submodule. Contains the module-level docstring that serves as a tutorial explaining array construction, slicing, element-wise differentiation (`.diff`), tensor products, index contraction (including divergence-like summation over matching indices), and conversion to matrices/lists. Also exports dense/sparse and mutable/immutable array classes along with `tensorproduct`, `tensorcontraction`, `derive_by_array`, and `permutedims`. |
| `array/ndim_array.py` | Defines the `NDimArray` base class with common functionality for N-dimensional arrays such as element access, shape validation, arithmetic, and transpose. Handles parsing of creation inputs (flat lists with shape tuples, nested lists, Matrix instances) into internal flat storage via `_handle_ndarray_creation_inputs`. `_scan_iterable_shape` recursively infers the shape from a nested iterable and raises `ValueError("could not determine shape unambiguously")` if sub-lists have inconsistent lengths (jagged arrays). Operates on concrete numeric arrays, not abstract indexed tensor expressions or subscript bound defaults (for those, see `indexed.py` and `tensor.py`). |
| `array/dense_ndim_array.py` | Implements `ImmutableDenseNDimArray` and `MutableDenseNDimArray`, which store all elements in a flat list for dense N-dimensional array representations. |
| `array/sparse_ndim_array.py` | Implements `ImmutableSparseNDimArray` and `MutableSparseNDimArray`, which store only non-zero elements via a dictionary-backed sparse representation. |
| `array/arrayop.py` | Provides array-level operations: `tensorproduct`, `tensorcontraction`, `derive_by_array` (elementwise differentiation), and `permutedims` (axis permutation). |
| `array/mutable_ndim_array.py` | Defines the `MutableNDimArray` base class that serves as the mixin for mutable N-dimensional arrays. |
