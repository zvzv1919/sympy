# sympy/tensor — Catalog

> Part of [SymPy](../catalog.md). Tensor algebra: indexed objects, index conventions, and multi-dimensional array operations.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package initializer; exports `IndexedBase`, `Idx`, `Indexed`, index-method helpers, and all N-dim array classes and operations. |
| `indexed.py` | Defines `IndexedBase`, `Indexed`, and `Idx` classes for representing indexed objects (e.g. matrix elements `M[i, j]`) with optional shape and range information. |
| `index_methods.py` | Provides purely symbolic/structural analysis functions for `IndexedBase`/`Indexed` expressions only (not abstract tensor algebra classes like `TensMul`/`TensAdd`): `get_indices` determines free and dummy indices, and `get_contraction_structure` maps out implicit summation patterns (does not perform numerical contractions). Does NOT handle index-label generation, dummy-name collision avoidance, or equality comparison for abstract tensors — for all of those see `TIDS.get_indices` and `TensMul.equals` in `tensor.py`. For extracting ordered multiplication chains, closed loops (traces), and transposition constraints from contracted abstract tensor components, see `get_lines` in `tensor.py`. |
| `tensor.py` | Implements tensors with abstract index notation (Penrose formalism), including tensor index types, symmetries, canonicalization via the Butler-Portugal algorithm, and Einstein summation. Core classes: `TensMul` (tensor products) with arithmetic operations (multiply, divide — division by a tensor raises `ValueError`) and an `equals` method that canonicalizes both operands via `canon_bp()` then compares structured tuples of (coefficient, components, sorted free indices, sorted dummy indices) — when comparing against a non-tensor scalar (not zero) it asserts the product has no tensor components before doing a plain coefficient comparison; `TensAdd` (tensor sums) with equality comparison that short-circuits when the other operand has a zero scalar coefficient; and `TIDS` (tensor-index data structure) whose `get_indices` method reconstructs the full index list for multi-component expressions, generating fresh dummy-index labels while scanning existing free indices to start the counter above any that follow the same naming convention (avoiding name collisions), and whose `mul` method detects matching covariant/contravariant index pairs across two operands for automatic dummy-index contraction and raises `ValueError` if two same-variance indices are mistakenly paired. Also handles numerical component data via a lazy-evaluation layer that: attaches numpy arrays to tensor heads; when multiplying two multi-indexed quantities, identifies matching covariant/contravariant index pairs across their free-index lists and delegates the axis-wise summation to `numpy.tensordot` (Einstein-summation-style contraction on raw ndarrays — distinct from the symbolic `tensorcontraction` in `array/arrayop.py` which operates on `NDimArray` objects); computes scalar magnitudes by contracting component arrays with associated bilinear-form (metric) data; and supports exponentiation of tensors with numeric components via iterative metric contraction and root extraction. Also provides `get_lines`, which extracts ordered multiplication chains (lines), closed loops (traces), and remaining elements from contracted multi-component tensor expressions by following dummy-index pairs of a given index type through components; an inner helper merges chain segments sharing endpoints, raises `ValueError` if a component carries more than two indices of the requested type, and raises `NotImplementedError` when contracted pairs occupy the same relative slot position (which would require a transposition flag) — this is distinct from `get_contraction_structure` in `index_methods.py`, which maps out implicit-summation patterns for `IndexedBase`/`Indexed` expressions only. Additionally, `TensExpr` provides a `get_matrix` method that converts rank-1 or rank-2 tensor component data into a SymPy `Matrix`, raising `NotImplementedError` ("missing multidimensional reduction to matrix") for tensors with rank > 2 — this is separate from the `tomatrix` method on `NDimArray` subclasses in `array/`. Note: this module is for *abstract* tensor algebra — for numeric N-dimensional array operations see `array/` subpackage; for symbolic index analysis of `IndexedBase` expressions see `index_methods.py`. |
| `array/__init__.py` | Package initializer for the N-dim array submodule; exports dense/sparse and mutable/immutable array classes along with `tensorproduct`, `tensorcontraction`, `derive_by_array`, and `permutedims`. |
| `array/ndim_array.py` | Defines the `NDimArray` base class with common functionality for numeric N-dimensional arrays such as indexing, shape handling, arithmetic (including element-wise division), and conversion utilities. This is for concrete numeric arrays — for abstract tensor algebra division/arithmetic see `TensMul` in `tensor.py`. |
| `array/dense_ndim_array.py` | Implements `ImmutableDenseNDimArray` and `MutableDenseNDimArray`, which store all elements in a flat list for dense N-dimensional array representations. |
| `array/sparse_ndim_array.py` | Implements `ImmutableSparseNDimArray` and `MutableSparseNDimArray`, which store only non-zero elements via a dictionary-backed sparse representation. Includes `tomatrix` for converting rank-2 arrays to `SparseMatrix` (raises `ValueError` for rank ≠ 2) — for converting abstract tensor expressions to `Matrix` see `TensExpr.get_matrix` in `tensor.py`. |
| `array/arrayop.py` | Provides numeric array-level operations: `tensorproduct`, `tensorcontraction` (symbolic contraction over specified axis pairs of `NDimArray` objects using itertools), `derive_by_array` (elementwise differentiation), and `permutedims` (axis permutation). These operate on `NDimArray` objects — for numpy-based Einstein-summation contraction on raw ndarrays during abstract tensor multiplication see `tensor.py`; for abstract tensor product/sum algebra and equality comparison see `TensMul`/`TensAdd` in `tensor.py`. |
| `array/mutable_ndim_array.py` | Defines the `MutableNDimArray` base class that serves as the mixin for mutable N-dimensional arrays. |
