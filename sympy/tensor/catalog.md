# sympy/tensor — Catalog

> Part of [SymPy](../catalog.md). Tensor algebra: indexed objects, index conventions, and multi-dimensional array operations.

## Python Files

| File | Summary |
|------|---------|
| `__init__.py` | Package initializer; exports `IndexedBase`, `Idx`, `Indexed`, index-method helpers, and all N-dim array classes and operations. |
| `indexed.py` | Defines `IndexedBase`, `Indexed`, and `Idx` for representing simple component-level indexed objects (e.g. matrix elements `M[i, j]`) with optional shape and range information. `Idx` is a plain integer subscript for array element access with optional lower/upper bounds — it does not support abstract tensor index notation, covariant/contravariant distinction, auto-generated dummy names, or tensor symmetry (for those, see `TensorIndex` and `tensor_indices` in `tensor.py`). |
| `index_methods.py` | Provides functions for analyzing indices of `Indexed`-based (not abstract tensor) expressions: `get_indices` dispatches to expression-type-specific handlers to determine free/dummy indices; `get_contraction_structure` returns a nested dictionary describing the hierarchical summation structure of an expression — keys are tuples of repeated (dummy) indices mapping to sets of terms sharing those summations, `None` keys collect non-contracted terms, and when a product (or power) contains factors that are themselves contracted, the product expression appears as a key mapping to a list of recursively obtained dictionaries representing the deeper internal contractions. This nested-dict design captures multiple levels of index summation so that innermost contractions can be evaluated first. |
| `tensor.py` | Implements tensors with abstract index notation (Penrose formalism), separate from the `Indexed`/`IndexedBase` system. Key index classes: `TensorIndexType` (defines a type of tensor index, e.g. Lorentz); `TensorIndex` (represents a single tensor index — accepts a name string, Symbol, or `True` to auto-generate a dummy name like `_i0`; tracks covariant/contravariant via `is_up`); `tensor_indices` (helper that creates `TensorIndex` objects from a comma-separated string of names — returns a single `TensorIndex` when only one name is given, or a list for multiple names). Core expression classes: `TIDS` (internal data structure pairing contracted indices); `TensExpr` (base for tensor expressions); `TensorHead` (the 'head' of a tensor expression — constructed with a name that must be a string or Symbol, validated in `__new__`; carries index types, symmetry, rank, and commutativity); `TensMul`/`TensAdd` (products and sums). Also covers symmetries (`TensorSymmetry`), canonicalization via Butler-Portugal, Einstein summation, and index replacement. |
| `array/__init__.py` | Package initializer and primary documentation entry point for the N-dim array submodule. Contains the module-level docstring that serves as a tutorial explaining array construction, slicing, element-wise differentiation (`.diff`), tensor products, index contraction (including divergence-like summation over matching indices), and conversion to matrices/lists. Also exports dense/sparse and mutable/immutable array classes along with `tensorproduct`, `tensorcontraction`, `derive_by_array`, and `permutedims`. |
| `array/ndim_array.py` | Defines the `NDimArray` base class with common functionality for N-dimensional arrays such as element access, shape validation, arithmetic, and transpose. Handles parsing of creation inputs (flat lists with shape tuples, nested lists, Matrix instances) into internal flat storage. Operates on concrete numeric arrays, not abstract indexed tensor expressions or subscript bound defaults (for those, see `indexed.py` and `tensor.py`). |
| `array/dense_ndim_array.py` | Implements `ImmutableDenseNDimArray` and `MutableDenseNDimArray`, which store all elements in a flat list for dense N-dimensional array representations. |
| `array/sparse_ndim_array.py` | Implements `ImmutableSparseNDimArray` and `MutableSparseNDimArray`, which store only non-zero elements via a dictionary-backed sparse representation. |
| `array/arrayop.py` | Provides array-level operations: `tensorproduct`, `tensorcontraction`, `derive_by_array` (elementwise differentiation), and `permutedims` (axis permutation). |
| `array/mutable_ndim_array.py` | Defines the `MutableNDimArray` base class that serves as the mixin for mutable N-dimensional arrays. |
